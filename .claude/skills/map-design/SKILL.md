# 红警战役地图的设计语言

用户 2026-11-22："游戏地图是为了玩法和游戏体验服务的，不是为了拟真服务的"；"抄他们的设计语言和设计思路，追求神似而不是形似，因为我们之后总会遇到原版没有参照的新地图"。11-25："skill重点不在数字测量，在于有没有学到原版的设计语言"；"剧本再好，也要玩家实际能体会到才有用"。

所以这里不记"某张图长什么样"，记两件事：**这一关的玩法要地形怎么摆才发生**（第一节），和**每个摆法想让玩家感到什么**（第二节）。量出来的数字在附录 [city.md](city.md)，只作白盒旁证。

## 一、先把玩法翻成空间关系，再画图

玩家只能通过地图体会到玩法。一条规则如果在地图上没有一个"它起作用的地方"，玩家就碰不到它，剧本写得再好也白写。

**画图的人拿到的应该是一张创意卡，不是流程稿**：一句话的戏、让这关好玩的那个点子、一两条核心规则、硬约束（比如"纯渗透、没有基地"）。别的都别给。规则和流程写得越细，画出来越死板，只会照着摆（11-23 试画：给完整剧本的两组照方框摆，只给一句话的那组最像红警；11-25 用户："我们不需要一个完整的流程稿，我们需要的是有趣的创意"）。下面的空间关系是**画的人自己边想边发明的**，不是别人事先填好交给他的；流程从画出来的图里长出来。

**做法**：边画边问，这个点子里的每条规则、每个动作（抢、炸、守、潜入、救、撤）：
- 它在哪里起作用；
- 地图必须怎么摆，玩家才会**碰到它、要为它做选择、看得见它的回报或代价**。

写下来的是**空间关系**，不是地物。常用的几种：
- **射程或视野罩住一条路**："那段石头的射程罩着去第二座电站的路"，翻过来就成了护送。
- **A 在 B 的射程或路边**："拿下的电站在敌人援兵路边、背对你推进的方向"，守还是推才是真取舍。
- **两处方向不同**："两处可救的人不在一条路上"，先救一处，另一处就得绕。
- **远近不同决定顺序**："内圈电站的进路只有两段外圈都归你时才不挨打"，顺序由地形给，不靠脚本锁门。
- **最好的位置旁边有代价**："光棱最好的射击位紧挨着藏幻影的树林"。
- **状态一变，哪里变安全、哪里变危险**："整阵掉头时，停在石头边的单位最先挨打"。

画完回头对一遍：**图上每样东西都要说得出它让哪条规则、哪个动作起作用**。只能说出"服务感受 2"、指不到任何一行的，多半是在填空，删掉或想清楚它到底让哪条规则起作用。真实地形最后才上，当皮（第三节）。

**坏了是什么样**（11-25 A6 盲画 v1，用户："地图和玩法几乎是各讲各的"）：二十来样东西每样都挂着"感受 1 / 2 / 3"，说得通，但这关的两条规则（谁供电替谁打、相连传能）在图上只剩"石阵射程圈是禁区"一句；哪座电站在哪段石头射程里、拿下打到谁、丢了打到谁，图上全没有。另一半布局是七样真实地物定的。

**先看清这一关是哪种关**，别拼两种：渗透关（小队、打一个少一个、路窄、有巡逻节奏、有暗处）和建基地的关（宽、要矿、要摆兵）对地图的要求相反，同一张图撑两种尺度，两种都做不好（A6 v1 草稿中途送基地车，用户："渗透任务为什么会有后方基地？"）。真要两段，就把它们做成两块空间、各按各的规矩。

## 二、红警地图要玩家感到的五件事

第一节的关系表画完后，拿这五件逐条检查：缺了哪件、哪件被做坏了。它们是**检查**，不是摆东西的理由。

### 1. "路是我自己选的"
- **意图**：策划心里有主攻方向和几条好路，但不说出来。玩家看地图、试探、吃亏，然后自己找到路；找到了会觉得是自己聪明。
- **怎么做**：路是一张网，任意两点之间都有好几种走法。主次靠街区大小、楼的疏密、开阔与否自然分出来，而不是靠地形把其他路堵死。真正的硬隔断只给水和桥，数量也少，并且通常不止一座桥。野外靠长崖或山脊把空间分成几个"房间"，每道崖留三到五个缺口；崖可以长，房间里的路要多。
- **几条路**：建基地的关，从立足点到心脏要能画出三条打法不同的路。渗透关和英雄关按 `docs/design/principles.md` P19：一到两条主路，备选路要想一想才找得到或付代价才打开。两条不矛盾，说的是两种关。
- **坏了是什么样**：整张图从敌人到玩家只剩一两条明摆的路，玩家一眼就看穿，不用思考，也很出戏。A1 第一版草图就是这样：基地只有两个坡口，要塞单独抬成一块台地。反过来也坏：怕崖线挡路就只撒几块小岩石包，野外没有走廊和房间，哪里都能走，也就没有选择（11-23 评审：A2 胡佛水坝那版）。
- **例子**：`all03u`、`sov08u` 华盛顿的棋盘街；`sov02smd` 雪原上交错的土路；`all06u`、`sov03umd` 用好几座桥连起来的河网。

### 2. "到处都在打，我顾不过来"
- **意图**：要的是压力和混乱感，像一场活的战争，而不是一条排好队的进攻线。
- **怎么做**：敌人分成一个主基地加几个大小不一的前哨，散在通往主基地的路上。进攻从敌方那半边的好几个口子轮流来。另外还有"意外的来路"：海上登陆或炮击、空投、两栖从侧后方插进来。中立的可驻军楼让敌我都能抢，前线就会一直挪动。
- **按关调量**：喘息关（难度低、接在高压关后面）来路少一两个、一次来的少；渗透关的压力是巡逻和追兵，不是轮番进攻。
- **坏了是什么样**：敌人只从一个方向、沿一条路来；或者来路全画在图上，玩家早早就把它守死了。
- **例子**：`sov07tmd` 三座尤里基地并排；`sov11s` 雪地里散着带围墙的电塔点；`all11t`、`all07t` 的海上队伍；`all05umd` 港口里的尤里潜艇。

### 3. "不用看小地图也知道往哪打"
- **意图**：路是隐含的，方向却必须清楚。玩家可以在路上犹豫，但不能迷路。
- **怎么做**：
  - 每张图有一个远远就能认出来的地标，并且把它和目标绑在一起：敌人盘踞在它旁边，或者把它改造成了武器。比如埃菲尔铁塔、金字塔、华盛顿纪念碑、恶魔岛上的心灵控制器。
  - 玩家从边角的一小块立足点出发，敌人在对角或中央，推进方向就是这条对角线。
  - 敌人的据点是城里被围墙圈住的一个街区，地势不抬高。玩家从街巷一路打到墙根，攻坚的节奏是破墙，不是爬坡。
- **地标会换边时**（中立的武器、关中途翻转）：每个状态各画一张功能图（或一张图上标出各阶段的安全区），游戏里要让玩家一眼看出"这一段现在归谁"（颜色、灯光、开火方向）。翻转本身就该是关的段落：哪一刻翻、翻完哪里变安全。
- **坏了是什么样**：地标只是摆着好看，和目标无关；或者据点被做成一块独立的地形，在图上像一座孤岛，场景很单调。
- **例子**：`sov05u` 的铁塔；`all04dmd` 被围起来的金字塔；`all12s`、`sov11s` 克里姆林宫的红墙；`sov01t` 五角大楼外的几圈围墙；尤里的复仇第一关里，盟军基地在城里只用一圈铁丝网和大门围着。

### 4. "这里本来有人住"
- **意图**：可信的世界让人愿意探索，探索也要有回报。
- **怎么做**：城里塞满民房、商店、停车场、车辆、路灯，空地很少，楼大多能进驻。城市不是方格纸：街会错位、拐弯、被斜街切开，街块大小不一，中间夹着广场、公园、停车场、球场、教堂院子，这些是认路的参照，也是交火的舞台。野外也有人住：村子、农场、加油站、灯塔、矿场、铁路和车站、输电线、水泵房。民房聚成村子，沿着路和河成串，村子之间才是真正的空地；空地留给交战，要有树林、岩石、小屋当掩体和视线遮挡。水面要有用处：目标所在、海军来路或者远景。岸线分沙滩（两栖能上岸）和堤岸、崖岸、码头（不能上岸或只能靠船），敌人的登陆点就是图上画出来的那几段。城区的具体做法见 [city.md](city.md)。
- **坏了是什么样**：一大片空地或空海；照搬真实地理，结果大半张图只是背景（A1 旧图大半面积给了海峡）。另一种是整齐划一的方格街区，玩家分不清这条街和那条街；野外图只放几块台地，中间全是土黄色。
- **例子**：城区图的中立建筑通常有上百个，敌方建筑才十几个；`all02s` 的雪地小镇；`sov11s` 的农场。

### 5. "一路在往前走"
- **意图**：节奏是递进的。每拔掉一个点都是一个小胜利，地图本身就排好了关卡的段落。
- **怎么做**：开局在安全角落站稳；中间是一串可以挑顺序去拔的前哨；最后是地标所在的据点。不对称是故意的，敌我的面积、资源、出路都不对等。
- **高潮在中间、最后要逃时**：撤离点放在追兵来路的另一侧或侧面，让最后一段是穿过去、冲出去，不是掉头沿来路往回跑（A6 v1 的结尾被自己评成"一眼看穿"）。
- **坏了是什么样**：多人对战式的对称布局；或者中段什么都没有，只能一路平推过去。

## 三、没有原型时怎么想

照下面的顺序过一遍，每一步都问"玩家会碰到什么、感到什么"：

1. **这一关的创意卡**：一句话的戏、好玩的那个点子、一两条核心规则、硬约束。**不看流程稿和剧本示意图**（照方框摆就成了填表）。先认清是哪种关（第一节末）。
2. **让点子在地形上长出来**（第一节）：这个点子最好玩的那一刻发生在哪、地形怎么摆才让它发生；再往前往后推出其他时刻。点子撑不起一张图，说明点子还不够，回去换点子，别靠补规则撑。
3. **定三个点**：立足点放在角上；敌人的心脏和地标放在对角或深处（或者地标本身就是那个会翻转的机关，见第二节第 3 件）；把剧情最重要的那个画面绑在地标上。
4. **定少数硬隔断**：先问一句"这里非要隔开吗"。城里用水、河、桥；野外没有崖时，用土堤、树篱、林子、河，或者**武器的射程本身当墙**（一圈射程就是一圈禁区）。每道隔断都给替代的过法。土堤、树篱、树林在红警3 里挡不挡步兵和坦克，没验过之前别把关押在上面。
5. **织路网**：按第二节第 1 件的条数。主路宽、开阔、好走，但被盯着；侧路窄、有遮挡，便于偷袭。
6. **放压力源**：主基地加几个前哨，每个前哨回答"它为什么在这里"（守桥、守电站、护地标）；再加一两条意外来路。按第二节第 2 件调量。
7. **放资源和诱饵**：建基地的关一定要画矿，矿决定仗在哪里打起来：家门口一块，其余放在敌我之间。渗透关的"资源"是能救的人、能偷的车、能占的建筑，按同样的道理放在逼玩家做选择的地方。
8. **上皮、填生活**：这时才挑真实地形（第四节），把它套在关系表要的形状上；再按第二节第 4 件填满。
9. **走一遍**：假装自己是第一次玩的老玩家，从开局走到结尾。问：哪里会犹豫？哪里一眼看穿？哪里会被意外偷袭？哪里走着走着无事可做？**每条规则是在哪一步第一次碰到的？**碰不到的规则就是地图和玩法脱节了。
10. **删**：一张图只有一个招牌机制。把地形本身挡住不看图例，还能读出这张图讲什么吗？图例超过十来项就删。删的是机制和标注，不是地上的东西：村子、树林、岩石照样要满。长崖画成连着的长线、中间留缺口。玩家不能进的地方用水、崖或墙这样的地形挡住，不能用一条线切开。

**剧本的要求和这份意图冲突时**（比如剧本要控制室坐在只有一条坡道的高台上）：剧本要的玩法优先，但别让玩家一眼看穿。可以让那条显眼的路是陷阱或者最贵的路，再给一到两条要想一想才找得到的过法（船闸升起来当梯子、炸开一段墙，挑一样），或者在高台周围铺上街区和前哨。别把替代过法全叠上去（11-23 评审：A5 那版十来个坡口加三个跳点，中段成了攀岩）。高差也一样，野外最多一层台地配三四个坡口。办不到就在说明里写出来，交给用户定。

**夜里**：红警3 的夜有没有视野上的效果还没验过。验过之前，别把"暗处能走、亮处被盯"当成一层设计；夜只是气氛。

## 四、真实地形是皮，不是底图

红警的关几乎都发生在真实地点：旧金山、华盛顿、巴黎、开罗。玩家一眼认得出来，这是代入感的一大半。但**顺序是先有关系表，再找能撑起它的真实地物**，不是先列地物再给它们找用处（A6 v1 先列了七样索尔兹伯里地物，一半布局就被它们定了）。
- **从关系表找地物**：表里要一道隔断，就看那里有没有河、堤、沟；要一条意外来路，就看有没有码头、机场、铁路；要一个高处，就看有没有山、塔、坟岗。找不到就按玩法造，不硬套。
- **保住认得出的构图**：几样标志性的东西摆在大致对的相对位置上（桥在哪个角、岛在哪片水），玩家就认得出这是哪里。
- **其余全部重排**：比例、街道、距离、面积都按玩法来定；对玩法没用的部分（大片海、郊区、空地）压缩或删掉。
- 例子：恶魔岛（隔水的岛 → 据点和最后目标）；波托马克河（隔开五角大楼和城区 → 几座桥上的争夺）；金门大桥（城市一角 → 出口、终点或背景）。

A1 旧图错在把真实地理整张搬了过来；第一版草图又错在只留下了"台地"这个抽象概念，旧金山的味道没了。两头都不对。

## 五、从草图到白盒，设计别丢在路上（11-23 A1 v8→v16 踩出来的）

A1 从 v13 起按游戏坐标画，每一轮都在修比例，数一项项进了原版范围，图却越来越像施工图，草图里"老城密、公园开阔、三条路各有各的打法"的味道淡了。**数字只说明落得下，不说明意图还在。**
- **草图是设计的正本，白盒是它的译本。** 对不上时先问是翻译走了样，还是设计本身要改。设计要改就回草图上改，再重新落地。
- **落白盒前，把第一节的关系表当验收**：每一轮都对照，哪条还在、哪条淡了，写进这一轮的记录。
- **白盒工具会把不规则抹平**：弯街、碎轮廓、碎边草地、曲折岸线都会变整齐；不规则要刻意留。
- **每块地写清它是什么、为什么这样**：写得出名字和用途的地，意图才留得下。
- **比较看缩略图，不只看数**：草图、上一轮白盒、这一轮白盒并排，先用眼睛判断像不像红警，再看数。
- **落地后用跑出来的仗验，不用进游戏**：赛跑或进攻路线（`experimental/mappage/attack_routes.py`：算敌方每个出兵点和玩家到每个目标的路程）。A1 v17 看着对，第一次跑就查出码头接不上陆地、前进兵营放在正中让苏军离五座电站都更近。图像原版不等于仗会按设计打。城区的驻军覆盖等量法见 [city.md](city.md)。

## 六、怎么从一张参照图里提炼思路

原版关是学语言的教材，不是每关的拐杖：设计一关时从这份语言出发，只在答不上来时回去看原版，学到的补进这里。看任何一张图都按这个顺序问：
1. 这关的规则和动作各在图上哪里起作用？
2. 玩家在哪站稳？第一眼看见什么？
3. 敌人的心脏在哪？靠什么认出来？
4. 哪些地方是真隔断？各有几种过法？
5. 主次路靠什么分出来？
6. 压力从哪几个方向来？有没有意外来路？
7. 中间那片地放了什么诱饵？
8. 这张图想让玩家感到第二节五件里的哪一件？哪个摆法最能做到？

只把第 1 和第 8 问的答案带走，形状留下。

## 七、注意
