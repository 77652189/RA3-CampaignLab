## 明确不做

- **AI 直接生成网格当成品**：形状对但表面软、细节丢（CampNew24 对比），见 [ADR 0002](adr/0002-ai-concept-hand-built-model.md)。
- **按"被冰冻"状态扩大索敌视野**：ObjectVisionRange 的过滤不检查状态，会把所有敌人都当目标去追，见 [ADR 0004](adr/0004-no-status-filtered-vision.md)。
- **旧版 1.10 SDK 编单位**：GameObject 布局旧，激活后随机堆损坏，见 [ADR 0001](adr/0001-sdk-v3-only.md)。
- **解密 Corona mod**：用户要求不做。
