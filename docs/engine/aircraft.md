# 飞机：飞行、对空、对地

引擎线 A 第 88 轮（2026-11-08），ADR 0022 第 ⑤ 项。**测** = 测试台读数；**推断** = 没上测试台。探针 `cnv_check engine_air <变体>`（任务 `missions/air_bench.py`，探针图 `maps/probe_air.py`：一块平地、一条海沟、一道 115 高的悬崖），读数写在 `experimental/cnv/checks/engine_air.py` 的文档串里。模拟器对拍在 `tests/test_simbench.py` 的 "air" 一段。飞起来的建筑和平台另见 `air.md`。

## 0. 结论：给关卡线抄的

| 问题 | 答案 | 状态 |
| --- | --- | --- |
| 飞机绕不绕地形 | 不绕：直线飞，平地、海、悬崖上空用时一模一样 | 测 |
| 飞多快 | 就是 XML 的 `Speed`（双刃 150），起步约 0.5 秒加速 | 测 |
| 防空打多远 | 武器射程 + 两边的外接圆半径，按**平面**量；飞行高度（双刃 130）不算 | 测 |
| 没有对空武器的单位打不打飞机 | 不打（守护者坦克在双刃下面 100 处，20 秒一枪没开） | 测 |
| 直升机打地面目标停在哪 | 停在射程 + 两边半径处开火，不飞到头顶 | 测 |
| 地图上直接摆的直升机 | **停在地上，不算空中目标**，防空不打；下一次移动命令才起飞。摆的基洛夫却是飘着的（`air.md` 第 1 节），哪个字段决定的没查 | 测 |

## 1. 读数

- **飞行**（`fly_flat` / `fly_sea` / `fly_cliff`）：双刃从西头飞 1200 到东头，三条航线都是 114 帧进终点方框，中途方框都在第 4、5 秒经过。1100 / 150 = 7.33 秒，多出的约 0.5 秒是起步加速。
- **防空炮**（射程 300，只打空中，要电）：中心距 280、320 都被打掉，370 不打。320 离中心已超过 300，但减去两边半径（约 40）只有 279，在射程内；如果把 130 的飞行高度算进去就够不着了。所以是平面、边到边。
- **防空步兵**（`SovietAntiVehicleInfantry`）：对空武器 `SovietAntiVehicleFlakLauncher_Aircraft` 射程 300，写成继承对地那门（`inheritFrom`），只改了射程和对空掩码。280、312 站着就打；354 在双方全图可见时**走过去追着打**，比 R8 量到的"视野 + 目标半径"远得多（那次没开全图），开全图后自动索敌的范围怎么定没查。
- **对地**：双刃攻击 600 外的守护者坦克，第 3 秒进 300 圈、第 4 秒进 200 圈、从没进 100 圈；第 4 秒开始掉血，机炮每秒约 1，第 8、9、17 秒各一轮导弹（-17～-27），第 18 秒剩 5。

## 2. 模拟器里的样子

- 飞机走直线（`Ground.route` 对 air 不看地形），速度取 XML，没有加速（比测试台早约 8 帧到）。
- 武器按目标挑：打飞机要 `ANTI_AIRBORNE*`，射程边到边、平面。
- 武器模板的 `inheritFrom` 现在会继承父模板没写的项（伤害、弹夹、射速、掩码、弹头）。原来防空步兵对空那门读成 0 伤害、从不打飞机。全部 111 条带继承的武器都受影响。
- 敌方玩家的 `MAP_REVEAL_ALL` 现在只让那一方看见全图，不再算成玩家揭图。
- 防空步兵掉血比测试台快约三成（模拟器 18 秒打死，测试台 24 秒剩 4），对地也是匀速而不是一轮一轮的，只对准到秒级。

## 3. 没测的

- 起降、回机场装弹（阿波罗、米格、世纪轰炸机这类不能悬停的飞机）：现有关卡没用到，没测。
- 飞机的视野和高地（飞机看高处、地面单位看飞机）：模拟器按"飞的一方不受高地遮挡"写，没上测试台。
- 地图摆的直升机落地状态：模拟器没有，摆下就当飞着。
- 开全图后的自动索敌范围（防空步兵 354 外走过去追）：strict xfail。
