# 遭遇战 AI 的三个脚本开关

我们的关卡在敌方 AI 醒来时都发这三个动作（`plan.py` 的 `敌方AI`：优先级 20、修理和重建默认"否"=0）。这里写它们在原版里实际管什么，给关卡线和模拟器用。

测试台探针：`experimental/cnv/missions/aiswitch_bench.py` + `checks/engine_aiswitch.py`（地图、AI 和玩家建筑同 `aitarget_bench`）；模拟器对拍在 `tests/test_simai.py` 末尾。

## 1. SKIRMISH_AI_SET_ALL_ENEMY_PLAYERS_PRIORITIES（玩家, n）

- 程序：清空 AI 的"敌方玩家表"，n ≠ 0 就把当时所有敌人以同一分数重新填进去（一档，不分先后），之后不再按人格的 EnemySorting 周期重排。n < 0 当 0。**n 的大小没有意义**，20 和 1 一样。
- **测**（aisw0near）：传 0 后，靠"最近的敌方建筑"找目标的进攻队 75 秒一个都不出门（对照 aitargetnear 传 20 时 s13 就到了近处电厂）。
- **测**（aisw0far）：传 0 后，按名字找的目标（NamedObject，原版战役 AI 的主要用法）照样去打：s15 到远处电厂，电厂倒后 RAMPAGE 去打近处的。也就是说传 0 只挡住"按敌方玩家挑"的启发，挡不住点名目标和 RAMPAGE。
- 给关卡：只有一个敌方玩家（玩家本人）时，传 20 和不传结果一样；想让 AI 暂时"不主动找玩家打"，传 0 有效，但点名目标仍会去。
- 没测：调用之后才变成敌人的玩家不会补进表（程序推断，没上台）。

## 1b. SKIRMISH_AI_SET_ENEMY_PLAYER_PRIORITY（玩家, 敌方玩家, n）（原版 343 次，多是开局一个敌人一行）

- 程序：同一张敌方玩家表，只改点到的那一个：关掉周期重排，先把这个玩家从表里删掉，n > 0 就以分数 n 放回去（不查他是不是"敌人列表"里的人）。表按分数分档，AI 先只在最高档里找目标。n ≤ 0 = 从表里拿掉。
- **测**（探针 `missions/aiprio_bench.py` + `checks/engine_aiprio.py`，地图同 `aitarget_bench`，近处电厂和两座炮塔改归 Soviet_4，开局脚本设成和 Soviet_1 互敌）：
  - aiprio1：Soviet_4 30、玩家 10（不调全体版）→ s14 到 Soviet_4 的近厂，从没去玩家的远厂。分档生效。
  - aiprio0：全体版 20 后再把玩家设 0 → s15 去近厂，从没去远厂。0 = 拿掉。
  - aipriorm：只把 Soviet_4 设 0（不调全体版）→ 75 秒没人出门：醒来时表还是空的，**没点到的敌人（这里是玩家本人）不在表里**。
  - aipriodef（对照，只调全体版 20）：先去玩家的远厂（s25），远厂倒了才 RAMPAGE 去近厂。两个敌人同一档时游戏挑了远的，模拟器挑近的——原因没读到（`tests/test_simai.py` 严格 xfail）。
- 给关卡：用这个动作就要**把每个想让 AI 打的敌人都写一行**（或先调全体版再改），漏掉的那个 AI 不会主动找他打（点名目标和 RAMPAGE 不受影响）。

## 2. SKIRMISH_AI_USE_REPAIRS（玩家, 开关）

- 程序：写 AI 的修理总闸；真正修理还要人格的 RepairBuildingsAtDifficulty 含当前难度、另一个内部字节为 0。战役里总闸默认关（推断）。
- **测**（aiswrep1 / aiswrep0）：AI 自己的半血电厂，传 1 后 60 秒、传 0 后 95 秒都停在 50%，没修。传 1 为什么也不修没定（当时 AI 钱为 0？另一道闸？），模拟器按"不修"做。
- **最可能的原因（读程序，没上台，11-10）**：AI 开始修理时不查钱，但修理是边扣钱边回血——这一帧该扣的钱玩家拿不出就这一帧不回血，也不停修。aiswrep1 的 AI 钱是 0，所以看上去"开了也不修"。要定：同一探针给 AI 几百块钱再跑一次（预测半血电厂约 +10 血/秒、−2 钱/秒、约 50 秒修满），配一条"钱 0"对照（预测血不涨）。归物体模块线（RepairUpdate）的台上做。
- 给关卡：写 `修理: 否`（默认）时 AI 不修建筑，这一点台上看到了；写 `是` 能不能让它修，还没在台上看到，别指望。

## 3. SKIRMISH_AI_USE_REBUILD_SYSTEM（玩家, 开关）

- 程序：开关值没变就什么都不做；变开时给自己的建筑拍一份位置清单，变关时清空。谁按这份清单去重盖没读到。
- **测**（aiswreb1 / aiswreb0）：醒来给 5000 钱，5 秒后炸掉 AI 自己的电厂；开或关，之后 105 秒都没再盖电厂。
- 给关卡：写 `重建: 否`（默认）时被毁的建筑不会被重盖，台上看到了；`是` 在这个短时间里也没看到重盖，别指望它补楼。

## 模拟器怎么做

`sim.py` 把三个动作按玩家记进 `Sim.ai_switches`；`simai.Brain.switches` 每帧把变化转成命令交给 AI 模型：优先级定下敌方玩家表（空表 = 没有可打的敌方玩家），修理和重建只记开关，不修、不重盖。单个玩家的优先级按调用顺序记进 `Sim.ai_priorities`，模型的表是 {玩家: 分数}，按分数分档（RA3-EngineModel `AIPlayer.set_enemy_priority`、`targets.table_tiers`）。
