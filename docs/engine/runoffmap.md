# 开出地图外：PLAYER_SET_ALL_UNITS_TO_FLEE 让谁跑、往哪跑、到了怎么消失、半路能不能叫停

引擎线 B 第 4 轮（2026-11-06），ADR 0019 第二层。写法照 `script-semantics.md`：**测** = 测试台；**推断，未实测** = 只从资料推出来；**对不上** = 测试台和模型不一致（本轮没有）。

探针 `experimental/cnv/checks/engine_runoffmap.py`（`cnv_check engine_runoffmap a` 到 `d`）。尼亚加拉图玩家基地摆建造场，西边草地放一个盟军维和步兵（朝 +x；步兵基类带 RunOffMapBehavior，路点名 `RunOffMap`）。任务第 1 秒（Test Go）对玩家发 `PLAYER_SET_ALL_UNITS_TO_FLEE`。四个计数器都从 Go 起**按帧累加**：帧数、逃帧（1 × 目标还在的帧 + 1000 × 目标带 FLEE_OFF_MAP 状态的帧）、死法（1 × 目标已被销毁的帧 + 1000 × 目标处于"正在死"的帧）、第四行（a、b、d：人在终点周围半边长 40 的区域里的帧；c：1 × 人还在的帧 + 1000 × 人带 FLEE_OFF_MAP 的帧）。运行 `work/testbench/runs/CampRunoffmapA_mcp_1106_035353` 到 `CampRunoffmapD_mcp_1106_040353`。

## 1. 谁会跑（测）

- 只有带 RunOffMapBehavior 的对象跑。原版步兵、车辆的基类都带；轰炸机、世纪运输机、卫星扫描道具也带（`FlyingOffMap`）；**建筑不带**。
- **没带的对象不受影响**（c：电厂不跑、不死）。这和动作说明"没有模块的单位忽略这条脚本"一致。程序里有一条"没有模块就杀死"的分支，可能是建筑根本不在被遍历的对象列表里（**推断，未实测**：哪种原因没分清）。
- 只管参数里那个玩家的对象。动作没有 TEAM / NAMED 版本，只有这一个。
- 模块的 `RequiresSpecificTrigger=false` 会让单位一造出来就跑（**推断，未实测**：原版没人这么写）。

## 2. 往哪跑、跑多久（测）

- 有名叫 `RunOffMapWaypointName`（原版是 `RunOffMap`）的路点，就去那个路点（a）。地图上有好几个同名路点时选哪个，没测。
- **没有这个路点，就朝自己当前朝向直走 1000**（b）。不会去最近的地图边。所以关卡想让敌人"撤出地图"，必须在地图边放一个 `RunOffMap` 路点，否则单位在图中间走 1000 就消失了。
- 下令当帧就开始走，按单位的移动速度（维和步兵 50/秒）。到点后 3 帧消失：200 远用 64 帧，1000 远用 304 帧。
- 一路带 FLEE_OFF_MAP 状态（`UNIT_HAS_OBJECT_STATUS` 能读，编号 54）。
- 走不到终点的地面单位会自杀（**推断，未实测**：程序里读到，台上没造这种场面）。`FlyingOffMap` 只是跳过"走不走得到"的检查。

## 3. 到了怎么消失（测）

- **无声删除，不是被打死**：`NAMED_DESTROYED` 变真，`NAMED_DYING` 从来不真（a、b）。不留尸体，不放死亡效果（**推断，未实测**：只看了脚本条件）。
- 下令时程序会把一次击杀记给这个单位最后的伤害来源（**推断，未实测**：读到调用，台上没测"被打过的单位逃跑后对方击杀数会不会加"）。

## 4. 半路能不能叫停（测）

- **能。后来的命令会接管**：d 在第 15 帧发 `NAMED_STOP`，人就停在原地，再也不消失。
- 但 FLEE_OFF_MAP 状态**一直挂着**。所以用这个状态判断"他是不是还在撤"是不准的。
- 其它移动类命令（MOVE、ATTACK、GUARD、HUNT……）同样会接管（**推断，未实测**：只测了 STOP）。
- 逃跑中会不会还手、是不是无敌，程序里没有相关代码，台上也没测。

## 给关卡的用法

- 让一方撤退：先在地图边放 `RunOffMap` 路点，再发 `PLAYER_SET_ALL_UNITS_TO_FLEE`。建筑不会跟着走，要另外 `PLAYER_SELL_EVERYTHING` 或删掉（原版东京港就是这么配的）。
- 撤退期间别再给那些单位下命令，否则他们会停在原地。
- "撤完了"用 `NAMED_DESTROYED` / 队伍消灭来判断；撤走的单位不会触发 `NAMED_DYING`。算不算玩家的击杀没测，见第 3 节。

## 对不上

本轮没有。模型 `runoffmap.py` 四个变体逐帧对上（进区域、消失的帧、状态、死法）。没建模的部分：寻路（模型走直线）、加速、飞行、DieOnMap（只读到它在两种移动命令之间二选一）。
