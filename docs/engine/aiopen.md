# 遭遇战 AI 的开局：先造什么、几秒出来

引擎线 B 第 6 轮（2026-11-06），ADR 0019 第四层（遭遇战 AI）第一块。写法照 `script-semantics.md`：**测** = 测试台；**推断，未实测** = 只从资料推出来。

探针 `experimental/cnv/checks/engine_aiopen.py`（`cnv_check aiopen a` / `b` / `c`，任务 `missions/aiopen_bench.py`）：尼亚加拉图，敌方改成盟军、人格 `1AlliedBalanced`（遭遇战的"平衡"沃伦），东基地只放一个建造厂；第 10 秒照原版关卡的写法唤醒（`UNIT_AI_TRANSFER_ALL`、`SKIRMISH_AI_MAKE_BASE` 等），给 50000 钱，让钱不成为限制。每秒数一次敌方自己的建筑和单位。

## 读数（测，唤醒后秒）

| 东西 | 出现时刻 |
| --- | --- |
| 兵营 | 10 |
| 电厂 | 20、70（开局之后又造：128、138） |
| 精炼厂 | 40、60（各带一辆采矿车，晚 4 秒：44、64） |
| 战车工厂 | 90 |
| 激流（地面型） | 102、114、122（开局之后又造：133、144） |
| 船坞 | 没造（陆路通，走的是陆地开局） |

## 结论（给关卡线）

- **AI 开局就是照 SDK 文件里的单子一项一项造**：`SkirmishAI/OpeningMoves/AlliedOpeningMoves.xml` 的 `AlliedStandard` 写的是兵营、电厂、精炼厂、精炼厂、电厂、战车工厂、3 辆激流，测试台的顺序一样。
- **钱够的时候，时间就是建造时间首尾相接**：一个建造厂一次只造一栋，盟军这 6 栋的建造时间是 10、10、20、20、10、20 秒，累加正好是 10、20、40、60、70、90。造兵在战车工厂里排队，跟建造厂并行。
- **所以要估"敌人几分钟能有坦克"，就把开局单子的建造时间加起来**：平衡沃伦第 90 秒才有战车工厂，第 100 秒左右第一辆车出门。我们自己写人格（`experimental/cnv/enemy_ai.py`）时，改开局单子就能直接改这个节奏。
- 开局走完以后（约 120 秒），预算从"开局专用"换成常态（造兵 85%），之后造什么由战略状态和队伍模板决定，不在这一块里。

## 没测的

- 钱不够时的样子（开局期间预算是 100% 存着，单子里的 `Deposit` 往造兵账户放钱，没测它怎么限制开局）。
- 别的难度（简单难度用 `AlliedStandard_EASY`）、别的阵营、海岛图（应该走 `AlliedIsland`，先造船坞）。
- 第二辆激流晚了约 2.6 秒（单子算 111 秒，测到 114 秒），原因没定：可能第一辆堵在门口。
