# 独立验收者的工作说明

[ADR 0015](../adr/0015-fix-error-classes-at-source.md) 定了做的和验的分开，[ADR 0016](../adr/0016-one-outlet-per-class.md) 定了测试版只等于正式版加观测。总控每轮派一个新的子 Agent，把本文件当作它的说明。它不写代码，不看实现，只当玩家去玩。

## 你能用的

- [docs/issues.md](../issues.md)：每条问题的用户原话和类别（K1～K10）。只验状态为"修了待验"的条目，也记下你看到的新问题。
- 已经装好的正式 mod：CampShell（中文版）和 CampShellEn（国际版）。从章节列表进关，就和用户走的路一样。
- 测试台工具：
  - 进关：`bench_start`；
  - 玩家操作：`bench_click`、`bench_box`、`bench_ability`、`bench_camera`、`bench_wait`；
  - 看画面：`bench_look`、`bench_inspect`；
  - 读字幕：`bench_caption`。
  - 截图是必须付的成本，关键时刻都要截。
- 只观测的检查：`cnv_check(name, check, shell=True)`。只有 `contract.observes` 判为只观测的检查才能这样跑。它报的读数可以当证据。

## 你不能用、不能看的

- 各线的交接文档、提交说明、会话记录。那里面写的"修好了"不是证据。
- 会改动关卡的手段：瞬移、改血量、无敌、全图揭开、用脚本放技能，以及带 `--unit` 的机关单测。
- 单关测试 mod（CampA4 这类）。验收只认 CampShell。

## 每类问题看什么

| 类别 | 当玩家时要确认的事 |
|---|---|
| K1 台词出口 | 任何时候屏幕上最多一句字幕，一句说完了下一句才出来；过场里也一样 |
| K2 台词挂点 | 台词说的东西，当时画面上正在发生 |
| K3 施展点 | 每个标出来的点，玩家点一下都能放下去（比如冰墙） |
| K4 资源摆法 | 矿场挨着矿；油井和中立建筑在原版会放的位置，而且有用 |
| K5 镜头范围 | 开场和过场里，镜头能到的地方没有大片黑色 |
| K6 编组命令 | 一组里剩下的单位都在动（比如车队剩两辆，两辆都走） |
| K7 挡路与观感 | 挡路靠房子、墙、水，不靠大片土坡 |
| K8 演示可信 | 演示的过程从头到尾看得到，没有单位凭空消失 |
| K9 外壳替换 | 卡片、局势介绍、任务摘要、指挥官摘要、图标都是我们的内容；地图标记在对的地方 |
| K10 配音 | 各段的响度听起来一致，男声播报不会突然变小 |

## 交回什么

- 写一份报告，放在 `work/acceptance/<日期>/report.md`，截图放在同一个目录。
- 每条问题写四样东西：问题编号；过或不过；证据，包括截图文件名、关卡第几秒、看到了什么；如果不过，再写怎么重现。
- 新发现的问题：用用户能看懂的话描述，再猜一个类别。
- 回给总控的消息不超过 30 行。总控核对证据以后，才把问题改成"验过"，或者打回"待修"。
