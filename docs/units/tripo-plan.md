# Tripo 建模清单（订阅到期前，2026-11-15）

用户 11-15："让策划线、单位线和关卡线协调，把需要用 tripo 建模的内容先确定下来，因为订阅应该是 20 号过期。"看过第一版（只做 7 个设计已定的）后，用户说："这样规划太保守了，相比于返工消耗积分，我认为让积分直接过期更亏一些。"
所以这一版的原则是：**能做成模型的都做，设计没定的照当前概念先做，不确定的多出一个结果留着挑。**
依据：[units.md](../story/units.md)（新单位设定）、[concept-cards.md](../story/concept-cards.md)（11-11 新概念）、[handoff.md](handoff.md)（已做的单位、Tripo 流程）、A3–A5 策划案（[plans/](../story/plans/)、[flow/](../design/flow/)）、总控交接里"两个 mod"的定法。

## 期限和成本

- 网页订阅积分 **2026-11-20 04:00（北京时间）作废**，本机时间约 **11-19 中午**。剩约 3025 积分。
- 道具（一整块）约 50 积分；车辆、带贴图、分部件约 80。下面 20 个模型约 1400；不确定的 8 个各多出一个结果约 500；合计约 1900，剩约 1100 留给 11-19 重做不满意的。
- 瓶颈是**用户的上传次数**：每个模型都要用户亲手把四张图拖进 Tripo 网页（内置浏览器没有上传文件的工具，见 handoff.md「Tripo 怎么用」）。20 个模型分 4 天，一天 5–7 个。
- 过期以后的退路：Tripo API（`tripo-cli` 已装好登录，全自动），价格约贵 3 倍，一个单位约 ¥3.5–4.2。

## 怎么判断

1. **原版有能借的 → 不用 Tripo**（先粗模，能借原版就借）。
2. **步兵、走路的机甲 → 这次不做**：Tripo 出静态网格，我们的接法（`tripo_unit.py`）只接刚体：车辆（车体 / 炮塔 / 炮管分开）、道具（一整块）、大平台。步兵和机甲要蒙皮骨骼动画，没有这一步的工具，做了也接不进游戏。
3. 其余的都做。设计已定的先传；设计还在变的照当前概念出图，Tripo 每个出两个结果，将来概念改了，至少形体和比例能参考。

## 四视图

出图说明（英文提示词）在 `work/units/tripo_batch/concept_1115.py`（第一批 7 个）和 `concept_1115b.py`（第二批 13 个），运行时注入单位线的 `concept_gpt.py`，没改单位线的代码；单位线恢复后可搬进 `concept_gpt.BRIEFS`。参考图 `work/reference/sheets/` 在 11-10 那次误删里丢了，这次重渲。

第一批看过都能用，几处留意：
- 裂开的冰雕：断下的龙头和底座是分开的两块（设计如此）；冰偏灰白磨砂，接进游戏时照 `ice_kit` 的冰色压暗偏青。
- 纸鹤：侧视图是 V 形（折纸鹤的脖子和尾巴都翘起来），翅膀薄，Tripo 可能把翅尖做厚或做断。
- 底座的参考图只是原版一堵灰石墙，只用来定材质。

第二批（13 个，11-15 出齐）看过都能用，几处留意：
- 游隼、收缩射线车：蓝色铺得太多，几乎整车都是阵营色；接进游戏时按色相取阵营色蒙版要收窄，只留顶部凸起的装甲。
- 游隼、天文台、超级要塞是第二次出的图（第一次侧视图和斜视图对不上）。超级要塞 v2 形体像要塞，但装甲偏米色、背上的太刀只剩一道发光的槽；v1 是细长的舱体、太刀清楚。两张都留着，Tripo 用 v2，太刀的样子参考 v1。
- 光棱坦克画成了四个独立履带（像雅典娜），各视图一致，可以用。
- 原子球塔的斜视图乱（像有十个球），正、侧、背三张是对的，上传只用这三张加 right。
- 十月号的机车和炮车厢很长，正视图、背视图里显得很小，正常。

## 进度和新定的规矩（2026-11-16）

**用户 11-15、11-16 定的设计规矩**（之后出图都照这几条）：
- 原创设计，但必须美观；流程里唯一能控制的是参考图，所以上传前先严审四视图，每件出 2–3 个方案挑最好的，给用户看对比图再传。
- 画风：科幻风格 + 精细纹理（面板缝、小舱盖、通风口、线缆、轻微磨损），不要玩具感。原来出图说明里写的"玩具感、敦实、手绘"是跑偏的原因。
- 设计从功能出发：光棱坦克用透镜远程攻击、光线折射（不是魔法水晶）；游隼是轻型坦克，减防护换机动（气垫 / 喷气）；收缩射线车是精密仪器 + 工程车。
- 超级要塞·完全体 = 巨型机器人，头是起义时刻的超级要塞（空中形态，原模型只作参考，用 Tripo 重建）；身体分部件设计再组合。风格偏日漫高达 + 特摄（为卖模型玩具设定、英雄比例、科技感强）；参考原版将军刽子手补它的不足；带帝国元素：实体太刀 + 念动力剑、喷气推进、纳米科技。

- **素材优先级**（用户 11-16："那就优先用原版自带的素材，不满足的时候靠tripo生成，风格统一按推荐来"）：道具和地标先找原版 SDK 的民用物体（`work/extsdk/SageXML/Civilian/`，38 套城市、3400 多个物体），能直接用、换贴图或拼装就不用 Tripo；原版不满足的才用 Tripo。积分优先花在单位上。
- **风格统一**（同一次定的）：不加全局屏幕滤镜，按阵营给 Tripo 贴图离线调色、往原版同阵营单位的亮度 / 饱和度 / 主色板靠，在游戏里和原版单位同镜头并排截图对比；能做就加一个检查（新贴图的亮度、饱和度落在原版同阵营范围内）。先拿一两个模型试给用户看，再批量。

## 2D 试验：建造栏图标和简报头像（2026-11-16）

用户："按A，模型出来后让Tripo线试一下"。拿音羽和新光棱坦克的 Tripo 模型试：先在 Blender 里按原版图标的角度和光照渲染（R 版），再让图像模型（Codex 里的 GPT 出图，现有订阅）参照原版图标重画（G 版），和原版并排比。脚本和图都在私有的 `work/units/tripo_batch/`（`art2d_*.py`，对比图 `review_icons_1116.png`、`review_portrait_1116.png`）。

- 原版生产按钮的画法：从上往下的三分之四视角，车头朝左下；画面偏暗、金属有颗粒感、边缘一圈冷色轮廓光；单位撑满格子、被框裁掉；英雄按钮是胸像，不是全身。
- 光棱坦克：直接贴渲染（R）发白、像 3D 截图；G2（暗枪灰、磨损、撑满画面）最接近原版。推荐 G2。
- 音羽：全身版的光环和细线缩到 106 像素会糊成一团，改用胸像；G 版保留了面罩、短发、头冠、耳翼和颈圈细线，和原版英雄按钮放在一起不突兀。推荐 G。
- 简报头像：拿模型的头肩特写渲 3 个角度当身份参照，加概念图，生成 4 张，4 张都认得出是同一个人（面罩、头冠、耳翼、颈圈细线、配色一致）。推荐 a2（纯深蓝背景、耳翼对称、最像模型），备选 b1（正面）。小偏差：面罩比模型更不透明、偏紫。
- 坑：提示词里写了"106 像素"，模型就直接出 106 的小图，没法再放大；以后要 1024 方图，再缩到 106。G 版底色靠模型自己画，和原版底板的接缝放大才看得出。

结论：拿 3D 模型当参照，图像模型画的 2D 能保持是同一个人、同一辆车，图标和头像这条路走得通。

## 游戏距离下认不认得出（2026-11-16 用户定，规格 + 自动检查）
