# Tripo 建模清单（订阅到期前，2026-11-15 定稿草案）

用户 11-15："让策划线、单位线和关卡线协调，把需要用 tripo 建模的内容先确定下来，因为订阅应该是 20 号过期。"
本文件是三边文档对齐后的结论：[units.md](../story/units.md)（新单位设定）、[handoff.md](handoff.md)（已做的单位、Tripo 流程）、A3–A5 策划案（[plans/](../story/plans/)、[flow/](../design/flow/)）、总控交接里"两个 mod"的定法。

## 期限和成本

- 网页订阅积分 **2026-11-20 04:00（北京时间）作废**，本机时间约 **11-19 中午**。剩约 3025 积分。
- 一个带贴图、分部件的车辆约 50–80 积分，道具（一整块）约 50。下面推荐的 7 个模型合计约 500，加上重做的余量也不到 1000，**积分不是瓶颈**。
- 瓶颈有两个：① 每个模型都要用户亲手把四张图拖进 Tripo 网页（内置浏览器没有上传文件的工具，见 handoff.md「Tripo 怎么用」）；② 设计没定的东西做了会返工。
- **错过了也有退路**：到期后可以走 Tripo API（`tripo-cli` 已装好登录，全自动、不用拖图），价格约贵 3 倍，一个带贴图、分部件的单位约 ¥3.5–4.2（handoff.md 里的定价）。所以"设计还在变"的东西不必赶这一波：将来定了再走 API，一件多花几块钱。

## 怎么判断要不要用 Tripo

1. **原版有能借、能拼的 → 不用 Tripo**（单位外观原则：先粗模，能借原版就借）。
2. **步兵、走路的机甲 → 不适合**：Tripo 出的是静态网格；我们的接法（`tripo_unit.py`）只接三种刚体：车辆（车体 / 炮塔 / 炮管分开）、道具（一整块）、大平台。步兵和机甲要蒙皮骨骼动画，这一步没有工具，这次不碰，换贴图、加角标就行。
3. **设计还在变 → 不做**，写清不做的损失（见上：将来走 API）。
4. 剩下的按"玩法上要用 → 用在哪个 mod 的哪一关 → 机制在测试台上验过没有"排先后。

四视图 11-15 全部出齐，每张一次出成，看过都能用。几处要留意的：
- 裂开的冰雕：断下的龙头和底座是分开的两块（设计如此）；冰偏灰白磨砂，不够透，接进游戏时照 `ice_kit` 的冰色压暗偏青。出图时用完好冰龙的渲染图当参考，龙头认得出。
- 纸鹤：侧视图是 V 形（折纸鹤的脖子和尾巴都翘起来），翅膀薄，Tripo 可能把翅尖做厚或做断；不满意就在余量那天重做。
- 气球的背视图稍微有点斜，不影响。
- 底座的参考图只是原版一堵灰石墙（没找到合适的日式石头道具），只用来定材质。

四视图的出图说明（英文提示词）在 `work/units/tripo_batch/concept_1115.py`（运行时注入单位线的 `concept_gpt.py`，没改单位线的代码；单位线恢复后可搬进 `concept_gpt.BRIEFS`）。参考图 `work/reference/sheets/` 在 11-10 那次误删里丢了，这次重渲。
