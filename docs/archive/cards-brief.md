# 选定的三张卡：灰盒需求

用户 2026-10-30 选了 A4 甲、S1 甲、J7 甲。卡面（明示的规则、衍生规则、考什么、为什么不能无脑过）在 [a4.md](a4.md)、[s1.md](s1.md)、[j7.md](j7.md)；这里按 [question-handbook.md](../question-handbook.md)"灰盒阶段补的栏目"补给关卡线。灰盒照 [ADR 0011](../../adr/0011-graybox-by-simulator.md)：模拟器定性回答四个问题（谁占优、每轮最优变不变、拿掉一项还成不成立、简单档有没有安全网），判断不了的写"实机"。"自然打法"指卡上"为什么不能无脑过"那几种，平推、拆源的脚本照它们写。

## A4 甲 · 三条街，两个工兵：灰盒已做完

第三版已经关卡线复算（[graybox-cards.md](../../story/graybox-cards.md)"复算"一节），数字全在提交 `e94bb0f` 的 `docs/design/cards/a4.md` 甲：接点相距 ≥ 800、每街一波 900、护卫 4250 第 2、4 波后各补满、三条绕行路长短差 ≥ 10 秒、号角间隔 30～50 秒不固定、冰墙 30 秒化冷却 40。新卡面只多了一条自然打法"冻两条、守一条"，它就是旧长版里的小考（第一波只开两条街、间隔长），不用重算。

下一步不是灰盒，是 ADR 0010 第 4 条：照这张卡配剧情和地图（策划线，[flow/a4.md](../flow/a4.md)、[maps/README.md](../maps/README.md)）。实机要用户看的：间距 800 够不够、错开 10 秒会不会被拥堵抹平、补给怎么到。

## S1 甲 · 拖在后面的卡车（新题，灰盒做完）

**底子**：苏联第 1 关、教 K5、难度 1.5。玩家没有坦克：磁钩（射程 300）、镰刀机甲、动员兵、防空步兵、工程师（[flow/s1.md](../flow/s1.md)）。护卫最远射程 150。冰面承重靠脚本（触发区里按种类杀，已确认）。

| 栏目 | 内容 |
|---|---|
| **地图** | 玩家在岸上。岸边一圈薄冰带，外面厚冰，车队沿厚冰开。押人的轻卡车（2～3 辆）每辆用钢缆挂在一辆守护者后面；另有不拖车的护卫。车队路线有几处湖岬贴近岸边（给"能反复试"），其余离岸远、钩不着。**岬角要比玩家的磁钩多**：3 台磁钩对 3 个岬角就能每处蹲一台，取舍没了（灰盒） |
| **几何（灰盒定了）** | 磁钩站在冰边后 d、薄冰带宽 w、守护者离薄冰外沿 g：钩得着 d + w + g ≤ 300；护卫开到外沿也打不着磁钩 d + w > 150。取 **w = 180～220、d ≈ 10、g ≤ 70～110**，每个岬角的出手窗口约 6 秒。镰刀跳距 300，等于磁钩射程，w 挡不住跳，改靠战斗堵（见漏洞表） |
| **每轮的取舍** | 第一辆守护者沉了以后，其余拖车的守护者改走厚冰中线，只在湖岬处贴近岸边：要提前到下一个岬角埋伏，岬角位置一轮比一轮不同；护卫会派步兵上岸打磁钩，要分兵护磁钩还是抢时间钩 |
| **转折** | 最后一辆卡车由两辆守护者一前一后拖着：钩一辆、另一辆往回拽，拔河又回来了；要两台磁钩同时钩，或先钩走一辆再钩另一辆（灰盒看哪种可行） |
| **暗示** | 演示：开场一辆盟军护卫偏离路线开上薄冰沉了（敌人也沉）。小考：第一个岬角只有一辆不拖车的守护者，钩它、它沉。正题：拖车的守护者。卡车头上的信息框写"钢缆 → 守护者"（信息框已确认）；钩卡车时光标显示"不能钩" |
| **难度** | 简单：岬角 4 处、车慢，卡车丢一辆不判负。普通：岬角 3 处。困难：护卫多派步兵上岸，转折段只给一台磁钩 |
| **漏洞表** | 钩卡车：堵住（拖行时光标不能钩，白白浪费一个岬角的窗口；d + w > 150，护卫打不到磁钩）。镰刀走上薄冰：堵住（脚本要把镰刀加进按种类沉）。镰刀跳过薄冰：允许但打不动，对守护者每秒 9.4 对 51（灰盒）。步兵走过薄冰追护卫：允许但很亏，要整队护卫约 7650 造价才打得过，钩守护者那路只对付约 830，差 9 倍，暂不用"湖心步兵也沉"，玩家钱够不够实机看。岸上集火：卡车被打死判负，护卫离岸 > 175 打不到 |
| **依赖的机制** | 冰面承重（已确认）；磁钩拽车（已确认）；**拖行**（待查：卡车每帧跟到守护者后面，脚本或跟随命令）；**拖行时钩不动**（待查：卡车用磁钩打不了的模板，守护者沉了以后脚本换成能钩的模板）；守护者沉了卡车停下（脚本）；敌方 AI 不自己开上薄冰（待查：寻路避开，或者开上去也沉，算玩家赚） |
| **灰盒结论**（关卡线 `7a89619`，[graybox-cards.md](../../story/graybox-cards.md)"第二轮"） | 聪明打法占优，三种自然打法都明显更亏（见漏洞表）；岬角比磁钩多时每轮要换地方埋伏；拿掉薄冰或拿掉钢缆题都不成立，两项都承重。留给实机：拖行和"拖行时钩不动"怎么做、玩家钱够不够堆步兵 |

## J7 甲 · 给谁修路（新题，灰盒做完）

**底子**（照旧 J7，[flow/j7.md](../flow/j7.md)）：帝国第 7 关、难度 4.5。三段：小队摸进山谷 → 主力和基地车进来、拆三座供能塔 → 护盾一掉苏联提前发射、最后两分钟合体机甲砸塔。干扰车 250 内所有单位（含苏联自己的、含飞机）慢到四成（已确认），一辆光环整个穿过多花 10～15 秒（模拟器）。纸鹤驱雾 900、式神护卫 200（已确认）。

| 栏目 | 内容 |
|---|---|
| **地图** | 玩家基地在南，发射场在北。三条谷南北向连通两边，谷壁走不过去，谷长 ≥ 1500；近、中、远谷不带干扰时对苏联援军差约 15 秒一档。干扰车间距 ≥ 500（光环不重叠）；**近谷要比远谷多摆 ≥ 3 辆**，否则拆光远谷援军也不走，远谷当不了诱饵，只剩近、中两条（灰盒）。三条谷口相隔 ≥ 1500，见"每轮的取舍"。苏联援军从西边界外进场（拆不到，扩边界外的单位由脚本开进来，已确认），目标是你的基地，每波挑当时最快的谷往南穿 |
| **援军怎么选谷** | 每波出发时比"路程秒数 + 剩下的干扰车 × 15 秒"，选最小的；打平走近的。AI 寻路自己会不会这么选是实机；退路是脚本按每条谷的干扰车计数选路点 |
| **每轮的取舍** | 苏联人每波后把一辆干扰车挪进你主力所在的谷：你那条变慢，它原来那条变快，援军下一波可能换谷。每轮要重算"现在最快的是哪条、伏击点放哪、要不要再拆一辆"。灰盒：最优每轮在变，但援军进场的小地图闪点让人看到再追也来得及（谷口相隔 < 1500 就追得上），那样就不用算了，所以谷口拉开到 ≥ 1500，闪点等援军进了谷才出 |
| **转折** | 护盾一掉、提前发射：苏联人把发射塔边开局就停着的 1～2 辆干扰车（不在三条谷里，玩家全拆谷里的也还在；灰盒说不预置的话全拆以后转折就没了）和谷里剩下的开到发射塔下，光环罩住塔，合体机甲走进去就慢。干扰车从"帮你拖住援军"变成"卡你砸塔"，这时才要拆它（式神引火、坦克杀手拆车） |
| **暗示** | 演示：开场纸鹤巡谷，一队苏联巡逻在光环里爬、另一条没干扰的谷里飞快。小考：第一段小队面前一条谷一辆干扰车，自己感受慢和快。援军进场时小地图闪点（已确认），能看出它挑了哪条谷。光环地面圈（**待查**，没有就脚本放标记物）。千岁的延迟台词只说规则："那东西不认人。" |
| **难度** | 简单：倒计时长、援军小，挑一条谷拆通直冲也能过。普通：直冲那条谷会撞上援军、基地被抄。困难：苏联每波挪两辆，援军更大 |
| **漏洞表** | 挑一条谷拆通直冲：普通档吃亏（援军走同一条谷）。全拆：吃亏（三条都快，援军按最近的走、量不变但到得早）。龟缩攒兵：倒计时。空军绕过：堵住（干扰车也减速飞机，已确认；台上防空多）。大军守在自家谷口吃援军：允许，这就是"把拆开的谷口当伏击场"的一种，但主力不去拆供能塔，钟在走。拆西边苏联基地：拆不到（边界外） |
| **依赖的机制** | 干扰车减速所有人（已确认）；扩边界外的单位开进来（已确认）；给敌方下令挪干扰车（已确认）；小地图闪点（已确认）；援军按干扰车计数选谷（**待查**，见上）；倒计时提前（待验证）；合体机甲拆建筑（待验证） |
| **灰盒结论**（关卡线 `7a89619`，[graybox-cards.md](../../story/graybox-cards.md)"第二轮"） | 拆空的谷一定成援军的路；两种聪明打法（拆一条不走的谷当诱饵、拆通一条守出口）占优，成立的窗口是援军为大军造价的 1.7～3.8 倍，很宽；最优每轮在变（条件见上）。 |
| **风险** | "不拆"反直觉，玩家可能根本不往这想：靠演示的对照和援军进场的小地图闪点撑。**最后两分钟的反扑灰盒说会一边倒**：用户 2026-10-31 定了不按玩家兵力分档派兵，反扑按难度分几档、兵力固定，等用户实机玩过、觉得一边倒了再说 |
