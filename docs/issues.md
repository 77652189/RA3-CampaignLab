# 问题跟踪

用户试玩反馈和各线发现的问题，一条一个编号。总控转述、各线报告都引用编号，不在消息里另记一份。

- **类别**：按 [ADR 0015](adr/0015-fix-error-classes-at-source.md) 归类。一个类别对应一条从源头的修法和一条只检查规则的检查；同一类别再出新例，说明源头没修住，要回到"修法"那一栏重修。
- **状态**只有四种：`待修`、`修了待验`（负责线已在源头改完，给出了检查和提交）、`验过`（独立验收者在 CampShell 上当玩家验过，附证据）、`不修`（写明原因）。只有验收能把一条改成 `验过`。
- 进度总览仍以 [plan.md](plan.md) 为准，这里只记一条条问题。

## 类别

| 类别 | 规则（修住以后应该一直成立） | 源头在哪 | 负责 |
|---|---|---|---|
| K1 台词出口 | 同一时刻屏幕上最多一句字幕，一句说完再说下一句，过场里也一样 | `plan.py` 只有一个排队出口 | 关卡 |
| K2 台词挂点 | 每句台词挂在一个镜头或事件上，播出时画面就是它说的东西 | 编译器不接受只写秒数的台词 | 关卡、策划 |
| K3 施展点 | 设计里玩家要在某处施展的能力，在那里用玩家的操作真能施展 | 生成器按施展条件整平；检查走玩家放置流程 | 关卡、策划 |
| K4 资源摆法 | 矿、矿场、油井、基地按原版的相对关系摆 | 生成器按规则摆，不手写坐标 | 关卡、策划 |
| K5 镜头范围 | 镜头只拍可玩区，画面里没有大片黑 | 编译时把镜头夹在可玩区里 | 关卡 |
| K6 编组命令 | 命令下给一队，活着的成员都执行 | 编译器只接受编组命令 | 关卡 |
| K7 挡路与观感 | 挡路默认用房子、墙、水；建筑密度和间距接近原版 | 准则 P36 加生成器默认值 | 策划、关卡 |
| K8 演示可信 | 演示里的动作玩家看得见，单位不凭空出现或消失 | 演示步骤的编译规则 | 关卡 |
| K9 外壳替换 | 战役外壳里玩家看得到的原版内容都换成我们的，或者换成占位 | 外壳构建 | 外壳 |
| K10 配音 | 响度统一，说话人分得清，语言符合 ADR 0013 | 配音管线 | 配音 |
