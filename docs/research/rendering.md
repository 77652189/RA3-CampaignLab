# 红警3 画面改进调研（2026-11-07 讨论记录）

只讨论和调研的结论，不是决定。按 [ADR 0022](../adr/0022-simulator-before-levels.md)，画面和美术放在逻辑层、灰盒之后；用户 11-07 同意现在先做"第 0 步"，并开画面线。

## 1. 现状和限制

- 红警3的程序（`ra3_1.12.game`，改了扩展名的 exe）是编译好的机器码，写死了用 DirectX 9 画。我们没有源码，能换的只有程序外的着色器文件，或者在程序和显卡之间插中间层。"只能在 DX9 框架里改"是**没有源码**的限制，不是 SAGE 引擎设计的限制。
- 着色器：EA 公开了 FX 源码（`CnC_Modding_Support`），我们能改能编（`experimental/rtx-remix/shaders/`）；受 DX9 着色器模型 3.0 和"游戏只传固定那些数据"限制。
- RTX Remix 试验（10-14，[experimental/rtx-remix/README.md](../../experimental/rtx-remix/README.md)）：中间层从着色器常量取摄像机（c119–c123）、模型矩阵（c124–c127）、骨骼（c128 起）、主光源（c5–c10）。单位和建筑光追正确；地形和水面（多层混合只拿到一层）、部分贴图、对局界面、放置虚影、残影没解决。

## 2. 帧率：画面层还是逻辑层

- 逻辑固定每秒 15 帧（测试台量过），画面原版锁 30 帧，逻辑帧之间插值。设计上已分开（比《将军》强：《将军》共用一个时钟）。
- 仍有耦合：两者在同一主循环，原版按画面帧排逻辑帧，画面掉到 30 以下整局变慢（社区公认，未在测试台量）；很多特效用"30"当时钟。
- SAGE-Unlocked（用户装的 120 帧插件）解开这两处耦合；我们的私有分支 SAGE-smooth 能编成 `d3dx9_35.dll`，把 `d3d9.dll` 让给 DXVK / ReShade，两者可同时用。
- "慢"有两种：画面慢（显卡 / 驱动）和逻辑慢（一个逻辑帧算不完，大战变慢动作）。三个画面方案都只治前一种。

## 3. 三个方案

| 方案 | 做法 | 帧率 | 代价 |
|---|---|---|---|
| 1 只换接口 | DXVK（DX9→Vulkan）或 D3D9On12（→DX12），画法不变 | 主线程负担略轻；不碰逻辑 | 最低；画面不变好 |
| 2 截获绘制指令重画 | 中间层识别每一笔画什么，用现代管线重画。2a 全场景重建（Remix 式）；**2b 以 DXVK 源码为底逐项替换（推荐）** | 画面变重；额外计算放 DXVK 独立线程和显卡，SAGE-smooth 常开，可加 FSR/DLSS 抵消 | 中；难在"猜" |
| 3 改游戏渲染模块 | 反编译找到"引擎把场景交给渲染器"的交接点，换成自己的或现成渲染器（可在 64 位独立进程里画，Remix 的结构，连 Unity 都能接） | 能从根上解耦：渲染线程按任意帧率插值 | 大；最大工作量是把原版内容（特效、地形、水、材质）搬到新渲染器，其次是反编译 |

## 4. 2b 能带来的提升和难点

| 批次 | 内容 | 难点 |
|---|---|---|
| 第 1 批（便宜） | 强制各向异性过滤、SMAA、GTAO 环境光遮蔽、调色锐化 | 不需要认出画的是什么，风险最低 |
| 第 2 批（中） | 更好的阴影、FSR / DLSS / DLAA（要低分辨率渲染、镜头抖动、深度、运动矢量）、水面反射 | 要认出每一笔画什么；跨帧认出同一物体（运动矢量）；把场景和界面拆开 |
| 第 3 批（大，可选） | 局部光追（阴影、水面反射），全局光照最后 | 光追要全场景，游戏只画看得见的；会动的单位每帧更新加速结构 |
| 美术阶段 | 高清贴图替换、PBR 材质按类调、换模型 | 美术活，2b 只提供替换能力 |

2b 改不了模型面数和特效本身的样子。猜不准的地方，用方案 3 的办法在游戏里挂钩子取数据（物体编号、上一帧位置、地形贴图层），只读需要的几个函数。

## 5. 现成方案参考

- 嵌入式渲染库：Ogre-Next、Diligent Engine、The Forge、bgfx、Filament；特效模块：AMD FidelityFX（FSR、AO、反射）、NVIDIA DLSS、Intel XeSS。红警3是 32 位进程，很多新库不出 32 位，可用"64 位独立渲染进程 + 共享内存"绕开。
- OpenSAGE（C#，Veldrid：Windows D3D11 / OpenGL 4.3、Mac Metal、Linux OpenGL）：着色器全部用 GLSL 重写（地形、水、道路、粒子、精灵、法线贴图模型、模拟固定管线），按游戏分模块（Generals、BFME、BFME2，没有红警3），官方自述"非常早期，远未可玩"。许可证有歧义，用前读原文。
- 做新游戏：Unity（URP / HDRP，DOTS 应对大量单位）、Unreal 5（Stormgate、Tempest Rising）、Godot 4（MIT）；见 [rts-engine-survey.md](rts-engine-survey.md)。

## 6. 路线（推荐）

0. 现在：方案 1（DXVK + SAGE-smooth 的 `d3dx9_35.dll`），量原版 / 120 帧 / 加 DXVK 的帧率、大战时谁先掉、掉帧是否变慢，顺带看蓝屏。
1. 美术阶段开 2b：第 1 批 → 第 2 批 → 第 3 批（可选开关）；硬规矩：不拖游戏主线程，每加一项量帧率。
2. 方案 3 只为红警3 mod 服务时代价过大（要搬原版内容），不做；做独立游戏时用自己的素材和现成引擎，不需要它。
