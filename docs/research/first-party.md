## WorldBuilder 说明书里对我们有用的规矩（摘要，原文见本地纯文本）

做图顺序（先大后小）：先定死单人或多人、地点、时间、气候、主题，写下来（"每个设计决定都是承诺"）→ 画草图 → 用路点标基地和资源 → 粗地形 → 查尺寸 → 细地形 → 可玩区 → 水 → 贴图先大片再单格再融合 → 物件 → 路 → 资源 → 路径 → 环境音 → 进游戏试 → 优化。

- **场景件**：做一个满意的，再复制、粘贴、修改；没有玩法作用的场景件不超过 6 个物件。原版里成组重复的摆法就是这样来的。
- **崖**：每套风格都有崖壁模型，放在高处一侧盖住崖面，大多高约 70（世界单位），地形高差要配它；崖下刷透明贴图。崖必须一眼看得出来（专用贴图）。
- **坡道**：高 70–80 配长 160–170 最好走。太陡的坡单位打不上去。
- **水**：一整块水面盖全图，水面 200，陆地从 210 起，海底至少比水面低 70（潜艇才走得了）。
- **空间**：卡口至少 200 宽，每个基地最多一个；基地至少三个入口（两条直路一条绕路）；桥不能是唯一的路；城里也要留空，太窄单位寻路会抖。
- **"像城、像林子"就够了**：做的是有城市感的战场，不是城市本身；40 棵树就能做出一片林子。物件总数控制在约 3000（原版战役图实际约 6000）。
- **镜头**：大物件放后面和边上，镜头朝北斜看，大东西会挡住后面。
- **少用围栏**：每节都是一个物件，步兵还翻不过去。
- **主题定了别改**：贴图按地方分文件夹，同一个文件夹里的能搭配。
- **脚本性能**（A 线）：脚本用到才启用；移动和攻击命令分几帧发；生成、摧毁、删除也分开时间做；同一处重叠的触发区不超过 5 个。
