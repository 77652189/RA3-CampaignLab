# 0039 城区先画路网，地块由路围出来；野外仍用块和界

**背景**：2026-11-26 地图工具第 4 项探针（A1 老城切片，`work/mapgen_probe/oldtown/`）走通了"决定 → 展开 → 检查"，楼也在游戏里加载了。但和原版海德堡同比例并排看，差的是城市的骨架，不是零件：

- 原版的街会拐弯、斜着走，分主路和小巷，路面是带路缘、车道线、斑马线的铺件，地块是路围出来的不规则形状，块里铺院子、草坪、停车场。
- 探针按 [ADR 0038](0038-agent-map-generator.md) 第 3 条，先划块，块之间的"界"推出街。结果天然是正交网格，街是一条条直的贴图带，楼立在一块空地上。

总控提了两条路：给界加弯曲参数（改动小），或者城区改成先画路网。用户选了后者（原话："都按推荐来"）。

**决策**：

1. **设计层加第五个名词"路"，只在城区用。** 路是一条带宽度档（巷、街、大道）的线，可以弯、可以斜，连成路网；交叉处自动成路口。agent 在城区先写路网，地块按路围出来的形状切，块里照旧写用途和主角。
2. **野外照旧用块和界。** 崖、岸、水、林子、台地的边界仍然只写两侧高度和谁能过，长相推出来。
3. **路和界相遇照旧自动配口子**：路碰到崖开坡道，碰到水架桥。路碰到一道写明"都不能过"的界时报错，不偷偷推翻已写的禁行。
4. ADR 0038 第 3 条"街由界推出来"在城区里由本条取代；其余各条不变。

**后果**：

- 设计文件多一个名词，城区的草图从"划块"变成"画路"。这一步本来就是玩家最先看到的东西。
- 展开器要按原版的做法铺路面、路口和弯道。原版的路到底是铺件、贴花还是编辑器画路工具画的，还没查过，排在下一个探针。
- 检查的"结构"类多一项：块必须被路或界完全围住，路网连通、不悬空。

**否掉的方案**：

- **给界加弯曲参数**：改动最小，但地块仍然先于路，长不出原版那种沿路排开的街区；弯街两侧的块形状也要人去对齐。
- **整片街区搬原版**：ADR 0038 已否（会被认出，又对不上我们的布局）。
