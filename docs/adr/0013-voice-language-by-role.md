# 0013 配音语言按角色分：剧情对话原声，播报、情报官、单位语音本地化

修改 2026-11-01 "出中文版和国际版两个版本、一次做全"里中文版的配音范围（配音仓库 `docs/campaign_voice.md` 第 7 节）：中文版不再给剧情角色配中文。

**背景**：同一天先定了两个版本：中文版全部中文配音，国际版英文字幕、按阵营配音。中文版想让各国角色带口音说中文，可跨语言克隆只带得过去音色和情绪，带不过去口音；改用真人语料、变声器也都试过或评估过，不划算。用户 2026-11-01："那我们还是以多语言配音和英语配音为主吧，中文这条线只保留战场播报，情报官这两条能显著改善游戏体验的"。

**决策**：

| 声音 | 中文版 | 国际版 |
| --- | --- | --- |
| 剧情角色的对话 | 阵营母语原声（盟军、未来科技英语，苏联俄语，帝国日语），中文字幕 | 同一套原声，英文字幕 |
| 战场播报 | 中文 | 英语 |
| 情报官（沃斯、卡佳、千岁，`docs/design/flow/cast.md`） | 中文 | 阵营母语 |
| 单位语音 | 中文：原版单位用配音 mod 现成的，新单位补配 | 原版英语，新单位补配阵营母语 |

- 剧情对话只配一套，两个版本共用，只换字幕。
- 带玩法信息的台词（什么时候来兵、冰墙要化、车被拦住、下一步做什么）只能由播报或情报官说。角色之间的对话只管剧情和笑点，玩家听不懂、来不及看字幕，也不影响操作。
- A4 已经配好的中文角色台词先留着试玩，之后换成原声，不专门返工。

**后果**：
- 配音工作量约减一半，"中文带口音"的难题不用再解。
- 外语发音地不地道我们自己听不出来：配完先用语音识别转回文字对一遍，国际版发布前请会说俄语、日语的人抽听。
- 写台词时要标出哪句带玩法信息，并分给播报或情报官。

**否掉的方案**：
- 中文版角色全部中文配音：要么没口音、各国角色没区别，要么卡在口音上做不好，工作量还翻倍。
- 用户自己录音、变声器转音色：要录上千句；声线差距大时失真；外语版的口音会跟着录音的人走。
