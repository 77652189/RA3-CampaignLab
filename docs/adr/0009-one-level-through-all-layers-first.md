# 0009 先让 A4 走完全部层、做成一关完整能玩的，再批量；修法仍改模板不改单关

取代 [0008](0008-levels-by-layer.md) 里"每层全战役做完才做下一层"和"第 3 层工具冻结"两条，其余照旧。

**背景**：0008 定了先横后纵：27 关的剧情流程全写完、过闸门，再做地图，再做摆放。第 1 层校准时（A4、S1、J7）用户又提了五条审核标准（2026-10-29：剧情完整连贯、分阶段展开不留空地、开局资源和敌方压力纳入考虑并引导不同打法、出乎意料的情况、兵力不足时给援军免得读档），其中第 2、3、5 条要到地图和摆放才看得出来，只看流程稿判断不了。用户上次试玩还发现游戏里很多内容停在早期阶段：音乐、单位、流程各线的新东西都没进同一个试玩包。

**决策**（用户 2026-10-29："我们尽量先做出一关比较完善的流程，然后再打磨"；同日要求"把音乐线的音乐，关卡线的地图和单位线的单位都实装到测试地图里，我一次性进行测试"）：
- **A4 先纵向走完三层**：流程稿按五条标准过用户审 → 地图内容 → 摆放与机制进游戏，配上当前的音乐、单位和配音，做成一关完整能玩的，用户试玩。
- **A4 就是第 2、3 层的校准关**：每层先在 A4 上出模板（地图内容稿、摆放的生成方式），用户在游戏里认可了，其余关再按层批量。
- **修法不变**：A4 上发现的问题，改产出它的模板、准则或生成器再重产 A4，不手工补。这样 A4 打磨出来的东西，后面 26 关直接受益。
- 第 3 层工具只为 A4 解冻：关卡线排着的取反 bug、模拟器对齐、A4 离线检查现在就做。其余关的粗版仍不动。
- S1、J7 的流程稿照旧校准第 1 层，不跟着 A4 往下走。

**后果**：第一关能玩比 0008 早很多，用户能在游戏里判断五条标准；代价是第 2、3 层的模板只在一种关型（A4）上校准过，批量前要再挑一两关不同类型的走一遍第 2、3 层。各线的活集中到 A4 上：音乐、配音、单位都按 A4 用到的先做。

**否掉的方案**：
- 照 0008 先横后纵：第 2、3、5 条标准要等 27 关剧情全写完才能在游戏里验，太晚，而且用户一直玩不到新东西。
- A4 纵向做完后就一关一关精修下去：回到 0008 之前的做法，工作流的毛病会被人工把关盖住。
