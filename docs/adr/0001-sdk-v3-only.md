# 0001 只用 Mod SDK v3.0

**背景**：手头先有一份 1.10 时代的 SDK（现 `sdk\RA3ModSDK`）。用它编的单位能加载、能显示，但单位一活动起来游戏就随机崩溃（堆损坏）。一度把原因归到动画、帧数、绘制模块上反复二分，结论都不稳定。

**决策**：只用从 archive.org 存档取得的 Mod SDK v3.0（1.12 布局，AllTypesHash 与游戏一致，现 `sdk\RA3ModSDK3`）。旧 SDK 只为最早几个探针保留。

**后果**：换成 v3 后同样的单位 3/3 稳定；先前的二分结论全部作废。默认路径集中在 `experimental/campaign/labpaths.py`（`SDK3`，可用 `CNV_SDK` 覆盖）。

**否掉的方案**：继续用旧 SDK 并绕开崩溃的模块——崩溃是布局不匹配，绕不开。
