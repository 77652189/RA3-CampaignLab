# 0010 关卡先出题：课程表 → 题卡 → 灰盒 → 配剧情 → 实装

取代 [0008](0008-levels-by-layer.md) 和 [0009](0009-one-level-through-all-layers-first.md) 的分层顺序。修法不变：出了问题改模板、准则或生成器，再重新产出，不手工补单关。

**背景**：0008 起的顺序是"剧情流程 → 地图内容 → 摆放"。准则攒到 35 条（`docs/design/principles.md`），关卡还是过不了用户的审：J7 后期流程太简单，A4 写了两种解法、可拆的压力源，仍然能平推。用户 2026-10-30："我认为我们目前主要的局限就在题目质量上，我们不知道如何去设计一个高质量的关卡……我们先做的应该是把怎么出题，题目考察什么能力，具体怎么考察这些事情想清楚，然后再去给题目补充场景"，"缺少出题这一步确实是一个结构性缺失"。

调研见 `docs/design/teardowns/data/` 下四份：`rts-campaign-question-types.md`、`puzzle-design-theory.md`、`level-generation-and-checking.md`、`simulator-gap-2026-10-30.md`。诊断有两条：
- 准则都是好关卡应该满足的条件，不产出题目。照清单拼出来的关卡，能每条都满足，却没有一个把整关串起来的核心想法。
- 没有便宜的试错回路。星际2的设计师说，一关有时两周就能做出可玩版，第一版从没成功过，经常整关推翻；灰盒的行话是"99% 撑不过第一次试玩"。我们一直想在纸面上一次写对。

**决策**（用户 2026-10-30："整套改吧"）：

1. **课程表**：全战役排一页。约 6～12 个新考点，每个按"教 → 练 → 组合 → 考"排开，之后至少换两次条件再出现。每关标出用途（教、练、组合、考、喘口气、高光）。27 关的"一句话巧解"不重复，难度像波浪一样起伏。用户审一次。
2. **题卡**：一关一张。栏目：
   - 课程位置；
   - 剧情一句话（这条规则在故事里为什么成立）；
   - 本关规则：一句话，最好是一个会动、会变、会倒计时的威胁或约束；
   - 卡点：平时的打法（龟缩攒兵平推，或者用户的打法：先拆压力源）为什么因为这条规则行不通，不能只是敌人数值更厚；
   - 巧解：一句话，由学过的规则推出来，解完以后成为后面关卡的工具；
   - 转折：同一条规则换一个后果；
   - 暗示：用到的东西开局就在场上，因果关系看得见，提示分层给；
   - 难度：等于不动脑的代价。简单档照平时打法慢慢能赢、有安全网；普通档照平时打法代价很大；困难档必须用巧解，省力的解法也被堵死；
   - 怎么检验。

   题从三处来：题型库（星际2的 15 种题型、起义时刻指挥官挑战的约束玩法、心灵终结的做法）、机制推论表（单位技能、地图机关、测试台测过的引擎事实推出的意想不到的后果）、剧情转折（P12）。每个关卡位置由 AI 出几张候选，用户挑一张。剧情的核心想法和题目一起定，台词和镜头放到后面写。
3. **灰盒**：用最简单的地图、原版单位，不配台词。先跑几套打法脚本，再给用户玩。
   - 打法脚本：平推、拆源（仿用户的打法）、巧解、失误（测保底援军）。
   - 断言：普通档巧解明显好过平推；简单档平推也能赢；禁掉巧解依赖的机制后，巧解退化到和平推差不多；先拆压力源不会让这关变得轻松无味；兵少时保底援军会出现。只断言大的差距。
   - 用测试台无人值守地跑游戏本身，结果只读数字，不用离线模拟器：模拟器没有经济，不模拟敌方 AI，三分之一单位读不到武器。要先探一下，地图脚本能不能替玩家这一方下命令。
   - 检查器要先拿用户下过结论的关卡校准：旧 A4 用户说能平推，原版战役用户说太简单，检查器都得判得出来；判不出来就先修检查器。
   - 用户玩 10～15 分钟，只回答两个问题："有没有'原来如此'的那一下"和"再玩一次会不会一样"，然后决定留下、改还是推翻。
4. **配剧情和地图**：在已验证的题目上套现有的流程模板和地图内容模板。原有准则大部分用在这一层。剧情和文字由另一个模型当评委，用用户以往的判定来校准它。
5. **实装和打磨**：真地图、音乐、单位、配音；打法脚本再跑一遍做回归；最后用户试玩。

**后果**：A4 先停在游戏实装之前，补写它的题卡，现有 A4 粗版当灰盒和检查器的校准样本。第一周拿出来的是出题手册、课程表、三关的候选题卡和检查器的校准结果，不是新的能玩关卡。检查只当筛子，不当优化目标，否则生成器会去钻检查的空子。人格打法比真人笨，只能算下限，上限靠用户试玩。阶段闸门：检查器连旧 A4 都判不出来，就先停下来重想验证手段，不往 27 关铺。

**否掉的方案**：
- 继续先写剧情再出题：就是卡了几天的现状。
- 先花 2～3 周把离线模拟器补成能比较打法的工具（经济、敌方 AI、武器数据）：补完也只是近似，最后还得上测试台对齐；直接用游戏本身跑更准。
- 先做一个带任务编辑和战斗模拟的地图编辑器：工时大，编辑器和策划案会成为两份权威。用户要的"反馈快"由灰盒和打法对比来满足。
