# 0004 不用按状态过滤的索敌视野

**背景**：想让游隼坦克"优先攻击被冰冻的敌人"。引擎的目标排序（TargetingCompareList）只有距离 / 战斗链 / 炮塔角度三种比较，没有按状态排的办法。于是在炮塔的目标选择里加了 ObjectVisionRange，过滤条件写 `StatusBitFlags="UNDER_FROZEN"`，想让它从更远处看见被冰冻的单位。

**决策**：删掉这条规则。"优先清理冰冻敌人"靠高射速加快速换目标实现：完全冰冻的单位受到 90000% 伤害，任何一发都能打碎。

**后果**：CampNew28 的对照实验证实两点：
- 其一，`Range` 是视野的百分比，写 "250" 等于 500 单位，于是坦克在下令之前就自己冲向 460 外的铁锤；
- 其二，过滤条件不检查状态，`Rule="ANY"` 和 `Rule="ALL"` 都一样，230 外没被冰冻的采矿车也照打；去掉规则后就不追了。

**否掉的方案**：保留规则只改成百分比——过滤本身无效，留着就等于全局扩大索敌范围。
