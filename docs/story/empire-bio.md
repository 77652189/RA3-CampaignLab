## 一句话

一个战败的国家，是把死者的怨气变成雷去复仇，还是把他们安葬好、让过去留在过去。音羽是那个替死者发声的人，整条帝国线是她在这两者之间做选择。

## 原作留下的地基

- **岛田的计划**：百合子小时候被同学排斥，被政府送进岛田的神罗心灵研究中心（`U_yfs01`）。研究中心的经费来自太子达郎（`MY02_Yuriko29`），里面有一整片克隆区，百合子说可能有几百个她（`MY03_Yuriko37`）。岛田最后的话，大意是他造了百合子和野泉，她们是同一个人；他不在了，就没人保护她们了（`U_yth03sh04`）。之后他再没出现。
- **战败**：盟军攻进东京，芳郎天皇已死，遗骸葬在奥基岛（`U_jfs02_06`）；日本被占领，忠于先帝的老派军阀不服达郎（`U_afs01`）。
- **帝国用过广播**：原版帝国线第 4 关是向全世界广播劝降（`R_jfs04`）。用声音打仗，在原作里有根。
- **百合子的反叛**：百合子最后毁掉了重建的研究中心，下落不明（`U_yfs03`）。她是帝国学到的教训，只被提到，不出场。

## 音羽

- **名字**：取自京都清水寺的音羽瀑布。J8 回到京都，是回到名字的出处。
- **她是谁**：岛田计划的下一代。百合子证明了一件事：力量放在一个完整的人身上，那个人就可能反叛。所以这一代把力量从人身上拿走，放进广播里。音羽的心灵能力本身很弱，只有通过歌声、经过全国的扩音器才被放大。离了广播，她只是一个嗓子很好的女孩。
- **她不存在**：她的户籍被注销了，官方记录里这个女孩已经死了。存在的只有"音羽"这个声音：宣传省用她的录音合成声库，全国听到的歌大多不是她当场唱的。盟军的狗仔队一拍照，就会弹出"合成音声 · 声源已注销"（见 [concept-cards.md](concept-cards.md) 街宣车那张），说的就是这件事。
- **她为什么深入人心**：战败的国家最需要一个声音。士兵在废墟里、在被占领的港口里，听着她的歌重新站起来。她不是宣传省硬塞给大家的偶像，是大家需要她，宣传省只是抓住了这一点。
- **她的本职**：巫女。传统里巫女替神说话，也负责安抚亡魂。战败后满国的战死者没有被好好哀悼，宣传省让她唱的不是安魂曲，而是把这份怨气变成战意。游戏里那道雷（损失攒成反击），在剧情里就是她的歌：战友倒下得越多，她唱得越响，雷落得越重。
- **说话**：平时话少、客气，像在台上训练出来的那样得体；只有唱歌时才像她自己。她不说"为了帝国"，她说"为了大家"（街宣车的广播词）。这个"大家"是谁，是她一路要想明白的事。

## 岛田真司

- 他是一个"父亲"的影子：造了百合子、野泉，也写下了音羽这一代的计划书，只是没来得及看到她。
- 他真心相信，力量必须被控制，否则会伤害拥有它的人。他给孩子编号、关起来，是在"保护"她们。他的计划书最后一页写着为什么要把力量放进广播：这样就没有人需要被关起来了。这是他想出来的仁慈，也是最彻底的控制。
- 他留下的问题，整条帝国线都在回答：被造出来的人，能不能有自己的声音。
- 黑尔接手了他的研究中心和克隆体（大纲第一节），把"控制"变成了生意：岛田控制是为了保护，黑尔控制是为了卖。音羽在 J3 的档案里，同时看到岛田的计划书和未来科技的收购合同。

## 她和其他人

三个人对"战败的过去"有三种态度，音羽站在中间：

| 人物 | 对过去的态度 | 和音羽 |
|---|---|---|
| 黑田将军（上级，J6 叛变） | 不接受：想用时间机器回去救天皇，把战败改掉 | 守陵的老将，守的是死者；音羽安抚死者。他是最早让她在奥基岛陵前唱歌的人，也是第一个想把那份怨气变成真正的武器的人 |
| 真壁少佐（宿敌，亲盟军的"新日本"） | 不记得：过去是包袱，丢掉、换上新的 | 他觉得音羽是旧帝国的宣传品，该被关掉；他说的"新日本"里没有死者的位置 |
| 音羽 | 哀悼：记住，安葬，然后往前走 | — |

- **千岁**（情报官）：宣传省派来管音羽广播的人，也是玩家的情报官。礼貌、精确，知道声库的事，一直没说。她是第一个对音羽说实话的人（J3 之后）。
- **达郎**（只被提到）：当年出钱给岛田，想要一支只听他一个人的心灵部队（大纲第一节）。J7 起他的命令由千岁转达，音羽从没见过他。
- **克隆体**（被黑尔用来控制别人的那些）：和音羽出自同一个计划，是她的"姐妹"。她们被造出来就为了控制别人，而音羽的声音，最后学会了放人。

## 九关里的她

| 关 | 她在这关是什么 |
|---|---|
| J1 奈良 | 一件刚交给玩家的武器。她唱，鸣神的雷就落下来。她自己没问过为什么 |
| J2 宫岛 | 舰队出海去追遗物；她在广播里送行，第一次唱给一支回不来的舰队（A1 背景里被苏军挡在旧金山外海的就是它） |
| J3 姬路城 | 潜进训练所，在档案里看到赛林斯基的名字，也看到自己：户籍注销、声库、岛田的计划书。全国听到的"音羽"不全是她 |
| J4 札幌 | 截下的那车克隆体，和她出自同一个计划。她第一次对着她们唱，不是为了让她们打仗 |
| J5 阿苏 | 和盟军临时联手挡苏联的钻地队；真壁站在盟军那边，当面说她是该被关掉的宣传品 |
| J6 日光 | 黑田偷走完全体，要用机器救回天皇。他请她在陵前唱最后一次，把满国的怨气都给他。她拒绝了 |
| J7 拜科努尔 | 千岁转达达郎的命令：突袭发射场，不让时间卫星上天 |
| J8 京都 | 黑尔用克隆体控制京都守军。她用同一种力量把人一个个放回来，登上完全体的驾驶舱；它第一次站起来，听的是她自己的声音，不是广播。黑匣子里那路偷传给黑尔的信号，她听出和自己的歌是同一种东西，顺着它找到布鲁塞尔 |
| J9 布鲁塞尔 | 最后一道雷劈向机器：用怨气最后一次，是为了让以后没人能再用时间去复仇。原子球塔倒下 |

**结局**：一个刚被解放的克隆体问"我们还存在吗？"音羽没有回答。她自己也是官方记录里不存在的人；存在不存在，要自己决定。这是她第一次没有替谁说话。

## 借的思路（只借问题，不借情节和人物）

- 平成哥斯拉《大怪兽总攻击》（2001）：哥斯拉被写成太平洋战争亡魂的化身，没被哀悼的死者会回来变成怪物。→ "怨气化雷"的阴暗面，黑田的路。
- 战后的歌声：1945 年的《苹果之歌》、美空云雀，战败的日本听着歌重新站起来。→ 音羽为什么深入人心。
- 《超时空要塞》：歌声最后不是武器，是让敌人想起自己是人的东西。→ J8 用歌放人。
- 《假面骑士》（1971）：主角是邪恶组织造的改造人，用同出一源的力量对抗它。→ 音羽和克隆体同出岛田的计划。
- 《阿基拉》：国家拿孩子做超能力实验、给他们编号。→ 岛田的研究中心。
- 《未麻的部屋》：偶像的公众形象比本人更"真实"，最后吞掉本人。→ 声库和注销的户籍。
- 《铁人 28 号》《巨人 Robo》：巨型机器人听遥控器或少年的声音行事，好坏看谁在操纵。→ 整部战役都在争"控制"；J8 完全体听的是她自己的声音。
- 《新世纪福音战士》：备用的克隆身体，"我到底是什么"。→ 结局那句"我们还存在吗"。
