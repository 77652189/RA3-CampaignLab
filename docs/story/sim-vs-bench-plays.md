# 对照局：同一份打法在模拟器和测试台上跑（ADR 0023 第 1 条第三个前提）

关卡线 2026-11-08 建。做法：把 `experimental/cnv/plays/<关>.txt`（玩家打法剧本）编译成关卡自己的脚本动作（`派` = `ATTACK_MOVE_NAMED_UNIT_TO`，`造` = `CREATE_NAMED_ON_TEAM_AT_WAYPOINT`，`删除` / `摧毁` / `旗标`；时间 = 任务开始时设的计时器，或 `<旗>+<秒>` = 旗升起后设的计时器），做成每关的 `play` 检查。模拟器跑的是**同一份**编译后的脚本，所以两边的差别只来自游戏规则，不来自翻译（`tests/test_playcheck.py` 验：编译版和模拟器原生剧本结局一致）。

```
python -I -X utf8 experimental/cnv/playcheck.py <关>              # 编译后的脚本和这个检查的期望
python -I -X utf8 experimental/cnv/playcheck.py <关> sim          # 模拟器读数：结果、旗升起的秒、各阶段开始的秒
cnv_check <关> play                                               # 测试台（a1 a3 a6 a9 j7 已注册；a7 a8 的剧本能编，检查没注册，等模拟器那边稳了）
```

## 比什么、怎么判

- 比三样：**结局的时刻**（任务结束 = 计数器随界面一起消失，那一帧就是胜负旗升起的时刻）、**各阶段开始的秒**（`CNV_<标签>_Phase_k` 旗，计数器 `玩家局阶段`）、**胜负**。差 15% 以上（不窄于 4 秒）就停下归因（`WINDOW`、`SLACK`）。期望是双向的：早于窗口也算不符，免得"到时候已经有了"盖住测试台快得多。
- **胜负不能用计数器读**：胜负旗一升起，库就把界面（含计数器）藏掉，再 5 秒（胜）/ 3 秒（负）才结束。胜负看这一局最后几帧的结算牌（胜利 / 失败，`work/testbench/runs/<局>/` 倒数几张），要人看一眼。
- 计数器最多 4 行：`玩家局阶段` + 最多 3 行 `WATCH`（某个角色的血量，或我方某类单位的数量），用来看差在哪。
- **表 `EXPECT` 只放两边一致过的打法**。别的关检查只打印读数、不下期望。模拟器规则变了读数偏出 15%，`test_playcheck` 变红 = 该重跑测试台、再定基线。

## 没翻译的
`血量`、`打`、`占领`、`不打`、`自动打掉`（模拟器自己的设定，测试台没法被告知）：编译时直接报错，不让一份打法在两边各打一半。原来没有名字的放置单位（如玩家的基地车）编译时自动起名 `UNIT - Play <模板> <n>`。
