## 定位

- 苏联第 6 关。解锁协调器干扰车，这一关就是它的教学关。
- 类型：守。玩家要学会：干扰车停在路口打开干扰，冲过来的机甲全都慢下来，炮塔和坦克才打得过来；但它自己也不能动，还会拖慢自己人。
- 剧情：苏联要把机器的稳定器——"时间卫星"——送上轨道。帝国的机甲从东边三条山谷冲向发射场。守住发射塔，挺到倒计时结束。

```yaml
关卡: s6
名字: 拜科努尔
一句话: 守发射塔到倒计时结束。帝国机甲从三条山谷冲来，干扰车停在谷口让它们慢下来
地图: baikonur
阵营: {我: 苏联, 敌: 帝国}
时长: 12
```

## 开局

玩家在西边有基地，发射塔在中间的发射场；两辆干扰车、一小队铁锤坦克。东边是帝国的前进营地（第 2 段交给遭遇战 AI）。

```yaml
开局:
  资金: 6000/5000/4000
  部队:
    - {单位: 建造厂, 在: base yard}
    - {单位: 兵营, 在: base barracks}
    - {单位: 战车工厂, 在: base factory, 朝向: 3.1416}
    - {单位: 电厂, 在: base power, 朝向: 0}
    - {单位: 矿厂, 在: base refinery}
    - {单位: SovietSuperWeapon, 在: launch pad, 角色: launch tower}
    - {单位: 协调器干扰车, 数量: 2, 在: launch yard, 偏移: [150, 0], 角色: jammer}
    - {单位: 铁锤坦克, 数量: 4, 在: launch yard, 偏移: [0, -150], 角色: hammer}
    - {单位: 磁暴线圈, 在: launch yard, 偏移: [250, 200], 角色: coil}
    - {单位: 兵营, 在: east barracks, 阵营: 敌, 角色: east barracks}
    - {单位: 战车工厂, 在: east factory, 阵营: 敌, 角色: east factory}
    - {单位: 电厂, 在: east power, 阵营: 敌, 角色: east power}
    - {单位: 矿厂, 在: east refinery, 阵营: 敌, 角色: east refinery}
    - {单位: 海啸坦克, 数量: 3, 在: east base, 阵营: 敌, 角色: east guard, 守: east base}
```

干扰车是这一关解锁的新单位，战车工厂能造。

```yaml
可造: {战车工厂: [协调器干扰车]}
```

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 布防 | 把干扰车开到谷口、打开干扰；补炮塔 | 没有：1:30 准备 | 干扰车停哪儿 |
| 倒计时 | 守住发射塔 | 三条山谷轮流来机甲，越来越密；东边营地交给遭遇战 AI。拆掉它的兵营和战车工厂，AI 就造不出兵 | 干扰 + 火力 |

```yaml
段:
  - 名字: 布防
    目标: [守住发射塔]
    开场:
      - 通报 帝国的机甲要从东边三条山谷冲过来。把干扰车开到谷口、打开干扰，冲过来的东西就全慢下来。
      - {倒计时: 开局 + 1:30, 文字: 帝国进攻, 直到: 段 倒计时}
    结束: 开局 + 1:30
  - 名字: 倒计时
    目标: [挺到发射, 拆掉帝国的前进营地, 干扰车一辆不丢]
    开场:
      - 通报 发射倒计时开始！守住发射塔。
      - {倒计时: 段 倒计时 + 7:00/8:00/9:00, 文字: 发射}
    存档: 是
```

## 敌人的进攻

- 三条山谷轮流来：北、中、南各一路，按时到；越往后越密（`加码`）。
- 东边营地第 2 段交给遭遇战 AI（A7 的做法）。

```yaml
敌方AI:
  性格: 机甲
  基地: east base
  资金: 3000/5000/8000
  唤醒: {任一: [段 倒计时, 攻击 east barracks, 攻击 east factory]}
  接管: [east barracks, east factory, east power, east refinery, east guard]
  上限: {基地车: 0, 兵营: 0, 战车工厂: 0, 电厂: 0, 矿厂: 0, 船坞: 0}

进攻:
  - 名字: 开场试探
    开始: 开局 + 0:30
    兵: {天狗: 1}
    从: middle mouth
    打: launch tower
  - 名字: 中路
    开始: 段 倒计时 + 0:10
    兵: {天狗: 2/3/4, 海啸坦克: 1/1/2}
    从: middle mouth
    打: launch tower
    每隔: 1:30/1:15/1:00
    最多: 5
    加码: {当: 段 倒计时 + 4:00, 兵: {鬼王: 0/1/1}, 每隔: 1:00/0:50/0:40}
    预警: 帝国机甲从中间的山谷冲过来了！
  - 名字: 北路
    开始: 段 倒计时 + 0:50
    兵: {天狗: 2/2/3, 坦克杀手: 2/3/3}
    从: north mouth
    打: launch tower
    每隔: 2:00/1:40/1:20
    最多: 4
    预警: 北边的山谷有帝国部队！
  - 名字: 南路
    开始: 段 倒计时 + 1:30
    兵: {海啸坦克: 2/2/3}
    从: south mouth
    打: launch tower
    每隔: 2:00/1:40/1:20
    最多: 4
    预警: 南边的山谷有帝国坦克！
```

## 规则

```yaml
规则:
  - 当: 开局 + 0:15
    做: [通报 协调器干扰车：按干扰钮，它就停在原地不动，周围所有单位——包括自己人——都慢下来。停在谷口最管用。]
  - 当: 血量 launch tower < 50
    做: [通报 发射塔受损过半！把部队调回来守住它。]
```

## 检查

测试台上的检查（`experimental/cnv/checks/s6.py`），每个写一句它证明什么。

```yaml
检查:
  hold: 发射塔每帧回满血，倒计时走完，任务结束（赢）
  lose: 发射塔开局只剩 1% 血，第一波机甲到了就被拆，任务很快结束（输）
```

## 玩家可能不知道的事

| 敌人从哪来 | 防错了路 | 每路的预警 |
