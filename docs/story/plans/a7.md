## 定位

- 盟军第 7 关，倒数第三关。不解锁新单位；本关的"新东西"是首领自由号，玩家第一次和它交手。
- 类型：建基地 + 打首领。玩家要学会：首领打不动的时候，去找它的弱点（电站）。
- 剧情：司令带着自由号和一批部队叛变，要"先发制人地抹掉苏联"。玩家先弄清谁还站在自己这边，再切断自由号的电，最后在它飞走之前把它打下来。

```yaml
关卡: a7
名字: 鹰派
一句话: 打自己的旗舰。自由号靠电站供电的超时空甲板跳到你防守最空的地方；先切断电站，再在它飞走前打下来
地图: niagara
阵营: {我: 盟军, 敌: 盟军, 其他: {哨所: 盟军, 叛军: 盟军}}
时长: 20
边界: west bank
```

## 开局

玩家只有基地车和一小队人。西岸有三座盟军哨所，两座忠诚（"哨所"一方），一座跟着司令叛变（"叛军"一方）；开局它们都是中立的，玩家的兵走近才知道。东岸是鹰派基地，第 2 段才唤醒；电站在山羊岛上。

## 机关

自由号：电站是它的（没被毁、没被占）就能跳。每次跳之前 15 秒报警并显示倒计时，按顺序挑玩家武装单位少于 3 个的落点：基地边、矿区、前线；在那停 30 秒放无人机、卸甲板工厂造的兵，然后跳回家。断电以后由第 3 段让它绕航线飞走。

```yaml
机关:
  自由号:
    类型: 自由号
    电站: station
    开始: 段 自由号来了 + 0:30
    落点: [base edge, base ore, front]
    空虚: 3
    每隔: 2:00/1:30/1:15
    停留: 30
    预警: 15
    家: carrier home
    航线: [route 1, route 2, north exit]
    血量: 70/100/100
```

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 清点人数 | 展开基地；派兵联系三座哨所 | 叛变哨所：拆掉 | 先侦察再进去 |
| 自由号来了 | 顶住跃迁突袭；过桥上山羊岛断电 | 跃迁←电站；地面进攻←东岸兵营和战车工厂 | 首领打不动就打它的弱点 |
| 它要飞走 | 倒计时内打下自由号 | 自由号本身；东岸最后一波 | 防空和集火 |

```yaml
段:
  - 名字: 清点人数

      - 通报 司令开走了自由号，带着一批部队叛变了。先展开基地，再派兵去联系西岸的三座哨所——不是每一座都还站在我们这边。
    结束: {任一: [目标 联系三座哨所 完成, 开局 + 6:00]}
```

## 敌人的进攻

原版的做法：开局有基地，20～30 秒内有一股象征性威胁；真正的进攻按时到，或者玩家先推进就提前；每路压力有来源，拆掉就停。

```yaml
进攻:
  - 名字: 开场骚扰
    开始: 开局 + 0:30
    兵: {多功能步兵车: 1/2/2}
    从: front
    打: mcv
  - 名字: 地面进攻
    开始: {任一: [段 自由号来了 + 2:30/1:30/1:00, 进入 goat island, 进入 east gate]}
    兵: {守护者坦克: 3/4/4, 维和步兵: 4/6/6, 幻影坦克: 0/0/2}
    从: east gate
    打: base edge
    每隔: 2:30/2:00/1:40
    最多: 6
    来源: [east barracks, east factory]
    预警: 鹰派的地面部队过桥了！
  - 名字: 最后一波
    开始: 段 它要飞走
    兵: {守护者坦克: 6, 阿波罗战机: 4, 冷冻直升机: 0/0/2}
    从: east gate
    打: base yard
    来源: [east barracks, east factory, east airfield]
    预警: 鹰派倾巢而出，想拖住你！
```

## 检查

```yaml
检查:
  jumps: 哨所一开始就处理掉（第 2 段马上开始）；自由号先在家，到点报警、跳到基地边，停一会儿再跳回家
  pick: 基地边站满玩家的武装单位，自由号改跳到矿区
  defend: 电站血量降到一半以下，自由号马上跳到电站边上
  power: 第一次跳过来以后炸掉电站，它不再跳回家，第 3 段开始后绕航线飞
  win: 自由号只剩 1% 血时被测试脚本跳到基地边，被我方打下，任务以胜利结束
```

## 玩家可能不知道的事

| 玩家不知道 | 后果 | 怎么告诉（上面哪一条） |
|---|---|---|
| 自由号靠电站供电 | 一直对着自由号打 | 第 2 段的镜头和通报；目标说明；8 分钟还没断电再提示一次 |
| 哪座哨所叛变了 | 小股部队走进去被吃掉 | 40 秒的通报"3 号哨所没有回应"；目标说明 |
| 跃迁落点在哪 | 来不及回防 | 每次跃迁前 15 秒报警和倒计时 |
| 工程师能占电站 | 只会炸，拿不到奖励 | 奖励目标说明 |
| 第 3 段要防空 | 只有坦克 | 断电时送防空部队，通报说明 |

## 对照原版之外、还没做的

- 敌方东岸基地现在是写死的波次，原版多用遭遇战 AI 持续施压；先求能测、可复现，AI 基地以后再试。
- 地面进攻"赶在跃迁前 20 秒出发、两面夹击"还没做成机关，现在两路各按各的时间。
- 困难难度给自由号加甲板炮塔要换单位变体，还没做。
