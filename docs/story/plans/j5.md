# J5 敌人的敌人 · 策划案

剧情见 [outline.md](../outline.md) J5 行，单位见 [units.md](../units.md)（式神护卫）。

**这份文件就是关卡本身**：改 `yaml` 块，重新编译，玩法就变（写法见 [README.md](README.md)，词表用 `plan_vocab` 查，改完先跑 `plan_show(j5)`）。

**粗版**（2026-10-27，总控"关卡先铺开再打磨"）：能玩、检查能过就行，原版对齐和难度以后再说。未来科技的雇佣兵先用盟军的兵代替；熔岩是美术，放最后。

## 定位

- 帝国第 5 关。解锁式神护卫：打开护卫后，200 内的敌人改打它，飞过来的炮弹也会拐到它身上。
- 类型：守。玩家要学会：雇佣兵专挑百合子打，把式神开着护卫挡在她前面，百合子就能腾出手来。
- 剧情：未来科技的雇佣兵袭击阿苏火山下的盟军观测站——那里记着赛林斯基的时间实验。帝国和盟军暂时联手，百合子带着式神守住观测站，等盟军把数据撤走。

```yaml
关卡: j5
名字: 敌人的敌人
一句话: 守观测站到数据撤完。雇佣兵专挑百合子打，式神开着护卫替她挡子弹
地图: aso
阵营: {我: 帝国, 敌: 盟军}
时长: 12
```

## 开局

玩家在西边有基地；百合子、三个式神在观测站旁，盟军借来两辆守护者坦克。火山东边是雇佣兵的营地（第 2 段交给遭遇战 AI）。

```yaml
开局:
  资金: 5000/4000/3000
  部队:
    - {单位: 建造厂, 在: base yard}
    - {单位: 兵营, 在: base barracks}
    - {单位: 战车工厂, 在: base factory, 朝向: 3.1416}
    - {单位: 电厂, 在: base power, 朝向: 0}
    - {单位: 矿厂, 在: base refinery}
    - {单位: AlliedTechStructure, 在: observatory, 角色: observatory}
    - {单位: 百合子, 在: observatory yard, 偏移: [250, 0], 角色: yuriko}
    - {单位: 式神护卫, 数量: 3, 在: observatory yard, 偏移: [330, 0], 角色: shikigami}
    - {单位: 守护者坦克, 数量: 2, 在: observatory yard, 偏移: [200, -200], 角色: loan tank}
    - {单位: 帝国武士, 数量: 4, 在: observatory yard, 偏移: [200, 200], 角色: warrior}
    - {单位: 兵营, 在: merc barracks, 阵营: 敌, 角色: merc barracks}
    - {单位: 战车工厂, 在: merc factory, 阵营: 敌, 角色: merc factory}
    - {单位: 电厂, 在: merc power, 阵营: 敌, 角色: merc power}
    - {单位: 矿厂, 在: merc refinery, 阵营: 敌, 角色: merc refinery}
    - {单位: 守护者坦克, 数量: 2/3/4, 在: merc camp, 阵营: 敌, 角色: merc guard, 守: merc camp}
```

观测站是盟军的科技中心（写模板名，免得按"我"的阵营编成帝国的），归玩家守。式神护卫是这一关解锁的新单位。帝国的建筑现在还不能加造新单位（`可造` 只做了盟军和苏联），这一关先只给开局的三个。

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 布防 | 把式神摆在百合子前面、打开护卫；补兵 | 没有：1:00 准备 | 式神怎么用 |
| 撤数据 | 守住观测站、别让百合子倒下 | 南北两条山口轮流来雇佣兵，有的专打百合子；东边营地交给遭遇战 AI，拆掉兵营和战车工厂它就造不出兵 | 护卫 + 火力 |

```yaml
段:
  - 名字: 布防
    目标: [守住观测站, 百合子必须活着]
    开场:
      - 通报 未来科技的雇佣兵要来抢观测站的数据。他们会专挑百合子打——把式神挡在她前面，打开护卫。
      - {倒计时: 开局 + 1:00, 文字: 雇佣兵来袭, 直到: 段 撤数据}
    结束: 开局 + 1:00
  - 名字: 撤数据
    目标: [挺到数据撤完, 拆掉雇佣兵营地]
    开场:
      - 通报 盟军开始撤数据了！守住观测站，直到传完。
      - {倒计时: 段 撤数据 + 7:00/8:00/9:00, 文字: 数据撤完}
    存档: 是
```

## 敌人的进攻

- 南北两条山口轮流来，越往后越密（`加码`）；"猎头"一路专打百合子，其余打观测站。
- 东边营地第 2 段交给遭遇战 AI（A7 的做法）。

```yaml
敌方AI:
  性格: 平衡
  基地: merc camp
  资金: 3000/5000/8000
  唤醒: {任一: [段 撤数据, 攻击 merc barracks, 攻击 merc factory]}
  接管: [merc barracks, merc factory, merc power, merc refinery, merc guard]
  上限: {基地车: 0, 兵营: 0, 战车工厂: 0, 电厂: 0, 矿厂: 0, 船坞: 0}

进攻:
  - 名字: 开场试探
    开始: 开局 + 0:30
    兵: {警犬: 2}
    从: north mouth
    打: yuriko
  - 名字: 猎头
    开始: 段 撤数据 + 0:10
    兵: {维和步兵: 3/4/5, 标枪兵: 2/2/3}
    从: north mouth
    打: yuriko
    每隔: 1:30/1:15/1:00
    最多: 5
    加码: {当: 段 撤数据 + 4:00, 兵: {幻影坦克: 0/1/2}, 每隔: 1:10/1:00/0:50}
    预警: 雇佣兵从北边山口冲着百合子来了！
  - 名字: 南路
    开始: 段 撤数据 + 0:50
    兵: {守护者坦克: 2/2/3, 多功能步兵车: 1/1/2}
    从: south mouth
    打: observatory
    每隔: 2:00/1:40/1:20
    最多: 4
    预警: 南边山口有雇佣兵的坦克！
```

## 规则

```yaml
规则:
  - 当: 开局 + 0:15
    做: [通报 式神护卫：打开护卫，周围的敌人都会改打它，飞来的炮弹也会拐过去。它扛得住枪，扛不住重炮。]
  - 当: 血量 yuriko < 50
    做: [通报 百合子受伤了！让式神挡到她前面去。]
  - 当: 血量 observatory < 50
    做: [通报 观测站受损过半！把部队调回来守住它。]
```

## 检查

测试台上的检查（`experimental/cnv/checks/j5.py`），每个写一句它证明什么。

```yaml
检查:
  hold: 观测站和百合子每帧回满血，倒计时走完，任务结束（赢）
  lose: 百合子开局只剩 1% 血、式神不开护卫，第一波猎头到了就把她打倒，任务结束（输）
```
