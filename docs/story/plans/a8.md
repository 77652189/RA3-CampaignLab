# A8 海上发布会 · 策划案（草稿，2026-11-04 重写）

题卡和好玩假设见 [cards/all.md](../../design/cards/all.md) A8。剧情见 [outline.md](../outline.md) A8 行。**这份文件就是关卡本身**（写法见 [README.md](README.md)）。旧的"击落"粗模（三座电厂 + 铁锤 + 牛蛙，玩家的自由号对轰）已归档为 `missions/a8_rough.py`，只留给 units.md 5.6 的有无航母对照用。

## 定位

- 盟军第 8 关，高光关。玩家**有**自由号（只有一艘，丢了就输），第一次把它当会飞的前线基地用：造兵、放无人机、超时空甲板载一队兵跳到别处。
- 考的是一条规则：**平台的炮随浪变，按浪的节奏挑平台，不按距离**。三座平台起伏不同步，总有一座在低处（炮近）；高着的那座（炮远）罩着旁边那座。
- 这一版用 island 图，平台摆在东端的三块地上当占位（真正的"公海平台"要一张海图，归地图线，草稿不等它）。
- 草稿不做：配音、过场、正式平台模型（炮塔是原版哨戒炮、平台是原版电厂）、难度细调。黑匣子小目标（题卡的剧情）草稿不做。

```yaml
关卡: a8
名字: 海上发布会
一句话: 三座供电平台的炮随浪起伏，浪高时打得比自由号远。按浪的节奏挑平台，用超时空甲板把兵送上去，赶在机器预热完之前拆光
地图: island
阵营: {我: 盟军, 敌: 盟军}
时长: 15
```

## 机关

浪：每座平台的两座炮塔是一组，三组相位错开（每 60 秒一周期，每组"浪高"25 秒、其余是"浪低"，三组间隔 20 秒）：总有至少一座在低处，且同一时刻最多两座在高处。炮塔升级的倍率在 `units/platform.py`（高 x2、低 x0.6，原版哨戒炮射程为 1）。节拍从开局 10 秒后开始，让玩家先看一眼。

```yaml
机关:
  浪:
    类型: 节律
    单位: 浪涌炮塔
    开始: 开局 + 0:10
    周期: 60
    开: 25
    组:
      - {角色: gun north, 相位: 0}
      - {角色: gun mid, 相位: 20}
      - {角色: gun south, 相位: 40}
```

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 预热中 | 看浪，挑一座正在低处的平台，把兵跃迁过去 | 平台的炮（高处远、低处近）、标枪兵（专打自由号）；拆掉平台炮就停 | 按浪挑，不按距离 |
| 第二座平台没了 | 接走上一座的兵，下一座正在降下来 | 同上；预热倒计时压着 | 跳上去的兵打完要接走 |
| 最后一座 | 拆最后一座 | 同上；护航机 | 综合 |

```yaml
段:
  - 名字: 预热中
    目标: [摧毁三座供电平台, 自由号必须存活]
    开场:
      - 通报 黑尔的发布会开始了，机器正在预热。三座供电平台的炮随着浪起伏：浪高时它们打得比自由号远，浪低时近。别硬压上去，挑低着的那座，用超时空甲板把兵送过去。
      - {倒计时: 开局 + 12:00, 文字: 机器预热完成还有}
    存档: 是
    结束: 摧毁 platform 1 个
  - 名字: 第二座平台没了
    开场:
      - 通报 "先生，第二座平台没了。"发布会上的价格报到一半被打断了。接走上一座平台的兵，下一座正在降下来。
    存档: 是

  - 名字: 最后一座

```

## 敌人的进攻

平台是固定的，压力主要来自炮、标枪兵和倒计时；加一小队护航机在 3 分钟后找自由号，逼玩家别让它一直挂在原地。

```yaml
进攻:
  - 名字: 护航机
    开始: 开局 + 3:00
    兵: {阿波罗战机: 2/2/3}
    从: east 2
    打: carrier
    预警: 平台的护航机起飞了，冲着自由号来！
```
