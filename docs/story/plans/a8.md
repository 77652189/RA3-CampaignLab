# A8 海上发布会 · 策划案（草稿，2026-11-04 重写）

题卡和好玩假设见 [cards/all.md](../../design/cards/all.md) A8。剧情见 [outline.md](../outline.md) A8 行。**这份文件就是关卡本身**（写法见 [README.md](README.md)）。旧的"击落"粗模（三座电厂 + 铁锤 + 牛蛙，玩家的自由号对轰）已归档为 `missions/a8_rough.py`，只留给 units.md 5.6 的有无航母对照用。

**v8 改版方向（2026-11-16，未实装，下文仍是旧草稿）**：前面加"用防盗系统把船偷走"一段。旧稿开场就给船、船毁即输，不能只在前面加一道谜题就算接好。Dot 的意见（RA3-RE-notes #19）：**一次短演示交代规则 → 可以安全反复试的夺船区 → 永久到手后马上把它当攻平台的前线基地**。15 秒考的是"知道什么时候、为什么开火"，不是"满血航母的火力检查"。

- **规则要补全，玩家推理对了才不像变魔术**：
  - "退回几秒前，那时主人是我"只解释了"此刻归我"，解释不了"15 秒到点为什么不还回去"。所以加一条：成功恢复我方所有权时，临时控制转为正式登记，原来的归还请求作废，发射器的计时本身不倒退。代码层面已有 `Rw Perm` 表达这条，演示画面和成功反馈也要表达出来。
  - 必须先让"几秒前的主人"变成你再触发回溯：一接管就打穿，记录可能还是敌方。要给可读的状态，比如"存档主人：未来科技 / 盟军"，或一条记录更新提示。
- **教法**：
  - 只演示一次。黑尔用一艘**样船**演示，不用真自由号，免得耗掉一次性旗标；按同一规则演，不偷换逻辑。
  - 按钮只写"临时接管 15 秒"，目标写"取得自由号的永久控制权"。第一次就想到的玩家要能直接成功，不强制失败两次。
  - 怎么攻击友军（强制攻击操作）、记录何时变成我方，这两样要明示，不拿来当谜。
- **提示梯度按误解升级**（时间是灰盒首版建议，只在能操作的尝试阶段累计）：
  - 第一次自然归还：只说"临时控制结束"。
  - 45–60 秒没进展，或第二次只控制不攻击：提示"恢复的不只是血量，还有那一刻的主人"。
  - 接管后立刻击穿、回到敌方：直接指出"要先让记录更新"。
  - 等到更新再开火但没打到门槛：给火力、射程、剩余时间的反馈。
  - 90–120 秒仍无进展：给完整步骤。
  - 已经成功：取消所有待播提示。
- **15 秒的公平性**：
  - 先布置再按发射器：预置一队确实能打到空天航母的对空单位（旧稿的守护者要实测，不能假定）。
  - 允许预削血，血条标出真正的触发线；预削太狠触发了敌方恢复，也只算一次试验，不耗掉唯一机会。
  - 计时从玩家真能操作时开始。火力按扣掉等记录、转向、锁定、弹道后的有效射击时间实测，不按纸面 DPS 乘 15。
  - 发射器可以重复用，冷却先试 10–15 秒并显示出来；关键火力打光了要有保底补充。
  - 成功后停掉这段教学的我方攻击、处理在途弹丸，免得刚到手又被自己打穿一次。敌方误伤帮了最后一击也按同一规则算。
- **前后两半是同一场发布会**：
  - 夺船区就在会场外围，三座平台和预热设备开局就看得见，玩家知道最终要断电，只是缺一个前线基地。
  - 夺船成功后海军沿看得见的航道到达，第一次甲板运输直接服务最近的平台，第一个浪低窗口放宽；后两座平台再要求比相位、选路线。
  - **正式预热倒计时从夺船成功后开始**（前半是演示和准备阶段），不让学谜的时间偷偷耗掉时限；存档点放在可重试夺船前、交接成功后。
- **后半保留回溯，但不再抢所有权**：
  - 回溯有可见的冷却或代价，只恢复船自己的状态；平台被拆、护航损失、任务时钟都不回退（沿用 A7 的"它能回去，战场进展不回去"）。
  - 压力来自平台和时限，不来自船受伤。要验"故意自伤反复回血"会不会成为最优解。
  - 不给每座平台再装所有权谜题：第一次是发现漏洞，后半是享用成果。
  - 旧稿"船毁即输"的文案和测试要跟真实实现统一。
- **和现有实现的差距（要实现再验证，不是现成事实）**：
  - `experimental/cnv/benches/body_death/state/scenes.py#engine_rewind` 有两种语义。真回溯分支每秒记 `Own1/2/3`、读旧主人、设 `Rw Perm`；当前的原地残骸演出版 `swapped` 是 15% 触发、补到 50%、按**触发当时**的主人定永久，并且只触发一次。
  - 检查脚本里有"过早击穿归敌 / 只控制会还回 / 组合后永久"的定义，但不等于都已台上通过；`swap` 检查靠 `NAMED_DAMAGE 99999` 保证触发，证明不了这队火力能在 15 秒里自然完成。
  - "冷却中可击毁、回溯保命但不无敌"也是待验证的约束：`ImmortalBody` 的测试记录显示 `NAMED_KILL` 也杀不死它。
- **用户定（2026-11-16，按总控推荐）**：规则认**几秒前的主人**（每秒记一次主人，回溯时读旧记录定永久）；画面仍是 11-11 选的原地残骸再出现，只当表现。要做的：把真回溯分支的每秒记主人接进原地残骸版，再上台验证上面三条检查。
  - 先用单次演出做灰盒的话，标明"只验证了夺取，没验证后半自保"。
- **灰盒先验这些边界**：
  - 历史语义：接管后马上触发、记录更新后触发、15 秒前后触发，各归谁。
  - 永久语义：跨过到期时间、再次回溯、读档后仍归我；到期归还和成功同帧时谁优先。
  - 玩家手动强攻：射程、对空、停火，慢手也能完成。
  - 反复尝试不耗尽一次性旗标；连点发射器不产生互相争抢的归还请求。
  - 夺船后哪些回退、哪些保留：外部计时、平台、损失不回退；生产队列、乘员、能力冷却逐项实测。
  - 第一次玩的人能说清"这次为什么永久归我"，并很快用这艘船做出新的战术选择。

## 定位

- 盟军第 8 关，高光关。玩家**有**自由号（只有一艘，丢了就输），第一次把它当会飞的前线基地用：造兵、放无人机、超时空甲板载一队兵跳到别处。
- 考的是一条规则：**平台的炮随浪变，按浪的节奏挑平台，不按距离**。三座平台起伏不同步，总有一座在低处（炮近）；高着的那座（炮远）罩着旁边那座。
- 这一版用 island 图，平台摆在东端的三块地上当占位（真正的"公海平台"要一张海图，归地图线，草稿不等它）。
- 草稿不做：配音、过场、正式平台模型（炮塔是原版哨戒炮、平台是原版电厂）、难度细调。黑匣子小目标（题卡的剧情）草稿不做。

## 机关

浪：每座平台的两座炮塔是一组，三组相位错开（每 60 秒一周期，每组"浪高"25 秒、其余是"浪低"，三组间隔 20 秒）：总有至少一座在低处，且同一时刻最多两座在高处。炮塔升级的倍率在 `units/platform.py`（高 x2、低 x0.6，原版哨戒炮射程为 1）。节拍从开局 10 秒后开始，让玩家先看一眼。

## 敌人的进攻

平台是固定的，压力主要来自炮、标枪兵和倒计时；加一小队护航机在 3 分钟后找自由号，逼玩家别让它一直挂在原地。

```yaml
进攻:
  - 名字: 护航机
    开始: 开局 + 3:00
    兵: {阿波罗战机: 2/2/3}
    从: east 2
    打: carrier
    预警: 平台的护航机起飞了，冲着自由号来！
```

## 规则

```yaml
规则:
  - 当: 开局
    做: [通报 自由号的超时空甲板每 45 秒能把一队地面部队送到视野里的任意一点。先看哪座平台的炮近。]
  - 当: 浪.开 gun north
    做: [通报 北边那座平台浪高了：它的炮现在打得很远。]
  - 当: 浪.开 gun mid
    做: [通报 中间那座平台浪高了：它的炮现在打得很远。]
  - 当: 浪.开 gun south
    做: [通报 南边那座平台浪高了：它的炮现在打得很远。]
```

浪高的提示只在每座第一次升起时报（规则只做一次），教玩家"炮会忽远忽近"；之后靠玩家自己看（草稿的看得懂层，真正的视觉提示等单位线换模型）。
