# A1 金门不锁 · 策划案（草稿，2026-11-04）

题卡见 [cards/all.md](../../design/cards/all.md) A1，流程稿见 [flow/a1.md](../../design/flow/a1.md)，剧情见 [outline.md](../outline.md) A1 行。**这份文件就是关卡本身**（写法见 [README.md](README.md)）。地图是 `maps/golden.py`（金门大桥，新做，A1 专用；外壳线的草图命令行出的，草图格式 [docs/shell/sketch-format.md](../../shell/sketch-format.md)）。

## 定位

- 盟军第 1 关，难度 1，教 K3 先后：**桥上埋着炸药，引信在两座桥塔顶的爆破手手里，看见自己人倒下就按**。北塔看得见南塔和桥面；南塔只盯着南岸。先打近的（南塔、桥面）正好是最坏的顺序。
- **碰了就输要公平**（11-05 第二轮验收 I20：开局全队右键往桥头走，约 38 秒结束、部队没少）：根因是兵路过会**自己开火**，南岸巡逻原来站在桥头 (1960, 620)，离出生点只 420，一走近就被打倒、第 3 条规则成立。修法：巡逻往桥上挪 160（`偏移 [0, 160]`），"走到桥头"不再进他们的射程；再加地点 `patrol watch`（半径 450，`maps/golden.py`），队伍一进来先通报一句"停下"。**停火姿态试过，不行**（11-05 测试台四次：`UNIT_SET_STANCE` 3 + `UNIT_ALLOW_AI_AUTOACQUIRE` 0、`TEAM_SET_STANCE`、`PLAYER_ALLOW_AI_AUTOACQUIRE` 0 都设过，守护者坦克照样开火，同样 13 秒结束）。
- 机关只有三条规则（"谁看见谁"），不需要新设备：爆破手是动员兵，分角色，脚本在**北塔还活着时**看到桥面守军倒下、南塔爆破手倒下，或**南塔还活着时**南岸巡逻倒下，就直接判失败（引信点着了）。
- 三段：摸上北塔（谭雅走海湾水道的浅滩，或游隼清掉哨位）→ 拆南塔（北塔没人看了）→ 过桥（基地车、双刃炸桥、夺回车队）。
- **草稿代替的东西**：
  - 游隼（盟军的新轻坦克，`units/` 里没有进名册）→ 用**守护者坦克**顶位；
  - 三辆卡车、北岸兵营工厂、直升机坪建筑：草稿不摆，"夺回车队"= 北岸码头敌人清空；
  - **桥断即失败没做**：桥是原版桥物件，没有血量；双刃直升机来炸桥面，草稿里只当压力（炸桥面上的兵），桥不会断（待做第 2 条）；
  - 不做：配音、过场、"不惊动桥面巡逻"奖励目标、黑尔和沃斯的台词（只有通报）。
- 难度只调数（铁锤坦克数、直升机数），不改结构。

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 摸上北塔 | 谭雅走海湾水道的浅滩摸上北塔；别碰桥面、南桥头巡逻、南塔 | 没有进攻，**压力是规则**：碰近的就输；防空兵哨位要先清（游隼/坦克沿浅滩打） | 先看谁看见谁，再动手 |
| 拆南塔 | 谭雅（或兵）上南塔，打掉爆破手 | 北塔没人看了，南塔只盯着南岸：不碰南桥头巡逻就行 | 顺序对了很松 |
| 过桥 | 展开基地车、造兵、过桥、清码头 | 铁锤坦克压桥头，双刃直升机炸桥面（标枪兵、多功能步兵车克制） | 备防空 |

## 规则

三条"谁看见谁"的规则是这一关的题：每条成立就直接判输。"北塔还活着"写成"还没进第 2 段"（`摧毁` 不是一次成立就一直成立的事，`还没` 只认 `段`）；"南塔还活着"写成"还没进第 3 段"。其余是提示和保底。

```yaml
规则:
  - 当: [摧毁 deck guard 1 个, 还没 段 拆南塔]
    做: [{失败: 桥面上有人倒下，北塔按下了引信。}]
  - 当: [摧毁 south bomber, 还没 段 拆南塔]
    做: [{失败: 南塔倒下，北塔第一个看见。}]
  - 当: [摧毁 south patrol 1 个, 还没 段 过桥]
    做: [{失败: 南岸有人倒下，南塔按了引信。}]
  - 当: [进入 patrol watch, 还没 段 过桥]
    做: [{通报: 停下！再往桥头走，兵会自己开火，南塔的人看见就按引信。先绕海湾。, 功能: 是}]
  - 当: [开局 + 2:00, 还没 段 拆南塔]
    做: [通报 南塔盯着南岸，北塔盯着南塔和桥面。谁先倒，另一个就按。]
    每隔: 2:00
  - 当: [进攻 双刃炸桥 开始, 兵少于 2 标枪兵、多功能步兵车]
    做: [{给: {多功能步兵车: 2}, 在: south camp}, 通报 给你送了几辆防空车。桥别让他们炸了。]
```

## 待做（A1 草稿还差什么）

1. **游隼**进名册（现在用守护者坦克顶位）；谭雅能不能游浅滩、浅滩上的哨位怎么清，整局实打一次。
2. **桥断即失败**：桥面要有血量（原版桥不是单位）；候选：桥头放一座可摧毁的中立建筑当"桥基"，直升机打它；或用桥面兵的损失量代替。
3. 三辆卡车、北岸兵营和工厂、直升机坪建筑、"不惊动桥面巡逻"奖励、沃斯/司令/黑尔台词和过场。
4. 爆破手是动员兵占位（要有望远镜/炸药桶造型）；"看见"现在是脚本规则（摧毁条件），不是真视野：玩家用射程外手段（空军、远程）打倒桥面守军也算被看见。
5. 数值（巡逻人数、压桥节奏、直升机数）要玩家试。
