# 策划案怎么写

这个文件夹里每个 `<关号>.md` 是一关的策划案（例子：[a4.md](a4.md)）。**策划案就是关卡本身。** 编译时读文件里所有 `yaml` 代码块，生成这一关的地图物体、脚本和目标；代码块外面的文字写设计意图，编译时不读。

所以改玩法只要改策划案：
1. 改 `yaml` 块里的内容；
2. 跑 MCP 的 `plan_show(<关号>)`，几秒钟出节拍表、对照原版的设计检查和接口检查，不用进游戏；
3. 跑 MCP 的 `plan_sim(<关号>, <剧本>)`，几秒钟推演出这一关的时间线和结局（下面"模拟器"一节）；
4. 只有要看引擎行为、或者最后和游戏对齐时，才跑 `cnv_check(<关号>, <检查>)` 上测试台，或者 `python -I -X utf8 experimental/cnv/build.py <关号>` 编出来，从测试启动器进游戏玩。

能写哪些词，用 MCP 的 `plan_vocab` 查（带地图名，例如 `plan_vocab(festival)`，还会列出这张地图的地点和边界）。原版是怎么做的、为什么这么排，见 [map-language.md](../map-language.md) 第 7 节。

## 模拟器

不开游戏，把编出来的任务脚本按游戏的规则跑一遍（`experimental/cnv/sim.py`；用户 2026-10-27：日常开发用它，测试台只留给引擎行为和最后的对齐）。

- **怎么跑**：MCP `plan_sim(name, script, check, level, until)`；命令行 `python -I -X utf8 experimental/cnv/sim.py <关号> [--check 检查] [--script "剧本"]`。一关几秒。
- **剧本**是玩家这边做了什么，一行一件事（或者用 `;` 隔开），时间写秒或 `分:秒`：
  - `60 派 tank 去 north camp`：派兵（地点、标记、触发区、物体名都行）；
  - `120 摧毁 north barracks`、`删除`、`90 血量 yuriko 1`、`打 <谁>`、`占领 <谁>`；
  - `40 造 CNV_IceWall 在 inside 2 1.57`：玩家做出来的东西，比如工兵的冰；
  - `自动打掉 5`：敌人在玩家东西 300 以内待满 5 秒就算被打掉（玩家在还手）；`不打`：关掉战斗模型，只看接线；
  - 不写就是"不动"。`<谁>` 写角色名（`yuriko`）、一组角色（`tank` = tank 1、tank 2……）、物体名、`名字含 W1-`（第一股波次）、`敌人 在 <地点>`。
- **输出**：
  - 带秒数的时间线：通报、目标亮出和完成、边界、揭图、镜头、倒计时、单位出现（玩家看不看得见）、易主、摧毁；
  - 结局：赢、输、卡住。没结束时，列出每条输赢脚本还差哪些条件；
  - 张力曲线（每分钟：玩家 800 以内的敌人数、敌我火力比、玩家剩余血量）、已知区域、第一股敌人是哪条脚本在什么条件下造出来的、第一次有单位阵亡的时刻；
  - 这次推演用到的假设，也就是待对齐的地方。
- **所有可能的走向**（`experimental/cnv/simstatic.py`，`plan_sim` 一起给）：每个难度下哪些段永远到不了、能不能赢、能不能输、哪些主目标完成不了、哪些脚本永远触发不了；等了却没有脚本去设的旗标、计时、计数。
- **单位怎么动**：速度、视野、能走的地面（陆、水、两栖、飞）取自游戏数据（`simunits.py`）。路线在地图自己的高度图上求：建筑和我们的冰墙、闸门挡路，桥面上的东西不挡（测试台 2026-10-27 `reroute`）；`IMMOBILE` 的单位不动，`UNATTACKABLE` 的剧本里摧毁不了。
- **战斗**：确定性的近似，数据取自游戏（血量、武器的伤害和射程、一梭子加装弹的射速、护甲对各伤害类型的百分比，`simunits.fight`）。每个有武器的单位打射程内最近、打得着的敌人；攻击移动的单位遇敌停下来打，普通移动边走边打；不追击，没有溅射、升级、驻军和技能。剧本的 `摧毁`、`自动打掉` 照样能盖过战斗结果。整套标"未对齐"，最后拿测试台的结果调参数。
- **高地视野**（未对齐）：按策划线地形卡（[terrain.md](../../design/teardowns/terrain.md) 第二节，用户 2026-10-27 确认）：比自己脚下高出 40 以上的地方看不见，看不见的打不了；飞机不受限；远程轰击单位开火后 3 秒内谁都看得见它。《将军》源码里视野是不看高度的圆，地形只挡直射武器的弹道，所以两种说法都记在待对齐清单里；`高地不挡` 关掉这条规则作对照。2026-10-27 拿 11 关"不动"对照，开和关结局、第一次阵亡时刻都一样：我们的高地上没有守军和低处对峙。
- **不模拟的**：遭遇战 AI 造什么、什么时候进攻，只按脚本给的路线和目标走。
- **检查的模拟器版本**：`experimental/cnv/simchecks.py` 列出只看接线的检查，每个写好剧本和应有的结局，`tests/test_sim.py` 每次都跑；测试台版本留着。
- **规则从哪来**：引擎语义按《将军/绝命时刻》官方源码定（[docs/engine/script-semantics.md](../../engine/script-semantics.md)）：没设过的计时器算没到；没出现过的物体既不算被摧毁也不算活着；被打死的单位播死亡动画时还在原地、血量读 0%、还被计数；删掉的单位下一帧才算被毁；"被玩家攻击"只看最近一次伤害；同一帧里赢和输都满足会报警。
- **待对齐清单**：`python -I -X utf8 experimental/cnv/sim.py --align` 打印。标"未对齐"的是源码定不了、要等测试台确认的：取反怎么求值、红警3的逻辑帧率、我们的脚本按哪个阵营的难度过滤、切边界前的永久揭图盖不盖得到新区域、按类别数区域时算不算所有玩家（实测算，和《将军》不同）、死亡动画多长、红警3独有的 30 个动作和条件。

## 词表

<!-- plan_vocab 从这里读到"## 例子"为止 -->

**难度**：会随难度变的数写成 `简单/普通/困难`，例如资金 `5000/3000/2000`、时间 `4:00/3:00/2:30`、兵力 `2/3/4`。只写一个数，就是三个难度一样。原版只改数，不改分段结构，这里也一样。

**时间**：`0:30`、`3:00`、`90`（秒）、`90秒`、`4分钟`。条件后面的时间可以写成随机的 `最早~最晚`，例如 `开局 + 0:15~0:30`：每局在这中间随机挑一刻（原版伏兵就这样出动）。节拍表按最晚的算。

**名字**：
- 地点：地图公开的地点名（`plan_vocab(<地图>)` 列出），例如 `west field`、`harbour`。
- 角色：开局部队里写了 `角色` 的那些。数量大于 1 时编号，例如角色 `engineer` 数量 2 就是 `engineer 1`、`engineer 2`；只写 `engineer` 指它们全部。
- 单位：中文名（`plan_vocab` 列出）。通用的建筑和单位（建造厂、兵营、基地车……）按阵营换成那个阵营的；也可以直接写模板名，例如 `AlliedAntiVehicleVehicleTech1`。我们的新单位（超时空信标兵、钻地运兵车……）也按名字写，和原版单位一样能摆、能造、能当援军和进攻的兵。

### 一关的各部分

| 写什么 | 意思 |
|---|---|
| `关卡` `名字` `一句话` | 关号、关名、一句话玩法（测试启动器显示这两样） |
| `地图` | 用哪张地图 |
| `阵营: {我: 盟军, 敌: 帝国}` | 双方阵营（盟军 / 苏联 / 帝国）。还有第三方时加 `其他: {哨所: 盟军, 叛军: 盟军}`：开局对双方都中立，部队的 `阵营` 就写这些名字。要它和玩家结盟，写成 `其他: {护送队: {阵营: 盟军, 对我: 盟友, 对敌: 敌人}}`（`对我`、`对敌` 是 盟友 / 中立 / 敌人，默认中立）：它的单位玩家点不了，敌人会打它（原版敖德萨、斯大林格勒的运输船就是这样单独一方）；车队机关的 `车` 写它的名字。玩家的维修厂修不到它的车（测试台 2026-10-27） |
| `时长` | 这一关大概多少分钟 |
| `音乐` | 这一关自己的配乐：`experimental/music` 里的名字，例如 `音乐: a4`。写了就能用动作 `音乐 <提示词>` 和 `战况音乐 开`，胜利、失败时自动先放胜负收尾；不写就是原版音乐。能用的提示词见那个模块开头的 `CUES` |
| `边界` | 开局时的地图边界（地图公开的边界名）；不写就是全图 |
| `开局` | `资金`，和 `部队`：一串 `{单位, 数量, 在, 偏移 [东, 北], 阵营 我/敌, 角色, 守, 朝向}`。`守: <地点>` 让它们守在那里；数量随难度变时，按最难的摆，简单难度删掉多的（原版的做法）。`无敌: 是`：谁都瞄不了它，脚本还能摧毁它（动作 `取消无敌` 解除）。`难度: 困难` 或 `难度: [普通, 困难]`：只在这些难度摆 |
| `可造` | 玩家的哪种建筑能造我们的新单位：`{兵营: [冰幕工兵]}`。新单位排在原版那几个后面；玩家的这种建筑和建造厂都换成我们的复制（开局摆的、`给` 的、后来自己造的都是），所以条件 `建成 兵营` 照样能写。只能写我们的单位（`plan_vocab` 末尾"我们的新单位"那些，或机关公开的），原版单位本来就能造。还不管：基地车展开、起重机造出来的仍是原版的；帝国的建筑（核心展开）不行 |
| `机关` | 这一关自己的机关：`{名字: {类型: <机关类型>, 参数...}}`。机关类型、参数、事件和动作见 `plan_vocab` |
| `段` | 按顺序的几段：`{名字, 目标 [这一段亮出的目标], 边界, 过场 [一步步], 开场 [动作], 存档, 结束 (条件)}`。第一段开局就开始；上一段的"结束"成立，下一段开始。目标在段开始 2 秒起每隔 4 秒亮一个（有过场就从交还控制起算；写了 `亮出` 的不排进来） |
| `过场`（段里） | 这一段开始时先放一段过场（原版 40 关里 36 关开场有镜头领着看）：从段开始就锁住玩家的输入、上下黑边，按顺序一步步走，走完把输入还给玩家。每一步是一个动作；`{镜头: <地点或角色>, 秒: 3}` 移过去、占这么多秒；`{跟随: <角色>, 秒: 4}` 镜头跟着它走这么多秒；`{停: 2}` 停 2 秒；`{揭全图: 看一眼}` 揭开全图，交还控制时收回（原版斯大林格勒）；别的动作（通报、技能、机关的动作、`{闪烁: <角色>}`）当场做、不占时间——让镜头当着它发生，例如先 `镜头` 到冰雕、再让它裂开、再 `停`。最后一步写 `镜头` 回到玩家身边。过场多长是 `过场 <段名>`（秒，`cnv_show` 的 facts），检查可以问 |
| `目标` | `{标题: {奖励, 说明, 标记, 完成, 失败, 亮出}}`。`标记` 是一串角色或地点，绿色标记挂在上面；写成 `{角色: 条件}` 的，条件成立时摘掉那一个。奖励目标写 `奖励: 是`，屏幕上是黄色的。`亮出: <条件>`：不按时间亮，等条件成立才亮（在哪一段的 `目标` 里，就还要那一段开始了），例如 `亮出: 进入 <地点>`——原版 43 个奖励里 13 个是走近才亮的；不在任何一段里的目标必须写 `亮出` |
| `进攻` | 一串 `{名字, 开始, 兵 {单位: 数量}, 从 (地点), 打, 守, 每隔, 最多, 来源, 加码, 预警}`。`打` 写地点（攻击移动过去）、角色（打它）、机关名（机关决定打谁，例如车队：最前面那辆车）或 `猎杀`；`守: <地点>` 则守在那里。`每隔` 写了就一波一波来，`最多` 是上限；`来源` 是一串角色，全被摧毁就不再来；`直到: <条件>`（只能是成立后一直成立的）成立以后不再来，例如 `直到: 敌方AI 醒来`——营地交给遭遇战 AI 以后，脚本波次就停，压力交给 AI（A4 北营）；`加码: {当: 条件, 兵: {...}, 每隔: 时间}` 条件成立后每波多这些兵、波次间隔换成这个（更快；要先写了外面的 `每隔`）；`预警` 是每波出发时的通报。`开始` 是任意条件：第一股敌人等玩家推进才动，就写 `开始: 进入 <地点>`、`开始: 攻击 <角色>`，或 `{任一: [进入 <地点>, 开局 + 3:00]}`（按时兜底）——原版 40 关里 22 关的第一股敌人是这样，按时出动的只有 3 关。开局就摆好的守军等玩家走近才出动，用规则：`{当: 进入 <地点>, 做: [{出动: <角色>, 打: <地点>}]}` |
| `规则` | 一串 `{当: 条件, 做: [动作]}`：条件第一次成立时做这些，只做一次。加 `每隔: 0:30`：条件成立时马上做一次，之后只要条件还成立，每隔这么久再做一次（原版的重复催促）。加 `难度: 困难`（或一串难度）：只在这些难度生效 |
| `敌方AI` | 把"敌"交给游戏自己的遭遇战 AI，让它自己造基地、补兵、进攻（原版的持续压力都从这来）：`{性格, 偏好, 上限, 分档, 基地, 资金, 唤醒, 接管, 修理, 重建, 技能}`。`分档: [{当: 敌方AI 醒来 + 2:00/1:30/1:00, 放开: [海啸坦克, 天狗]}, ...]`：写进任何一档的兵种开局不许它造，那一档的条件成立才放开（原版斯大林格勒：苏军 AI 醒来后按时间先步兵、再战车、再飞机，难度越高放得越快）；同一种兵也写了 `上限` 的，放开以后照上限管。分档只管"不许造"，不管"一定造"：测试台 2026-10-27 扣住的步兵车放开前一辆没有、放开后才造；可同一个盟军 AI 写了 `偏好: {守护者坦克: 5}` 也一辆守护者都不造，只造四辆步兵车就停了——放开的兵种它造不造、造多少，要上测试台看。AI 是"敌"的一个盟友玩家（原版宫古岛也这样分）：写了 `阵营: 敌` 的部队、机关的单位都还归策划案指挥，AI 碰不到；`接管: [角色, ...]` 是醒来时交给 AI 的建筑和部队（例如东岸的兵营、战车工厂、机场、电厂、矿厂），它用这些造兵；那片基地里的守军也要写进来（原版宫古岛醒来时也把部队交给 AI）：留给"敌"的守军会打 AI 的建筑（测试台 2026-10-26：守大门的坦克把 AI 的兵营打掉了，原因还没查清）。要给它收入（矿厂和矿车写进 `接管`）：测试台 2026-10-26（A4 北营，帝国）没给矿厂时它钱花到一部分就停了、一直不出击，给了以后醒来约 4 分钟第一次下山；也不要给帝国 AI 建造厂——帝国先造核心再展开，按建筑设的 `上限` 拦不住，它马上多盖了一座兵营、把钱花光。`敌人清空` 只看"敌"自己，不看 AI 的兵。`性格` 从这个阵营的遭遇战指挥官里挑打法（盟军：平衡 / 空军 / 特种；苏联：平衡 / 突击 / 空军；帝国：平衡 / 机甲 / 海军，默认平衡）；`偏好: {单位: 倍数}` 让它多造或少造某种兵（0 = 不造），我们的新单位也能写；`上限: {单位或建筑: 最多几个}`，写 0 就是不许造（原版就这样锁住 AI 能造的东西）：只给它造兵、不许盖房子和造基地车，钱才花在兵上，拆掉交给它的兵营、工厂它就真的造不出兵（测试台 2026-10-25：什么都能造时，它把钱花在重建基地上，5 分钟没攒出一次进攻）；`基地` 是地点；`资金` 可按难度写；`唤醒` 是条件：之前它不动也不花钱；之后拿到"接管"的东西，自己造兵、自己进攻，测试台上交给它守军时醒来约半分钟守军就压过来、之后约每 40 秒一波（A7 普通难度），只给建筑时约 1 分钟才第一次交火，所以节奏靠什么时候唤醒来定（原版也是按段、按玩家推进唤醒）；`修理` `重建` `技能`（秘密协议）写 `是` / `否`，默认都是否。编译时按这些生成这一关自己的 AI 性格 |
| `胜利` | 条件：成立就赢 |
| `失败` | 一串 `{当: 条件, 原因}`：成立就输，屏幕上显示原因 |
| `检查` | `{检查名: 它证明什么}`，和 `experimental/cnv/checks/<关号>.py` 里的检查一一对应 |

### 条件

| 写法 | 成立的时候 |
|---|---|
| `开局` | 任务开始 |
| `段 <名字>`、`段 <名字> 开始` | 这一段开始了 |
| `段 <名字> 结束` | 这一段结束了（下一段开始了） |
| `过场 <段名> 结束` | 那一段的过场放完、输入还给玩家了 |
| `进入 <地点>` | 玩家有单位在这个地点 |
| `<角色> 进入 <地点>` | 这个角色到了那个地点（一组就是其中任一个），例如敌方处决者走上桥（原版敖德萨）、侦察兵到村子 |
| `敌方AI 醒来` | 遭遇战 AI 醒了（`敌方AI` 的 `唤醒` 成立过），之后一直算数 |
| `敌人清空 <地点>` | 这个地点里没有"敌"那一方的单位和建筑了（玩家自己的、中立的桥都不算；`其他` 里后来翻脸的一方也不算） |
| `摧毁 <角色>` | 这个角色（一组就是全部）被摧毁 |
| `摧毁 <一组> <n> 个`、`摧毁 <a>、<b>、<c> <n> 个` | 其中任意 n 个被摧毁了（原版哈瓦那的发射点：拆一个算一个） |
| `冻住 <角色>` | 它现在被冻住了（一组就是其中任一个；原版伊贺：目标是冻住，不是打死） |
| `攻击 <角色>` | 玩家打了它 |
| `占领 <角色>` | 它归玩家了 |
| `血量 <角色> < 50` | 它的血量低于 50% |
| `建成 <单位>` | 玩家有了至少一个这种单位或建筑 |
| `没有 <单位>` | 玩家一个这种单位或建筑都没有 |
| `还没 <条件>` | 那件事还没发生：只能用在发生一次就一直算数的事上（`段 …`、`目标 … 完成`、`进攻 … 开始`、机关里这样的事件），例如 `[段 A + 8:00, 还没 段 B]`；带时间的 `还没 X + 4:00` 不行 |
| `目标 <标题> 完成`、`目标 <标题> 失败` | 那个目标完成 / 失败了 |
| `进攻 <名字> 开始` | 那一路进攻开始了 |
| `<机关名>.<事件> 参数` | 机关的事件，例如 `车队.出发`、`车队.到达 halt`、`广场.封住 1` |
| `<条件> + <时间>` | 那个条件第一次成立之后，再过这么久，例如 `开局 + 3:00`、`车队.出发 + 1:00/0:45/0:30` |
| 一串 `[A, B]` | A 和 B 都成立 |
| `{任一: [A, B]}` | A 或 B 成立：原版最常见的进攻写法是"按时到，或者玩家先推进就提前" |

### 动作

| 写法 | 做什么 |
|---|---|
| `通报 <文字>` 或 `{通报: 文字, 秒: 8}` | 屏幕上方的通报 |
| `{镜头: <地点或角色>, 秒: 3}` | 镜头移过去（秒：移动用多久） |
| `{跟随: <角色>, 秒: 4}` | 只在 `过场` 里：镜头跟着它这么多秒 |
| `{停: 2}` | 只在 `过场` 里：停这么多秒 |
| `{闪烁: <角色>}` | 让它闪几下（原版交还控制时闪基地车） |
| `{揭开: <地点>, 半径: 300, 永久: 是}` | 揭开那里的迷雾。半径不写用地点自己的半径（没有就 300）；`永久: 是` 一直开着，直到 `{收回: <地点>}`；不写永久就只看一眼，过一会儿重新盖上 |
| `{收回: <地点>}` / `{收回: 全图}` | 盖回 `揭开 永久` 的那一处 / `揭全图 永久` |
| `{揭全图: 永久}` / `{揭全图: 看一眼}` | 揭开全图；`看一眼` 只能写在 `过场` 里，交还控制时自动收回 |
| `{给: {单位: 数量}, 在: <地点>}` | 给玩家增援 |
| `{资金: +2000}` | 给玩家钱 |
| `{边界: <边界名>}` | 换地图边界（扩大可玩区域） |
| `存档` | 自动存档 |
| `{倒计时: '<条件> + <时间>', 文字: 车队出发}` | 屏幕左下显示到那个时间的倒计时，到点自动收起。加 `直到: <条件>`（只能是成立后一直成立的，例如 `段 …`）：它先成立就提前收起，之后也不再显示——段的"结束"写成"按时或玩家先动"时，两个倒计时都写上 `直到: 段 <下一段>`（A4 布防段） |
| `{摧毁: <角色>}` | 直接摧毁它 |
| `{转给我: <角色>}` | 它归玩家 |
| `{出动: <角色>, 打: <地点 / 角色 / 猎杀>}` 或 `{出动: <角色>, 守: <地点>}` | 开局摆好的部队出发（原版的伏兵到点出动：玩家先打掉，这一路就没了） |
| `{无敌: <角色>}` / `{取消无敌: <角色>}` | 让它谁都瞄不了 / 恢复 |
| `{技能: <技能名>, 角色: <角色>}` | 按下我们的单位的一个按钮技能（`cnv_show` 里单位公开的 abilities，例如干扰车的 `jam`、钻地车的 `burrow`）：敌人的干扰车开局就打开干扰 |
| `{锁住: <角色>}` / `{放开: <角色>}` | 让它怎么下令都不动（还能开火）/ 恢复。船闸关着的舰队就这么写：地图摆在水面上的建筑挡不住船（测试台 2026-10-27） |
| `{翻脸: <其他里的一方>}` | 这一方和玩家互相变成敌人 |
| `胜利` / `{失败: 原因}` | 直接赢 / 输 |
| `<机关名>.<动作>` | 机关的动作，例如 `车队.停下`、`车队.继续` |
| `音乐 <提示词>` | 换配乐段落，例如 `音乐 行进`、`音乐 伏击`（要先写顶层 `音乐`）。卡准时机的（伏击、港口）立刻切，其余等当前小段放完 |
| `战况音乐 开` | 打开游戏自己的战况音乐：之后开打、我方吃亏、扳回来、战斗平息，游戏都自动换段落，关卡不用管。原版在开始交战的那一段打开 |

## 例子

一路"按时到、玩家先动手就提前、拆了兵营就停"的进攻（A4 的北营）：

```
进攻:
  - 名字: 北营小队
    开始: {任一: [车队.出发 + 1:30/1:00/0:45, 攻击 north barracks]}
    兵: {帝国武士: 2/3/4, 坦克杀手: 0/1/2}
    从: north base
    打: 车队
    每隔: 1:30/1:15/1:00
    最多: 6
    来源: [north barracks]
```
