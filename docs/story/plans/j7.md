## 定位

- 帝国第 7 关。不解锁新单位；本关的题是对付苏联的新单位干扰车（S6 解锁的）：它停在谷口，冲进去的全都慢下来。
- 类型：限兵力突袭（原版敖德萨、伊贺开头：固定兵力、没有基地）。玩家要学会：先找到并拔掉干扰车，或者绕开它，再冲发射塔。
- 剧情：苏联要把"时间卫星"送上轨道。帝国突击队从东边三条山谷杀向发射场，要在倒计时走完前拆掉发射塔。

```yaml

地图: baikonur
阵营: {我: 帝国, 敌: 苏联}

```

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 突破 | 纸鹤侦察看清三个谷口，挑一路先拔掉干扰车，再冲发射塔 | 倒计时；谷口的干扰车和守军；西边苏军基地第 2 段醒来 | 对付干扰车：先拔它，或者从它罩不到的地方过 |
| 最后冲刺 | 拆掉发射塔 | 苏军的 AI 增援；倒计时 | 抢时间 |

```yaml
段:
  - 名字: 突破
    目标: [赶在发射前拆掉发射塔]
    开场:
      - {镜头: east base}
      - {技能: jam, 角色: north jammer}
      - {技能: jam, 角色: middle jammer}
      - {技能: jam, 角色: south jammer}
      - {倒计时: 开局 + 8:00/7:00/6:00, 文字: 发射}
      - 通报 苏联人要把"时间卫星"送上天。三条山谷的谷口都停着干扰车，冲进去的东西全会慢下来。先用纸鹤看清楚，挑一路先拔掉干扰车。
    结束: {任一: [摧毁 north jammer, 摧毁 middle jammer, 摧毁 south jammer, 开局 + 3:00]}
  - 名字: 最后冲刺

    开场:
      - 通报 苏军基地派兵来守发射塔了！抓紧时间。
    存档: 是
```

## 敌人的进攻

- 西边苏军基地第 2 段交给遭遇战 AI，造兵守发射塔、出来追玩家（只许造兵）。
- 开局 40 秒一小队动员兵从发射场出来试探。

```yaml
敌方AI:
  性格: 平衡
  基地: start
  资金: 3000/5000/8000
  唤醒: {任一: [段 最后冲刺, 攻击 west barracks, 攻击 west factory]}
  接管: [west yard, west barracks, west factory, west power, west refinery]
  上限: {基地车: 0, 兵营: 0, 战车工厂: 0, 电厂: 0, 矿厂: 0, 船坞: 0}

    从: launch yard
    打: east base
```
