## 定位

- 苏联第 2 关。解锁装甲列车（脚本车：沿着铁路开，玩家只能瞄准和刹车）。
- 类型：追。玩家要学会：装甲列车边走边打、打不坏，但只能沿着轨道走；轨道外面的事交给步兵和坦克。
- 剧情：宿敌用冷冻列车运走被冻住的老兵。冷冻列车每到一站停下装货，玩家的装甲列车沿着同一条铁路追，在它开出地图前截住它。中途匿名金主第一次送来物资（伏笔）。

```yaml
关卡: s2
名字: 西伯利亚快车
一句话: 追车。装甲列车沿铁路追盟军的冷冻列车，它每站都要停，在它开出地图前打掉它
地图: siberia
阵营: {我: 苏联, 敌: 盟军}
时长: 12
```

## 开局

玩家没有基地：装甲列车停在西边的岔线，旁边一小队镰刀和动员兵。冷冻列车已经开到了前面的西站。沿线三个车站各有盟军守军。

## 机关

两辆列车，都沿同一条铁路开：玩家的装甲列车一开局就开；冷冻列车在前面，每到一站停 25/20/15 秒装货。

```yaml
机关:
  装甲列车:
    类型: 列车
    角色: armoured
    起点: west siding
    路线: [west station, birch station, bridge west, river station, east station, line exit]
    出发: 开局 + 0:10
  冷冻列车:
    类型: 列车
    角色: cryo
    阵营: 敌
    起点: west station
    路线: [birch station, bridge west, river station, east station, line exit]
    出发: 开局 + 0:05
    停靠: 25/20/15
    血量: 4000
```

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 追车 | 跟着冷冻列车，打掉沿线的守军，追上就打 | 各站的守军；冷冻列车按时走 | 装甲列车边走边打；轨道外靠别的兵 |
| 过河 | 冷冻列车过了河，金主的物资送到 | 河东两站的守军更硬 | 用好补给 |

```yaml
段:
  - 名字: 追车
    目标: [截住冷冻列车]
    开场:
      - 通报 宿敌的冷冻列车拉着被冻住的老兵往东开。它每到一站都要停下装货：开上装甲列车追上去，在它开出地图前打掉它。
    结束: 冷冻列车.到站 river station
  - 名字: 过河
    目标: [装甲列车不能丢, 拔掉河东站的守军]
    开场:
      - {给: {镰刀: 2, 铁锤坦克: 2}, 在: west station}
      - 通报 一位不愿透露姓名的朋友送来了一批坦克。冷冻列车已经过河了，抓紧！
    存档: 是
```

## 检查

测试台上的检查（`experimental/cnv/checks/s2.py`），每个写一句它证明什么。

```yaml
检查:
  catch: 两辆列车都沿着铁路开；冷冻列车在每站停靠，装甲列车追到它身后；测试脚本在冷冻列车到河东站时把它打掉，任务结束（赢）
  escape: 玩家什么都不做，冷冻列车一站站开到终点，任务结束（输）
```
