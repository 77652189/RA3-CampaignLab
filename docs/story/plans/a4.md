# A4 冰雕里的兵 · 策划案

剧情见 [outline.md](../outline.md) A4 行，原版的做法见 [map-language.md](../map-language.md) 第 7 节。

**这份文件就是关卡本身。** 改下面 `yaml` 块里的内容，重新编译，游戏里的玩法就跟着变。文字部分写设计意图，编译时不读。
- 写法：见 [README.md](README.md)；能写哪些词，用 MCP 的 `plan_vocab` 查。
- 改完先跑 `plan_show(a4)`：看节拍表、设计检查和接口检查，不用进游戏。
- 再跑 `cnv_check(a4, <检查>)`：上测试台验证。
- 难度不同的数字写成 `简单/普通/困难`，例如 `5000/3000/2000`；只写一个数就是三个难度一样。

## 定位

- 盟军第 4 关，前半段。解锁冰幕工兵，这一关就是它的教学关。
- 类型：护送。玩家要学会：冰墙能把敌人关住，但会化，什么时候冻是关键。
- 剧情：帝国残部把兵藏进雪祭的冰雕，要劫走运克隆体的车队。玩家先布防，护送车队走完会场；半路港口出事，要先清场，车队才能过桥。

```yaml
关卡: a4
名字: 冰雕里的兵
一句话: 护送。车队按时间表穿过雪祭会场，冰雕里藏着帝国的兵；冰幕工兵冻冰封住广场出口，但冰会化
地图: festival
阵营: {我: 盟军, 敌: 帝国}
时长: 15
```

## 开局

玩家有一座小基地，资金少，主要靠开局部队；冰幕工兵两个。敌人：三个广场的冰雕里藏着兵；北边高地有一座营地；港口有埋伏，在地图边界外，开局看不到。1 号广场多放一座"演示冰雕"，30 秒时自己裂开，让玩家看到冰雕里有兵。

```yaml
开局:
  资金: 5000/3000/2000
  部队:
    - {单位: 建造厂, 在: base yard}
    - {单位: 兵营, 在: base barracks}
    - {单位: 战车工厂, 在: base factory, 朝向: 3.1416}
    - {单位: 电厂, 在: base power, 朝向: 0}
    - {单位: 矿厂, 在: base refinery}
    - {单位: 冰幕工兵, 数量: 2, 在: west field, 偏移: [250, 100], 角色: engineer}
    - {单位: 守护者坦克, 数量: 4, 在: west field, 偏移: [250, 30], 角色: guardian}
    - {单位: 激流 ZX, 数量: 2, 在: west field, 偏移: [250, -40], 角色: riptide}
    - {单位: 冰雕, 在: plaza 1, 偏移: [0, 90], 阵营: 敌, 角色: demo sculpture}
    - {单位: 兵营, 在: north base, 阵营: 敌, 角色: north barracks}
    - {单位: 帝国武士, 数量: 2/3/4, 在: north base, 偏移: [0, -150], 阵营: 敌, 角色: north guard, 守: north base}
    - {单位: 天狗, 数量: 2/3/4, 在: harbour, 阵营: 敌, 角色: harbour ambush, 守: harbour}

```

## 机关

车队和冰雕广场是这一关自己的机关（`experimental/cnv/devices/`）。车队在第 2 段开始时出发；每座冰雕里藏的兵按难度 1 / 2 / 3 个。

```yaml
机关:
  车队: {类型: 车队, 出发: 段 第一程}
  广场: {类型: 冰雕广场, 车队: 车队, 每座兵: [坦克杀手, 帝国武士, 坦克杀手], 每座几个: 1/2/3}
```

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 布防 | 车队出发前用冰封口，或者先打碎冰雕清兵 | 没有：准备时间 | 冰雕里有兵（演示）；冰幕工兵怎么用 |
| 第一程 | 跟着车队过 1 号、2 号广场 | 广场的兵：冰封或清掉；北营小队：拆兵营 | 冰会化，要算好时间 |
| 港口生变 | 车队停下等；主力过桥清港口 | 北营还在打停着的车队 | 攻守切换：车队边上要留人 |
| 最后一程 | 护送过 3 号广场到港口 | 3 号广场的兵 | 再冻一次：开局的冰早化了 |

```yaml
段:
  - 名字: 布防
    目标: [护送车队穿过雪祭会场, 出发前封住三个广场的出口, 三辆车全部送到]
    开场:
      - 通报 帝国残部把兵藏进了雪祭的冰雕。车队几分钟后出发：先用冰幕工兵冻住广场出口，或者先把冰雕打碎。
      - {倒计时: 开局 + 4:00/3:00/2:30, 文字: 车队出发}
    结束: 开局 + 4:00/3:00/2:30
  - 名字: 第一程
    目标: [护送车队通过 1 号、2 号广场, 拆掉北边的帝国营地]
    存档: 是
    结束: 车队.到达 halt
  - 名字: 港口生变
    边界: whole
    目标: [清除港口桥头的埋伏]
    开场:
      - 车队.停下
      - {镜头: harbour}
      - 通报 港口桥头有埋伏！车队先停下，清掉桥头的敌人再走。
      - {给: {冰幕工兵: 1, 守护者坦克: 2}, 在: convoy start}
    存档: 是
    结束: {任一: [敌人清空 harbour, 段 港口生变 + 4:00]}
  - 名字: 最后一程
    目标: [护送车队通过 3 号广场、到达港口]
    开场:
      - 车队.继续
      - 通报 车队接着走了。开局冻的冰早就化了：车到 3 号广场之前，再冻一次。
    存档: 是
```

地图边界：开局只开放运河以西（`west of the canal`），第 3 段开头的过场里扩到全图（`whole`）。

```yaml
边界: west of the canal
```

## 目标

    标记: [{seal 1: 广场.封住 1}, {seal 2: 广场.封住 2}, {seal 3: 广场.封住 3}]
    完成: 广场.全部封住
    失败: 车队.出发

    奖励: 是
    说明: 一辆车都不丢。
    完成: 车队.到终点 3
    失败: 车队.损失 1

    说明: 车到广场前，冰雕会碎，藏着的兵冲出来劫车。

  拆掉北边的帝国营地:

    完成: 摧毁 north barracks
  清除港口桥头的埋伏:

## 敌人的进攻

- 演示冰雕的兵：30 秒时出来一个，走到 1 号广场前的路口守着。
- 北营小队：车队出发后一段时间开始，也可能更早——玩家先打北营就马上来；每波打最前面那辆车；拆了北营兵营就停；港口出事以后每波多一个坦克杀手。

```yaml
进攻:
  - 名字: 冰雕演示
    开始: 开局 + 0:30
    兵: {帝国武士: 1}
    从: plaza 1
    守: approach 1
  - 名字: 北营小队
    开始: {任一: [车队.出发 + 1:30/1:00/0:45, 攻击 north barracks]}
    兵: {帝国武士: 2/3/4, 坦克杀手: 0/1/2}
    从: north base
    打: 车队
    每隔: 1:30/1:15/1:00
    最多: 6
    来源: [north barracks]
    加码: {当: 段 港口生变, 兵: {坦克杀手: 1}}
    预警: 北边营地派小队下山了。拆掉它的兵营，就不会再来。
```

## 规则：教学、提示和兜底

原版快输了不送援军，只给提示（map-language.md 第 7 节）。唯一的例外是冰幕工兵：两个都死了送一个，没有工兵这一关的核心玩法就没了。

```yaml
规则:
  - 当: 开局 + 0:20
    做: [通报 冰幕工兵：走到广场出口里面的平地上，放冻结技能，冻出一块冰挡住出口。]
  - 当: 开局 + 0:30
    做: [{摧毁: demo sculpture}, 通报 1 号广场的一座冰雕裂开了——里面藏着帝国的兵！]
  - 当: 摧毁 engineer
    做: [{给: {冰幕工兵: 1}, 在: west field}, 通报 两个冰幕工兵都倒下了，司令部又派来一个。]
  - 当: [段 港口生变 + 4:00, 还没 目标 清除港口桥头的埋伏 完成]
    做: [通报 车队等不下去了，冒险自己走。]
```

## 输赢

三辆车都在就等第三辆也到了再赢（它比第二辆晚一秒多，要给奖励目标"三辆车全部送到"留出结算的时间）；丢了一辆，剩下两辆到就赢。

```yaml
胜利: {任一: [车队.到终点 3, [车队.到终点 2, 车队.损失 1]]}
失败:
  - {当: 车队.损失 2, 原因: 车队被劫走了……两辆车被毁。}
```

## 对齐原版的改版（2026-10-25 定方向，逐步做）

用户 2026-10-25 定了顺序：先把设计向原版对齐，再给 MCP 和编译器补能力、补条件，最后逐条做进来。下表左边是对照的原版关（[retail/](retail/README.md)：伊贺、敖德萨）怎么做，右边是 A4 要改成什么、缺哪个词；做完一条，就改上面的 `yaml`，再把那一行删掉。

| 原版怎么做 | A4 现在 | 改成 | 缺的词或能力 |
|---|---|---|---|
| 护送对象遇伏就停在火力下，伏兵清光才走（伊贺） | 车队按时间表走，不停 | 冰雕碎、伏兵出来，车队就停在原地挨打，伏兵清光才走。封住出口就不用停，所以冻冰成了让车队一路不停的办法 | 车队参数 `遇伏: 停下` |
| 新单位的目标只能用它完成（伊贺"冻住"） | 冻冰可选，不冻也能硬打 | 2 号广场的冰雕打不碎（无敌），兵会一直冲出来，只能封口；冻住 2 号出口是主目标 | 部队 `无敌: 是`；冰雕广场按广场设参数 |
| 车辆血量按难度（伊贺 7000/5000/3000） | 三个难度一样 | 车的血量分难度 | 车队参数 `血量` |
| 护送只占一部分，之后换一件事（伊贺、敖德萨） | 15 分钟全是护送 | 港口生变以后，北营变成遭遇战 AI 管的帝国营地：这一段唤醒，玩家先打它就提前。目标改成"拆掉北营的生产建筑"，每拆一座，剩下的更凶。最后一程放在这件事之后 | `敌方AI` 小节；`摧毁 <组> <n> 个`；`加码` 能缩短间隔 |
| 没有布防段，开局十几秒就出发（伊贺、敖德萨） | 布防 4:00/3:00/2:30 | 缩短到 1:30/1:00/0:45；工兵冻过一个出口就提前出发（按时或玩家先动） | 已有 |
| 重复催促（伊贺每 9 秒一句） | 每条提示只说一次 | 车队停着等伏兵清光时，每 30 秒提示一次 | 规则 `每隔` |

## 检查

测试台上的检查（`experimental/cnv/checks/a4.py`），每个写一句它证明什么。

```yaml
检查:
  seal: 车队出发前 10 秒在 1 号广场出口冻冰墙，2 号不封。2 号的兵几秒内上路，1 号的兵在冰墙化掉前一直没上路，化了才出来
  placed: 对照，地图直接摆一道同样长的冰墙堵 1 号出口，兵也出不来
  smash: 提前打碎 2 号广场的一座冰雕，它的兵马上出现，另一座冰雕不受影响
  ambush: 车队开到 1 号广场前，冰雕碎、兵出来
  win: 车一直满血、港口的埋伏一开始就清掉，车队开完全程，任务结束
  lose: 车只剩 1% 血，第一次伏击就丢两辆，任务很快结束
  idle: 玩家什么都不做，车队出发后很快就丢了，任务结束（守关不会自己赢）
  harbour: 玩家的三辆坦克一直站在港口里，港口的敌兵活着时"港口清空"不成立，10 秒时全杀掉就成立（我方单位在场不影响）
```

## 玩家可能不知道的事

| 玩家不知道 | 后果 | 怎么告诉（上面哪一条） |
|---|---|---|
| 冰雕里有兵 | 不知道该防什么 | 30 秒的演示冰雕（规则 2、进攻"冰雕演示"） |
| 冰幕工兵怎么用 | 不会封口 | 20 秒的通报（规则 1）+ 出口的标记（奖励目标） |
| 冰会化、还剩多久 | 冻完以为万事大吉 | 冰墙在时屏幕左下显示剩余秒数（机关"广场"）；第 4 段的通报 |
| 车队为什么停了 | 以为卡住了 | 第 3 段的过场、通报和新目标 |
| 北营一直在派兵 | 不知道源头 | 每波的预警 + 北营兵营上的奖励目标 |
