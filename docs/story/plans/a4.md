## 定位

- 盟军第 4 关。解锁冰幕工兵，这一关就是它的教学关。
- 体验目标：**冰墙不只是挡人，还能给敌人排队：看着号角倒计时，决定这一波用几道墙、留哪条街开着。**
- 六段（流程稿）：开场（过场）→ 会场（护送，拮据）→ 港口生变（过场，号角停）→ 北营（攻，掌控）→ 布防（倒计时）→ 最后一程（守，高潮）。
- 题：号角一响，开着的地道口同时出兵扑车；两个冰幕工兵各封一条街。**会场**冻住的街，兵改去开着的街、晚 10 秒以上出（绕路错开）；**最后一程**的地道口开在口子上，冻住的口子兵出不来，在墙后攒着，冰一化一起涌出；第三声号角起鬼王上岸，先砸离它最近的冰墙，替帝国开闸。

## 开局：玩家手里（P29）

第 1 段没有基地（拮据）：1 个冰幕工兵、3 辆守护者、4 个维和步兵、2 个标枪兵，站在走廊西头，背后是地图边。车队的三辆车归"护送队"（和玩家结盟的第三方，玩家点不了），停在西边界上。
冰幕工兵开局只有 1 个，**补到最大数量 2 个为止**（用户 2026-10-31："减少初始工兵，后续只给补充到最大数量就行"）：会场开场 20 秒后补第一个（第一声号角最早 30 秒，困难档赶得上），以后少于 2 个就每 45 秒补一个，补在起步点 `entry`。冰墙本身没有数量上限（"冰墙不需要限制"）；最大数量 2 沿用灰盒按两个工兵算的平衡，后面有了基地玩家自己造多少都行。

敌人：
- 会场的三条街（后巷、一号广场、二号广场）底下是地道，口子打不坏；号角响才出兵（机关"雪祭"，不摆单位）。
- 北高原的北营：指挥所（第 3 段要拆的）、兵营、战车工厂、电厂、矿厂、矿车和守军；后坡顶上另一座电厂供两座波能塔（正坡顶上）。
- 港口桥头的帝国武士（"港口生变"过场里"港口被堵"）：北营派的。指挥所一倒，他们撤回北营。

电视塔（西岭）开局归平民，玩家的兵走到跟前就归玩家。

## 机关

车队第 1 段一起开到 2 号广场的门口（停车点 `halt`），最后一程从那里分批走：0 / 50 / 110 秒一辆（`分批从: 继续`）。车血 700/500/300，挨几下就没了，当不了肉盾（a4-redesign P9）。

**车速 12**（用户 2026-10-31 选"按第 1 种降速"；原来是矿车的 50）。算法：会场路长约 2730（`convoy start` x 250 到 `halt` x 2980），12 一秒走 12，约 227 秒，加开场后倒计时 20/15/10 秒，开到停车点约 4 分钟，号角响满五声（间隔表合计 225/215/180 秒，第五声都在车到之前（简单档车到停车点约 247 秒，最后一声提前 22 秒，那一波在港口生变的过场（玩家不能操作）开始前打得完））。**最后一程同一个速度**：`halt` 到 `road exit` 约 920，一辆车路上 77 秒；三辆车 0/50/110 秒出发，第三辆 187 秒到港口；号角照同一张间隔表，五声合计 225/215/180 秒，正好盖住第三辆车上路的这段；第三声（鬼王上岸）在 100～135 秒（按难度），那时第三辆车刚出发，前两辆在路上或刚到，鬼王砸墙开闸压在最后一辆车身上。理由：两程用同一个节奏，玩家学一次；最后一程要是车跑得更快，五声号角只够响两声，鬼王压不到车，题就空了。
- 间隔拉长是为了对上车速：原来的表合计只有 195/140（普通/困难），车还在路上号角就响完了。

**雪祭**（机关 `号角`，`devices/horn.py`）：号角按间隔表一声声响，倒计时一直在屏幕上。**开场演示**（`演示`）：会场开场过场里，一个工兵冻住一号街口，兵撞上冰掉头钻进地道，从后巷口冒出来（演示的工兵和兵过场一结束就收走，冰自己化）。**小地图闪点**：每一波的第一个兵出生时、鬼王上岸时，小地图上那个位置闪一圈。
- 会场：三条街（后巷 `lane foot`、一号 `inside 1`、二号 `inside 2`），每街一波 2 武士 + 2 坦克杀手，扑车。街口里有冰墙，那条街的兵改在开着的街出生、晚几秒出（`绕路` 表：冻住的街 → 开着的街 → 晚多少秒；去同一条街的两条绕路相差 ≥ 10 秒，机关编译时检查）。二号街第二声号角起才开，第一声只有后巷和一号。
- 最后一程：三个口子（北坡口、三号广场的门、东街口），号角照旧，每口一波按难度固定。口子里有冰墙，那口这一波不出、记下来；冰没了（化了或被砸开）一起放出。第三声号角起，突击运输车从海上靠岸，鬼王下车先砸离它最近的冰墙，没有冰墙就扑车（数量 1/1/2）。
- 间隔：简单都 ≥ 45 秒，普通 30、50 混着，困难短的多；第一个数是倒计时开始到第一声。

## 敌人的进攻

- 号角的兵（机关"雪祭"）是全关的主压力，不是 `进攻`：会场 5 声、最后一程 5 声，每声每口一波。
- 北营的遭遇战 AI（原版持续压力都交给 AI：宫古岛、斯大林格勒）：北营段开始 2:00/1:30/1:00 后醒，玩家先打北营就提前醒（P8）。醒来时兵营、战车工厂、营里的电厂、矿厂、矿车和守军交给它；只许造兵，不许盖房子。醒来先只能造步兵，再过 2:00/1:30/1:00 放开海啸坦克和打击者（`分档`，原版斯大林格勒）。指挥所、后坡的电厂和波能塔留给"敌"，AI 碰不到：拆指挥所就是这一段的结束。
- 旧版的北坡反扑（鬼王加海啸）、海上天狗、后巷无人机都删了：北坡口一路拆光北营就不来的老毛病，新题里北坡口是三个口子之一，号角照出兵；鬼王改成第三声号角起从海上靠岸。

```yaml
敌方AI:
  性格: 平衡
  基地: north base
  资金: 3000/5000/8000
  唤醒: {任一: [段 北营 + 2:00/1:30/1:00, 攻击 north command, 攻击 north barracks, 攻击 north factory]}
  接管: [north barracks, north factory, camp power, north refinery, north miner, north guard, north buster]
  上限: {基地车: 0, 兵营: 0, 战车工厂: 0, 电厂: 0, 矿厂: 0, 船坞: 0, 机场: 0}
  分档:
    - {当: 敌方AI 醒来 + 2:00/1:30/1:00, 放开: [海啸坦克, 鹰击者VX]}
```

## 输赢

三辆车都在就等第三辆也到了再赢（给奖励目标"三辆车全部送到"留出结算的时间）；丢了一辆，剩下两辆到就赢。

```yaml
胜利: {任一: [车队.到终点 3, [车队.到终点 2, 车队.损失 1]]}
失败:
  - {当: 车队.损失 2, 原因: 车队被劫走了……两辆车被毁。}
```

## 检查

测试台上的检查（`experimental/cnv/checks/a4.py`），每个写一句它证明什么。都按普通难度、车保持满血、没有结局、全图揭开，数每一波兵的名字。整关的 `win` 走查还没重做（旧的按冰雕广场写的，已删）。

```yaml
检查:
  horn: 第一声号角只有后巷和一号两条街各出一波（共 8 个），二号街第二声才出
  detour: 工兵赶在第一声号角前冻住一号街口：后巷的兵照出，一号的兵晚几秒、在后巷口出来（绕路）
  queue: 测试台开口的号角，工兵先冻北坡口：另两口的兵照出（8 个），北坡口的这一波攒着，冰化了才出（4 个）
  smash: 同上，第三声号角（鬼王）：运输船靠岸，鬼王上岸，工兵冻在东街口的冰墙血量自己往下掉（没人下令）
  demo: 开场演示：工兵冻住一号街口，一号的兵撞冰后被收掉，后巷口冒出一对兵（过场被测试台跳过时，演示跟着收走，这条看的是演示自己的时间线）
  idle: 整关走查，玩家什么都不做：车队自己往前开，号角的兵拿下两辆车，任务在会场里失败（防守关不能自己赢）
  hold: 整关走查，车保持满血、玩家不动：街上五声号角响完，车队开到二号广场门口，计划转到港口生变
  win: 整关走查，车保持满血、北营一开始就拆掉指挥所：六个阶段走完，三辆车到港口，任务胜利
  derrick: 新流程稿的资源点（工程师占油井，机制表里待验证）：出发点旁放一座中立油井，玩家的工程师第 2 秒被下令去占，油井归玩家，玩家的钱涨上来
```

## 玩家可能不知道的事

| 玩家不知道 | 后果 | 怎么告诉（上面哪一条） |
|---|---|---|
| 号角一响三条街同时出兵 | 护卫守不过来 | 开场过场里镜头扫三个街口；屏幕上一直有号角倒计时 |
| 冰幕工兵怎么用、冰会化 | 不会封口，冻完以为万事大吉 | 交还控制 12 秒的通报；冰墙在时屏幕上显示剩余秒数 |
| 冻住的街的兵会绕去开着的街 | 以为冻一条就清净了 | 冰墙已就位的播报；绕路兵晚几秒出，倒计时间隔里看得到 |
| 拆指挥所就开始最后一程 | 没摆防线就拆 | 目标"拆掉北营的指挥所"的说明；布防倒计时 |
| 后坡能断电 | 硬冲正坡的波能塔 | 同一条目标说明 |
| 最后一程冻住的口子兵出不来，冰化了一起涌出 | 冻了不管，冰一化挨一顿 | 目标"把车队送到港口"的说明；口子出兵的通报 |
| 鬼王专砸冰墙 | 白白搭了冰墙 | 鬼王上岸的通报；占了电视塔，布防时报出船往哪靠 |

## 号角返工（2026-10-31）

按流程稿 [flow/a4.md](../../design/flow/a4.md) 和 [a4-layer3.md](../../design/cards/a4-layer3.md) 重写；地图 `maps/sapporo.py` 改了三个街口（后巷口 x 1200、一号广场门 2015、二号广场门 2830，间隔 ≥ 800；后巷坡宽 120 能被一道冰墙封住）和最后一程三口后的炮位站点（`gun north`、`gun plaza 3`、`gun east`）。

做了：号角机关（`devices/horn.py`）、冻街绕路、冻口攒兵、鬼王砸最近的冰墙。2026-10-31 用户拍板后又做了：车速降到 12（会场约 4 分钟、五声号角）、开场演示（`雪祭.演示`：工兵冻一号街口，兵掉头从后巷冒出来）、冰墙不设上限（"封顶两个"删了）、冰幕工兵开局 1 个按时补到 2 个、小地图闪点（每波第一个兵、鬼王上岸）、工兵头上的信息框、`idle`/`hold`/`win` 整关走查检查。留着没做：
