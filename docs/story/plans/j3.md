# J3 白鹭城下 · 策划案

剧情见 [outline.md](../outline.md) J3 行，单位见 [units.md](../units.md)（纸鹤侦察机）。

**这份文件就是关卡本身**：改 `yaml` 块，重新编译，玩法就变（写法见 [README.md](README.md)，词表用 `plan_vocab` 查，改完先跑 `plan_show(j3)`）。

**粗版**（2026-10-27，总控"关卡先铺开再打磨"）：能玩、检查能过就行，原版对齐和难度以后再说。未来科技的雇佣兵先用盟军的兵代替。

## 定位

- 帝国第 3 关。解锁纸鹤侦察机：没有武器，看得很远，一直隐身。
- 类型：潜入（原版的特工关：少量精英、没有基地）。玩家要学会：先让纸鹤看清守军和路，再让百合子挑没人的路走。
- 剧情：百合子潜进姬路城下的未来科技训练所，在档案里看到了赛林斯基的名字，然后撤出来。正门有重兵，城山东北角有一条没人守的后坡——纸鹤能找到它。

地图: himeji

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 潜入 | 纸鹤看清正门和后坡；百合子从后坡摸上去，进到档案旁 | 镇上的巡逻、正门的守军；被发现就是一场硬仗 | 纸鹤：看得远、打不着 |
| 撤离 | 百合子撤回西边的接应点 | 城山的守军醒了，一路追（遭遇战 AI） | 跑 |

```yaml
段:
  - 名字: 潜入
    目标: [潜进训练所看档案, 百合子必须活着]
    开场:
      - 通报 正门有重兵把守。先放纸鹤去看清楚城山的守军，找一条没人走的路，再让百合子摸上去。
    结束: yuriko 进入 archive yard
  - 名字: 撤离
    目标: [撤回接应点, 烧掉训练所]
    开场:
      - 通报 档案里有赛林斯基的名字……警报响了！百合子，马上撤回西边的接应点。
      - {镜头: extraction}
    存档: 是
```

## 目标

```yaml
目标:
  潜进训练所看档案:
    说明: 让百合子走到城山东边训练所的档案楼旁。
    标记: [archive]
    完成: yuriko 进入 archive yard
  百合子必须活着:
    说明: 百合子倒下，任务就失败了。
    标记: [yuriko]
    失败: 摧毁 yuriko
  撤回接应点:
    说明: 百合子回到西边树林旁的接应点。
    标记: [extraction]
    完成: [段 撤离, yuriko 进入 extraction]
  烧掉训练所:
    奖励: 是
    说明: 拆掉训练所的档案楼，让它再也训练不了克隆体。
    标记: [archive]
    完成: 摧毁 archive
```

## 检查

测试台上的检查（`experimental/cnv/checks/j3.py`），每个写一句它证明什么。

```yaml
检查:
  run: 测试脚本让百合子满血、开局就走后坡上城山到档案旁，再撤回接应点，任务结束（赢）
  lose: 百合子开局只剩 1% 血、直接走正门，被打倒，任务结束（输）
```

## 玩家可能不知道的事
