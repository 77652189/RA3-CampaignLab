## 定位

- 苏联第 5 关。解锁钻地运兵车，这一关就是它的教学关。
- 类型：突袭 + 守点。玩家要学会：钻进地下的车打不着，能从敌人的炮塔底下开过去卸兵。
- 剧情：盟军舰队要从湖里经船闸开出运河。控制室在东岸高台上，盟军守着唯一的坡道。玩家让钻地车从炮塔底下钻上高台、夺下控制室，关闸把舰队堵住，再守住控制室挡盟军反扑。

```yaml
关卡: s5
名字: 巴拿马之锁
一句话: 钻地车从盟军炮塔底下钻上高台，夺下船闸控制室，关闸把盟军舰队堵在运河里
地图: panama
阵营: {我: 苏联, 敌: 盟军}
时长: 15
```

## 开局

## 节拍

| 段 | 玩家要做 | 压力从哪来、怎么关掉 | 这一段教什么 |
|---|---|---|---|
| 潜入 | 动员兵坐进钻地车，钻进地下开过坡道的炮塔，上高台卸兵，消灭控制室的守军 | 时间：舰队按时从湖里出发，开过船闸就输；硬冲坡道会被炮塔打光 | 钻地：打不着，但也不能开火 |
| 关闸 | 守住控制室 | 西岸的盟军交给遭遇战 AI 来反扑；被堵住的舰队开炮 | 守点 |

```yaml
段:
  - 名字: 潜入
    目标: [夺下船闸控制室]
    开场:
      - {镜头: east base}
      - 通报 盟军舰队要从湖里开过船闸出海。控制室在西边那块高台上，坡道上有炮塔：让动员兵坐进钻地车，钻进地下从炮塔底下开上去。
      - {倒计时: 开局 + 4:00/3:00/2:30, 文字: 盟军舰队起航, 直到: 段 关闸}
    结束: [摧毁 control guard, 摧毁 control tank]
  - 名字: 关闸
    目标: [守住控制室, 击沉被堵住的舰队, 拆掉西岸的盟军基地]
    开场:
      - {转给我: control room}
      - {锁住: fleet}
      - 通报 控制室到手，闸门关上了！盟军舰队被堵在运河里。西岸的盟军要反扑了，守住控制室。
      - {倒计时: 段 关闸 + 4:00/5:00/6:00, 文字: 援军到达}
    存档: 是
```

## 目标

```yaml
目标:
  夺下船闸控制室:
    说明: 消灭高台上控制室的守军。高台只有东侧一条坡道，坡道上有炮塔；钻进地下的车打不着，开上去再卸兵。舰队开过船闸就失败了。
    标记: [control room]
    完成: [摧毁 control guard, 摧毁 control tank]
  守住控制室:
    说明: 援军到之前，控制室不能丢。
    标记: [control room]
    完成: 段 关闸 + 4:00/5:00/6:00
    失败: 摧毁 control room
  击沉被堵住的舰队:
    奖励: 是
    说明: 舰队动不了，但还会开炮。
    标记: [fleet]
    完成: 摧毁 fleet
  拆掉西岸的盟军基地:
    奖励: 是
    说明: 西岸的盟军基地一直在造兵反扑。拆掉它的兵营和战车工厂，它就造不出兵了；运河上没有桥，过河靠会游水的车。
    标记: [{west barracks: 摧毁 west barracks}, {west factory: 摧毁 west factory}]
    完成: [摧毁 west barracks, 摧毁 west factory]
```

## 敌人的进攻

- 舰队按时从湖里出发，往运河南端的出海口开；第 1 段结束前开到闸室以南就算冲过去了。
- 西岸盟军第 2 段交给遭遇战 AI，只许造兵。

```yaml
敌方AI:
  性格: 平衡
  基地: start
  资金: 3000/5000/8000
  唤醒: {任一: [段 关闸, 攻击 west barracks, 攻击 west factory]}
  接管: [west yard, west barracks, west factory, west power, west refinery, west guard]
  上限: {基地车: 0, 兵营: 0, 战车工厂: 0, 电厂: 0, 矿厂: 0, 船坞: 0}

进攻:
  - 名字: 开场骚扰
    开始: 开局 + 0:30
    兵: {维和步兵: 3}
    从: east beach
    打: east base
  - 名字: 反扑
    开始: 段 关闸 + 0:30
    兵: {守护者坦克: 2/3/4, 维和步兵: 3}
    从: east beach
    打: control room
    每隔: 1:00/0:50/0:40
    最多: 5
    来源: [west barracks, west factory]
    预警: 盟军从南边滩头摸上来了，守住坡道！
```

## 规则

```yaml
规则:
  - 当: 开局 + 4:00/3:00/2:30
    做: [{出动: fleet, 打: sea exit}, 通报 盟军舰队起航了！在它开过船闸之前夺下控制室。]
  - 当: 开局 + 0:20
    做: [通报 钻地运兵车：按钻地钮就钻进地下，谁都打不着它，它也不能开火；开到地方钻出来，再让乘客下车。]
  - 当: [fleet 进入 south canal, 还没 段 关闸]
    做: [{失败: 盟军舰队冲过了船闸……}]
```
