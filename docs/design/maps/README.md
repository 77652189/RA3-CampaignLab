# 地图内容稿（第 2 层）

每关一份，写的是流程剧本里每一段**发生在什么地方**：什么场所、玩家记得住的地标、第一眼看见什么、讲故事的布景、这一段的玩法要的地形。这是 [ADR 0008](../../adr/0008-levels-by-layer.md) 的第 2 层；按 [ADR 0009](../../adr/0009-one-level-through-all-layers-first.md)，模板先在 A4 上定，A4 在游戏里过了再批量。

- 前提：这一关的流程剧本（[flow/](../flow/)）已经过用户审。地名用流程剧本示意图里的地方名；摆在哪用实际地图的地点（`SITES`）或地块（`LAYOUT.blocks` 的 `what`）。
- 不写数字、不写摆放坐标：那是第 3 层。这里只说"在哪个地点、是什么、为什么要它"。
- 不重复流程剧本：可玩区、资源点、伏击点、援军位置已经在流程剧本的 `示意图` 和 `摆放要求` 里，这里只补"那里看起来是什么样、地形够不够"。
- 每一样东西标清楚现在的状态，谁来做一目了然（下面 `地图` 一栏）。

## 一、文件

| 文件 | 是什么 |
|---|---|
| [mapcheck.py](mapcheck.py) | 机器检查：完整和一致（第四节），并列出给地图线、关卡线、美术的清单 |
| `<关号>.md`（如 `a4.md`） | 每关一份地图内容稿 |

查看器（[flow/flowview.py](../flow/flowview.py)）有一种看法"地图内容"：每段一张实际地图，标出这一段的场所、地标和布景，旁边是第一眼和各项的状态。

## 二、每关写什么

```yaml
关: A4
地图: sapporo                     # 实际地图（experimental/cnv/maps 的模块），和流程剧本的示意图一样
场所: 札幌雪祭的会场和港口         # 一句话：这一关在什么地方
方向: 西边图外进场，沿大街往东推，东边港口收尾   # 玩家从哪进、往哪推、在哪结束（P17、P18）
地标:                             # 全关玩家记得住、拿来认路的东西；每个都要在流程剧本里被看见或被提到
  - 名: 冰雕
    在: [plaza 1, plaza 2, plaza 3]   # 地图的地点或地块，一个或几个
    是什么: 宫墙围起来的庭院，一个门，里面立着冰雕
    作用: 一个庭院一道题，玩家靠它数走到哪了
    地图: 有                       # 有 / 要改 / 要加 / 关卡摆 / 美术（见下）
段:                               # 流程剧本的每一段都写一条，名字照抄
  - 段: 开场
    第一眼: 镜头给玩家看的第一个画面（对上流程剧本这一段第一个镜头）
    场所: [起步, 大街]              # 这一段发生在流程示意图的哪几个地方
    布景:                          # 讲故事的摆设：看见它就知道这里发生过什么
      - {什么: 沿大街的彩旗和灯笼, 在: the avenue, 讲什么: 雪祭照常开放, 地图: 有}
    地形:                          # 这一段的玩法要的地形；写了动词的段至少一条
      - {要: 大街两侧垫高一层，成一条街谷, 为了: 车队只能走大街, 在: the avenue, 地图: 有}
```

`地图` 一栏的五种状态：
- **有**：地图上已经有了。
- **要改**：地图上有，但不够（宽度、高度、位置不对），地图线改。
- **要加**：地图上没有，地图线加（地形、布景模型）。
- **关卡摆**：任务脚本摆的东西（冰雕兵、科技建筑、靠岸的船），关卡线在第 3 层摆。
- **美术**：现在只能用替代品，等美术阶段（雪地、专门的模型）；照"美术放最后"，不挡试玩。

## 三、写法准则

1. **第一眼**：每段都写，写镜头停下时屏幕上看得见的东西，和流程剧本这一段第一个镜头说的是同一件事。没有镜头的段写交还控制那一刻屏幕上是什么（P21：先领着看）。
2. **地标少而好认**：全关三到六个，形状和颜色一眼分得开；每个都要在流程剧本里被镜头指过或被台词提到，不然玩家不会拿它认路。
3. **布景讲故事**：每段至少一样布景，回答"这里发生过什么"（雪祭照常开放、帝国兵从哪塞进冰雕）。只是好看、不讲事的不用写（树、石头由地图生成器撒）。
4. **地形跟着动词**：写了动词的段至少一条地形，写清它为了哪个玩法（冰墙封门要 120 宽的门、走后坡要一条窄坡）。地形准则 P24～P28 在 [a4-redesign.md](../a4-redesign.md) 一类的布局草图里已经过了一遍，这里引用结论，不重做。
5. **状态要诚实**：没核对过的不写"有"。"有"要能在地图模块里找到（地点、地块、布景清单）。

## 四、机器检查（只查完整和一致）

`python docs/design/maps/mapcheck.py` 检查所有地图内容稿：

- 顶层的键都在；`关` 和文件名一致，有对应的流程剧本；`地图` 和流程剧本示意图的地图一样，地图模块存在；
- 流程剧本的每一段都有一条，没有多出来的段；每段有 `第一眼`、`场所`、至少一样 `布景`；流程剧本里写了动词的段至少一条 `地形`；
- `场所` 是流程示意图里的地方；写了动词的段，场所在这一段已经打开（开 ≤ 这一段），过场可以先给看后面才开的地方（P21）；
- 地标、布景、地形的 `在` 都是地图的地点或地块；`地图` 是五种状态之一；
- 每个地标的名字（或它 `是什么` 里的关键词）在流程剧本里出现过——这一条用名字匹配，匹配不上的列出来给写的人看，不算错；
- 最后列三张清单：**给地图线**（要改、要加）、**给关卡线**（关卡摆）、**给美术**（美术）。

好不好、像不像、有没有代入感，由用户在查看器里看了判断。
