# S8 火山下的工厂 · 流程剧本（第一遍）

苏联第 8 关，考 K4 时机、K5 借力，难度 4.5。题卡见 [cards/all.md](../cards/all.md) S8：火山几个喷口轮流喷发，喷之前那一侧冒烟；喷发把附近的兵冲散、掉血，敌我不分；别列津的工厂在火山里，入口围着火山口一圈。大纲第四节：别列津把机器的控制权交给黑尔；[units.md](../../story/units.md) 5.2 节：磁力空间站的光束反过来吸玩家的部队，要攻下火山工厂里的地面控制站。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

新机制待查：喷口轮流喷发，喷前冒烟、喷时冲散掉血（handoff"第一遍"表 S8 一行，退路是脚本在区域里放伤害和击退）；磁力空间站的光束沿路点拖着走、吸起地面车辆（units.md 5.2 做法 B）；光束看不见喷口烟里和地下的单位（脚本按区域和钻地状态跳过）。
