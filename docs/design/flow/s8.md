苏联第 8 关，考 K4 时机、K5 借力，难度 4.5。题卡见 [cards/all.md](../cards/all.md) S8：火山几个喷口轮流喷发，喷之前那一侧冒烟；喷发把附近的兵冲散、掉血，敌我不分；别列津的工厂在火山里，入口围着火山口一圈。大纲第四节：别列津把机器的控制权交给黑尔，玩家攻下他藏在火山里的工厂。第一遍按"先加戏"从头写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/s8_beats.md`），只挑了长在已有规则和人物上的；同一天补成第二遍的全量稿（点子草稿在 `work/beats/s8_beats2.md`），段落、规则、人物、意外没改，只补字段和台词；别列津说出口的要紧事，按 README 第 24 条由卡佳跟一句把玩法那层再说一遍。
