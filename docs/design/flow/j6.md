# J6 守陵人 · 流程剧本（第一遍）

帝国第 6 关，练 K3 先后、K9 引火，难度 4。题卡见 [cards/all.md](../cards/all.md) J6：东照宫的眠猫机关门打不坏，门边的守军轮班转着机关才锁得住；一扇门边的守军一走开，那扇门就松开几十秒；东照宫被毁即失败。衍生规则分四步显出来：守外苑时守军自己冲出来帮你打，门松了一下（演示）；黑田翻脸后炮轰机关门、正面打守军都吃亏，引走哪一队开哪扇门，开错了门后正是黑田的主力（第一反应吃亏）；坂下门的守军学会补位，被引走那队的门有人顶上，补位那队的门反而松了（每轮最优在变）；最后同一条规则换个后果：引人不再是为了开门，而是把黑田的主力拽出东照宫的院子。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。还没有地图，示意图写在 100×60 的格子上。

新机制待查（[handoff.md](../handoff.md)"第一遍"一节）：门边的守军人数决定门开不开（退路：脚本在门边区域里数守军，少于几个就开门、回来就关）；守军追式神离岗、追远了才回去（式神挡枪已确认，追多远没测）；一队离岗时最近的一队过来补位（退路：脚本按区域人数给邻队下移动令）。
