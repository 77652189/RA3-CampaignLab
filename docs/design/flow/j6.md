# J6 守陵人 · 流程剧本

帝国第 6 关，练 K3 先后、K9 引火，难度 4。题卡见 [cards/all.md](../cards/all.md) J6：东照宫的眠猫机关门打不坏，门边的守军轮班转着机关才锁得住；一扇门边的守军一走开，那扇门就松开几十秒；东照宫被毁即失败。衍生规则分四步显出来：守外苑时守军追出来帮你打，门松了一下（演示）；黑田翻脸后炮轰机关门、正面打守军都吃亏，引走哪一队开哪扇门，阳明门后面正是黑田的主力（第一反应吃亏）；坂下门开着，门后的忍者也出得来，引走的守军追完回来，门一锁，进了一半的人堵在门洞里（每轮最优在变）；最后同一条规则倒过来用：开阳明门不是为了进去，是让院子里的主力出来。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j6_beats.md`），只挑了长在已有规则和人物上的；2026-11-01 补第二遍（体验目标、简报、目标说明、提示、卡住了、摆放要求、逐句台词；点子在 `work/beats/j6_beats2.md`，规则没加）。带玩法信息的台词按 ADR 0013 只给播报和千岁；黑田只说剧情（"去吧"从吩咐变成走开，最后一声是告别），真壁只说剧情和笑点。还没有地图，示意图写在 100×60 的格子上。

黑田在关里当场翻脸，沿用上一稿（拍板清单第 8 条，按推荐写）。完全体的身体照大纲是被黑田偷走的；units.md 写它"要一个心灵驾驶员"，所以这一关它站不起来，只以空中要塞的样子飞走，J8 百合子坐进驾驶舱，它才第一次站起来。

新机制待查（[handoff.md](../handoff.md)"第一遍"一节）：门边的守军人数决定门开不开（退路：脚本在门边区域里数守军，少于几个就开门、回来就关）；守军追式神离岗、追远了才回去（式神挡枪已确认，追多远没测）；门锁上时门洞里的兵怎么办（退路：门洞画成触发区，门关时里面的兵算被堵住、挨两面打，不做挤死）。
