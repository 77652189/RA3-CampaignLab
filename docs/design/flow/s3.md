# S3 通古斯之谜 · 流程剧本

苏联第 3 关，教 K2 视野，难度 2.5。题卡见 [cards/all.md](../cards/all.md) S3：倒伏的树林一眼望得很远，探照灯照到的地方营地都看得见，娜塔莎的狙击枪也打得那么远；哪盏灯一灭，营地就派巡逻去那片看。打灭你要走的那片的灯，巡逻就堵在你的路上；打灭一盏你不走的灯，巡逻被调走；巡逻派出去就留在那里，下一片要重想。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/s3_beats.md`）；第二遍（2026-11-01）在第一遍上补全体验目标、简报、目标说明、提示、卡住了、摆放要求和逐句台词，点子来自 `work/beats/s3_beats2.md`，只挑了长在已有规则和人物上的，段落、规则、人物和意外没改。带玩法信息的台词只给播报和卡佳（README 第 24 条，ADR 0013）：施泰因下令派巡逻、催装箱、叫守军列队，卡佳都跟一句把玩法那层再说一遍。这关还没有地图，摆放要求写示意图里的地方，第 2 层出图时补地点。最后一段西北角原来是一大片空地（flowcheck 量出 19%），补了一条没有灯的老伐木道当撤回林边的另一条路：原路上调来的巡逻都还站着，老伐木道绕得远，不加规则。

娜塔莎只说原版单位台词，这里只写她的动作。最后一段是转折：同一条"灯灭了就派人去看"，前两段是麻烦，到营地变成把守军一队队送进卡佳小队的伏击圈。上一稿自己加的两条规则去掉了（题卡没有）：警犬靠近会嗅到娜塔莎；路口哨车的车灯也算一盏灯。光只有探照灯一种，巡逻只按灯走。

新机制待查（[handoff.md](../../archive/design-handoff.md)"第一遍"一节的表没列 S3，这里补）：探照灯照到的地方营地看得见（光里被看见就响警报，光外不响）；灯被打灭，营地派最近的一队巡逻去那片，到了就留在那里；警报一响营地烧笔记（脚本：警报后笔记帐篷起火、判负）；探照灯按固定角度来回转。
