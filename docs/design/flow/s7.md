# S7 红场上的金主 · 流程剧本（第一遍）

苏联第 7 关，高光 + 练 K5 借力，难度 3（苏联线后段的一次下探）。题卡见 [cards/all.md](../cards/all.md) S7：阅兵方阵是中立的，谁先走到跟前就跟谁；黑尔的克隆体在控制方阵，控制从信号源往最近的方阵一个个蔓延；仓库里开出磁暴坦克。大纲第四节：别列津在阅兵式上和黑尔公开握手，金主第一次露脸。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

新机制待查：中立方阵走近就归你（mechanics.md 的"走近就归你"只写了平民建筑，方阵没测）；控制从信号源往最近的一队蔓延，方阵分完以后蔓延到玩家自己的兵；有兵挡在信号源和方阵之间时蔓延变慢（handoff"第一遍"表 S7 一行，退路是克隆体收买）。
