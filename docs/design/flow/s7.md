# S7 红场上的金主 · 流程剧本

苏联第 7 关，高光 + 练 K5 借力，难度 3（苏联线后段的一次下探）。题卡见 [cards/all.md](../cards/all.md) S7：阅兵方阵是中立的，谁先走到跟前就跟谁；黑尔的克隆体在控制方阵，控制从信号源往最近的方阵一个个蔓延；仓库里开出磁暴坦克。大纲第四节：别列津在阅兵式上和黑尔公开握手，金主第一次露脸。第一遍按"先加戏"从头写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/s7_beats.md`），只挑了长在已有规则和人物上的；同一天补成第二遍的全量稿（点子草稿在 `work/beats/s7_beats2.md`），段落、规则、人物、意外没改，只补字段和台词；别列津说出口的飞艇时刻表，按 README 第 24 条由卡佳跟一句把玩法那层再说一遍。

这一稿考的是"抢在控制前面"：看清控制下一步到哪，赶在它前面把远处的方阵拉走、拿人挡住它，和 J8 的"先解哪队"分开。去掉了上一稿自己加的两条：客人在台上时信号源打不坏；方阵分完以后控制蔓延到玩家自己的兵（Gemini 的"自己人调转枪口"点子也因此不用）。压轴的飞艇方队照题卡也是一个中立方阵：谁先迎上去就跟谁。

新机制待查：中立方阵走近就归你（mechanics.md 的"走近就归你"只写了平民建筑，方阵没测）；控制从信号源往最近的方阵一个个蔓延；有兵挡在信号源和方阵之间时蔓延变慢（handoff"第一遍"表 S7 一行，退路是克隆体收买）；飞艇方队按时刻表从城外飞进红场，路上谁先迎到跟谁。
