# A9 布鲁塞尔，1927 · 流程剧本（第一遍）

盟军第 9 关，考 K1 改道、K4 时机、K7 跳点、K8 换兵，难度 5，全线最难。题卡见 [cards/all.md](../cards/all.md) A9：原子球塔的九个球轮流充能，亮着的那个在充；九个球共用一层护盾；跳跃倒计时挂在屏幕上。三方同图的终局，这里只写盟军从西边打进来的一版；苏联 S9 从东面、帝国 J9 从北面海上，另写。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

自由号（[units.md](../../story/units.md) 5.2.1）不在术语表和大纲第三节的单位格里，`出场单位` 先不列。最后一段塔站起来走路照 units.md 5.4"原子球塔巨构"写。

新机制待查：九个球轮流充能、亮着的那个才打得动（"无敌到条件"已确认，要轮着给一个球取消无敌）；下一个球亮之前一道光沿钢管跑过去（脚本特效）；每拆一个剩下的充得更快（"倒计时提前"待验证）；塔站起来往北走、亮着的球对附近开火，三种球三种打法（units.md 5.4，没测过）。
