# A9 布鲁塞尔，1927 · 流程剧本（第一遍）

盟军第 9 关，考 K1 改道、K4 时机、K7 跳点、K8 换兵，难度 5，全线最难。题卡见 [cards/all.md](../cards/all.md) A9：原子球塔的九个球轮流充能，亮着的那个在充；九个球共用一层护盾；跳跃倒计时挂在屏幕上。三方同图的终局，这里只写盟军从西边打进来的一版；苏联 S9 从东面、帝国 J9 从北面海上，另写。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"），2026-11-01 按"先加戏"从头重写（点子草稿在 `work/beats/a9_beats.md`）。

自由号（[units.md](../../story/units.md) 5.2.1）不在术语表和大纲第三节的单位格里，`出场单位` 先不列；这一关它只负责把拆塔队和基地车送到西郊。

这一稿去掉了上一稿的"剩三个球时整座塔站起来往北走、三种球三种打法"（units.md 5.4 的巨构，卡上没有，一关多出好几条要记的规则）。最后一段的 K8 换兵改由苏联人杀进来承担：亮着的球底下来的不再只是未来科技的回援，还有基洛夫扔下来的天启坦克，玩家得照来的兵换兵。苏联第三方和 S9、J9 的对法仍按 [handoff.md](../handoff.md)"第一遍"那条跨关接口，三张终局稿要对一遍。

新机制待查：九个球轮流充能、亮着的那个才打得动（"无敌到条件"已确认，要轮着给一个球取消无敌）；下一个球亮之前一道光沿钢管跑过去（脚本特效）；每拆一个剩下的充得更快（"倒计时提前"待验证）；基洛夫飞艇把天启坦克投到亮着的球底下（脚本：飞艇飞到点上，在那里放出天启坦克）。
