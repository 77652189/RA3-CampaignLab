# A3 格林尼治时差 · 流程剧本

## 用户 2026-11-22 改版方向（取代下面的旧流程；旧流程留作素材，按这里重写）

- **致敬**：起义时刻苏联战役那关——时间停止时敌人进攻玩家基地，原版只能靠占冷却塔减轻影响，玩家缺少应对手段。
- **核心**（实现按用户 11-22 定：炮弹留敌我不分的减速力场，时停抓不住力场里的东西，说明里不写这条、靠第一次时停演出来，见 units.md 第四节）：时滞炮车打自己的部队，被打中的部队在时间停止期间也能行动；时停越久，收益越明显。时滞炮车还能远程瘫痪一部分苏军高级防御塔，让强攻少损失。因时间实验失控被停住的单位也能被时滞炮车解救。
- **剧情**：苏军突袭，正是抓住了时间实验失控的时间点。
- **时停和苏军（用户 11-22 定）**：苏军也会被停住，只在时停的空档进攻。原本的盟军守军因为实验事故陷入了永久时停，成了苏军的靶子：玩家要尽快行动、用时滞炮车救下一部分，还得选救援顺序（救不全）。
- **和旧版不同**：时停区从"子午线以东、一圈圈扩张"改成全局；撤离 / 护送平民改成少量盟军部队从战场外赶来支援；类型从限时撤离换成顶着时停强攻苏军基地。
