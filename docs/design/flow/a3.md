盟军第 3 关，教 K1 改道、顺带 K5 借力，难度 2。题卡见 [cards/all.md](../cards/all.md) A3：子午线以东成了时停区，进去的全停住、敌我不分；时停区每隔一阵往西扩一圈，地上亮线画着下一圈到哪；限时把没被困的部队和平民接到撤离点。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/a3_beats.md`）；第二遍（2026-11-01）在第一遍上补全体验目标、简报、目标说明、提示、卡住了、摆放要求和逐句台词，点子来自 `work/beats/a3_beats2.md`，只挑了长在已有规则和人物上的，段落、规则、人物和意外没改。这关还没有地图，摆放要求写示意图里的地方，第 2 层出图时补地点。

新机制待查：时停区（区域里的单位全停住、打不坏，区域按时往西扩一圈，地上画出下一圈的线），见 [handoff.md](../handoff.md)"第一遍"的表；退路是区域里的单位无敌加不能动，按段换区域。另外"冻住的车挡路"靠的是停住的单位还占着地方，关卡线查时停区时一起看窄街能不能被几辆停住的车堵死。
