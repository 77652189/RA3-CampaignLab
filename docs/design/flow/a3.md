# A3 格林尼治时差 · 流程剧本（第一遍）

盟军第 3 关，教 K1 改道、顺带 K5 借力，难度 2。题卡见 [cards/all.md](../cards/all.md) A3：子午线以东成了时停区，进去的全停住、敌我不分；时停区每隔一阵往西扩一圈，地上亮线画着下一圈到哪；限时把没被困的部队和平民接到撤离点。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"），逐句台词、摆放要求、提示和卡住了留到第二遍。

新机制待查：时停区（区域里的单位全停住、打不坏，区域按时往西扩一圈，地上画出下一圈的线），见 [handoff.md](../handoff.md)"第一遍"的表；退路是区域里的单位无敌加不能动，按段换区域。另外"冻住的车挡路"靠的是停住的单位还占着地方，关卡线查时停区时一起看窄街能不能被几辆停住的车堵死。

解法:

平推会怎样: 守在撤离点打追兵，追兵三面压上，人数比玩家多；拖到下一圈，连撤离点和守着的兵一起停住。绕开时停区走远路，平民走得慢，赶不上最后一船。照上一圈的路口再引一次，那里已经在区里了，自己的兵跟着停。用户先拆光压力源的打法拆不到源头：追兵从边界外来；能拆的只有冻住的车，可冻住的打不坏，挡在路上的照样挡着。
