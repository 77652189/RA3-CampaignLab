# J4 金奖展品 · 流程剧本（第一遍）

帝国第 4 关，教 K6 分兵，难度 3。镜像关①：和盟军 [A4](a4.md) 同一张札幌雪祭地图、同一支车队（三车查封的克隆体），A4 是守方；起点两边一样，结果各算各的（大纲第五节）。题卡见 [cards/all.md](../cards/all.md) J4：车队很长，盟军的冰幕工兵跟在车队里，哪座冰雕一动就封哪座的门；车不能打爆，车里的人活着才算；合体机甲合在一起拳头最重，分开是两台快的。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"），逐句台词、摆放要求、提示和卡住了留到第二遍。

地图用 A4 的 `sapporo`，地方名照 A4。A4 里从地道口出的帝国伏兵，这一关换成玩家藏在冰雕里的兵；A4 的号角和北营攻坚这一关不用，北营在这一关是黑田交给玩家的基地。胜负和 A4 对着：A4 被劫走两辆算输，J4 救下两车人算赢。

新机制待查：冰幕工兵看见哪座冰雕里的兵动了就去封那座的门（脚本下令造墙，造墙本身已确认）；截停（车头前、车尾后同时有帝国的兵挡着，车就停下；只挡一头，另一头掉头跑）；护卫打光后车里的人下车跟玩家走；车打爆了车里的人就没了。合体机甲破冰墙在 mechanics.md 是待验证（units.md 已有 `combo_breach` 读数）。
