# 流程剧本能承诺什么：机制和引擎事实

流程剧本的目标、说明、台词里承诺玩家能做的事，要对得上已经确认的引擎事实（总控 2026-10-28）。这张表是第 1 层用的摘要，每行写明出处，事实本身以出处为准：[plan.md](../../plan.md)"第 3 层"一行、[docs/engine/know-how.md](../../engine/know-how.md)、[units.md](../../story/units.md) 的验证进度、各关策划案。出处改了，这里跟着改。

每份流程剧本在 `用到的机制` 里列出它承诺的机制（写这张表的**键**），[flowcheck.py](flowcheck.py) 查三件事：
- 键都在这张表里；
- 没有用到"不能做"的；
- 全文没有出现"不能做"那一行的**禁用说法**（正则）。

用到"待验证"的不算错，检查会列出来，第 3 层先测这些。

禁用说法只是一张网，捞得住常见的写法，捞不全中文的各种说法。写剧本的人还是要先读这张表。漏网的说法被发现了，就在这里补一条正则，再重新检查全部剧本。
