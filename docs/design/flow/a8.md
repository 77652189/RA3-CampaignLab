# A8 海上发布会 · 流程剧本（第一遍）

盟军第 8 关，高光 + 练 K7 跳点、K6 分兵、K4 时机，难度 3.5。题卡见 [cards/all.md](../cards/all.md) A8：三座供电平台随浪起伏，浪高时平台的炮打得远、你的够不着，浪低时反过来；自由号能载一队兵跳上平台，只有一台，丢了就输；机器预热在倒计时。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。粗模地图 `island` 还是旧玩法，这一稿示意图仍在格子上写设想。

自由号（[units.md](../../story/units.md) 5.2.1：甲板跃迁、甲板工厂、可拆炮塔）不在术语表和大纲第三节的单位格里，`出场单位` 先不列。

新机制待查：平台随浪起伏、射程时远时近（[handoff.md](../handoff.md)"第一遍"表 A8，退路是脚本定时给平台的炮换射程）；站在平台上的兵跟着平台升降、高时看得远打得远（同一个退路，给平台上玩家的兵换射程）；黑匣子泄密时，敌人在自由号落地前就把炮转向落点（脚本：自由号起跳时把落点告诉敌方队伍，让它们先移过去）。

平推会怎样: 自由号压上去对轰，浪一高平台的射程比它远，自由号只有一台，丢了就输。按距离一座座跳，撞上正高着的那座，跳上去的兵挨两座的交叉火力。用户先拆光压力源：平台本身就是目标，拆它就是解法；可浪拆不掉，发布会平台上的倒计时也拆不掉，西岸船坞造一支舰队来平推，赶不上倒计时。
