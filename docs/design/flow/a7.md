# A7 鹰派 · 流程剧本

盟军第 7 关，组合 K1 改道、K3 先后、K4 时机，难度 4。题卡见 [cards/all.md](../cards/all.md) A7：自由号靠尼亚加拉电站供电，总挑你防线最空的一段跳；电站一停它就困在原地；掉到一成血就迫降，不能打下来。2026-11-01 按"先加戏"从头重写第一遍（点子草稿在 `work/beats/a7_beats.md`），同一天补第二遍（体验目标、简报、目标说明、提示、卡住了、摆放要求、逐句台词；点子在 `work/beats/a7_beats2.md`，规则没加）。粗版策划案 [plans/a7.md](../../story/plans/a7.md) 和地图 `niagara` 还是"击落"的旧玩法，这一稿照用户 10-28 定的"一成血迫降"写，示意图仍在格子上写设想。

自由号（[units.md](../../story/units.md) 5.2.1）不在术语表和大纲第三节的单位格里，`出场单位` 先不列；它的炮塔、甲板工厂是它身上的部件。

这一稿去掉了上一稿的"叛军工程队隔一阵自己修好闸刀"（卡上没有）：闸刀就是一个开关，谁占着闸房谁说了算；断电断错了地方，自己推回去让它再跳一次，代价是又多一跳。叛军会来抢闸房，想把闸推回去放哈洛韦走。

新机制待查：自由号"挑玩家防线最空的一段跳"（脚本按段数玩家的兵和炮，跳到最少的那段）、"不跳回上次的落点"；断电后甲板跃迁失效（units.md 5.2.1 写了，测试台没测）；闸房里的闸刀拉下、推回（脚本：占着闸房的一方切换电站的电）；一成血迫降、并朝最空的一段滑下去（[handoff.md](../handoff.md)"第一遍"待拍板第 9 条，按推荐写；脚本：血量到一成时锁血，沿路点移到选中的那段）。
