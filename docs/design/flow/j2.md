# J2 涨潮的鸟居 · 流程剧本（第一遍）

帝国第 2 关，教 K4 时机、顺带 K1，难度 1.5。题卡见 [cards/all.md](../cards/all.md) J2：运输船吃水深，只有涨潮时才过得了浅滩，潮一退就搁在原地；盟军护航机跟着船队飞；烟花兵放出的花火云在原地留一阵，飞进去的飞机掉血。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"），逐句台词、摆放要求、提示和卡住了留到第二遍。

新机制待查：涨潮退潮（潮位到时脚本开关水道，退潮时浅滩露出来能走人，[handoff.md](../handoff.md)"第一遍"表的退路）；每一潮只开一个门洞；船被堵在门洞外会停下等；运输船在水里打不沉、搁浅后才打得坏（可以拿"无敌到条件"做，已确认）。

  敌方: 运输船在外海等潮，地图外开进来，打不到也拆不掉；护航机跟着船从边界外飞来，每一潮换方向；潮水按点涨落，拆不掉。码头仓库是未来科技的，有守军，但打仓库不拦船。
解法:
  - {打法: 潮来之前把花火云挂在要开的那个门洞上空，薙刀巡洋舰横在门洞里拖到退潮, 段: 第一潮, 提示: 开场千岁说深水只剩鸟居下面那一条；演示时云留在原地}

  - {打法: 先看潮位标再挪云，三个门洞里只守这一潮开的那个, 段: 第二潮, 提示: 千岁说每一潮开的门洞不一样}

平推会怎样: 烟花兵追着护航机在头顶放云，云留在原地，飞机一下就过去了；造一大队船追运输船，护航机一路炸你的船，运输船皮厚，在水里打不沉；等它靠上码头再打，人已经装上船，下一潮就走了。用户先拆压力源的打法在这关拆不到东西：船和飞机都从地图外来，潮水按点涨落；打下码头仓库也拦不住船，船会照常进来等人。最后一潮按老办法拿船堵门洞，潮退到底自己的船先搁住，正好给轰炸机当靶子。
