# J2 涨潮的鸟居 · 流程剧本（第一遍）

帝国第 2 关，教 K4 时机、顺带 K1，难度 1.5。题卡见 [cards/all.md](../cards/all.md) J2：运输船吃水深，只有涨潮时才过得了浅滩，潮一退就搁在原地；盟军护航机跟着船队飞；烟花兵放出的花火云在原地留一阵，飞进去的飞机掉血。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j2_beats.md`），只挑了长在已有规则和人物上的；逐句台词、摆放要求、提示和卡住了留到第二遍。

新机制待查：涨潮退潮（潮位到时脚本开关水道，[handoff.md](../handoff.md)"第一遍"表的退路）；每一潮深水只剩一个门洞，每潮换一个；运输船退潮时没过浅滩就搁在原地。
