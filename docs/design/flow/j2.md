# J2 涨潮的鸟居 · 流程剧本

帝国第 2 关，教 K4 时机、顺带 K1，难度 1.5。题卡见 [cards/all.md](../cards/all.md) J2：运输船吃水深，只有涨潮时才过得了浅滩，潮一退就搁在原地；盟军护航机跟着船队飞；烟花兵放出的花火云在原地留一阵，飞进去的飞机掉血。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j2_beats.md`）；第二遍（2026-11-01）在第一遍上补全体验目标、简报、目标说明、提示、卡住了、摆放要求和逐句台词，点子来自 `work/beats/j2_beats2.md`，只挑了长在已有规则和人物上的，段落、规则、人物和意外没改。带玩法信息的台词只给播报和千岁（README 第 24 条，ADR 0013）：真壁换门洞、叫轰炸机，黑田交烟花兵，千岁都跟一句把玩法那层再说一遍。这关还没有地图，摆放要求写示意图里的地方，第 2 层出图时补地点。

第一潮千岁把开的门洞点名说一次（教），第二潮起只说"看潮位标"。黑田那句"神明的门，放进来一次就再也关不上了"是帝国线"不许再改"的回响。

新机制待查：涨潮退潮（潮位到时脚本开关水道，[handoff.md](../../archive/design-handoff.md)"第一遍"表的退路）；每一潮深水只剩一个门洞，每潮换一个；运输船退潮时没过浅滩就搁在原地。
