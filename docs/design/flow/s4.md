# S4 科学城 · 流程剧本

苏联第 4 关，练 K1 改道、K2 视野，难度 3。题卡见 [cards/all.md](../cards/all.md) S4：盟军轰炸机高速走直线进场，研究所被毁即失败；阻塞气球车展开后放起系留气球，挂线区里的飞机变慢、掉血。飞到研究所头顶时已经在投弹，气球挂在头顶太晚；它走直线，航线能预先算出来；每波换一个方向，要先看见它从哪来；气球也拦你自己的飞机。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/s4_beats.md`），只挑了长在已有规则和人物上的；2026-11-01 补第二遍（体验目标、简报、目标说明、提示、卡住了、摆放要求、逐句台词；点子在 `work/beats/s4_beats2.md`，规则没加）。带玩法信息的台词按 ADR 0013 只给播报和卡佳，保底的那句从别列津挪给了卡佳。

"气球也拦你自己的飞机"落在玩家自己的米格上：米格追轰炸机，一头扎进自己挂的气球。上一稿让金主的运货直升机按固定航线穿过气球阵，那是一种第三方飞行单位，题卡没有，这稿去掉；金主的货改成坐火车进东北的货场，护货是奖励目标，用的是已有的"地面部队来打"。上一稿"占下气象站、每波小地图闪方向"也去掉，看方向只靠气球车本身的视野（[units.md](../../story/units.md)：气球给大范围视野）和播报。

新机制待查：阻塞气球车的挂线区（[units.md](../../story/units.md) 验证进度里测试台已测过"减速、伤飞机，展开成立"，[mechanics.md](mechanics.md) 还没有这一行，所以没写进 `用到的机制`）；轰炸机按脚本航线直线进场、每波换方向；气球车收起后再开走（原版展开类单位的收起，没在测试台对过；做不了就只能造新车）。
