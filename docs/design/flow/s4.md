# S4 科学城 · 流程剧本（第一遍）

苏联第 4 关，练 K1 改道、K2 视野，难度 3。题卡见 [cards/all.md](../cards/all.md) S4：盟军轰炸机高速走直线进场，研究所被毁即失败；阻塞气球车展开后放起系留气球，挂线区里的飞机变慢、掉血。飞到研究所头顶时已经在投弹，气球挂在头顶太晚；它走直线，航线能预先算出来；每波换一个方向，要先看见它从哪来；气球也拦你自己的飞机。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

最后一段的转折用卡上"气球也拦你自己的飞机"：金主的运货直升机从东北飞进来，航线正好穿过前几波挂在北山的气球，同一条"挂线区不认敌我"这次拦的是自己人的货。

新机制待查：阻塞气球车的挂线区（[units.md](../../story/units.md) 验证进度里测试台已测过"减速、伤飞机，展开成立"，[mechanics.md](mechanics.md) 还没有这一行，所以没写进 `用到的机制`）；轰炸机按脚本航线直线进场、每波换方向；金主的运货直升机按固定航线飞、归第三方，玩家指挥不了；气球车收起后能挪（原版展开类单位的收起，没在测试台对过）。
