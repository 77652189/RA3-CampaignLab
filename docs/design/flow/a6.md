# A6 古代的服务器 · 流程剧本

盟军第 6 关，喘 + 练 K2 视野，难度 2.5。题卡见 [cards/all.md](../cards/all.md) A6：哨塔躲在巨石背后，从外面看不见也打不着；巨石是未来科技装的测距棱镜，光棱打上去会折射；谭雅进石阵当眼睛，外面的光棱当炮；拆掉一座，剩下的换到另一块石头后面。2026-11-01 按"先加戏"从头重写第一遍（点子草稿在 `work/beats/a6_beats.md`），同一天补第二遍（体验目标、简报、目标说明、提示、卡住了、摆放要求、逐句台词；点子在 `work/beats/a6_beats2.md`，规则没加）。

新机制待查：光棱打巨石折射（[handoff.md](../handoff.md)"第一遍"表 A6，退路是巨石做成中立的光棱塔式建筑）；哨塔沉进地下、换一块石头再升起（退路：脚本删掉这一座，在另一块石头后面造一座）；撤出段坑里的光谱塔借巨石折射打外面（和第一条同一个机制，只是换了一边用）。
