# A6 古代的服务器 · 流程剧本（第一遍）

盟军第 6 关，喘 + 练 K2 视野，难度 2.5。题卡见 [cards/all.md](../cards/all.md) A6：哨塔躲在巨石背后，从外面看不见也打不着；巨石是未来科技装的测距棱镜，光棱打上去会折射；谭雅进石阵当眼睛，外面的光棱当炮；拆掉一座，剩下的换到另一块石头后面。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

文中的"哨塔"就是 `出场单位` 里的多功能炮塔。光棱坦克（[units.md](../../story/units.md) 5.3 的情怀单位）不在术语表和大纲第三节里，`出场单位` 先不列，等补进术语表再加。

新机制待查：光棱打巨石折射（[handoff.md](../handoff.md)"第一遍"表 A6，退路是巨石做成中立的光棱塔式建筑）；哨塔沉进地下、换一块石头再升起（退路：脚本删掉这一座，在另一块石头后面造一座）；撤出段坑里的光谱塔借巨石折射打外面（和第一条同一个机制）。
