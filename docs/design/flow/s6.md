# S6 时间卫星 · 流程剧本（第一遍）

苏联第 6 关，组合 K1 改道、K5 借力，难度 4。题卡见 [cards/all.md](../cards/all.md) S6：帝国机甲总挑当时最快的那条谷冲发射塔；干扰车光环里谁都慢到四成，自己人也一样；三条谷，只有两辆干扰车；倒计时到了才算赢。镜像关③，帝国 J7 在同一个发射场当攻方（甲卡 [cards/j7.md](../cards/j7.md)，灰盒结论 [cards/brief.md](../cards/brief.md) J7 部分）：两关共用三条谷、发射塔、干扰车，J7 拆苏联人的干扰车，S6 挪自己的。方位照地图 `experimental/cnv/maps/baikonur.py`：苏联基地在西，发射场居中，三条谷在东边南北排开，帝国从东边图外来（brief 里写的"南北"是灰盒的抽象，第 2 层以地图为准）。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

新机制待查：帝国机甲按干扰车挑最快的谷（和 brief J7"援军怎么选谷"是同一条，退路是脚本按每条谷的干扰车数选路点）；燃料车同样挑谷；北谷口的滑坡中途清开（用扩边界做）。
