# S6 时间卫星 · 流程剧本

苏联第 6 关，组合 K1 改道、K5 借力，难度 4。题卡见 [cards/all.md](../cards/all.md) S6：帝国机甲总挑当时最快的那条谷冲发射塔；干扰车光环里谁都慢到四成，自己人也一样；三条谷，只有两辆干扰车；倒计时到了才算赢。镜像关③，帝国 J7 在同一个发射场当攻方（甲卡 [cards/j7.md](../cards/j7.md)）：两关共用三条谷、发射塔、干扰车，J7 拆苏联人的干扰车，S6 挪自己的（[handoff.md](../../archive/design-handoff.md)"第一遍"待拍板第 1 条，按推荐写）；J7 卡上"苏联援军总挑当时最快的那条谷"，这关的援军车队也一样。方位照地图 `experimental/cnv/maps/baikonur.py`：苏联基地在西，发射场居中，三条谷在东边南北排开，帝国从东边图外来。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/s6_beats.md`），只挑了长在已有规则和人物上的；2026-11-01 补第二遍（体验目标、简报、目标说明、提示、卡住了、摆放要求、逐句台词；点子在 `work/beats/s6_beats2.md`，规则没加）。带玩法信息的台词按 ADR 0013 只给播报和卡佳，两条保底的台词从别列津挪给了卡佳。

上一稿自己加的几条去掉了：北谷口的滑坡中途清开（三条谷一开始就都通，两辆干扰车一开始就都在）；燃料车要接到、燃料车全死就输（题卡只有"倒计时到了才算赢"，输只输在发射塔）；纸鹤侦察机"看你的车停在哪"（题卡里机甲只看哪条快，打下侦察机也不该有用，干脆不派）；山脊观察哨的奖励。题卡上"你的援军也走这些谷"留着，落在一支援军车队上，护它进场是奖励目标。

新机制待查：帝国机甲按干扰车挑最快的谷（和 J7"援军怎么选谷"是同一条，退路是脚本按每条谷的干扰车数选路点）；援军车队同样挑谷；发射倒计时（目标上挂一个计时器，倒计时到了算赢）。
