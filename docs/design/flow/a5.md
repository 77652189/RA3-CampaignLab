# A5 巴拿马之锁 · 流程剧本（第一遍）

盟军第 5 关，教 K7 跳点、顺带 K2 视野，难度 3.5；镜像关②，苏联 S5 是攻方。题卡见 [cards/all.md](../cards/all.md) A5：船闸控制室在东岸高台上，守军的炮全朝着唯一的坡道；超时空信标兵能把一整队人拉到自己身边；闸里的水位每隔一阵升降一次，困在闸里的船跟着升降。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"），逐句台词、摆放要求、提示和卡住了留到第二遍。

地形的走向照已有的 `experimental/cnv/maps/panama.py`（和 [s5.md](s5.md) 一致）：运河南北走向，南边是海、北边是湖；玩家在西岸，控制室在东岸的高台上，坡道在高台东面、背着水；苏联基地在东北的湖边；高台南边有一片滩头。和那张图不一样的一处：题卡要"哪一级闸升到顶，梯子就在哪一边"，这里把闸室分成上下两级（中间多一道闸门），那张图现在只有一级闸室、两道闸门，要关卡线定。

新机制待查：船闸水位升降、水位升到顶时闸里的船贴着高台边当梯子（见 [handoff.md](../handoff.md)"第一遍"的表，退路是水位换时脚本开关一条从西岸闸边经船到高台的路）；船升到顶时看得见闸墙外、降下去就看不见（退路是脚本按水位揭一块图）。信标兵拉人已在测试台验证过（[units.md](../../story/units.md) 超时空信标兵），钻地运兵车钻地和出地面也测过（`burrower --check pass / drop`），mechanics.md 里还没有这两行。
