# S2 西伯利亚快车 · 流程剧本（第一遍）

苏联第 2 关，教 K4 时机，难度 2。题卡见 [cards/all.md](../cards/all.md) S2：冷冻列车开着时挂冰甲打不动；每到一站停下放冷卸压，白雾一放冰甲就掉，白雾里的东西也冻住；你的装甲列车走旁边那条轨道，道岔扳到哪它就停在哪。装甲列车只做脚本车（[units.md](../../story/units.md) 第四节），玩家开不了它，能决定的只有道岔。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

新机制待查（[handoff.md](../handoff.md)"第一遍"一节的表）：冷冻列车进站卸压、冰甲掉（冰甲本身用"无敌到条件"）；白雾冻住雾里的单位，敌我都冻；道岔房清掉哨兵、派兵站进去就扳过去，装甲列车按道岔停在不同的停车点（退路：几个可选的停车点）；打掉一节制冷车，后面那节车厢化冻、老兵下车归玩家（"给兵"已确认，化冻的样子没做）；冷冻直升机冻住装甲列车，它就停在原地。
