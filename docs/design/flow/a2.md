# A2 坝上风云 · 流程剧本（第一遍）

盟军第 2 关，教 K8 换兵，难度 1.5。题卡见 [cards/all.md](../cards/all.md) A2：坝体挨炸就掉血，自己的溅射也算；苏联特工贴着坝走，每波打头的兵和来的路都不一样；缩小的车炸不动坝。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"），逐句台词、摆放要求、提示和卡住了留到第二遍。

新机制待查：坝体（中立建筑）挨玩家自己的溅射掉血、炸药车死在坝上就炸坝、缩小的车炸药失效（这三条 mechanics.md 还没有，[handoff.md](../handoff.md)"第一遍"的表里也没列，请关卡线一起查；做不了的退路：坝体只在脚本区域里按"有爆炸"扣血，炸药车死在坝体区域里由脚本扣一截血、缩小的车不扣）。
