# S9 红色的 1927 · 流程剧本（第一遍）

苏联第 9 关（终局），考 K5 借力、K6 分兵、K7 跳点、K8 换兵，难度 5。题卡见 [cards/all.md](../cards/all.md) S9：原子球塔外围一圈护盾，盟军从西面也在打它，护盾的炮火全朝着压上来最凶的一方；钻地车能从地下过去，出了地面是活靶子；跳跃倒计时。三方同图（大纲第二节"终局"），这里只写苏联从东面打进来的一版：盟军是另一个敌人，从西面啃护盾；帝国从北面海上来的那一版在 J9。大纲第四节：夺回空间站时揭开它的黑匣子。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

新机制待查：护盾环上的炮火转向压得最凶的一方（脚本按每段区域里双方的兵力挑目标）；护盾按盟军啃的进度分段变薄；盟军作为第三方按进度往塔心推、也抢机器；盟军用超时空把一队兵送进护盾（原版有超时空传送仪，给 AI 下令放没测）；拿下中继站后空间站回到玩家手里（units.md 5.2）。
