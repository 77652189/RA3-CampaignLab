# S9 红色的 1927 · 流程剧本

苏联第 9 关（终局），考 K5 借力、K6 分兵、K7 跳点、K8 换兵，难度 5。题卡见 [cards/all.md](../cards/all.md) S9：原子球塔外围一圈护盾，盟军从西面也在打它，护盾的炮火全朝着压上来最凶的一方；钻地车能从地下过去，出了地面是活靶子；跳跃倒计时。三方同图（大纲第二节"终局"），这里只写苏联从东面打进来的一版；帝国从北面海上来的那一版在 J9。大纲第四节：夺回空间站时揭开它的黑匣子。第一遍按"先加戏"从头写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/s9_beats.md`），只挑了长在已有规则和人物上的；同一天补成第二遍的全量稿（点子草稿在 `work/beats/s9_beats2.md`），段落、规则、人物、意外和跟 A9、J9 对过的台词（黑尔那句"野蛮人"、科尔那句"这单我不干了"、卡佳那句"别打球"、北边海上帝国舰队那句）没改，只补字段和台词；施泰因说出口的要紧事，按 README 第 24 条由卡佳跟一句把玩法那层再说一遍。

和 A9（[a9.md](a9.md)）对上的几件：地图的地名和方位照 A9（西郊、西环路、原子球塔、北街、南街、东桥、北边机场）；盟军从西郊一个个拆球，他们总围着亮着的那个球打，所以"盟军压得最凶的那段"就是亮着的球底下，球碎一个，那一段的护盾就薄一段；苏联在盟军拆到最后三个时从东桥杀进塔下，基洛夫飞艇往亮着的球底下扔天启坦克，苏联要的是完整的机器，见谁打谁；苏联人打到南街，科尔带着人撤了；黑尔那句"野蛮人"两边听到的是同一句。球亮哪个、只有亮着的打得动是盟军那一关的规则，这里只当看得见的"盟军在哪儿压"，苏联玩家不用记。

这一稿去掉了上一稿自己加的：盟军用超时空把一队兵送进护盾（卡上没有，A9 也没有）；夺回的空间站光束冷却变短的奖励（空间站只在剧情里回来）。Gemini 的"两军在炮火死角并肩避弹、光谱塔只轰先开火的一方"是新规则，不用。

新机制待查：护盾环上的炮火转向压得最凶的一方（脚本按每段区域里双方的兵力挑目标）；护盾按盟军拆球的进度分段变薄；盟军作为第三方按进度拆球、往塔心推；基洛夫飞艇把天启坦克投到亮着的球底下（和 A9 同一段脚本）。
