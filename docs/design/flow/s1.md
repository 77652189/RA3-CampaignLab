# S1 破冰 · 流程剧本

校准用的三关之一（基地对抗）。也是苏联线的第一关：领袖别列津、情报官卡佳、宿敌施泰因都在这关第一次露面，所以它同时校准"怎么介绍一条线的人"。

大纲 S1 只有一句："盟军冷冻车队押着被俘的苏联科学家，横穿冰湖。磁钩把车一辆辆钩出车队，集火打掉。"这里按"基地对抗"补成三段：建基地 → 钩车救人 → 反攻施泰因的冰上营地。"冰面承重有限、重型单位会压碎冰面"是这关的地标玩法。

**2026-10-29 按五条审核重写**（[README.md](README.md) 第 16～20 条）。查出的问题：最后一段东边大片冰面没用上（空地 18%）；施泰因说"让湖面再冷一点"以后什么都没发生；别列津只喊口号，没有自己的选择；没有意外，也没有保底。改成：车队提前出发是意外（伏笔在简报"施泰因从不照时刻表走"），配"磁钩援军"保底；反攻开头卡佳劝撤、别列津决定打上门；东南岸加一个救冻住老兵的奖励，回报是一队兵，也接上胜利时那列装老兵的火车。
