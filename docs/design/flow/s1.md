# S1 破冰 · 流程剧本

校准用的三关之一（基地对抗）。也是苏联线的第一关：领袖别列津、情报官卡佳、宿敌施泰因都在这关第一次露面，所以它同时校准"怎么介绍一条线的人"。

大纲 S1 只有一句："盟军冷冻车队押着被俘的苏联科学家，横穿冰湖。磁钩把车一辆辆钩出车队，集火打掉。"这里按"基地对抗"补成三段：建基地 → 钩车救人 → 反攻施泰因的冰上营地。"冰面承重有限、重型单位会压碎冰面"是这关的地标玩法。

```yaml
关: S1
关名: 破冰
阵营: 苏联
类型: 基地对抗
地点: 贝加尔湖冰面
新东西: 磁钩坦克
出场单位:
  我: [磁钩坦克, 基地车, 动员兵, 防空步兵, 战斗工程师, 镰刀机甲]
  敌: [守护者坦克, 冷冻军团兵, 冷冻直升机, 光谱塔, 维和步兵]
用到的机制: [磁钩拽车, 冰面承重, 目标和标记, 信息框, 小窗通讯, 关前简报, 播报]
一句话: 地下抵抗运动的第一仗：在贝加尔湖岸边建起基地，用磁钩把押着科学家的车一辆辆钩出盟军车队；施泰因报复时，冰面只撑得住轻的，反攻他的冰上营地要挑兵
体验目标: 冰面是第三支军队：它替你挡住重坦，也会吞掉你的重坦
取舍:
  - 钩车：车队开过来时，先钩押人的车，还是先钩护卫让车队停下
  - 防守：施泰因的冷冻部队从冰上来，在岸上守，还是把冰面打碎让他过不来
  - 反攻：冰上营地只能派轻的兵去，造多少磁钩、多少步兵，要不要等冰面冻结实
张力: 拮据（建基地，车队已经在路上）→ 紧（钩车）→ 掌控（反攻）
接上一关: 战役第一关。苏联被占领，抵抗运动藏在西伯利亚。别列津是领袖，卡佳是情报官，玩家是新来的指挥官
引出下一关: 施泰因丢了科学家，撤走时把冻住的老兵装上冷冻列车往东开（S2 西伯利亚快车）

简报:
  - 别列津: 同志们，这是我们的新指挥官。
  - 别列津: 苏联输了战争，可没有输掉人。今天，我们要把自己人抢回来。
  - 卡佳: 盟军的冷冻部队押着一批科学家横穿贝加尔湖。他们研究过协调器。
  - 卡佳: 车队的指挥官叫施泰因，占领军里最冷的一个。车队明天中午过湖。
  - 卡佳: 我们只有一辆基地车和几台磁钩坦克。磁钩能把车从车队里拽出来。
  - 别列津: 指挥官，湖是我们的。让他们记住这一点。

段:
  - 名: 开场
    时长: 约 20 秒
    镜头:
      - 看: 白茫茫的冰湖，远处一列盟军车队在冰上排成一行，前后是守护者坦克，冷冻军团兵跟在车边
        台词:
          - 施泰因: 零下三十一度。正适合运货。
      - 看: 车队里几辆封着窗的卡车，车门上挂着锁
        台词:
          - 卡佳: 科学家就在那几辆封窗的卡车里。别打坏它们。
      - 看: 冰面上一道裂缝从一辆坦克脚下裂开，坦克慢慢沉下去
        台词:
          - 卡佳: 还有，冰没有看上去那么厚。重的东西别往湖心开。
      - 看: 西岸的树林边，一辆基地车和三台磁钩坦克
    结束: 交还控制，车队已经在路上

  - 名: 建基地
    时长: 约 3 分钟
    目标:
      - 种: 主
        题: 在西岸建起基地
        说明: 车队要过一阵才到我们这边的湖岸。抓紧时间展开基地车，建好兵营和战车工厂。
    事件:
      - 时机: 交还控制
        台词:
          - 卡佳: 车队离岸边还有几分钟。先把基地展开。
      - 时机: 战车工厂建好
        台词:
          - 卡佳: 战车工厂好了。多造几台磁钩，它们是今天的主角。
      - 时机: 车队开到湖心
        台词:
          - 播报: 敌方车队正在接近。
    下一步靠什么:
      - 基地车和基地位置在开场最后一个镜头里
      - 车队在小地图上一直标着，看得见它往哪开
      - 卡佳报车队还有多久到
    卡住了:
      - 时机: 很久没有展开基地车
        台词:
          - 卡佳: 指挥官，基地车还没展开。车队可不等我们。
    结束: 车队开到西岸附近的冰面上

  - 名: 钩车
    时长: 约 4 分钟
    目标:
      - 种: 主
        题: 救出被押的科学家
        说明: 科学家关在车队里那几辆封窗的卡车里。用磁钩坦克把卡车从车队里拽到岸边，别把车打坏。
      - 种: 奖励
        题: 打掉车队的护卫
        说明: 护卫的守护者坦克会追着卡车跑。打掉它们，卡车就没人看着了。
    事件:
      - 时机: 车队开进磁钩的射程，玩家还没用过磁钩
        文字: 磁钩坦克：选中磁钩坦克，点一辆车，把它拽到身前。被钩住的车开不了火。
      - 时机: 第一次钩住车
        台词:
          - 播报: 已锁定目标。
          - 卡佳: 钩住了！拖回岸上！
      - 时机: 第一辆押人的卡车拖到岸边
        镜头: 卡车门被撬开，几个穿白大褂的人跳下来
        台词:
          - 卡佳: 第一批科学家安全了。
      - 时机: 护卫追上了冰面薄的地方
        台词:
          - 卡佳: 守护者坦克太重了。往湖心引，冰会替我们干活。
      - 时机: 施泰因发现车被抢
        镜头: 小窗通讯，施泰因站在一辆守护者坦克上
        台词:
          - 施泰因: 有意思。抵抗运动学会钓鱼了。
          - 施泰因: 那就让湖面再冷一点。
    下一步靠什么:
      - 封窗的卡车在小地图上闪
      - 开场镜头已经指过卡车，卡佳点过名
      - 钩住的车被拖向岸边，看得见进度
    卡住了:
      - 时机: 押人的卡车被打坏了
        台词:
          - 卡佳: 别打卡车！里面是我们的人！用磁钩。
      - 时机: 车队快开出地图，还有卡车没钩
        台词:
          - 卡佳: 车队快过湖了。最后几辆，现在不钩就没了。
    结束: 科学家救下来了。施泰因决定报复：他的冷冻部队从湖东岸的冰上营地开过来

  - 名: 反攻
    时长: 约 5 分钟
    镜头:
      - 看: 湖东边一座建在冰上的盟军营地，光谱塔，机场上停着冷冻直升机
        台词:
          - 卡佳: 那是施泰因的冰上营地。车队就是从那里出发的。
      - 看: 营地前的冰面，有几处厚冰，也有几处发黑的薄冰
        台词:
          - 卡佳: 去营地只能走冰面。重坦压上去会沉，挑轻的兵去。
    目标:
      - 种: 主
        题: 摧毁施泰因的冰上营地
        说明: 施泰因的营地建在湖面上。拆掉他的光谱塔、机场和兵营，盟军就再也不敢从这里过湖。冰面撑不住重坦，派轻的部队，或者走厚冰。
    事件:
      - 时机: 施泰因的第一波报复
        台词:
          - 播报: 我们的基地遭到攻击。
          - 卡佳: 冷冻部队从冰上来了。在岸上顶住。
      - 时机: 玩家的重型单位压碎了冰
        台词:
          - 卡佳: 冰裂了！太重了，换轻的上。
      - 时机: 营地只剩最后几座建筑
        镜头: 小窗通讯，施泰因看着窗外
        台词:
          - 施泰因: 这些科学家你们留着吧。
          - 施泰因: 冻住的那些老兵，我先带走了。
    下一步靠什么:
      - 营地在过场镜头里指过，建筑挂着标记
      - 厚冰和薄冰看得出颜色深浅
      - 卡佳每次在冰裂时提醒
    卡住了:
      - 时机: 玩家一直在岸上守，没有出兵
        台词:
          - 别列津: 指挥官，光守是守不回苏联的。
      - 时机: 第二次有重型单位沉下去
        台词:
          - 卡佳: 又沉了一台。走厚冰，或者别派重的。
    结束: 营地拆完，任务胜利

胜利:
  镜头: 冰上营地的残骸慢慢沉进湖里，远处东岸的铁路上，一列冷冻列车开走
  台词:
    - 卡佳: 营地沉了。可施泰因跑了，那列火车上装的是冻住的老兵。
    - 别列津: 同志们，今天贝加尔湖替我们说了话。
    - 别列津: 指挥官，追上那列火车。
失败:
  - 原因: 押着科学家的卡车全没了
    台词:
      - 播报: 我们的任务目标失败了。
      - 卡佳: 科学家一个都没救出来。我们白来了。
  - 原因: 基地被摧毁
    台词:
      - 播报: 我们的基地被摧毁了。
      - 别列津: 撤退！保住人，以后还能再打。
```
