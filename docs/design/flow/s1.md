# S1 破冰 · 流程剧本（第一遍）

苏联第 1 关，教 K5 借力，难度 1.5。题卡是用户 10-30 选的甲"拖在后面的卡车"（[cards/s1.md](../cards/s1.md) 甲）：押科学家的轻卡车用钢缆挂在守护者坦克后面拖着走，钩卡车拽不动；岸边一圈薄冰，重车压上去就沉，双方都算；把守护者拽过薄冰带让冰吞掉它，钢缆一断卡车就是你的。几何、岬角比磁钩多、镰刀靠战斗堵，照 [cards/brief.md](../cards/brief.md) S1 的灰盒结论。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

2026-11-01 照甲卡重写 10-29 的旧稿：旧稿的"钩卡车拖上岸""往湖心引""反攻冰上营地"都是旧题，删了；人物、开场的沉车镜头、西岸、南北湖口、施泰因带走冻住老兵的结尾留下。**步兵上冰**：新甲不用旧稿"湖心按种类连步兵也杀"，薄冰只沉重车，双方的步兵都能走过去：护卫派冷冻军团兵上岸打磁钩，玩家要分兵护磁钩；玩家的步兵也能上冰追车队，但守护者在厚冰上碾步兵，要堆很多人才打得过（灰盒：约九倍的钱），玩家钱够不够留给实机。

新机制待查（[handoff.md](../handoff.md)"第一遍"一节、brief.md 的"依赖的机制"）：卡车每帧跟在守护者后面（拖行）；拖行时卡车钩不动、守护者沉了以后换成能钩的；敌方 AI 不自己开上薄冰；镰刀机甲走上薄冰也沉（加进按种类沉）；冷冻直升机冻住的磁钩钩不了车（原版冷冻效果，没在测试台对过）。
