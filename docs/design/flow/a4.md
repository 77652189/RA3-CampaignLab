# A4 冰雕里的兵 · 流程剧本

## 用户 2026-11-22 改版方向（取代下面的旧流程；旧流程留作素材，按这里重写）

- **机制**：护送从"摧毁"改成"争夺"，类似运载目标（推车）。帝国的目的是解决护卫、拖到克隆体苏醒；盟军要在那之前把车队护到终点。车队血量相应上调，帝国只在最后一段才殊死一搏、试着摧毁载具。
- **压力**：帝国多线进攻，让指挥官疲于奔命。冰雕里只出步兵，但混着坦克杀手和忍者，给盟军脆弱的载具和步兵压力。
- **要点**：让帝国找到指挥官防守的薄弱点。海量冰雕铺满全图，盛大的节日气氛和紧张感强烈对比；出兵的位置和规律要尽量藏，指挥官要是看出来了，难度明显下降。
- **暗示不明说（用户 11-22 定）**：出兵前给不点破的信号，比如出兵冰雕附近的摊贩先跑开、灯笼灭掉；细心的看得出规律，粗心的只当是气氛，也不会觉得兵是凭空刷出来的。
- **和旧版不同**：旧版"号角一响三条街同时出兵、冒红烟提前十秒预告"是明示的规律，新版要藏；车队从"挨打就丢"改成"推车争夺"，前段的威胁是拖时间不是打车。
