# J7 发射窗口 · 流程剧本（第一遍）

帝国第 7 关，组合 K5 借力、K1 改道、K2 视野、K9 引火，难度 4.5。镜像关③：苏联 S6 是守方，同一次发射（大纲第五节），起点一样（发射场、三条谷、干扰车、倒计时），结果各算各的。题卡是用户 10-30 选的甲"给谁修路"（[cards/j7.md](../cards/j7.md) 甲）：三条谷里摆着苏联干扰车，光环里谁都慢到四成；苏联援军从地图边界外开来，拆不到，总挑当时最快的谷走；干扰车不认人，你拆通哪条谷就是给援军修哪条快路。选谷的算法、每轮挪车和塔边预置的干扰车照 [cards/brief.md](../cards/brief.md) J7 的灰盒结论。镜像关同一辆车两边各当一次题眼（[handoff.md](../handoff.md)"第一遍"待拍板第 1 条，按推荐写）：S6 挪自己的车，这里拆敌人的车。第一遍按"先加戏"从头写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j7_beats.md`），只挑了长在已有规则和人物上的。

上一稿自己加的去掉了：发射场北边的燃料库奖励（炸了它提前发射时倒计时少跳一截，卡上和灰盒都没有，多一条要记的规则）。奖励换成台上的防空阵地，回报只是纸鹤和天狗飞得上去，不改规则。

**方位和地名对齐 S6**（[s6.md](s6.md)，地图 `experimental/cnv/maps/baikonur.py`）：苏联基地在西，发射场居中，北、中、南三条谷在东边南北排开，帝国从东边来；brief 里"玩家在南、发射场在北"是灰盒的抽象。示意图照 s6.md 的 100×60 格子写，苏联基地这一关在边界外、拆不到。**要关卡线核对**：灰盒要"谷口相隔 ≥ 1500"才追不上援军，现有地图三条谷的中线相隔约一千一。

新机制待查（brief.md"依赖的机制"）：援军按"路程 + 剩下的干扰车 × 15 秒"挑谷（退路：脚本按每条谷的干扰车计数选路点）；光环地面圈（没有就脚本放标记物）。
