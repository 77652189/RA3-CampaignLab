# J7 发射窗口 · 流程剧本（第一遍）

帝国第 7 关，组合 K5 借力、K1 改道、K2 视野、K9 引火，难度 4.5。镜像关③：苏联 S6 是守方，同一次发射（大纲第五节）。题卡是用户 10-30 选的甲"给谁修路"（[cards/j7.md](../cards/j7.md) 甲）：三条谷里摆着苏联干扰车，光环里谁都慢到四成；苏联援军从地图边界外开来，拆不到，总挑当时最快的谷走；干扰车不认人，你拆通哪条谷就是给援军修哪条快路。选谷的算法、每轮挪车和塔边预置的干扰车照 [cards/brief.md](../cards/brief.md) J7 的灰盒结论。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

2026-11-01 照甲卡重写 10-29 的旧稿：旧稿的"小队拔掉一辆干扰车主力就进来""打通全部三条谷换三路援军"都是旧题（拆路只有好处），删了；千岁的转折、黑尔被普雷斯顿打断、别列津"护盾一掉马上点火"的伏笔、三座供能塔、提前发射、后备机甲、燃料库奖励留下。衍生规则分四步显出来：开场演示巡逻在光环里爬、出了光环就快；小队照命令拆通北谷，第一波援军就顺着这条谷冲到刚展开的基地（第一反应吃亏）；拆塔时苏联人每波把一辆干扰车挪进你大军那条谷，援军跟着换谷（每轮最优在变）；提前发射时同一辆车换个后果：塔边和谷里剩下的干扰车开到塔下，从"替你拖住援军"变成"拖住你的机甲"。

**方位和地名对齐 S6**（[s6.md](s6.md)，地图 `experimental/cnv/maps/baikonur.py`）：苏联基地在西，发射场居中，北、中、南三条谷在东边南北排开，帝国从东边来；brief 里"玩家在南、发射场在北"是灰盒的抽象。示意图照 s6.md 的 100×60 格子写，苏联基地这一关在边界外、拆不到。**要关卡线核对**：灰盒要"谷口相隔 ≥ 1500"才追不上援军，现有地图三条谷的中线相隔约一千一。

新机制待查（brief.md"依赖的机制"）：援军按"路程 + 剩下的干扰车 × 15 秒"挑谷（退路：脚本按每条谷的干扰车计数选路点）；光环地面圈（没有就脚本放标记物）。
