校准用的三关之一（突击）。关名照 [story-questions.md](../story-questions.md) 第 3 题（用户 2026-10-28 定；原名"拜科努尔"，和 S6 重名）。镜像关是苏联 S6：同一次发射，起点两边一样，苏联守、帝国攻（大纲第五节）。

**第二版（2026-10-28）**：第一版用户没过："J7以后期关卡的角度来看是不是流程太简单了"。第一版只有两段、一个动词（摸进去拆塔）、地图开场就全开、没有基地、没有综合用前面的工具。修的是模板和准则（[principles.md](../principles.md) P31：关的规模跟着战役位置走，下限按原版 40 关量出来，[scale.md](../teardowns/data/scale.md)），这一关照新规矩重写，结构参照原版后期的横滨：英雄开路 → 交基地 → 攻 → 转折后限时拆。

镜像关 S6 的起点要跟着改：发射塔有护盾、靠三座供能塔供电（S6 重写时照这个起点）。

**2026-10-29 按五条审核重写**（[README.md](README.md) 第 16～20 条）。查出的问题：最后一段开了全图，南北两头的草原一半是空地（52%）；提前发射没有伏笔，初见只觉得被坑；合体机甲打光就砸不开塔，是坏档；千岁整关只转达命令，没有自己的转折。改成：最后一段只开中间一条（西边的苏联基地到谷口），苏联反扑分南北两路绕过发射场；第二座供能塔倒下时截到别列津"护盾一掉，马上点火"；"后备机甲"保底；发射场北边加一个炸燃料库的奖励（提前发射时多出时间，是对付意外的另一种准备）；千岁在提前发射时第一次没等太子的命令。
