# J7 发射窗口 · 流程剧本

帝国第 7 关，组合 K5 借力、K1 改道、K2 视野、K9 引火，难度 4.5。镜像关③：苏联 S6 是守方，同一次发射（大纲第五节），起点一样（发射场、三条谷、干扰车、倒计时），结果各算各的。题卡是用户 10-30 选的甲"给谁修路"（[cards/j7.md](../cards/j7.md) 甲）：三条谷里摆着苏联干扰车，光环里谁都慢到四成；苏联援军从地图边界外开来，拆不到，总挑当时最快的谷走；干扰车不认人，你拆通哪条谷就是给援军修哪条快路。选谷的算法、每轮挪车和塔边预置的干扰车照 [cards/brief.md](../cards/brief.md) J7 的灰盒结论。镜像关同一辆车两边各当一次题眼（[handoff.md](../handoff.md)"第一遍"待拍板第 1 条，按推荐写）：S6 挪自己的车，这里拆敌人的车。第一遍按"先加戏"从头写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j7_beats.md`），只挑了长在已有规则和人物上的；2026-11-01 补第二遍（体验目标、简报、目标说明、提示、卡住了、摆放要求、逐句台词；点子在 `work/beats/j7_beats2.md`，规则没加）。带玩法信息的台词按 ADR 0013 只给播报和千岁，别列津的嘲讽后面都由千岁跟一句。
