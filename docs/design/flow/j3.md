# J3 白鹭城下 · 流程剧本（第一遍）

帝国第 3 关，教 K2 视野，难度 2.5。题卡见 [cards/all.md](../cards/all.md) J3：训练所的巡逻按城上的钟走，一分不差，一队接一队；纸鹤隐身，飞到哪看到哪；百合子能把一个人举起来扔掉，可少了一个人，那一队要原地等他归队才往下走。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j3_beats.md`），只挑了长在已有规则和人物上的；逐句台词、摆放要求、提示和卡住了留到第二遍。

地图用已有的 `himeji`（城山、大手门坡、天守阁、山东边的训练所档案室、东北角的后山小路），它只有 `whole` 一块边界，前两段的可玩区用世界坐标提议，第 2 层加进地图。

新机制待查：巡逻按钟点走、少一个人整队原地等几十秒（[handoff.md](../handoff.md)"第一遍"表：脚本数队伍人数）；被发现一次整个训练所换一张钟点表；在训练所里被发现就拉警报，档案开始烧（倒计时，已确认的倒计时显示能用）。
