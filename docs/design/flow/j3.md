# J3 白鹭城下 · 流程剧本（第一遍）

帝国第 3 关，教 K2 视野，难度 2.5。题卡见 [cards/all.md](../cards/all.md) J3：训练所的巡逻按城上的钟走，一分不差，一队接一队；纸鹤隐身，飞到哪看到哪；百合子能把一个人举起来扔掉，可少了一个人，那一队要原地等他归队才往下走。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"），逐句台词、摆放要求、提示和卡住了留到第二遍。

地图用已有的 `himeji`（城山、大手门坡、天守阁、山东边的训练所档案室、东北角的后山小路），它只有 `whole` 一块边界，前两段的可玩区用世界坐标提议，第 2 层加进地图。

新机制待查：巡逻按钟点走、少一个人整队原地等几十秒（[handoff.md](../handoff.md)"第一遍"表：脚本数队伍人数）；被发现一次整个训练所换一张钟点表；警报以后档案开始烧（倒计时，已确认的倒计时显示能用）。

接上一关: 宫岛仓库的账上写着，早几天有一批克隆体送去了姬路；黑田要知道未来科技拿她们干什么。
引出下一关: 档案里写着克隆体在这里学怎么控制别人，还夹着一张收货单：盟军在北海道查封的一车克隆体，要在札幌雪祭那天交给未来科技的船（J4）。下一关手上：纸鹤侦察机留在帝国的兵种里；百合子知道了克隆体被拿去控制人。

开局:
  手上: 百合子一个人，两架纸鹤侦察机，从西边树林进；没有基地，也没有别的兵。
  敌方: 城下町、大手门和训练所都有按钟点走的巡逻，一队接一队；大手门有一辆对空的多功能步兵车；训练所门口守着冷冻军团兵，山上营房里停着守护者坦克，警钟响了才出来。百合子一个人拆不了营房，扔光巡逻也不行。
解法:
  - {打法: 纸鹤先绕一圈记下钟点，百合子只在空当里走, 段: 城下町, 提示: 千岁说钟点都是死的，看一遍就记得住}
  - {打法: 故意扔掉一个人，让前一队走远、后一队堵住，把空当挪到自己的路上, 段: 城楼, 提示: 开场演示时那一队站着等人归队}
  - {打法: 先占天守阁，从高处一眼看清训练所的钟点再下山, 段: 城楼, 提示: 千岁说天守阁上看得最远}
  - {打法: 不动档案室门口那一队，扔掉半路上往这边来的下一队里的一个，门口空着的时间就长了, 段: 训练所, 提示: 千岁说停在哪就堵在哪}
平推会怎样: 纸鹤开路、百合子一路扔过去，每扔一个那队就停下，后面的撞上来、前面的走远，路越走越堵；等最大的空当，它在城山另一侧，不在路上；硬闯，被发现一次钟点表全换，在训练所被发现警钟一响，档案就开始烧。用户先拆压力源的打法用不上：手上只有百合子和纸鹤，拆不了营房，巡逻扔不完，扔得越多越堵。
