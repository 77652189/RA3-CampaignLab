# A1 金门不锁 · 流程剧本

## 用户 2026-11-22 改版方向（取代下面的旧流程；旧流程留作素材，按这里重写）

- **致敬**：尤里的复仇盟军第 1 关的阴谋感（围绕给时间机器充能的发电站争夺）。
- **开局**：苏联海军残部反攻，开局就打掉盟军基地的大部分、控制了未来科技的车队；指挥官只临时接管地图东南角的盟军步兵基地。
- **压力**：苏联基地源源不断训练步兵占领建筑，逼盟军打巷战；谭雅能炸掉建筑推进。11-22 补充：苏军**几座兵营同时出兵**，先抢着占下尽量多的楼，再慢慢把楼里的人数填满（拖得越久楼越硬）；**大量用动员兵的燃烧瓶清玩家的驻军**，所以躲进楼里不是安全答案。
- **防平推**：谭雅不开局给。支线：占领地图上多座发电站，启动主基地里的超时空传送。苏军也派兵抢发电站，抢够了同样能启动超时空传送，拿到镰刀机甲增援——双方赛跑。11-22 补充：**电站多摆几座、散在全图各处**，让玩家到处混战，难度往上加；传送启动后**谭雅和多功能步兵车直接传进要塞**，从里面夺回传送仪和主基地（里应外合），不是传到步兵基地。
- **赛跑规则**（11-22 定）：7 座电站，先占 4 座的一方给传送仪供上电。苏军先凑够不判输：传来一队镰刀机甲，传送仪重新充能，玩家抢回多数还能再赛。
- **间谍支线**（11-22 用户加，为合理性）：传送仪在苏军手里，供上电它只会把车队传走。派间谍穿过街区渗透进要塞、夺下传送仪的控制，玩家占到多数时它才把谭雅和多功能步兵车传进来；不做或失败，玩家的多数只能拦住苏军，没有谭雅，指挥官得靠自己的兵硬打回要塞（更难，但能赢）。
- **难度**：不做教学（11-22 用户：mod 面向打过原版战役的玩家，第一关也按懂基本战术的人设计）。
- **地图**（11-22 讨论，总控骨架）：旧金山北角——西北要塞区（Presidio）= 被占的盟军主基地和传送仪；东北码头区 = 苏军登陆基地和几座兵营；中间街格压在陡坡上，楼多可占可炸；东南角 = 玩家的步兵基地；金门大桥在西北，结尾车队困在雾里的桥头（民用车流当路障）。下一步按 [teardowns/real-places.md](../teardowns/real-places.md) 画图顺序第 3 步排箭头。用户 11-22 定：旧图 `golden` 几乎照搬真实地理，**重新设计**；先找手法相近的原版关作参照、照 [map-language.md](../../story/map-language.md) 的检查单画地形草图（台地 + 坡道、斜 45° 街道、进攻路线一到三条、驻军楼成片），旧金山只取两三笔，再写地图内容稿、出白盒。
- **收尾**：夺回盟军基地后，发现苏联没来得及转走的未来科技车队。
- **和旧版不同**：敌人从苏联抵抗军换成海军残部；旧版"两座桥塔的爆破手先后"整题拿掉；类型从潜入换成巷战推进 + 抢点赛跑。游隼不在这关的描述里。
