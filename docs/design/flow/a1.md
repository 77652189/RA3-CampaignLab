# A1 金门不锁 · 流程剧本（第一遍）

盟军第 1 关，教 K3 先后，难度 1。题卡见 [cards/all.md](../cards/all.md) A1：引信在南北两座桥塔顶的爆破手手里，看见自己人倒下就引爆；北塔看得见南塔，南塔看不见北塔。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"），逐句台词、摆放要求、提示和卡住了留到第二遍。

```yaml
稿: 第一遍
关: A1
关名: 金门不锁
阵营: 盟军
类型: 潜入
位置: 前期

  我: [谭雅, 游隼, 维和步兵, 标枪兵, 多功能步兵车]
  敌: [动员兵, 防空步兵, 铁锤坦克, 磁暴步兵, 双刃直升机]
一句话: 新上任的指挥官从苏联抵抗军手里夺回一支被劫的车队；桥上埋着炸药，谭雅得先按对的顺序拆掉两座桥塔上的引信，大军才能过桥。
接上一关: 战役第一关。玩家只知道车里是未来科技的"公司财产"，被苏联抵抗军抢了，帮盟国公司抢回货天经地义。
引出下一关: 黑尔来电道谢，顺口提到胡佛水坝那边的超时空网络电源"也请多照看"；当晚苏联特工就摸向了水坝（A2）。

故事:
  开头: 苏联抵抗军劫了未来科技的车队，开上金门大桥，在桥上埋了炸药、扬言谁上桥就一起下海；车队今晚就要从北岸开走。
  起伏:

    - {段: 拆南塔, 向: 顺, 事: 两座塔的引信都拆了，桥是你的了，司令给了一辆基地车}

    - {段: 胜利, 向: 顺, 事: 车队夺回，黑尔第一次在通讯里出现，道谢}
  结尾: 盟军夺回了车队，黑尔拿回了"公司财产"；沃斯问车里装的是什么，黑尔笑着说"未来"，挂了。
人物:
  - 谁: 沃斯
    想要: 车队和桥都要，一样也不能丢
    转折: {段: 胜利, 事: 想看一眼车里的货，被黑尔客客气气地挡回来，第一次对这家公司起了好奇}
    看得出: 结尾她那句"他没说车里是什么"
  - 谁: 司令
    想要: 按计划把货找回来，别闹大
    转折: {段: 过桥, 事: 抵抗军来炸桥，他第一次松口"桥没了也行，车不能丢"}
    看得出: 过桥那段他改口的那句命令
开局:
  手上: 谭雅一个人，加南岸一小队游隼和维和步兵；没有基地，拆完两座塔才给基地车。
  敌方: 桥上有巡逻的动员兵，两座塔顶各一个爆破手；北岸有抵抗军的营地和车队，营地后面停着双刃直升机。爆破手打得死，引信只能从塔顶拆；北岸的营地打得掉。
解法:
  - {打法: 谭雅下水绕到北塔先拆，再回头拆南塔, 段: 摸上北塔, 提示: 开场镜头扫过北塔时爆破手正举着望远镜看南塔}
  - {打法: 谭雅留在南岸当诱饵吸住桥上巡逻，游隼沿北岸浅滩绕过去打北塔下的守军, 段: 摸上北塔, 提示: 沃斯说北塔底下就是浅滩}
  - {打法: 过桥后先造防空，再推北岸营地, 段: 过桥, 提示: 谭雅在北塔顶上看见过直升机坪}
平推会怎样: 大军一上桥就引爆，任务直接失败；按距离先打南塔，北塔看见就按。用户的打法（先拆光压力源）在这关会先撞墙一次：压力源是两个人，拆的顺序就是题。拆塔以后的过桥段允许平推，只是不先造防空会被双刃直升机炸桥。
意外:
  - 名: 双刃炸桥
    段: 过桥
    初见: 大军走到桥中间，北岸起飞一队双刃直升机直奔桥面
    伏笔: {段: 摸上北塔, 事: 谭雅站在北塔顶上时，揭图露出北岸营地后面的直升机坪}
    准备: 过桥前先造标枪兵和多功能步兵车
    补救: 防空援军

    援军: 一队多功能步兵车
    从哪来: 南岸营地

      - 沃斯: 给你送了几辆防空车，桥别让他们炸了。

  - 司令: 听好了，指挥官。车队被抢了，今晚就要从北岸开走。
  - 沃斯: 桥上埋了炸药，引信在两座桥塔顶上。

  - 名: 开场
    时长: 约 20 秒
```
