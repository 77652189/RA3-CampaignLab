# A1 金门不锁 · 流程剧本（第一遍）

盟军第 1 关，教 K3 先后，难度 1。题卡见 [cards/all.md](../cards/all.md) A1：引信在南北两座桥塔顶的爆破手手里，看见自己人倒下就引爆；北塔看得见南塔和整座桥面，南塔只盯着南岸。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/a1_beats.md`），只挑了长在已有规则和人物上的；逐句台词、摆放要求、提示和卡住了留到第二遍。

接上一关: 战役第一关。玩家只知道车里是未来科技的"公司财产"，被苏联抵抗军抢了，帮盟国公司抢回货天经地义。
引出下一关: 黑尔来电道谢，顺口托盟军"照看"胡佛水坝那边的超时空网络电源；当晚苏联特工就摸向了水坝（A2）。

故事:
  开头: 苏联抵抗军劫了未来科技的车队，开上金门大桥，在桥上埋了炸药，扬言谁上桥就一起下海；车队今晚要从北岸码头开走。
  起伏:

    - {段: 摸上北塔, 向: 顺, 事: 谭雅从水里摸上北塔，爆破手倒下；南塔拿起对讲机呼北塔，没人回，他骂了一句信号，接着看南岸}
    - {段: 拆南塔, 向: 顺, 事: 两座塔都拆了，桥归了盟军，司令派来一辆基地车}

  结尾: 盟军夺回了车队，黑尔拿回了"公司财产"；沃斯问车里是什么，黑尔说是一份改变未来的合同，卡车上的铅封一个也没动过。
人物:

    看得出: 过桥那段他那句"明天坐渡轮上班"
开局:
  手上: 谭雅一个人，加南岸一小队游隼和维和步兵；没有基地，两座塔拆完才给基地车。
  敌方: 桥面上一队动员兵守着炸药箱，两座塔顶各一个爆破手，北塔底下有防空步兵的哨位；北岸码头是抵抗军的营地和车队，营地后面停着双刃直升机。爆破手打得死，引信只能从塔顶拆；北岸营地打得掉。
解法:
  - {打法: 谭雅下水绕到北塔先拆，再回头拆南塔, 段: 摸上北塔, 提示: 开场镜头里北塔的爆破手举着望远镜看南塔}
  - {打法: 谭雅留在南岸不动，游隼沿北岸浅滩绕过去打掉北塔底下的哨位，谭雅再从水里上塔, 段: 摸上北塔, 提示: 沃斯说北塔底下就是浅滩}
  - {打法: 过桥前先造标枪兵和多功能步兵车，守住桥面再推北岸营地, 段: 过桥, 提示: 谭雅站在北塔顶上时揭图露出直升机坪}
平推会怎样: 大军一上桥先清桥面守军，北塔看见就按，任务直接失败；按距离先打南塔，北塔看着呢。用户先拆光压力源的打法在这关先撞一次墙：压力源就是两个人，拆的顺序就是题。拆完塔以后的过桥段允许平推，只是不先备防空，双刃直升机会一轮轮炸桥。
