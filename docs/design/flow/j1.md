# J1 鹿与机甲 · 流程剧本（第一遍）

帝国第 1 关，教 K1 改道，难度 1。题卡见 [cards/all.md](../cards/all.md) J1：未来科技的工兵队挨了打就全队去追打它的人，追不上才回去接着挖；奈良的鹿群是中立的，谁都得绕着走；鸣神跑得比谁都快。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"），逐句台词、摆放要求、提示和卡住了留到第二遍。

新机制待查：工兵队挨打后整队追打它的那个人、追不上回工地接着挖；鹿群受惊换地方；工地的挖掘进度（挖穿就撤）。这三样 mechanics.md 里还没有，第 3 层先查；百合子能不能驻进大佛殿也要查。
