# J1 鹿与机甲 · 流程剧本（第一遍）

帝国第 1 关，教 K1 改道，难度 1。题卡见 [cards/all.md](../cards/all.md) J1：未来科技的工兵队挨了打就全队去追打它的人，追不上才回去接着挖；奈良的鹿群是中立的，谁都得绕着走；鸣神跑得比谁都快。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j1_beats.md`），只挑了长在已有规则和人物上的；逐句台词、摆放要求、提示和卡住了留到第二遍。

新机制待查：工兵队挨打后整队追打它的那个人、追不上回工地接着挖；鹿群受惊换地方；工地挖到东西就抱着撤。这三样 mechanics.md 里还没有，第 3 层先查；百合子开局驻在大佛殿里、不归玩家，后一段才交给玩家（驻军加换归属），也要查。
