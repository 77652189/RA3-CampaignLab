# J8 金阁守卫 · 流程剧本

帝国第 8 关，考 K3 先后、K5 借力，难度 4（帝国线第 6～8 关的那次下探）。题卡见 [cards/all.md](../cards/all.md) J8：黑尔的克隆体控制了京都守军，围着金阁打；心灵巫女能解开一队的控制，解开的人站到你这边；克隆体死了，她控制的人才全部回来；金阁被毁即失败。考的是"先解哪一队、解开的人往哪站"，和 S7 的"抢在控制前面"分开（[handoff.md](../../archive/design-handoff.md)"第一遍"待拍板第 2 条，按推荐写）：这里控制不会自己往外蔓延，只会流回离克隆体最近的那队，玩家每解一队都要想好他站哪。第一遍按"先加戏"从头写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j8_beats.md`），只挑了长在已有规则和人物上的；2026-11-01 补第二遍（体验目标、简报、目标说明、提示、卡住了、摆放要求、逐句台词；点子在 `work/beats/j8_beats2.md`，规则没加）。带玩法信息的台词按 ADR 0013 只给播报和千岁。还没有地图，示意图写在 100×60 的格子上。

接 J6（[j6.md](j6.md)）：黑田带着完全体的身体以空中要塞的样子飞走，驾驶舱空着，他说"会有人坐进去的"。这一关交代它飞去了哪：黑田把它落在京都金阁后面的衣笠山上，等一个能坐进去的人；黑尔的克隆体顺着驾驶舱里的黑匣子信号先找到了这里，控制了京都守军，连黑田也被控制了。上一稿"黑田把身体交给了黑尔"不用了。黑田的下场大纲没写，这一稿补的：最后一个克隆体倒下，他醒过来，看着百合子坐进驾驶舱，交给太子殿下发落。大纲里的"鸣神的复仇机制翻盘"卡上没有，不加。

新机制待查：心灵巫女解开一队被控制的单位、转给玩家（退路：脚本把巫女身边一队守军换成玩家所有）；控制回流到离克隆体最近的一队（退路：脚本每隔一阵把离克隆体最近的一队玩家单位换回敌方）；克隆体死后她控制的全部转回（退路：同上，整批换主人）；百合子登上驾驶舱、完全体站起来（units.md 5.2，退路：剧情镜头里换成巨人形态）。
