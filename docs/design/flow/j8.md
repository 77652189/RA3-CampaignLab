# J8 金阁守卫 · 流程剧本（第一遍）

帝国第 8 关，考 K3 先后、K5 借力，难度 4（帝国线第 6～8 关的那次下探）。题卡见 [cards/all.md](../cards/all.md) J8：黑尔的克隆体控制了京都守军，围着金阁打；心灵巫女能解开一队的控制，解开的人站到你这边；克隆体死了，她控制的人才全部回来；金阁被毁即失败。衍生规则分四步显出来：开场看巫女解开一队（明示）；见一队解一队、解开的人留在原地，离克隆体近的下一刻又被抓回去（第一反应吃亏）；街区里克隆体躲在守军中间，先解谁、解开的人往哪站每次都不一样（每轮在变）；最后一段同一条规则换个后果：最后一个克隆体自己走下山，你堆在金阁门口的那道"墙"成了离她最近的，整道墙倒戈。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。还没有地图，示意图写在 100×60 的格子上。

新机制待查：心灵巫女解开一队被控制的单位、转给玩家（退路：脚本把巫女身边一队守军换成玩家所有）；控制回流到离克隆体最近的一队（退路：脚本每隔一阵把离克隆体最近的一队玩家单位换回敌方）；克隆体死后她控制的全部转回（退路：同上，整批换主人）。大纲里的"鸣神复仇翻盘"这一稿没用上。
