# J9 一刀两断 · 流程剧本（第一遍）

帝国第 9 关，终局，考 K2 视野、K6 分兵、K9 引火、K8 换兵，难度 5。关名照大纲第四节（题卡 [cards/all.md](../cards/all.md) 的小节标题写的是"布鲁塞尔，1927"，三方终局共用的叫法）。题卡：帝国从海上打进来；球塔的球在高处，看得远、打得远，低处看不见高处；舰炮打得到高处，可要有人看见目标；岸防火力扑最近的威胁；跳跃倒计时。衍生规则分四步显出来：开场舰炮打高处落空、纸鹤一到第一炮就中（演示）；登滩时舰队直接轰球塔、登陆队硬冲岸防都吃亏（第一反应）；球轮流充能，报点要跟着换，海上还有驱逐舰来抄舰队（每轮在变、两线同时）；最后同一条规则换个后果：球塔站起来朝海边走，"扑最近的"从替登陆队挡火变成九个球一起扑向走上岸的完全体，离它最近的还有你的舰队。

三方同图：这一版只写帝国从北面海上打进来；盟军（南边）和苏联（东边）的战线只当远景，各打各的，不进这一关的可玩区。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。还没有地图，示意图写在 100×60 的格子上，北边是海。

新机制待查：球轮流充能、只有正在充能的球打得坏（退路：脚本按顺序给球开关"无敌到条件"）；原子球塔站起来朝海边走（[units.md](../../story/units.md) 5.4，退路：一张地图加一个会动的建筑，脚本沿路点挪）；完全体巨人形态的能量太刀一刀切开一个球（units.md 5.2，借将军处决者前身的武士刀）；岸防按"最近的威胁"挑目标（同 J5 的退路）。
