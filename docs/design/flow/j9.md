# J9 一刀两断 · 流程剧本

帝国第 9 关，终局，考 K2 视野、K6 分兵、K9 引火、K8 换兵，难度 5。关名照大纲第四节。题卡见 [cards/all.md](../cards/all.md) J9：帝国从海上打进来；球塔的球在高处，看得远、打得远，低处看不见高处；舰炮打得到高处，可要有人看见目标；岸防火力扑最近的威胁；跳跃倒计时；球轮流充能，报点要跟着换。第一遍按"先加戏"从头写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j9_beats.md`），只挑了长在已有规则和人物上的；2026-11-01 补第二遍（体验目标、简报、目标说明、提示、卡住了、摆放要求、逐句台词；点子在 `work/beats/j9_beats2.md`，规则没加）。带玩法信息的台词按 ADR 0013 只给播报和千岁。

上一稿自己加的去掉了：剩三个球时原子球塔用钢管腿站起来朝海边走（[units.md](../../story/units.md) 5.4 的巨构，卡上没有，A9 也已经去掉）；球一碎倒计时就跳小；"九个球一起扑最近的"。最后一段的转折改成完全体自己走上岸：岸防扑最近的威胁，最大的那个就是它，式神得站到它前面去。球"只有亮着的那个打得坏"沿用 A9 同一座塔的说法，不算新规则。

**三方同图，和 A9、S9 对上**（[a9.md](a9.md)、[s9.md](s9.md)）：地名和方位照 A9（西郊、西环路、北街、南街、东桥、北边机场），北边多一片海。帝国从北海登滩，经过北边机场和北街打到球塔下。帝国到的时候，盟军已经从西郊开始一个个拆球（开场远景里自由号停在西郊上空）；帝国打碎北面三个、盟军拆掉西边三个，正好剩最后三个，这时苏联人从东桥杀进来，基洛夫往亮着的球底下扔天启坦克，他们要完整的机器，见谁打谁；苏联人打到南街，科尔带人撤走。黑尔那句"野蛮人"、科尔那句"这单我不干了"、卡佳那句"别打球"三条线听到的是同一句；第二遍把普雷斯顿那句也对成 A9 的原句"老板，船备好了，我们走吧"：A9 里黑尔不走，这里他走了。盟军这一路这关只有远景和千岁的转述，不给盟军角色台词（A9 是沃斯、S9 是施泰因，这关不挑）。**黑尔的下场和另两条线分开**：A9 他攥着合同走进核心被抛回一九二七年，S9 苏联人拿下了核心；这一关核心没等到他，完全体一刀劈开塔，塔倒下前他坐逃生舱往南跑了（大纲帝国结局）。

新机制待查：九个球轮流充能、只有亮着的打得坏（同 A9，"无敌到条件"轮着取消）；岸防按"最近的威胁"挑目标（同 J5 的退路）；完全体巨人形态的能量太刀劈开原子球塔（units.md 5.2，借将军处决者前身的武士刀）；基洛夫飞艇把天启坦克投到亮着的球底下（和 A9、S9 同一段脚本）；盟军、苏联两路第三方按进度出场（脚本按打碎的球数开关）。
