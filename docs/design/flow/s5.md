# S5 关门 · 流程剧本（第一遍）

苏联第 5 关，教 K7 跳点、顺带 K6 分兵，难度 3.5。题卡见 [cards/all.md](../cards/all.md) S5：盟军防线全朝海，钻地车从底下钻过去；舰队困在船闸里，水位高时才露出炮口、打得到也挨得打；两道闸门各放一半舰队。镜像关②，盟军 A5 在同一座船闸当守方（大纲第五节）；地图的走向照 `experimental/cnv/maps/panama.py`：运河南北走向，南边是海、北边是湖，闸室在中间，上下两道闸门。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

新机制待查：船闸水位升降、两道闸门跟着水位轮流开（handoff"第一遍"表 A5、S5 一行，退路是脚本开关）；守军按时换班去盯闸门（脚本让一队兵在两处之间来回）；钻地运兵车钻地、出地面（units.md 已测 `burrower --check pass / drop`，mechanics.md 还没有这一行）。
