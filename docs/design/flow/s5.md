# S5 关门 · 流程剧本

苏联第 5 关，教 K7 跳点、顺带 K6 分兵，难度 3.5；镜像关②，盟军 A5 在同一座船闸当守方。题卡见 [cards/all.md](../cards/all.md) S5：钻地车钻进地下谁也打不着，出了地面就是活靶子；盟军的防线全朝海；困在闸里的舰队只有水位升起来时才露出炮口高度，打得到也挨得打；船闸有两道闸门，各放一半舰队。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/s5_beats.md`），只挑了长在已有规则和人物上的；2026-11-01 补第二遍（体验目标、简报、目标说明、提示、卡住了、摆放要求、逐句台词；点子在 `work/beats/s5_beats2.md`，规则没加）。带玩法信息的台词按 ADR 0013 只给播报和卡佳，地道援军那句从别列津挪给了卡佳。

地形照 [a5.md](a5.md)，两关同一座船闸：运河南北走向，南边是海、北边是湖；闸室分上下两级，中间一道中闸门（[handoff.md](../../archive/design-handoff.md)"第一遍"待拍板第 5 条，按推荐写）。两级闸一高一低轮流换：上闸室水满时开上闸门通湖，下闸室水落时开下闸门通海，所以题卡的"两道闸门"一道朝北、一道朝南，有时同一刻都开着。苏联在西岸闸边起家（A5 里苏联兵守着的"闸边工棚"一带），火箭车最后摆在东北湖岸（A5 开场打船的那片阵地）；东岸高台上的控制室这关不碰，留给 A5。

上一稿自己加的"施泰因炸泵房、把船闸放干"去掉了（题卡没有放水这条），最后一段的压力改成两道门同一刻开；上一稿东岸高台上的盟军机场也去掉，高台留给 A5。S4 的奖励目标拿到了，开局多一辆钻地运兵车。

新机制待查：船闸两级水位轮流升降、两道闸门跟着水位开（handoff"第一遍"表 A5、S5 一行，退路是脚本按时开关闸门、换船的高度）；水位低的船看不见闸墙外（退路是脚本按水位开关这些船的武器）；守军按时换班去盯闸门（脚本让一队兵在两处之间来回）；钻地运兵车钻地、出地面（units.md 已测 `burrower --check pass / drop`，mechanics.md 还没有这一行）。
