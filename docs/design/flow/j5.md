# J5 敌人的敌人 · 流程剧本（第一遍）

帝国第 5 关，教 K9 引火、顺带 K2 视野，难度 3.5。题卡见 [cards/all.md](../cards/all.md) J5：未来科技的雇佣军只扑眼前最近的威胁，式神一打开护卫，周围的敌人全改打它；观测站被毁即失败，盟军也在帮你守。衍生规则在关里分三步显出来：开场演示"谁近打谁"，第一批里式神贴着站吸火、溅射照样砸站（第一反应吃亏），盟军撤走后每波换山口、火箭车在射程外拆站（每轮最优在变），撤离段同一条规则换个后果：雇佣军不打车，只打车边上最近的兵。第一遍只写骨架（[README.md](README.md) 第二节"分两遍写"）。

地图用现成的 `aso`（两条山口绕过火山，在西脚观测站门口汇合，雇佣军营地在东边）。可玩区写的是这一关提议的世界坐标边界：营地始终在边界外，拆不到。

新机制待查：雇佣军按"眼前最近的威胁"挑目标、打完一个找下一个（原版 AI 不一定这样挑；退路：脚本每隔几秒给每队雇佣军下令打离它最近的一个玩家或盟军单位）；雇佣军不打无武装的卡车（退路：卡车无敌、溅射照算，或者卡车归盟军第三方、脚本不给雇佣军下打车的令）。
