# J5 敌人的敌人 · 流程剧本（第一遍）

帝国第 5 关，教 K9 引火、顺带 K2 视野，难度 3.5。题卡见 [cards/all.md](../cards/all.md) J5：未来科技的雇佣军只扑眼前最近的威胁，打完一个找下一个；式神一打开护卫，周围的敌人全改打它；观测站被毁即失败，盟军的部队也在帮你守。衍生规则在关里分三步显出来：开场镜头演"谁近打谁"和式神替百合子挡枪；第一批里式神贴着站开护卫，敌人在门口开火、溅射照砸站（第一反应吃亏）；盟军撤走后每波换山口、火箭车在射程外拆站；最后一批盟军回来了，"盟军也是最近的威胁"这条才用得上。第一遍按"先加戏"写（[README.md](README.md) 第二节），点子来自 Gemini（`work/beats/j5_beats.md`），只挑了长在已有规则和人物上的；逐句台词、摆放要求、提示和卡住了留到第二遍。

地图用现成的 `aso`（两条山口绕过火山，在西脚观测站门口汇合，雇佣军营地在东边）。可玩区写的是这一关提议的世界坐标边界：营地始终在边界外，拆不到。

新机制待查：雇佣军按"眼前最近的威胁"挑目标、打完一个找下一个（原版 AI 不一定这样挑；退路：脚本每隔几秒给每队雇佣军下令打离它最近的一个玩家或盟军单位，盟军单位也算）。
