# 策划案模板的增补建议

**只是建议。** 策划案（`docs/story/plans/*.md`）、编译器 `experimental/cnv/plan.py` 和 `plancheck.py` 归关卡线；这里写要加什么、为什么、plancheck 能查什么，由关卡线决定怎么落。依据是 [principles.md](principles.md)，括号里是准则编号。

现在的策划案管"机制"这一层管得很全：开局、机关、段、目标、进攻、规则、输赢、检查，`plan_show` 还对照原版查分段数、第一波时间、来源和上限。缺的是上面两层：**动态**（玩家会怎么想、怎么选）和**体验**（玩家该感受到什么）。所以加的栏目都放在 yaml 之外或作为新的 yaml 顶层键，编译时不读，只给 `plan_show` 和 plancheck 用。

## 一、加哪几栏

建议放在"定位"之后、"开局"之前，按顺序写；它们决定后面所有 yaml 怎么写（P1）。

### 1. 体验目标（P1）

一句话，写玩家的感受，不写机制。再写一张"情绪弧线"小表：每段一行，玩家的感受 + 对照的原版关。

```yaml
体验:
  目标: 冰是借来的时间：冻早了会化，冻晚了来不及；冻对了，车队一路不停
  弧线: {会场: 拮据, 北营: 掌控, 最后一程: 高潮}
```

### 2. 每段的"动词"和"决策"（P2、P5）

给 `段` 的每一项加两个键，编译不读：

```yaml
段:
  - 名字: 会场
    动词: 护送            # 这一段玩家主要做的事：护送 / 守 / 攻 / 潜入 / 建 / 追 / 解谜
    决策:
      - 选: [先冻, 先打碎, 硬扛]
        代价: [冰 30 秒就化、工兵要活着到门口, 要兵要时间, 车停在火力下挨打]
    教: 冰幕工兵         # 这一段在新机制上走到哪一步：教 / 练 / 考 / 变（P4）
    张力: 3              # 0～5，这一段的峰值（P7）
```

### 3. 张力曲线（P7）

`plan_show` 已经能出节拍表（每段几点开始、每路进攻几点来）。建议它再画一条按分钟的粗线：段的 `张力` 值 + 进攻波次叠加（每一波在它开始的那一分钟 +1）。策划写的 `张力` 和算出来的对不上，就是一个要看的地方。

### 4. 信息表（P10、P11）

A4 已经有"玩家可能不知道的事"（玩家不知道 / 后果 / 怎么告诉）。建议所有策划案都有这张表，并加一列"失败时屏幕上说什么"。

### 5. 空间表（P13）

每段一行：这一段用的边界、新开的地点、每个决策对应的两块地或两条路。

### 6. 布局（P17～P20）

放在"开局"之前，先定布局再摆兵。理由和原版的数字见 [teardowns/layout.md](teardowns/layout.md)。

```yaml
布局:
  体验: 推进            # 推进（背靠角落或边）/ 被包围（四处救火，才放中间）
  出生点: 第一块的西边，路的西头   # 写位置，也写为什么在这
  背后: 地图边          # 出生点背后是什么：地图边 / 水 / 悬崖 / 自己的基地
  推进方向: 东           # 主目标在出生点的哪边
  敌人来路: [东（街）, 北（广场门）]   # 第一块里敌人从哪几个方位来
  路线: {主路: 大街, 备选: 1 号广场后巷（要先清掉巡逻）}
  支线: [{奖励: 占修理厂, 在: 1 号广场后巷, 代价: 绕路、有守军, 回报: 第 2 段修车}]
```

每段的空间表里再加两列：这一段结束时出生点在可玩区的什么位置（角 / 边 / 中）、这一段新开的那一块朝哪个方向长。

## 二、plancheck 能查什么

按"能机器判断"排。每条写查什么、为什么、需要的新信息。

| # | 查什么 | 依据 | 需要 |
|---|---|---|---|
| 1 | 有 `体验.目标`；每段有 `动词`、至少一条 `决策` | P1 P2 P5 | 新键 |
| 2 | 相邻两段的 `动词` 不同（同一个动词连两段要给理由） | P2 | 新键 |
| 3 | **本关解锁的单位（`可造` 里的、`outline.md` 解锁栏里的）出现在至少一个主目标的 `完成` 条件里，或者出现在某个只认它的机关条件里**（例如"冻住"、"广场.封住"） | P3 | 已有信息：`可造`、目标、机关事件；要知道哪些机关事件只能由这个单位触发（机关公开一个 `由谁触发` 就能查） |
| 4 | 新机制的 `教` 走完四步里至少三步（教、考必须有） | P4 | 新键 |
| 5 | 每条 `决策` 的选项数 ≥2，且每个选项有 `代价` | P5 | 新键 |
| 6 | 奖励目标的标记地点离主路线（主目标标记的连线）≥ 某个距离，否则提示"顺路的奖励不算取舍" | P5 | 已有：地点坐标、目标标记 |
| 7 | 结尾那一段的 `张力` 是全关最高或并列最高 | P7 | 新键 |
| 8 | 交基地或段切换之后，第一波进攻前有一段喘息；喘息长度随难度变短（简单 > 普通 > 困难） | P7 | 已有：段开始时间、`进攻.开始` 的难度写法 |
| 9 | 至少一段的结束条件是"按时或玩家先推进"，或者由玩家的动作决定（`摧毁`、`占领`） | P8 | 已有：`plan_show` 已经在查"只靠玩家推进"和"按时或先推进" |
| 10 | 护送对象：有"停下"条件（遇伏等人），或者有按难度的容错（`损失 2/2/1`）；只按时间表走、两者都没有就警告 | P9 | 已有：车队机关参数、失败条件 |
| 11 | 每路 `进攻` 有 `预警`；每个 `失败` 有 `原因` | P10 P11 | 已有 |
| 12 | 失败条件按段不同（至少两段的失败原因不一样），或者每个失败原因说得出"是哪一路/哪一处" | P11 | 已有 |
| 13 | 有过场（`镜头` 或 `边界`）的那一段，开场同时换了目标、给了新单位或换了边界 | P12 | 已有 |
| 14 | 每段要么换边界，要么新标记一块之前没标过的地点 | P13 | 已有：`边界`、目标标记 |
| 15 | **跨关**：统计所有策划案里"压力开关"的写法（`来源: [兵营, 战车工厂]`、`接管` 后拆生产建筑），同一种写法在一条战役线里超过两关就提示 | P6 | 已有：所有策划案的 `进攻.来源` 和 `敌方AI` |
| 16 | 有 `张力` 值时，`plan_show` 画出按分钟的曲线，标出"连续 3 分钟张力 ≤1"的地方（可能拖沓） | P7 | 新键 |
| 17 | 奖励目标完成时触发了给玩家东西的动作（`给`、`资金`、`转给我`，或改变下一段的机关），否则提示"奖励只是成绩" | P16 | 已有：目标、规则 |
| 18 | 写了周期型机关（定时发作的地形、潮汐、喷发）：每次发作前有 `倒计时` 或 `通报`；而且这个机关也能伤到"敌" | P15 | 要机关公开"周期"和"伤谁" |

布局的检查（P17～P20）可以直接用 [data/layout_measure.py](teardowns/data/layout_measure.py) 量编好的地图，和原版的范围比（[data/layout.md](teardowns/data/layout.md)）。也可以做进 `cnv_preview` / `map_study` 的输出里，地图一改就能看到：

| 20 | 出生点在中间时，第一块里敌人的来路 ≤ 3 条（有水或悬崖护着） | 冰岛、纽约：中间靠水护着 | P17 | 量：陆路条数、敌方据点方位 |
| 21 | 第一块可玩区占全图的比例：除了基地对抗，> 0.7 就提示 | 中位数 0.41，12/40 开局就是全图 | P18 | 已有：`边界` |
| 22 | 推进纵深：第一块里最远的主目标标记离出生点 < 0.15 条第一块对角线就提示（守点关除外，守点关查"敌人从多远来"） | 中位数 0.57，< 0.15 的 1/40 | P18 | 已有：目标标记、地点坐标 |
| 23 | 扩边界时，新开的一块朝 `布局.推进方向` 长；扩完以后出生点仍在角或边 | 扩到最后 35/40 在角或边 | P18 | 已有：各段 `边界` |
| 24 | 去最远主目标的陆路 ≥ 4 条就提示"平地太开阔" | 有陆路的 19 关里 9 关 ≥ 3 条，10/40 没有陆路 | P19 | 量：layout_measure 的路线条数 |
| 25 | 第一块可玩区里至少一个奖励目标，且它要么绕路 > 500、要么离敌方据点 < 600 | 29/56 在第一块里，26/56 绕路，19/56 贴敌 | P20 P5 | 已有：目标标记、地点、开局敌方部队 |
| 26 | **跨关**：同一条战役线里，出生点落在同一个坐标附近（< 300）的关超过两关，就提示"出生点是模板默认值" | 原版各关出生点各不相同 | P17 | 已有：所有策划案的开局地点 |

## 三、不建议机器查的

这些只能靠试玩（[playtest.md](playtest.md)）：
- 玩家**真的**犹豫了没有（第 5 条只能证明"写了代价"）；
- 体验目标达到没有；
- 喘息是"舒服的喘口气"还是"无聊"。

## 四、落地顺序建议

1. **先加第 3、10、15 条**：只用已有信息，就能抓到现在最普遍的三个问题（新单位不是钥匙、护送不依赖玩家、压力开关一个模子）。布局这边先加第 19、22、26 条（出生点在中间、目标贴着出生点、出生点是模板默认值），我们 11 关里分别有 9、5、5 关会被它们抓到（A4、A5、A7、A8、J3 的出生点彼此相距不到 300：7 张新地图都从 `island.py` 复制了 `start` 那组地点）。地图这边也可以加一条：地图模块不许原样复制别的地图的 `start`，要按这张图的玩法给。
2. 再加 `体验` 和每段的 `动词` / `决策` / `张力` 新键，先在 A4 返工时试用；
3. 最后让 `plan_show` 画张力曲线。
