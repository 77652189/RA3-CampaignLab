# 试玩问题（对照体验目标）

Fullerton 的做法：先定体验目标，再拿试玩去对照。所以每个问题都对着一张拆解卡或 A4 样板里的一个"关键决策"，问的是**玩家有没有在那里犹豫、有没有感觉到**，不问"好不好玩"。

怎么玩：
- 普通难度，不看攻略，第一次玩就记；
- 每关玩完马上回答，记"有 / 没有 / 记不清"加一句为什么；
- 记下大概的时间点（第几分钟），对照卡片里的张力曲线。

## 原版：建议玩 2 关

选这两关的理由：都和 A4 的返工直接相关（A4 样板的第 1 段学伊贺，第 2、3 段学斯大林格勒），一关 20～30 分钟。

### 1. 伊贺国（起义时刻 盟军第 1 关）——看"新单位是钥匙"和"车停在火力下等你"

卡片：[teardowns/iga.md](teardowns/iga.md)

1. 基地车第一次被伏击停下时，你是冲到车前面去清，还是守在车边？你有没有意识到"不清它就不走"？
2. 南桥被炸、车改道的时候，你觉得是"自己走太快触发的"，还是"剧情安排的"？
3. 拿到 4 架冷冻直升机以后，到"冻住宅邸"之前，你有没有试过用它们干别的？
4. "冻住宅邸"这个目标，你第一次看到时知道该怎么做吗？有没有想过直接打？
5. 找车的时候，你冻错过吗？冻错那一刻你知道发生了什么吗（那辆车开始打你）？
6. 交基地以后、敌人第一次大举进攻之前，你觉得那段时间够你喘口气吗，还是无聊？
7. 整关哪一刻最紧张？是不是找车那几分钟？
8. （布局）开局你在西南角，第一块地图只开了三成。开局头一分钟，你有没有担心过背后或侧面？还是注意力一直朝东北？
9. （布局）地图扩大的那一刻，你是先看新开的地方，还是先回头看基地？

### 2. 斯大林格勒（红警 3 帝国第 2 关）——看"玩家决定节奏"和"在家门口守一条看得见的线"

卡片：[teardowns/stalingrad.md](teardowns/stalingrad.md)

1. 两处基地位你选了哪一处？为什么？到第 3 段时你后悔或庆幸过吗？
2. 拆母亲像之前，你有没有先在河边摆兵、摆防御？还是拆完才发现要守船？
3. 你有没有去东北角拆那 3 座雕像？看到旁边的钱箱了吗？值不值？
4. 布防倒计时出来的时候，你知道船会走哪吗（河道被揭开、路线上有标记）？
5. 三档敌人（先坦克、再步兵、再直升机）来的时候，你的防线有没有跟着换？
6. 第 3 段比前两段更紧张吗？哪一刻最紧张？

## 我们的 A4

**两轮都要玩**：现在的 A4（返工前）玩一次，按下面的问题记；返工后再玩一次，同样的问题再答一遍，对照有没有变。问题对着 [a4-redesign.md](a4-redesign.md) 的"关键决策"表和"现在的 A4 哪里不符合准则"。

### 返工前就能问的（验证第〇节的三个问题是不是真问题）

1. 车队出发前那 1 分钟，你在做什么？冻完冰以后，你是在等车开过去，还是还在忙别的？
2. 车队开过 1、2 号广场时，你有没有犹豫"现在冻还是等一等"？还是早就冻好了？
3. 你有没有发现一个冰幕工兵站在门口，冰一化就能马上再冻？
4. "港口生变"车队停下以后，你觉得紧张，还是觉得"终于可以去做别的了"？那一段你花了多久？
5. 第二段你有没有犹豫要不要去打北营（还是只是因为目标要你去）？拆一座北营后报复波来的时候，车队边上有没有留人？
6. 最后一程（过 3 号广场到港口）你记得吗？它比前面紧张还是轻松？
7. 整关哪一刻最紧张？哪一段最想快进？
8. （布局）开局你有没有往西、往南或往北派过兵、看过一眼？那几块空台地给你什么感觉：安全的后方，还是"那边会不会来人"？
9. （布局）往东推、在屏幕上横着走，和伊贺那种往屏幕上方推比，看前方的敌人顺不顺手？（原版 78% 的主目标在出生点北面，要不要把我们的地图转过来，就看这一题）

### 返工后再加的

1. 第 1 段：每个广场你是冻、打碎还是硬扛？有没有哪个广场你换了做法？为什么？
2. 第 1 段：两个工兵你怎么分工的？有没有过"冰化了另一个工兵还在冷却"的时刻？
3. 第 2 段：你是一拿到基地就去拆北营指挥所，还是先在 3 号广场那一带摆好防线？
4. 第 2 段：你去占电视塔了吗？第 3 段看到反扑从哪来，有没有帮上忙？
5. 第 3 段：你冻过哪条路？冻完敌人改道了吗？你是想把它关在外面，还是逼进你的炮口？
6. 第 3 段：天狗从海上来的时候，你留了防空吗？
7. 丢车的时候，你知道是哪一路、因为什么丢的吗？
8. 和返工前比：哪一段感觉变了？"冰是借来的时间"这句话你有感觉吗？
9. （布局）第 1 段只开一条走廊、背后是地图边，你还会分心看后面吗？后巷你发现了吗？打碎巷口冰雕抄近路，值不值？
