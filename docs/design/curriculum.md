# 课程表（初稿，待用户审）

[ADR 0010](../adr/0010-question-first.md) 第 1 条：全战役排一页。新考点按"教 → 练 → 组合 → 考"排开，之后至少换两次条件再出现；每关标用途；27 关的一句话巧解不重复；难度像波浪。出题方法见 [question-handbook.md](question-handbook.md)，27 关的剧情概念以 [campaign.md](campaign.md) 为准，这里只排"考什么"。

**一个前提要用户定**：三条线能不能任意顺序打（原版可以）。这里按"可以"排：每条线自己把它负责的考点走完"教练合考"，别的线的考点在本线出现时算"换条件"，那一关开场要演示一次。若改成固定顺序，可以去掉重复的"教"，腾出关卡给新题。

## 三、自查

- **巧解不重复**：27 句并排看，没有两句是同一个动作（A4、S1、J7 先填了评委排第一的卡，用户换卡后再查一次）。最像的一对是 S6"干扰车停在谷口外沿"和 J7"留着敌人的干扰车"：一个是自己放，一个是借敌人的，动词相反；两关又是同一次发射的镜像（大纲第五节），同一辆车在两边各当一次题眼，算有意的呼应，用户不喜欢就把 J7 换成乙卡。
- **难度波浪**：每条线都在第 6～8 关有一次下探（A6、A8；S7；J8），终局是全线最高。三条线入门都在 1～1.5。
- **用途**：每条线 3～4 关"教"、1～2 关"组合"、2～3 关"考"，每条线至少一关"喘"或"高光"。
- **一关只教一件事**：标了两个考点的"教"关（A3、A5、S5、J2、J5），第一个是这关的主考点，第二个只是顺带用到，不单独教。
- **考点和新单位对得上**：教关的考点都落在这一关新给的单位上（[units.md](../story/units.md) 第四节的解锁表），没有新单位的关（A6、A9、S9、J7、J9）都不是"教"。
