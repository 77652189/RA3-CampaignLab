# 拆解卡：伊贺国（起义时刻 盟军第 1 关）

- 类型：护送 → 建基地打 AI → 限时找人。对照我们的 **A4**（护送 + 新单位教学）。
- 事实来源：[plans/retail/ep01_a01_iga.md](../../story/plans/retail/ep01_a01_iga.md)（从原版脚本反推，方括号里是原版脚本名）。本卡只做"为什么这样排"的判断；判断写"推断"，是从脚本行为推出来的设计意图，原版设计师没说过。
- 一句话：护送盟友的基地车上河心岛展开；接手基地清剿效忠派；用冷冻直升机冻住慎三的宅邸，再从 6 辆一模一样的车里找出他。

## MDA 三层

| 层 | 这一关 |
|---|---|
| 机制 | 基地车遇伏就停、清光才走 [MCV Ambush01]；炸桥改道 [BlowBride]；两个主目标的完成条件是"身上有冻结状态"，打死就输 [Objective 3 - Complete/Failed]；冻错假车，假车转给敌方 AI [unLink Part2]；宫殿按你带去的冷冻直升机数量开刷兵线 [Shinzo Palace - Reinforcements] |
| 动态 | 玩家被逼着冲到车前面清路；手里有了冷冻直升机就想一窝蜂堆，宫殿让堆得越多挨打越多；找车时玩家会边冻边记、边猜 |
| 体验 | 推断：**"新玩具第一次到手，就发现它是唯一的钥匙；最后它还变成了侦探的放大镜。"** |

## 1. 体验目标

推断：让玩家觉得"冷冻"不是一个技能按钮，而是这一关的解题方式。前 1/3 的护送是热身和剧情铺垫（"我们是来帮盟友的"），真正的高潮是最后 3～7 分钟的找车。

## 2. 关键决策（每段玩家在什么之间取舍）

| 段 | 取舍 | 为什么是真取舍 |
|---|---|---|
| 护送 | 冲到车前面清伏兵，还是守在车边 | 车停在火力下等你，不清不走 [MCV Ambush01]；守着不动车就一直挨打 |
| 护送 | 继续往前推，还是先停下 | 玩家自己的部队走进炸桥区才触发炸桥 [BlowBride]：越急越早吃到改道 |
| 清剿 | 先打哪个敌人；工程师分不分去占道场 | 3 座道场一座在西北村、一座在西岸前哨、**一座在敌人主基地里**；每占一座当场给一队兵 [Objective Bonus 1 - Complete] |
| 清剿 → 冻宅邸 | 冷冻直升机堆多少 | 宫殿区里你的冷冻直升机 >0 / >2 / >4 架各多开一条刷兵线：堆得越多挨打越多 |
| 找车 | 先冻哪一辆 | 冻对就赢；冻错一辆就多一辆会打你的海啸坦克；倒计时 7:00 / 5:05 / 3:05 |

## 3. 新机制怎么教（教 → 练 → 考 → 变）

这一关几乎是教科书式的四步，全部落在冷冻直升机上：

| 步 | 在哪 | 怎么做 |
|---|---|---|
| 教 | 交基地时 | 直接给 4 架；同时禁造冷冻军团兵 [Map Setup - Unit Restrictions]，所以"冻"只有这一个来源 |
| 练 | 冻宅邸 | 目标不会动、不会跑；只能冻，打死就输。没有一句"怎么用技能"的文字，只有情报官每 9 秒一句催促 [MA01_AlliedIntel41] |
| 考 | 找车 | 目标会动、有 6 个、有倒计时 |
| 变 | 找车 | "冻"变成侦察：冻一下才知道真假，冻错有代价 |

另一个新单位先兆炮艇走的是更短的套路：**给到手的同一刻，8 辆海啸坦克冲山顶**，15 秒后再来 3 辆 [Hill Top - Enemy Assault / 02]。

## 4. 张力曲线

脚本里护送段的时刻取决于玩家（未实测），下面的分钟是估的；第二段起有确定的计时。`█` 越多越紧张（0～5）。

```
段      时刻(估)   张力
开场     0:00      ·
伏击     ~1:00     ████        车停在火力下
A村4波   ~2:00     ████        进村 +1 起 5/16/26/42 秒（简单）四波
空投     ~3:00     ██          半路停 ≤30 秒，等空投
上岛展开 ~4:00     █████       8+3 海啸冲山顶，同时给炮艇
交基地   ~5:00     █           Japan02 进攻延迟 0/120/210 秒 = 按难度给的喘息
清剿     5～13     ██▲███      AI 开打；西北村打得越狠出兵线越多
包围岛   T2+8:00   ████        7 个点同时一队
冻宅邸   ~14       ███         Japan01 AI 99999 资金；宫殿刷弓手
找车     +7/5/3分  █████       倒计时，冻错多一个敌人
```

读法：两个最高点都落在"新单位刚到手 / 刚练熟"的那一刻（炮艇、冷冻）；最大的喘息就在交基地后，而且**喘息长度就是难度旋钮**（困难 0 秒）。

## 5. 信息

| 玩家什么时候知道什么 | 怎么告诉 |
|---|---|
| 车会走哪 | 路线上 5～6 个标记做"跑马灯"，车在动每秒前移一个，车停全灭 [Objective 1 - Link 1/2] |
| 我离车太远了 | 距离 ≥600 时基地车喊话、闪白 [MA01_AlliedSoldier07] |
| 下一个该打谁 | "打败效忠派"的标记每帧指向离玩家最近的 2 座生产建筑 [Objective 2p5 - Linker] |
| 冻错的后果 | **立刻看得见**：那辆假车摘标记、转成敌人开火 |
| 输了错在哪 | 失败按段换，每种失败有专门的情报官台词 [第 8 节]：丢车、全灭、基地全毁、打死了慎三、超时 |

故意藏起来的只有一件：哪辆是真车。这正是最后一段的题目。

## 6. 剧情转折 = 玩法转折？

是，而且每次都对上：
- "盟友的基地车展开了" → 玩法从护送变成守山顶、交基地；
- "慎三必须活捉" → 目标只能冻、不能打；
- "慎三伪装逃跑" → 找车谜题；
- "盟友 Tatsu 送来工程师" → 占道场的奖励目标有了人手。

## 7. 地图支撑哪些决策

- **两座桥**：南桥给玩家炸、西桥是备用路线，所以"改道"有地方可改；西桥路上的 9 辆路卫和回血箱让改道这一路有自己的味道。
- **河心岛**：展开点四面是水，山顶突击的 3 辆海啸是两栖的、从河里上来 → "刚展开就被从意想不到的方向打"。
- **道场摆在三块地方**：路过的、要绕一点的、在敌人老巢里的，奖励目标天然分出了三档风险。
- **6 个随机落点 + 3 组随机目的地**散布全图，连玩家基地一带都有：找车段逼玩家看全图，不能靠记位置。

## 可以借的 / 不该照搬的

- 借：**新单位的目标做成"只能用它完成"**；教练考变四步落在同一个单位上；护送对象"停在火力下等你"；喘息长度当难度旋钮。→ 准则 [P3](../principles.md#p3) [P4](../principles.md#p4) [P7](../principles.md#p7) [P9](../principles.md#p9)
- 借：失败按段换原因 → [P11](../principles.md#p11)
- 不照搬：一关换 5 件事对我们 12～15 分钟的关太多；伊贺是起义时刻第 1 关，靠剧情过场串起来。我们取"护送只占前一段"这个比例，不取件数。
