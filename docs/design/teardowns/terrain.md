# 拆解卡：地形复杂度和地图利用率（全部 40 张原版战役图 + 我们的 11 关）

- 这张卡拆的是"地形给不给玩家事做"这一层。用户 2026-10-27 指出："我们还要解决的就是地形过于简单，只使用了一小部分的问题，这更接近设计问题。"
- 做法和布局卡一样，先量再定准则。[data/terrain_measure.py](data/terrain_measure.py) 用同一把尺子量了红警 3 和起义时刻的全部 40 张战役图，以及我们 11 关各自最新的完整构建。11 关用了 8 张图：festival（A4、J4）、panama（A5、S5）、baikonur（S6、J7）、niagara（A7）、island（A8）、himeji（J3）、aso（J5）、siberia（S2）。脚本只读原版存档和 Mods 里我们编好的地图，结果是 [data/terrain.md](data/terrain.md)，每关一行，另有中位数。各项怎么量，见脚本开头。
- 量了两件事：
  1. **地形复杂度**：
     - 高度层数和各层面积、高台块数、坡道数、斜坡占比；
     - 悬崖长度；水面和桥；
     - 能驻军的建筑、科技建筑、墙段；
     - 路口、隘口，主路过几个隘口，主路旁有没有高地。
  2. **地图利用率**：任务用到了能走到的地面的多大一部分。"用到"指目标标记、敌方据点、主路（最短的一条，加一条不长于 1.8 倍的备选）、奖励的路、敌人进攻的路，各自留一圈宽度，其余算空地。另外把能走到的地面切成 500×500 的块，每块归一种用途：
     - 前线：有敌方据点、刷兵点或主目标；
     - 支线：有奖励目标、科技建筑、能驻军的建筑，或离出生点较远的矿；
     - 后方：离出生点 900 以内；
     - 通道：只有路经过；
     - 空地：什么都没有。
- **按阶段、按玩家视角**：每个阶段只量那时的可玩区（MAP_SWITCH_BORDER 的矩形，和布局卡同一套排序），分三处读：第一块、关末整块、每个阶段新开的那一块。**只算玩家走得到的地面**：从出生点或某个目标标记出发、陆路连得通的部分。海、悬崖、围死的高台、研究所外面那片沙漠，都算"远景"。
- 量法的局限（读数时记住）：
  - "用到"的几个半径（目标 400、奖励 300、据点 250、路 150～200）是人定的，只适合拿来比原版和我们，绝对值没有意义。
  - 敌方据点只数地图上预摆的敌方物体。我们的敌人多是脚本刷出来的，这一项会偏少；刷兵点和进攻路线已经算进"用到"，补回一部分。
  - 能驻军的建筑不管任务用不用都算"支线"。A4 那 47 栋民房只是 platprops 摆的布景，所以我们的数字**偏好看**。
  - 墙段按物体数：一堵长墙是几十段。树、栅栏、石头不算。红警 3 没有步兵掩体加成，只有挡路、能打掉的东西才算。
  - 走路用 20 单位的格子，一个格子里 4 个地形格都能走才算能走。这样不会穿过一两格宽的薄悬崖，但宽度不到 20 的缝也就丢了。
  - 北海（盟 5）、深海（帝 5）第一块是海战，陆地利用率记成 0。
- 判断写"推断"。

## 一、量出来的规律

### 1. 原版每张图都有几种地形"花样"；平地图靠建筑和水补

把复杂度来源分成五种，每张图数一数有几种：

| 来源（门槛） | 原版 40 张 | 我们 11 关 |
|---|---|---|
| 高低层（≥2 层，坡道 ≥3） | 25 | 3（A4、J4、A7） |
| 能驻军的建筑（≥15 栋） | 23 | 3（A4、A7、J3，都只是布景） |
| 水面 ≥30% 或有桥 | 35 | 5 |
| 墙（≥50 段） | 28 | 0 |
| 隘口（≥10 个） | 32 | 2 |
| **每张图几种（中位数）** | **4**（最少 1） | **1**（5 关一种都没有） |

- 原版只有 7 张图是一层平地：布莱顿海滩、直布罗陀、东京港、哈瓦那、珍珠港、阿姆斯特丹、研究所。它们的复杂度从别处来：
  - 直布罗陀、东京港、哈瓦那、珍珠港、阿姆斯特丹是城市或港口，有 28～128 栋能驻军的建筑，水面占 36～68%；
  - 布莱顿海滩是抢滩登陆，34% 是海；
  - 研究所是走廊迷宫：24 个隘口，可玩区的 61% 是走不到的远景。
- 我们也有 7 关是一层平地（A5、S5、A8、J5、J7、S6、S2），7 关的能驻军建筑**全是 0**，其中 4 关也没有水。
- 中位数对照：

| 量 | 原版 | 我们 |
|---|---|---|
| 高度层数（能走到的地面） | 2 | 1 |
| 高台块数（高于最低一层、≥0.04 km²） | 3 | 0 |
| 坡道 | 5.5 | 1 |
| 斜坡占能走的地面 | 14% | 5% |
| 水面 | 39% | 11% |
| 桥 | 0.5 | 0 |
| 能驻军的建筑 | 19 | 0 |
| 科技建筑 | 2 | 1 |
| 墙段 | 126 | 0 |
| 路口 / km² | 1.78 | 0.53 |
| 隘口 | 15 | 2 |

### 2. 高地上得去，而且上面有东西

- 原版能走到的高台中位数 3 块、坡道 5.5 条。高台上放的是敌方基地、矿和科技建筑：
  - 宫古岛的敌方基地坐在几块高台上，只能从坡道上去，中间一条河只有 3 座桥（[map_study 图](../../../work/mapstudy/camp_ep01_a03_miyako_stewart.png)，本地文件）；
  - 复活节岛的要塞在火山顶最高一层，上去只有几条坡道（[map-language.md](../../story/map-language.md) 第 2 节）；
  - 拉什莫尔山 7 块高台、19 条坡道；罗马尼亚 13 块、29 条。
- 星际 2 也一样：魔鬼游乐场的高地安全，低地富，但会被岩浆淹（[web-sources](data/web-sources.md) A2 第 4 条）。
- **我们的高地多半是布景。**
  - baikonur（S6、J7）、aso（J5）、siberia（S2）这几张图的高台一条坡道都没有，围死了，所以能走到的地面只有一层。
  - panama（A5、S5）只有 1 条坡道。
  - 只有 festival 有 6 块能上的高台和 6 条坡道。
- 地图看上去有高低，玩起来是一整块平地。

### 3. 主路要过隘口，旁边有高地

- **隘口**：原版中位数 15 个。40 张图里 21 张的主路至少穿过一个隘口（坡道、桥头、街口）。
- **路口**：原版每 km² 有 1.78 个，我们 0.53 个。原版的地面是街道和山谷连成的网，我们的是开阔的大平地。
- **高地俯瞰主路**：主路两边 300 以内有高出 40 以上的地面，就算"有高地"。按这个算：
  - 原版有陆路的 30 张里，17 张主路至少 15% 的路段旁边有高地，例如斯大林格勒 45%、宫古岛 38%、洛杉矶 38%、富士山 37%；
  - 我们 11 关里 5 关达到 15%：A4、J4 靠路边的广场，A7、A8、S5 各有一点。其余 6 关的主路是平地。
- 星际 2 的零点：基地只有两座桥能进，桥后汇成一条主坡，上了高地，攻略建议"放弃桥头、收到坡顶"（[web-sources](data/web-sources.md) A1 第 3 条）。地形把"守前还是守后"变成了一个选择。

### 4. 大部分地方都有事做；用不上的地方做成走不到的远景

| 关末（能走到的地面） | 原版中位数 | 我们中位数 |
|---|---|---|
| 任务用到的比例 | **59%** | **20%** |
| 空地块 | **17%** | **56%** |
| 前线块 | 45% | 13% |
| 支线块 | 15% | 8% |
| 通道块 | 12% | 10% |
| 后方块 | 1% | 10% |
| 远景（可玩区里走不到的部分） | 49% | 33% |
| 能走到的地面（km²） | 14.1 | 16.8 |

- **原版的可玩区里有一半是走不到的**：海、悬崖、围死的台地、研究所外的沙漠。剩下能走的地方，八成以上的块里都有事。
- **我们反过来**：
  - 能走到的地面比原版还大（16.8 对 14.1 km²），用到的只有两成，一半以上的块里什么都没有；
  - 布景和空地混在一起：玩家走得到，那里什么都不发生；
  - J3 最典型，城堡周围一小块在用，四周 75% 的块是空的。
- **后方很小（推断）**：原版只有 1% 的块是"后方"，基地就贴着前线、矿和支线。我们离出生点 900 以内常有一圈空地。

### 5. 按阶段看：第一块和每块新开的地也是满的

| | 原版：用到 / 空地块 | 我们：用到 / 空地块 |
|---|---|---|
| 第一块 | 58% / 17% | 20% / 56% |
| 每个阶段新开的那一块 | 55% / 23% | 21% / 49% |

- 原版第一块虽小（布局卡：中位数占全图 41%），但里面差不多是满的。伊贺第一块用到 97%，富士山 90%，俄罗斯村庄 89%。
- 新开的块也满：克里姆林宫第二块 90%，敖德萨新开的城区 77%，纽约 94%。敖德萨第一块只用到 28%，因为第一段是海上护航，陆地本来就不是重点。
- 我们有三关会扩边界：
  - A4 新开的港口区用到 27%；
  - A5 新开的块用到 19%，75% 是空地；
  - A7 新开的块用到 21%，49% 是空地。

### 6. 空军：地形管不住它

用户 2026-10-27 提醒：空军无视地形，飞得过悬崖、坡道和冰墙，也看得见低处看不见的高地。所以上面那些地形取舍能不能成立，要看这一关怎么处理玩家的空军：要么限制它，要么在敌人的据点配防空。

[data/air_measure.py](data/air_measure.py) 统计了 40 张原版图和我们 11 关（结果 [data/air.md](data/air.md)）：
- 脚本用 `ALLOW_DISALLOW_ONE_BUILDING` 和 `PLAYER_LOCK_PLAYER_TECH`（空军科技锁）开关玩家阵营的机场和飞机；统计开局禁没禁、后来放没放开；
- 敌方预摆的防空，以及每个敌方据点 600 以内有没有防空。

| 玩家有基地的关 | 原版 21 关 | 我们 8 关 |
|---|---|---|
| 开局就禁空军（机场禁了，或空军科技锁住） | 4：戛纳、直布罗陀、日内瓦、机器人岛 | 0 |
| 开局禁一部分飞机 | 6：斯大林格勒、敖德萨、珍珠港、米科诺斯、冰岛、摩尔曼斯克 | 0 |
| 不限 | 11：多是战役后段（东京港、帝国 5～9、复活节岛、起义时刻） | **8（全部）** |
| 关里后来才放开一种飞机 | 6：戛纳给对地攻击机（Vindicator）、直布罗陀给冷冻直升机、米科诺斯给米格、冰岛给基洛夫、东京港解开空军科技、机器人岛整套放开 | 0 |
| 敌方预摆防空（中位数） | 不限空军的关 5 座；限制了的关 1～3.5 座 | 0 |
| 敌方据点旁有防空 | 不限空军的关 18/56；限制了的关 8/44 | 1/7（全部 11 关） |

- **原版的做法有两种，按战役进度换着用。**
  - 前中段限制玩家空军：禁掉，或者只放一种，而且常常放在关中间才给，当成这一关的新东西（冰岛的基洛夫、直布罗陀的冷冻直升机）。
  - 后段放开空军，同时敌人据点配更多防空（复活节岛 38 座、海参崴 34 座、阿姆斯特丹 18 座）。
- 没有基地的 19 关（突击队、英雄关）玩家本来就造不了飞机，敌方防空中位数反而有 8 座，防的是脚本给玩家的飞机和支援技能。
- **我们一关都没限过。** 编译器只用这个动作给敌方 AI 分档，从来不限制玩家能造什么。所以只要给了基地，玩家就能造全套空军；敌人那边又几乎没有防空。A4 的冰墙封门、S6 的谷口、J3 的城楼，玩家造几架飞机就都绕过去了。
- 敌人的空军反过来也一样：冰墙、隘口拦不住敌方飞机。A4 第 3 段让天狗从海上来，逼玩家留防空，就是用这一点出题。

量法的局限：
- "有基地"只认地图上预摆的建造厂或基地车、转交给玩家的建造厂，以及脚本里明写的基地车。用增援队送来的基地车认不出，所以原版"有基地"的关数偏少。
- 敌方遭遇战 AI 自己造的防空不算，只数预摆的。
- 帝国的飞机是变形单位，按 3 个有空中形态的模板认：天狗、天翼、VX。
- 我们构建里的玩家阵营都记成了盟军，因为地图的玩家表是从 island 复制的。不影响结论：我们没有任何限制。

## 二、原版怎么用地形制造取舍

| 地形 | 制造的取舍 | 例子 |
|---|---|---|
| 高台 + 少数坡道 | 走哪条坡道上去；在坡底挨打还是绕远路；先拿下高台当炮位 | 宫古岛三块高台上的基地、复活节岛火山顶、拉什莫尔山 |
| 坡道、桥、街口（隘口） | 守前一层还是后一层；把敌人放进来打还是挡在外面；冰墙、路障封哪一个 | 零点两桥一坡；列宁格勒 8 座桥、克里姆林宫 4 座、大阪 20 座（map-language 第 2 节） |
| 路网（路口多） | 正面还是绕侧翼；分兵还是合兵 | 宫古岛每 km² 3.6 个路口，俄罗斯村庄 3.1 个 |
| 水 | 陆军过不去：要海军、两栖或空军；桥变成争夺点 | 35/40 张有水或桥；纽约陆路根本到不了自由岛 |
| 能驻军的建筑 | 平地图上的"高地"：先占街角的楼，还是先拆敌人占着的楼 | 阿姆斯特丹 128 栋、海德堡 84 栋、哈瓦那 47 栋 |
| 高地俯瞰主路 | 路边高处有敌人就是伏击，自己占了就是护送的掩护 | 斯大林格勒 45% 的主路旁有高地，宫古岛 38% |
| 远景 | 不分散注意力，又给出"这是什么地方"（代入） | 原版可玩区一半走不到；研究所 61% |
| 空军（地形的例外） | 玩家的飞机绕过所有地形取舍：要么不给、晚给、只给一种，要么据点配防空；敌人的飞机也绕过玩家的防线，逼玩家留防空 | 前中段 10/21 关限制玩家空军；后段放开、据点防空变多；冰岛关里才给基洛夫 |

- **视野遮挡**（用户 2026-10-27 确认）：红警 3 有和星际 2 一样的高地视野规则。
  - 低处看不见高处：高台上的兵，低处的敌人没有视野就打不到。星际 2 零点的地堡守在坡顶也是这个道理（web-sources A1 第 3 条）。
  - 站在高处视野更开阔。
  - 例外：远程轰击单位开火时会暴露自己的位置，给对方视野，例如航母、无畏舰。
- 所以高地在红警 3 里有三种用处：挡路（悬崖）、当炮位，还有**藏和看**。
  - 占了高处，就能看见低处、低处却看不见你。伏击点和侦察点都可以用高台来做。
  - 想打高处的敌人，要先派兵上去拿到视野，或者用侦察、揭图补上。这本身就是一个取舍。
  - P22 的"先看见、后够得着"，地形自己就能做一部分：目标在高台上，玩家在低处只看得见悬崖，走上坡道才看清。
- 远程轰击单位开火即暴露，正好是 P10"后果看得见"的一个现成例子：敌方航母、无畏舰从高处或远处开炮，玩家马上知道它在哪。
- **每一块地有一种用途**（推断）：前线（敌人在那里）、支线（奖励和科技）、通道（连起来）、远景（走不到）。原版几乎没有"走得到、但什么都不发生"的地方。地图越大，这一点越要守住，否则玩家会觉得空。

## 三、我们的地图差在哪

1. **能走的地面太大、太空**：用到 20%，原版 59%；空地块 56%，原版 17%。能走到的面积反而比原版大。
2. **高地是布景**：4 张图的高台没有坡道，能走到的地面只有一层。地图有高低，打起来是平的。
3. **主路是开阔平地**：隘口中位数 2 个（原版 15），路口密度不到原版的三分之一；6 关的主路旁没有高地。所以 P19"路线收紧"在我们的图上很难成立：哪都能走，也就没有"走哪条"的决策。
4. **平地图没有补偿**：7 关是一层平地，能驻军的建筑全是 0，墙全是 0，4 关连水都没有。原版 7 张平地图靠建筑、水或走廊迷宫来补。
5. **空军没人管**：有基地的 8 关全都不限空军，敌方据点几乎没有防空（1/7）。地形做得再好，玩家造几架飞机就都绕过去了。
6. **一张图给两关用**：festival（A4 护送、J4 劫车）、panama（A5 突击、S5 改成"建"）、baikonur（S6 守、J7 攻）。镜像关动词相反，地形要同时撑两个动词。最好在地图上给两边各留一块只有自己用的地方。

## 四、生成器（platmap）能表达什么、缺什么（给关卡线）

platmap 已经按原版的做法写成"台地 + 悬崖 + 坡道 + 水道 + 桥"，加 platprops 摆布景（[map-language.md](../../story/map-language.md) 第 2、4、6 节）。缺的不是造地形的能力，而是**用途**：地图模块只写了形状，没写每块地给任务干什么；lint 只查"造得对不对"（坡道够不够缓、建筑位平不平、桥从岸到岸），不查"用没用上"。

| 要素 | 现在能不能写 | 缺什么 |
|---|---|---|
| 台地、悬崖 | 能：`rect` / `poly` / `circle` 给层，悬崖自动生成 | — |
| 坡道 | 能：`Ramp`，直坡，给宽度 | lint 查"每块能走的高台至少一条坡道"；围死的高台要显式标成远景 |
| 水、运河 | 能：0 层的形状 | — |
| 桥 | 能：`bridge()`（原版桥对象） | — |
| 道路 | 能：`Road`，只是地面贴图 | 道路不挡路，挡路的要靠高台、水或下面的墙、建筑 |
| 分阶段边界 | 能：地图模块的 `BORDERS` | — |
| 矿、科技建筑 | 能：地图模块的 `OBJECTS` | — |
| 能驻军的建筑 | 只能当布景：platprops 的 `house` 一律避开道路和地点 | 缺"据点"：把一栋能驻军的楼摆在指定地点（街角、坡顶、桥头），发布成地点，任务可以引用（敌人预先驻进去，或者给玩家抢） |
| 墙、路障 | 不能 | 缺"沿折线摆墙段、留缺口"：原版 28/40 张图有 50 段以上，能打掉的墙就是会变的路线 |
| 指定宽度的口子 | 间接能：两块高台之间留缝 | 缺口子的声明和检查（例如 A4 要 120 宽，冰墙正好封住）：lint 量缝宽 |
| 每块地的用途 | 不能：`Shape.what` 只是说明文字 | 缺 `role`：前线、支线、后方、通道、远景。lint 对照任务查：能走到的地面里空地 ≤25%；标"远景"的块必须走不到；标"支线"的块里要有奖励、科技或据点 |
| 主路过隘口、旁边有高地 | 不能查 | 把 terrain_measure 的量法接进 `cnv_preview`，和原版范围对照，像现在对照平地、悬崖、矿那样 |

建议的先后：`role` 和"空地 ≤25%"的 lint 先做，它直接对着用户说的"只用了一小部分"；然后是据点和墙；最后把隘口、俯瞰接进 cnv_preview。

## 可以借的 / 不该照搬的

- 借：
  - 每块地给一个用途，用不上的做成走不到的远景（P24）；
  - 每张图至少两种复杂度来源，而且是这一关的动词用得上的（P25）；
  - 高台要上得去，上面有东西（P26）；
  - 主路过隘口、旁边有高地（P27）；
  - 每关回答"玩家的空军怎么办"：限制它，或者给据点配防空（P28）。
- 不照搬：
  - 原版的数量，比如 126 段墙、19 栋驻军楼，是城市图的布景密度，不是指标。准则只要"有、而且任务用得上"。
  - 原版不少高地是为了基地对抗的炮位。护送、突击队关的高地应该服务于伏击和潜入，不是越多越好。
