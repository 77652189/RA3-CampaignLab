# 拆解卡：研究所（起义时刻 百合子第 1 关）

- 类型：突击队（只有一个英雄，没有基地、没有钱、没有补员）。对照我们的 **J3**（百合子潜入）、**A5**（信标兵带突击队）、**J7**（限兵力突袭）、**S5**（钻地车潜入）。
- 事实来源：原版脚本导出 `work/retailref/camp_ep01_y01_facility_rao.txt`、`.json` 和 `map_study`，由子 Agent 按 [plans/retail/j03_odessa.md](../../story/plans/retail/j03_odessa.md) 的读法约定整理成 [data/facility-facts.md](data/facility-facts.md)（2026-10-27；方括号是脚本名；按帧等待按每秒 15 帧折算，未核实）。"存档要求区内无敌人"已对照脚本原文核过。判断写"推断"。
- 一句话：百合子从岛田的心灵研究所里逃出来，一路读 5 份机密文件、逐个解锁心灵诱惑、护盾、猛击和升级点数，最后在出口打掉 3 辆鬼王——刚出门就被火箭天使锁定、重新抓了回去。

## 1. 体验目标

推断：英雄的成长，同时也是起义时刻百合子线的教学关。整关的结构就是"拿到一样 → 立刻用一样"的链，最后一场竞技场把四样一起考。结尾"打赢了反而被抓回去"是给下一关的剧情钩子。

## 2. 关键决策

这一关**故意把决策压得很少**：路线被门锁成单线、标记永远只有一个下一步。剩下的取舍都很局部：

| 时候 | 取舍 | 代价 |
|---|---|---|
| 每场遭遇 | 用哪个能力（冲击、诱惑、护盾、猛击） | 能力有冷却；用错了吃伤害，回血只有 14 座治疗站和慢慢自回 |
| 武士成群时 | 拉成己方带着走，还是杀掉 | 带着走能挡子弹，但会被追兵打掉 |
| 巡逻组 | 绕开还是打 | 绕开省血，打掉清场（存档要求清场） |
| 东侧 | 去不去读二级升级文件 | 不在目标链里、没有标记（推断：给探索的人的奖励） |

推断：突击队关是"教学 + 操作"关，决策少是代价，不是失误；它靠能力组合和节奏撑场面，而且很短。

## 3. 新机制怎么教

每份文件同一个流程，五步（[第 5 节]）：

1. 在"访问终端"区用 2～3 秒运镜把镜头带到文件上：告诉你它在哪；
2. 读文件时强制停顿；
3. 给能力、按钮闪 5 秒、出说明字幕；
4. 几秒后伊豆美讲用法；
5. **马上来一批专门考这个能力的敌人**。

| 能力 | 考题 | 变 |
|---|---|---|
| 心灵冲击（开局就有） | 进第一个区按钮闪，武士当面万岁冲锋 | — |
| 心灵诱惑 | 武士在掩体后压制射击，打不着，只能拉过来（推断） | 拉过来的人变成临时兵源 |
| 心灵护盾 | 3 秒后两辆天狗冲来；开着护盾反弹子弹有专门台词 | 之后的激光刃、箭雨都适合用护盾挡 |
| 心灵猛击 | 立刻 4 辆海啸坦克 | 最后的 3 辆鬼王（普通、困难每 15 秒扑一辆）|

## 4. 张力曲线

整关几乎没有固定计时，全是进区触发，下面按路线顺序。

```
段            张力
开场 ~78 秒    ·
冲击          ██        武士冲锋
诱惑文件      █ → ██    读文件的停顿 = 喘息；然后压制射击的武士
护盾文件      █ → ███   3 秒后天狗追来
猛击文件      █ → ████  4 辆海啸 + 天狗 + 标枪兵；存档 01a
南侧走廊      ███       兵营、工厂按区开；防御塔蛋依次展开（困难 1～4 秒一座）
升级文件      █ → ██▌   音乐转紧张
运输车 C 区   ████      10 辆运输车每 3 秒放一车，共 30 人
最终竞技场    █████     门在身后关上；工厂兵营按在场上限一直补；鬼王每 15 秒一辆
出门          ·         火箭天使锁定，被抓回去
```

读法：**每读一份文件就是一次"喘息 → 新能力 → 考题"的小循环**，一个循环比一个高；最后一场把门关上、不许退，是全关的高潮。

## 5. 信息

- 没有倒计时、没有计数器。
- **永远只有一个标记**：从文件链一路挪到出口、鬼王、出口（推断：突击队关把玩家的注意力收到一个点上）。
- 字幕排队，一次只出一条；血量 ≤25% 时提示"找治疗站"，9 秒后提示"会自己回血"。
- 大量按区域播出的士兵、岛田喊话（"她要突破了""封门"），**同时是前方有什么的预告**。
- 失败只有一种（百合子死），给出"重新载入"的教程提示。
- 视野：全图永久揭开，雷达关闭，没有潜行判定 [Map Setup - Reveal]。"被发现"只是区域触发加警报音效。

## 6. 剧情转折 = 玩法转折？

- 中间每份文件都是剧情（岛田的研究）+ 玩法（新能力），一一对上。
- 结尾的"被抓回去"**只是剧情、不改玩法**：发生在胜利判定之后的过场里。原版把"不改玩法的转折"放在关尾当钩子，而不是放在关中间。

## 7. 地图支撑哪些决策

- **布局实测**（[layout.md](layout.md)）：出生点在西边 (0.14, 0.39)；室内迷宫，只有 1 条路，门把它锁成单线。同一条线的第 3 关"大院"是原版仅有的 4 个中间出发之一：百合子在大院正中，敌人从 6 个方位来——那一关就是"杀出重围"。

- 室内迷宫：悬崖 23.6%（原版战役图中位数 3.7%），45° 斜向的走廊和房间，地形压平到 200、不渲染，墙全是道具拼的（map_study）。**空间就是一条有门的链**。
- 门按文件进度开，5、6 号门在身后关：不能回头，节奏握在设计师手里。
- 14 座治疗站沿路，平均每段走廊一座：**治疗站就是喘息点**。
- 刷兵器按区域开、离开就停（工厂 1），在场有上限：压力只在你站的地方。

## 可以借的 / 不该照搬的

- 借：**每给一样能力，镜头指路 → 停顿 → 给 → 讲 → 马上考**，最后一场把所有能力一起考 → [P4](../principles.md#p4)；突击队关只给一个标记，前方用喊话预告 → [P10](../principles.md#p10)；刷兵器"进区才开、离开就停、有上限"是又一种压力开关 → [P6](../principles.md#p6)；存档要求清场，用安全奖励清场 → [P5](../principles.md#p5)；不改玩法的剧情转折放关尾 → [P12](../principles.md#p12)
- 对 J3、A5、S5：我们的潜入关有"被发现就是一场硬仗"的说法，但原版这一关**没有潜行系统**，全靠区域触发。如果我们要做真潜入（视野、警报），那是原版没有验证过的新玩法，要先粗模试玩；如果不做，就照研究所写成"一扇门一个考题"的链。
- 不照搬：近 80 秒的开场过场和读文件时 10 秒的强制停顿，对我们没有配音视频的关太长；停顿可以用来放一句通报，但要短。
