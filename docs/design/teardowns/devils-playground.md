## MDA 三层

| 层 | 这一关 |
|---|---|
| 机制 | 胜利条件：存够 8000 矿（花掉的不算；按难度的数字未确认）[LQ][FD]；低地定时被岩浆淹，Browder 发售前说"每 5 分钟"[DTOID]，攻略说每次持续约 1 分钟 [BLOG]（正式版的精确周期未确认）；除残酷外有"下次涨潮"倒计时，残酷只靠声音和岩浆发亮预警 [FD][LQ]；淹到的单位、建筑直接摧毁；新单位死神开局约 45 秒送 4 个，能跳崖 [LQ][FD]；奖励：西南角的雷兽（守着资源箱，奖励 3 点虫族研究）[LQ][FD] |
| 动态 | 每一轮都是"再采一点 / 现在撤"的赌；老手把指挥中心落在低地矿区中间，涨潮前升空飞走 [FD 岩浆词条][LQ]；有人把雷兽引下低地，涨潮前一刻跳回高地，让岩浆替自己打（成就"Red Lobster"）[LQ][FD] |
| 体验 | 推断：**"贪心和撤退的节拍：地面本身就是敌人，而它也能替我打敌人。"** |

## 1. 体验目标

推断：节拍感 + 贪心。敌人压力故意很弱（虫族"不会大举进攻"，以小股袭扰为主 [FD]），把舞台让给环境：岩浆就是这一关的对手，倒计时就是它的出招预告。Browder 把这一关当作"每关一个小游戏"的例子：每关就像一个自己的小游戏，关卡多长由这个小游戏能好玩多久决定 [DTOID]；他明确反对"这是你的基地、那是敌人基地、去杀"的模式 [DTOID]。

## 2. 关键决策

| 时候 | 取舍 | 为什么是真取舍 |
|---|---|---|
| 每一轮涨潮前 | 再采几秒，还是现在撤 | 低地矿最富，但淹到就没 [FD 岩浆词条] |
| 开局 | 主基地留在高地，还是指挥中心落到低地矿区 | 低地近矿、涨潮前要升空；高地安全、矿远 [LQ] |
| 全程 | 矿花掉还是存着 | 胜利是"存够"，花掉的不算 [LQ]：每一笔造兵都在推迟胜利 |
| 奖励 | 打不打雷兽、怎么打 | 硬打（1500 血、50 伤害 [LQ]）还是引进岩浆 |
| 可选 | 救不救地图上的死神、矿工 | 救下归你；北边的失踪矿工送一个指挥中心 + 5 个 SCV [LQ][FD] |

## 3. 新机制怎么教

| 步 | 死神 | 岩浆 |
|---|---|---|
| 教 | 开局约 45 秒送 4 个，同时解锁生产 [LQ][FD] | 第一次涨潮有倒计时、有副官提示 [FD] |
| 练 | 多层地形，死神能跳崖抄近路 [LQ] | 每轮同样的节拍 |
| 考 | 救散落各处的死神（"Reaper Man"成就：困难找齐全部）[LQ] | 指挥中心落低地的打法 |
| 变 | — | 把敌人（雷兽）引下去，岩浆变成武器 |

岩浆的"变"是这一关最漂亮的一步：**机关从"只伤你"变成"你也能拿它伤敌人"**。

## 4. 张力曲线

```
时间(按 5 分钟一轮，示意)   张力
0:00～4:00                 █▌        采矿；小股虫子
4:00～5:00                 ████      倒计时将尽：撤不撤？
5:00～6:00                 ███       岩浆在低地；高地上等
6:00～9:00                 █▌        退潮，冲回低地
9:00～10:00                ████      第二轮
……                         ▲▼▲▼      锯齿形，直到存够 8000
```

读法：**锯齿形**，紧和松由环境按固定周期给，玩家能学会、能利用。和守点关的"逐级抬高"不同，这里每个齿差不多一样高；变化来自玩家越来越贪（第三轮你会采到最后几秒）。

## 5. 信息

- "下次涨潮"倒计时一直在（残酷难度除外）[FD][LQ]；Liquipedia 说预警时间"足够"。
- 残酷难度拿掉倒计时，只留声音和发亮：**同一个机关，难度靠"给多少信息"调**。
- 后果最严厉（淹到就没），所以预告必须最清楚。
- 兜底：短时间丢大量 SCV，Raynor 补一批（只一次）；指挥中心全丢，补一个（只一次）[FD]。

## 6. 剧情转折 = 玩法转折？

剧情很薄：雷诺一伙在 Redstone 采矿挣钱（佣兵的活）。剧情 = 目标（矿 = 钱），没有中途转折。这一关靠机关本身撑，不靠转折——它短，撑得住。

## 7. 地图支撑哪些决策

- **高地安全、低地富**：整关的取舍直接画在地形上 [LQ][FD 岩浆词条]。
- 多层台地 + 能跳崖的死神：新单位和地图互相成全 [LQ]。
- 雷兽在西南角的低地边上，旁边有资源箱、东侧有坡道通低地（引怪路线）[LQ][FD]。
- 这套"采够定额、低地定时毁灭"在初代星际的 Old Faithful 就有过 [FD]：好机关可以复用、换个包装。

## 可以借的 / 不该照搬的

- 借：**环境机关要可预告、能两面用**（玩家能拿它打敌人）→ [P15](../principles.md#p15)；危险越重预告越清楚、难度靠给多少信息调 → [P10](../principles.md#p10)；取舍直接画在地形上 → [P13](../principles.md#p13)；"一关的长度由核心玩法能好玩多久决定"→ [P2](../principles.md#p2)
- 对我们的机关关：A3 时停区、J2 潮汐、S8 火山口都是周期型机关，照这张卡写：①周期和预告；②玩家在周期里的取舍；③敌人也会被它伤；④难度改预告不改结构。
- 不照搬："存够矿"这种胜利条件和红警的经济不太合（红警矿车、矿厂和建造厂的节奏不同），借机关的节拍，不借胜利条件。
