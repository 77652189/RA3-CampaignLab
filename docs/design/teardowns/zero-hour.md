# 拆解卡：零点（星际争霸 2 自由之翼 · Mar Sara 第 3 关 Zero Hour）

- 类型：守点 + 限时（坚守 20 分钟等撤离）。对照我们的 **S6**（守发射塔到倒计时结束）和 **J5**（守观测站到数据撤完）。
- 事实来源：公开资料，子 Agent 2026-10-27 查证，整理稿见 [data/web-sources.md](data/web-sources.md)。缩写：
  - [LQ] Liquipedia https://liquipedia.net/starcraft2/Campaign/Zero_Hour
  - [FD] StarCraft Wiki https://starcraft.fandom.com/wiki/Zero_Hour
  - [SW] StrategyWiki 攻略 https://strategywiki.org/wiki/StarCraft_II:_Wings_of_Liberty/Zero_Hour
  - [TTH] TenTonHammer 的 BlizzCon 2008 报道 https://www.tentonhammer.com/articles/blizzcon-2008-starcraft-ii-gameplay-panel
  - 下面的攻势时间线是从攻略里拼出来的，**不是官方数据**；判断写"推断"。
- 一句话：基地只有两座桥能进来，桥后汇成一条主坡；守满 20 分钟等休伯利安号来接人。

## MDA 三层

| 层 | 这一关 |
|---|---|
| 机制 | 20 分钟倒计时 [LQ][SW]；开局送 4 座地堡：2 座在主坡顶，2 座在两座桥头 [LQ][SW]；波次不随机，每波数量固定、时刻固定，左右两侧轮流来，越往后越多越强（跳虫为主，渐加刺蛇、蟑螂）[SW]；约剩 4 分钟唯一一次两侧同时进攻 [SW]；剩 1 分钟进入无尽波次 [LQ]；3 组反抗军分别在约剩 17:20、15:00、9:05 出现，没及时救会被虫族杀掉，救下归你 [SW][LQ]；8 座孵化场只和成就有关 [LQ][FD] |
| 动态 | 玩家先想守桥头，后来发现收缩到坡顶更省（攻略普遍这么建议 [SW]）；两波之间有空窗，玩家会趁空窗出去救人、打孵化场（攻略建议剩 10～11 分钟时出击 [SW]） |
| 体验 | 推断：**"被围着倒数；守住越来越猛的浪，还忍不住在浪的间隙冲出去捞一把。"** |

## 1. 体验目标

推断：围城。倒计时一直在，压力一直在涨，最后一分钟浪不停；但设计师在浪与浪之间留了空窗，并在地图上摆了"现在不去就没了"的反抗军，让纯防守里出现主动的冲动。BlizzCon 2008 的演示版就已经是"两桥守家"，攻势"从零星的虫子慢慢加码"[TTH]。

## 2. 关键决策

| 时候 | 取舍 | 为什么是真取舍 |
|---|---|---|
| 开局 | 守两座桥头，还是收缩到坡顶 | 两处桥头地堡分散火力；坡顶一点集中，但放弃桥外的空间 [SW] |
| 剩 17:20 / 15:00 / 9:05 | 出不出去救反抗军 | 三组都有时限，晚了被虫族杀掉；出去就要从防线抽兵 [SW] |
| 波次间隙 | 出不出去拆孵化场 | 没有任务奖励，只有成就；虫族会重建 [LQ][FD]——给爱冒险的人的选项 |
| 全程 | 钱花在地堡/导弹塔还是兵 | 本关解锁的就是地堡和导弹塔 [LQ]；飞龙小队专挑导弹塔和地堡打 [SW] |

## 3. 新机制怎么教

- 本关解锁的是**防御建筑**（地堡 + 导弹塔）[LQ]；火焰兵在下一关才给（攻略常见的误记）。
- 教：开局直接送 4 座地堡，摆在正确的位置上 [LQ][SW]。
- 练：前几波零星的跳虫。
- 考：约 3 组"每组 3 只飞龙"的小波次，第一组打上方中央的导弹塔、第二组打左下地堡 [SW]：**专门考新建筑**。
- 变：困难 / 残酷难度用空投囊往基地里砸跳虫和菌毯瘤，绕过防线 [FD]。

## 4. 张力曲线

横轴是倒计时剩余时间（攻略拼的，非官方）。

```
剩余      张力
20:00     █          第一波在你造好第一个兵营挂件时到
17:20     ██▲        第 1 组反抗军出现（要不要去？）
15:00     ██▲        第 2 组
11～10    █▌         两波之间的空窗：攻略建议此时出击
9:05      ███▲       第 3 组
5:30      ████       满级跳虫
4:00      █████      唯一一次两侧同时进攻
1:00      █████      无尽波次
0:00      ·          休伯利安号舰炮清场
```

读法：标准的"峰谷交替、逐级抬高、结尾最高"。**谷底不是空的**：每个谷底都放了一个"现在不去就没了"的诱惑（反抗军）。左右轮流来，给玩家一个可以学会的节奏，第 4 分钟打破它（两侧同时）。

## 5. 信息

- 倒计时一直在屏幕上。
- 波次不随机、左右轮流（[SW]）：玩家能学会节奏、能预判下一波从哪来。
- 反抗军出现时在地图上标出，有时限。
- 输的条件很宽：只有全部建筑被毁才算输，建筑可以升空飞走苟活 [FD][LQ]。

## 6. 剧情转折 = 玩法转折？

只有一个：倒计时到零，休伯利安号来了，舰炮清场——剧情的"得救"就是玩法的"结束"。这一关是整段的守，不靠转折靠**加码**；它短（20 分钟），所以撑得住。

## 7. 地图支撑哪些决策

- **两座桥 → 一条主坡**：天然的两层纵深，"守前面还是守后面"就是地形给的决策 [FD][LQ]。
- 高地：蟑螂、刺蛇没视野时打不到坡顶的地堡 [SW]。
- 3 个虫族基地 8 座孵化场在三个角上（左上 2、右上 3、左下 3）[LQ]；反抗军出现在虫族基地之间的路口 [SW]：救人的路就是冒险的路。
- 基地外的中立建筑提供视野，困难以上会被打掉 [FD]：信息本身也是会丢的资源。

## 可以借的 / 不该照搬的

- 借：**守点关的守本身要有变化**：轮流来的节奏 → 打破节奏的一次齐攻 → 无尽的最后一分钟 → [P7](../principles.md#p7)；谷底放"现在不去就没了"的诱惑 → [P5](../principles.md#p5) [P16](../principles.md#p16)；两层纵深的地形给"守前还是守后" → [P13](../principles.md#p13)；飞龙专打新建筑 = 考新东西 → [P4](../principles.md#p4)；整段只能扛的压力 → [P6](../principles.md#p6)
- 对 S6：S6 是"1:30 布防 + 一整段守 + 拆东营 AI 就停"。零点没有"拆了就停"的开关，压力只能扛；它靠节奏变化和谷底的诱惑撑满 20 分钟。S6 要么学零点（去掉"拆东营就停"，改成轮流 → 齐攻 → 最后一分钟），要么学横滨（守只是一关里的一段）。
- 不照搬：20 分钟对我们 12 分钟的关太长；照比例，我们的"齐攻"大约在最后 2 分钟，"无尽"在最后 30 秒。
