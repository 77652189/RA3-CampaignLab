# 原版盟军九关怎样开放生产

口径为普通难度、主玩家 `Player_1`，从开场交还操作起算，包含可选任务，排除副指挥官、过场演员、玩家自行占领敌厂等非常规路线。来源为 `work/retailref/camp_a0*.txt` 的脚本和同名 JSON 的玩家、摆放及队伍归属。只把主玩家列表中的 `<This Player>`、明确点名主玩家或面向所有玩家的动作算给主玩家。
`ALLOW_DISALLOW_ONE_BUILDING` 的 0/1 对建筑和单位都有效，另查了全局生产开关、模板可造状态和科技限制。有现成生产建筑时可以使用它的队列，见 a02 奖励机场。缺厂又不能造厂时，该队列就没有。关卡没禁的项目按 SDK 的常规菜单和前置推算。脚本之外是否有零售关卡专用默认限制，待核。
菜单来源为 SDK `SageXML/GlobalData/LogicCommandSet.xml`、盟军单位与建筑的 `GameDependency`、`GlobalData/Upgrade.xml`。高科技权限按建造场或前哨的范围生效。二级需要矿厂，三级接二级。谭雅按 1.11 版 SDK 还需要防御局。
建筑全集（常规菜单）是电厂、兵营、矿厂、战车工厂、船坞、机场、防御局、围墙、多功能炮塔、光谱塔、超时空传送仪、质子撞击炮。建造场由基地车展开，前哨由矿车展开。雷达、起重机、内置维修站、墙段、涡轮等没有独立的常规建筑按钮，地图可直接摆放。建筑下文用「全套」指上述 12 项。
兵营出警犬、维和、标枪、工程师、间谍、谭雅。战车工厂出陆版激流、IFV、守护者、雅典娜、幻影、矿车、基地车。船坞出水版激流、海豚、水翼船、驱逐舰、航母、水版矿车和基地车。机场出先锋、阿波罗、冷冻直升机、世纪轰炸机。表内合并两栖单位的陆／水模板。
指挥官能力的锁和点数按地图动作读。技能树的普通与战役前置见 SDK `System/PlayerTechs.xml` 和 `Includes/CampaignOverrides/PlayerTechs_CAMP.xml`。各关最终装入的树版本待核，下文「开放」指脚本明放或未锁，实际购买仍要满足前置与点数。「给」指直接交到玩家手中的移动单位，矿厂附带的矿车和镜头内单位另计。

## 每关开局、解锁和发兵

**a01 布莱顿**  
开局只有步兵，实际造不了。主玩家的 `Allied Structure Restrictions` 只留电厂、兵营、矿厂。单位限制保留警犬、维和、工程师，以及尚缺工厂的矿车。二级许可锁死。
清掉镇内苏军后，`First Sub-mission Split - Part 02` 给基地车、兵营、电厂和矿厂，兵营三项开产（表中「基」）。目标 3 公布后，简报 A01TH09 或联机计时触发 `Temp Text - Javelins 01` 放标枪（「标」）。击退苏联海军并播完 A01TH06 后 2 秒，`Help Text - IFV Unlocked 01` 放工厂、IFV、多功能炮塔（「厂」）。工厂也让矿车可排产，进而可展开前哨。陆版激流仍禁，水版缺船坞。
给兵：开场 4 维和、2 警犬，清镇过程与转场另交维和小队，转场给基地车。后段世纪轰炸机由剧情盟军操纵。能力：点数上限 1，首级冷冻和空投节点未锁，空军升级、高科技、扫描、精确打击、定时炸弹、超时空及生产折扣受限。

**a02 戛纳**  
`Setup - Build Restrictions` 开局只留电厂、兵营、矿厂的建筑权限。玩家手里已有兵营和前哨，缺矿厂开二级，间谍有权限但暂造不了。其余常规单位被禁或没有厂。谭雅禁产，开场简报结束后 3 秒且场上仍有谭雅时，`Intro - Enable Commando Build` 撤销单位禁令。防御局仍禁，按 SDK 前置她全关造不了。
港务局事件的过场结束后，`Chrono in Structures - B/C` 倒计时交建造场和工厂，矿厂按位置检查补给。工厂、IFV、维和、标枪、守护者、工程师、基地车、矿车、警犬和两版激流开权限（「港」）。二级后可补间谍、守护者，矿车可展开前哨。加分任务拆掉指定电厂和磁暴线圈，`_Objectives - Bonus - 1 - Complete` 撤销先锋禁令并触发 `Civ - Transfer Vindicators`，交现成机场和 4 架先锋（「奖」）。新建机场仍禁。
给兵：开场 1 谭雅、3 间谍，另有加分先锋。能力：分数先清零，击沉无畏舰后 `Setup - Power Points - Obj 4 Complete` 把上限提到 2。首级冷冻、空投和生产折扣未被主玩家脚本点名锁住。恐怖机器人切武器另有全局禁令。

**a03 海德堡**  
开局只有水翼船，实际无厂。主玩家 `Allied Structure Restrictions` 留电厂、兵营、矿厂、工厂、机场、围墙、多功能炮塔。船坞、高级防御、两座超武、防御局禁。单位再单禁四种舰艇、雅典娜、幻影、谭雅、阿波罗、冷冻直升机和世纪。
护送基地车到终点、播完 A03TH04，`Sub-mission Split - Part 04` 将基地车一组和两队步兵交给玩家。展开建造场才有生产（「基」），没有额外的单位解禁动作。能造除谭雅外的步兵、陆版激流、IFV、守护者、矿车、基地车、先锋。
给兵：开场 4 水翼船，转场 1 水上基地车、2 激流、4 维和、4 标枪、2 警犬。奖励目标成功可由 `Tanya Ungarrison` 接收谭雅。能力：最多 3 点，禁高阶冷冻、高科技、精准、炸弹、生产折扣、全级空投及交换。首级冷冻、扫描、空军升级和超时空裂隙没有被该段锁住。

**a04 直布罗陀**  
先用谭雅拆机库，开局实际造不了。P1 权限允许全套中的电厂、兵营、矿厂、工厂、船坞、机场、围墙、多功能炮塔。禁防御局、光谱塔和两座超武。开局另禁驱逐舰、航母、雅典娜、幻影、世纪和阿波罗。冷冻直升机在开局名单已准。
机库与指定工厂被拆后，`P1 -  Reinforcements Spawn` 给基地车并展开（「基」）。救驱逐舰的目标开始约 28 秒后，`Objective 2 - Cryocopter Reveal` 重申冷冻直升机放行并交 3 架（正常前置已齐时可先造）。打掉看守目标的 4 个对象后，`Objective 2 - Complete` 解禁驱逐舰，随后 `Objective 2 - Transfer` 交 5 艘（「救」）。
给兵：开场谭雅，其后基地车、冷冻直升机和驱逐舰。谭雅开局的全局模板动作短暂忽略前置，随后恢复正常。能力：开局 0 点，建基地后的 `Objective 2 - Setup` 给 1 点、上限 5。基地车展开脚本开启后续能力脚本，放空军升级、扫描、精确打击、冷冻 1–2，其他开场锁仍在。

**a05 北海**  
开局护航，没有生产设施。权限是全套去掉防御局、光谱塔和两座超武。另禁航母、雅典娜、幻影、世纪，先锋和阿波罗明确准。第二艘雷达船被击沉后，`Objective3Activate1` 倒计时给水上基地车，展开后正常建厂（「基」）。`Objective03StartScripts` 让多功能炮塔短暂跳过前置，`PlayerMoney` 恢复。
`GrantAircraftCarrier02` 在战列舰简报结束后启用，两艘指定的将军战舰均被打掉才放航母（「舰」）。`GrantB69Bomber01` 写了「延时到期且玩家有机场」才放世纪，但该延时 `Timer-DelayToGrantTechs` 在本关导出里只有读取，没有找到设置动作。实际能否触发待核（「？」）。
给兵：开场各 4 艘海豚、水翼船，打雷达船分段给 4 名间谍和谭雅，攻堡段给基地车。救援船是护送对象。能力：先 0 点，`MCVsMove` 给 1 点、上限 6 并放空军升级、扫描、精确打击、冷冻 1–2、炸弹 1。仍锁高阶冷冻、炸弹 2–3、交换、裂隙、高科技、折扣。

**a06 拉什莫尔山**  
开局只有谭雅，权限是全套去掉船坞、光谱塔和两座超武。四种舰艇、雅典娜、幻影禁，水版矿车也禁。拆通信塔后转场，若 AI 副指挥官占下步兵营，`Objective01-TransferBarracksIfCaptured` 先交兵营（「营」，二级以上仍需基地）。随后 `Objective02-StartHere3` 给基地车，主力生产开始（「基」）。
`GrantPrismTower-P2OwnsConyard` 实际检查的是玩家 1 拿到三级许可，5 秒后 `GrantPrismTower01` 放光谱塔。总统基地击杀 18 个盟军名单内单位后，`GrantPrimageTank01/02` 等 4 秒，放幻影并转交两队共 6 辆（「援」）。
给兵：开场谭雅，随后基地车及有条件的幻影援军。展示激光的脚本守护者是过场牺牲单位。能力：先 0 点，第二阶段 `Obj02-MoveMCV` 给 1 点、上限 5。空军升级、冷冻 1–2、高科技、扫描开放，裂隙、交换、冷冻 3、精准、炸弹、折扣和高阶空投受限。

**a07 东京港**  
开场 `Player_1 - Clear Base` 先关建筑。镜头结束后，`Player_1 - Spawn MCV / Base Spawning` 给并展开基地车、给二级许可并摆兵营、工厂、机场、船坞等。开场标记 `IdleGuy1` 消失后，`Player_1 - Base Building - Allow Building` 恢复建筑。开场部署后是全套去掉两座超武，单位只禁雅典娜，其余按工厂与科技前置造（「起」）。
帝国超武开火后，`Objectives - Objective 2 Reveal` 公布跨港任务并放超时空传送仪，6 秒后 `Objectives - Objective 2 Reveal Desc` 再放行并给实物。任一方在对岸有建筑、完成跨港目标后 6 秒，`Objectives - Objective 2 Grant Siege` 放雅典娜（「渡」）。`Objectives - Objective 2 Grant Siege Spawn Team P1` 同时发援军，玩家在对岸已有建造场或前哨就送到对岸，否则送到原基地。
给兵：开场部署用基地车；攻超武的战斗援军只有 IFV、雅典娜、幻影（玩家实测补足导出缺失的队伍编成）。质子撞击炮全关禁。能力：上限 8，开场 0.2 秒的 `P1 - Allied Special Power Restrictions` 明放空军升级、冷冻 1–2、高科技、精准、扫描、炸弹 1–2、空投 1。其他节点沿用关卡默认，待核。

**a08 哈瓦那**  
潜入段 `Player01 - Permissions - Part 1 Restrictions` 禁建筑、开单位队列，但手上无厂。开局 `Map Setup - Build Restriction` 禁传送仪。摧毁苏军建造场、兵营和工厂后切第二阶段，`Player01 - Permissions - Build` 禁质子炮并开放建筑、单位，`Split - Transfer Base(s)` 交已展开的基地并重申开放（「基」）。因此全套少两座超武，常规单位全开。
给兵：开场交 2 警犬、2 间谍，脚本里叫 `Destroyer` 的两个对象在 JSON 实为间谍。中段交的是脚本已展开的基地，不计作给移动基地车。能力：0 点起，第二阶段上限 9；锁交换、全级裂隙和炸弹 3。若玩家曾有至少 5 辆守护者且后来降到 0，最终飞艇设施镜头分支经 `AI - 22 - Final KLF`、`AI - 23 - Time Bomb` 设三级炸弹技能为可用，技能树节点本身未解锁。

**a09 列宁格勒**  
开局交基地车，展开前无生产。常规菜单全套只扣掉 `Superweapon - Lock` 的质子撞击炮，常规单位的权限无关卡禁项，展开后按前置造（「展」）。清平台、进入第二阶段后 180 秒，`Superweapon - Unlock` 放质子撞击炮。
给兵：开局 1 基地车，在指定投送区展开后，`Objective 0a - Complete` 调 `Chrono - P1` 送 5 辆幻影。能力：先 0 点，第二阶段上限 10，交换、全级裂隙受限，其余沿用默认。

## 五条节奏观察

- a01 先用步兵打巷战，再用保卫目标教标枪和 IFV，把工厂与防御塔留到下一波压力前。
- a02 收回大量选项，让间谍和谭雅先完成港口任务。a03 也先只给水翼船护航，上岸后才开放地面生产，并把空军压到先锋。
- a04 先拆机库，再把冷冻直升机和救回的驱逐舰放进同一段。a05 先护航、再上岛、最后建基地，航母用两艘敌舰作解锁门槛。
- a06 又收走舰队，以单人潜入开场，用三级许可和战损事件分别引出光谱塔和幻影。a07 开场已给近全套，单独留传送仪和雅典娜对应跨港与攻坚。
- a08 再切回警犬和间谍，破坏基地后才交还全兵种。a09 把开基地场压到开局就能做，最后只把质子炮留到第二阶段计时结束。
