# 拆解卡：宫古岛（起义时刻 盟军第 3 关）

- 类型：基地对抗（建基地 + 连打两位指挥官的遭遇战 AI，第二位会把整座基地超时空搬走）。对照我们的 **A7**（打会跃迁的首领旗舰）和以后所有"建 + 打基地"的关。
- 事实来源：[plans/retail/ep01_a03_miyako.md](../../story/plans/retail/ep01_a03_miyako.md)。判断写"推断"。
- 一句话：在任一突破口建基地，打败高良；盟友龙背叛，他的整座基地会跳到你不在的地方——拆他的电和超时空仪，把他钉死。

## MDA 三层

| 层 | 这一关 |
|---|---|
| 机制 | 龙每轮跳之前要四件事都成立：充能到、电够、有超时空仪、技能就绪 [evaluate need to chrono base]；能去的点 = 玩家在那里兵 <5、建筑 <2，且龙的关键建筑 ≤5 座；没处可去就改成把一艘将军战舰传到能看见你关键建筑的点 [tatsu chrono attack]；充能随龙剩下的关键建筑缩短 90 → 75 → 60 → 45 秒 [chronosphere reset timer]；超时空仪被拆 30 秒重生，建造厂没了就不再重生；背叛那一刻按你的阵容给龙生成克制部队 [sub counter *] |
| 动态 | 玩家一开始拆不动他（关键建筑 >5，他只会战舰突袭）；拆掉两座后他开始搬家，越拆越勤；玩家很快发现"追不上"，转而去找让他跳不了的那根线：打低电 → 拆超时空仪 → 拆建造厂 |
| 体验 | 推断：**"追猎一个会逃的对手；越逼越急，直到我找到让他跑不掉的那根钉子。"** |

## 1. 体验目标

推断：让"打 AI 基地"不再是推平一座不动的城。对手有了"逃"这个动词，玩家的问题从"怎么打穿"变成"怎么钉住"。

## 2. 关键决策

| 段 | 取舍 | 为什么是真取舍 |
|---|---|---|
| 打开突破口 | 在哪个突破口建基地 | 目标是"在任一突破口建基地"[3.1]，几个口子都行；龙之后会把基地搬到玩家打下来又离开的突破口（推断） |
| 打败高良 | 去不去占通讯塔 | 唯一的奖励：4 鬼王 + 揭图 |
| 打败龙 | 先拆什么 | 三层弱点，效果不同：电（整套停）、超时空仪（停 30 秒+）、建造厂（永久不重生）——**这是一组有排序的选择，不是一个开关** |
| 打败龙 | 留兵守着空点，还是全军追 | 他只跳到你兵 <5、建筑 <2 的点：在几个点各留一点兵就能封住去路 |
| 背叛前 | 造什么兵 | 背叛那一刻按你的炮艇、和平使者、车、步兵、飞机的数量给他克制部队（玩家不知道，推断：是给老玩家的惩罚，不是给新手的决策） |

## 3. 新机制怎么教

- 和平使者火炮车、冷冻军团兵、两栖基地车：第 1 段靠"打开突破口建基地"这个目标逼着用（突破口有前哨守军）。
- 龙的超时空：没有文字教学。**靠观察**：第一次战舰突袭 → 拆两座后第一次搬家（闪光、雷达事件、龙的台词）→ 技能倒计时被脚本同步到游戏内超武倒计时上，玩家能看着它变短。前三次搬家各有一句台词，等于"三次讲解"。
- 教 → 练 → 考 → 变：教（战舰突袭，只会这一种）→ 练（拆到 ≤5 后开始搬家）→ 考（越拆越快）→ 变（找到电 / 仪 / 厂这三层）。

## 4. 张力曲线

三段都由玩家推进，**整关没有任何计时失败**。

```
段          时刻(估)     张力
开场过场    0:00～0:32   ·
突破口      ~1～4        ██        前哨守军被打才动，没有定时进攻
高良        ~4～12       ███       唤醒后 0～180 秒爬行炮塔、伪装车陆续出发；210 秒交给 AI
背叛过场    ~12          ·         扩到全图、隔墙炸掉、龙的舰队并入、拉平部队生成、存档
龙 前期     +0～3        ███       90 秒一次战舰突袭
龙 中期     +3～?        ████▲     拆到 ≤5：开始搬家，75 → 60 秒
龙 后期     ?            █████ 或 ██  45 秒一次——除非你已经断了他的电或仪
```

读法：张力的上升**由玩家自己的进度驱动**（拆得越多越急）；而且玩家能主动把它压下来（断电）。紧张和喘息不是设计师排好的，是玩家打出来的。

## 5. 信息

- 看得见：超时空技能倒计时（与脚本同步）、搬家闪光、每座建筑的雷达事件、前三次搬家的台词。
- 看不见：他会跳去哪（规则是"你不在的地方"，没有提示）；拉平部队的存在。
- 推断：弱点没有被直接说出，靠"拆掉电厂后他不跳了"这个**看得见的后果**让玩家自己发现。原版这里没有"N 分钟还没做到"的提示 [11.7]，对新手偏难。

## 6. 剧情转折 = 玩法转折？

是：盟友龙背叛 = 第二个对手登场 = 超时空搬家这个新机制出现 = 地图扩到全图。一个过场同时完成五件事（边界、隔墙、舰队并入、拉平部队、存档）[第 4 节]。

## 7. 地图支撑哪些决策

- **布局实测**（[layout.md](layout.md)）：玩家从第一块可玩区（西半边，占全图 59%）的东边开进来 (1.00, 0.13)；突破口在西北；背叛后扩到全图，出生点落在南边的中段 (0.59, 0.13)，龙的基地点散在全图。

- 几个突破口：玩家选一个建基地；龙后来会跳进玩家离开的口子。
- 4 个基地点、11 个战舰落点散布全图，包括玩家出生地 [3.3]：全图都是他的舞台，玩家不能只守一面。
- 中间一排仓库隔开两半地图，背叛时炸掉：**地图的结构变化 = 段落变化**。

## 可以借的 / 不该照搬的

- 借：**首领的弱点是一套有排序的系统**（电 / 仪 / 厂），给玩家真的选择 → [P5](../principles.md#p5) [P6](../principles.md#p6)；压力随玩家进度升级，玩家也能主动压下去 → [P8](../principles.md#p8)；背叛过场一次换掉对手、机制、地图 → [P12](../principles.md#p12) [P13](../principles.md#p13)；拉平部队反制玩家阵容 → [P14](../principles.md#p14)；用看得见的后果教机制 → [P10](../principles.md#p10)
- 不照搬：完全没有提示。我们的玩家群体更需要"拆掉电厂他就跳不了"被至少暗示一次（A7 已有 8 分钟提示，留着）。
