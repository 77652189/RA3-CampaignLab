# S1 破冰 · 候选题卡

苏联第 1 关，教 K5 借力，难度 1.5（[curriculum.md](../curriculum.md)）。模板见 [question-handbook.md](../question-handbook.md) 第二节。带数字、射程宽度、复算的旧长版在提交 `e94bb0f`，灰盒时再取。

## 甲 · 拖在后面的卡车（推荐，第四版：旧甲"把卡车钩上岸"就是自然打法，重出）

- **明示的规则**：押科学家的轻卡车用钢缆挂在一辆守护者坦克后面拖着走；岸边一圈薄冰，重车压上去就沉，双方的坦克都算；你有磁钩，能把车拽过来。
- **衍生规则**：钩卡车等于和守护者拔河，拽不动；守护者也是重车，把它拽过薄冰带，冰替你吞掉它，钢缆一断卡车就是你的；岸边那圈薄冰，敌人的坦克也过不来。
- **考什么**：借敌人的规则——冰面不认敌我。
- **为什么不能无脑过**：钩卡车是第一反应，钩不动，白白错过这个岬角；开镰刀上冰追，沉，跳过薄冰也打不动守护者；岸上集火，够不着湖上的车队，够得着的几秒里打卡车会打死科学家。
- **剧情**：施泰因以为冰面替他挡住了苏联坦克，让守护者走冰、拖着卡车——他忘了守护者自己也是坦克。

## 丙 · 借施泰因的冷（第二）

- **明示的规则**：冰面薄，重车会沉；冷冻直升机冻过的冰发白变厚，约 60 秒内重车能过。
- **衍生规则**：直升机冲着你的车冻，冻到哪冰就厚到哪，所以诱饵摆在哪，路就修在哪；60 秒一过冰又变薄，冲到一半照样沉。
- **考什么**：借敌人的武器给自己铺路。
- **为什么不能无脑过**：开坦克上冰，沉；看见直升机先打下来，路就没了；在岸上等，车队开走。入门关偏绕，湖要够大才有压力。
- **剧情**：施泰因说"让湖面再冷一点"，他的直升机就去冻湖面——冻厚的冰，苏联坦克也能过。

## 乙 · 先钩不打（不推荐，"挨打就跑"可以并进甲当护卫的反应）

- **明示的规则**：车队只要有车挨打，就全速冲向对岸；被磁钩拽走不算挨打。
- **衍生规则**：只钩不打就惊动不了车队；钩到它看不见的地方再打。
- **考什么**：先后：先拆护卫还是先抢人。
- **为什么不能无脑过**：开枪就跑、追不上；可"只钩"是磁钩唯一的本事，第一反应就是巧解。
- **剧情**：施泰因的车队有条死规矩：一挨打就冲向要塞，人比车重要。
