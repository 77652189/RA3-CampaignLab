# S1 破冰 · 候选题卡

苏联线第一关，入门段。模板和自查清单见 [question-handbook.md](../question-handbook.md)，课程位置见 [curriculum.md](../curriculum.md)。

三张卡共用的底子（来自 [flow/s1.md](../flow/s1.md)，已定的不再改）：
- 三段：岸边建基地 → 钩车救科学家 → 反攻施泰因的冰上营地；
- 新单位磁钩坦克：射程 300，把一辆车拽到身前，被钩住的车不能开火（已确认）；射程比守护者、铁锤都远；
- 冰面承重：重车压上去会裂、会沉（**待验证**，从没测过；三张卡都依赖它。退路：薄冰做成触发区，区里的重车由脚本删掉并放沉没效果）；
- 车队提前出发是意外（伏笔在简报"施泰因从不照时刻表走"），配"磁钩援军"保底。

入门关的分寸：题要有，但规则只能一条，暗示要给足，简单档照平时打法能赢。

## 甲 · 拉上岸（评委后第二版）

| 栏目 | 内容 |
|---|---|
| **课程位置** | S1，苏联第 1 关（入门）。教 K5 借力（借敌人的车、借冰面）。难度 1.5 |
| **剧情一句话** | 盟军押着科学家横穿贝加尔湖；施泰因知道冰撑不住坦克，押人的只敢用轻卡车走湖心，护卫的守护者沿着厚冰带走——他以为冰面替他挡住了苏联的坦克 |
| **本关规则** | 湖面分三层：岸边一圈薄冰带，外面是厚冰带，湖心又是薄冰。重车（坦克一级）压上薄冰就沉。押人的轻卡车走湖心，离岸超过坦克的射程，只有磁钩（射程 300）够得着；磁钩把车拽到自己身前 |
| **强和弱同一条规则** | 施泰因强，是因为冰：苏联的重车上不了冰、追不上车队。施泰因弱，也因为冰：他也只敢用轻车押人（轻车钩得动），他的守护者也是重车，一旦被拽过薄冰带就沉 |
| **每轮的取舍** | 车队分几批经过贴岸段，每批护卫配比不同（有的批带冷冻直升机，有的带守护者）。磁钩有冷却、数量有限，每批都要选：先钩押人的卡车（目标），还是先钩那辆会冻住你磁钩的护卫（保自己下一批还能钩） |
| **卡点** | **平推**：开坦克上冰追车 → 过岸边薄冰带就沉；卡车在坦克射程外，岸上的大团兵打不着，也就误伤不了（不考微操）。**拆源**：车队不是建筑；施泰因的营地在湖心，重车过不去，轻兵穿过整片冰面要几分钟，车队早过去了。**龟缩**：车队按（提前了的）时刻表走，等不起。**单兵种**：护卫里有冷冻直升机，光带坦克会被冻，要带防空步兵 |
| **巧解** | 不上冰：磁钩在岸边把押人的车一辆辆拽过薄冰带上岸（轻车不沉），再围住打护卫 |
| **转折** | 反攻施泰因的冰上营地：营地在湖心厚冰上，四周一圈薄冰沟，他的守护者在沟里侧巡逻。磁钩站在沟外侧的厚冰上，把守护者往自己这边拽——拽过薄冰沟的那一下，冰替你把它吞了。冰面从"挡你"变成"帮你" |
| **暗示（可推理）** | ①演示：开场一辆盟军守护者开上岸边的薄冰带，当着镜头沉下去；一辆抵抗运动的磁钩把一辆盟军卡车拽过同一条冰带，卡车没沉（示范"轻的过得去、重的过不去"）。②小考：第一批车队只有一辆押人车、两辆护卫，玩家单独练一次钩车。③可见：薄冰发暗、厚冰发白（地图贴图，美术期，灰盒先用不同地面贴图）；车队路线在开场揭图时画出（揭图，已确认）；押人车头上挂标记（目标标记，已确认）。④卡佳的台词"人在车里，车得完整地过来" |
| **难度** | 简单：车队慢，贴岸经过两次；打坏押人车只扣奖励不判负。普通：每批只经过一次，打坏 2 辆押人车判负。困难：每批都带冷冻直升机，先冻你的磁钩；车队快，磁钩必须在车到之前摆好 |
| **漏洞表** | 坦克上冰：堵住，沉。岸上集火打卡车：堵住，卡车在坦克射程外。空军：堵住，苏联 T1 没有空军，本关禁造机场（禁造，已确认）。水陆单位（牛蛙、魟鱼）下冰：允许，冰面碎了它们也能走，但牛蛙不能对地、魟鱼打卡车会把人打死——更慢更亏。只派步兵上冰追：允许，追不上大半批次。意外的好点子：先钩一辆守护者过薄冰带沉掉，卡车的护卫少一辆，下一批钩卡车更安全（留着） |
| **依赖的机制** | 磁钩拽车（已确认）；冰面承重（**待验证**，退路：薄冰带做成触发区，区里的重车由脚本删掉并放沉没效果——这就是"拽过薄冰带就沉"的实现）；打坏押人车判负（目标和标记，已确认）；禁造（已确认）；兵少补援（已确认） |
| **怎么检验** | ①**平推**（造坦克上冰追车）：沉车 ≥ 3，普通档救出不到一半；简单档能赢（车队第二次贴岸时也能钩到）。②**拆源**（直扑施泰因营地）：到营地前车队已过湖，没救下人。③**巧解**（磁钩摆在贴岸段，钩车上岸）：救出 ≥ 80%，损失小。④**消融**：禁掉磁钩 → 巧解 = 平推。⑤**机制事件**：被钩上岸的押人车数；反攻段被拽过薄冰沟沉掉的敌车数。⑥**最优解测试**：巧解脚本每批先钩的对象不全相同。⑦**失误**：磁钩全灭 → 送两辆磁钩（已有的"磁钩援军"） |
| **风险** | 冰面承重做不成时，退路的"脚本删车"不够自然；薄冰带、厚冰带的宽度要配合磁钩射程 300 和坦克射程，地图要按这个画 |

**第一版评委挑出的漏洞**（已改）：转折有逻辑洞——磁钩站在岸上，守护者是往厚冰这边拽、不会去薄冰，现在改成"磁钩和目标之间隔一圈薄冰"；没限空军、水陆单位；岸上的大团兵会自动开火误伤卡车，等于考微操，现在卡车在坦克射程外。

## 乙 · 先钩不打

| 栏目 | 内容 |
|---|---|
| **课程位置** | S1。教 K5 借力（借敌人的警戒规则），带一点 K3 先后。难度 1.5 |
| **剧情一句话** | 施泰因的车队有条死规矩：一挨打就全速冲向对岸的要塞，人比车重要——所以抵抗运动不能开枪，只能"偷" |
| **本关规则** | 车队只要有车挨打，就全速冲向对岸（到了对岸就救不回来了）。被磁钩拽走不算挨打 |
| **卡点** | **平推**：一开火车队就跑，大军追不上，科学家全丢。**拆源**：没有源头；对岸要塞在地图外。**龟缩**：车队不等你。**卡点的反面**：钩一辆就开火打它，枪声照样惊动车队（打的是钩上岸的车也算） |
| **巧解** | 先钩不打：在车队看不见的岸边雾里，把护卫一辆辆钩走，钩到车队视野外再打，最后把押人的车钩上岸 |
| **转折** | 反攻营地：施泰因的营地一挨打就炸开四周的冰当护城河，你的兵就过不去了。同一招：先把营地边的爆破车钩走（不打），再开火 |
| **暗示** | ①开场：一只苏联侦察兵朝车队放了一枪，车队立刻加速冲走（演示规则）。②车队头上显示"警戒"状态；岸边有一片雾和雪丘挡视线。③卡佳："别惊动他们，一辆一辆来" |
| **难度** | 简单：车队受惊后只冲一小段又停下（有第二次机会）。普通：受惊冲到对岸，没救下的就丢了。困难：护卫多一辆侦察车，视野更远，钩的位置要更靠后 |
| **依赖的机制** | 磁钩拽车（已确认）；车队受击判定（单位受伤条件，待查）；"钩不算挨打"（磁钩是否造成伤害，待验证）；车队视野（雾，已确认的迷雾规则） |
| **怎么检验** | ①**平推**（直接开火打车队）：普通档救出 ≤ 1 辆。②**拆源**：无源可拆，同①。③**巧解**（先钩护卫到视野外再打）：车队不受惊，救出 ≥ 80%。④**消融**：让磁钩也触发警戒 → 巧解 = 平推。⑤**机制事件**：车队受惊次数，巧解 0。⑥**失误**：保底援军 |
| **风险** | 偷偷摸摸不是苏联的味道，也和 S3 娜塔莎的潜入撞；"钩不算挨打"若引擎做不到，整题塌；入门关就一次失手全丢，过于苛刻（简单档的第二次机会必须有） |

## 丙 · 借施泰因的冷

| 栏目 | 内容 |
|---|---|
| **课程位置** | S1。教 K5 借力（借敌人的武器）。难度 2（比入门偏难） |
| **剧情一句话** | 施泰因说"让湖面再冷一点"，他的冷冻直升机就去冻湖面——冻厚的冰，苏联的坦克也能过 |
| **本关规则** | 冰面薄，重车会沉；冷冻直升机冻过的冰面变厚（发白），约 60 秒内重车能过 |
| **卡点** | **平推**：重车上冰就沉；只派轻兵打营地，营地的光谱塔专克步兵。**拆源**：营地在湖心，重车过不去。**龟缩**：营地每隔一阵派冷冻部队上岸冻你的基地 |
| **巧解** | 故意把磁钩开到冰边当诱饵，引冷冻直升机来冻，趁冰厚开重车冲过去 |
| **转折** | 冻厚的冰 60 秒后变回薄冰：冲到一半的车要沉，所以冲锋要算着时间；施泰因发现了以后不再冻你身边的冰，改冻自己营地门口——那里变成唯一的厚冰路，正好是你的冲锋路 |
| **暗示** | ①开场：冷冻直升机冻住一片冰，一辆盟军卡车从上面开过去，旁边没冻的冰上一辆车沉了。②冻过的冰发白，有倒计时的裂纹。③卡佳："他冻过的地方，我们也能走" |
| **难度** | 简单：厚冰持续久，营地守军少。普通：60 秒。困难：40 秒，营地有防空，要先引直升机再打掉 |
| **依赖的机制** | 冰面承重（待验证）；"冷冻直升机冻厚冰面"（全靠脚本：直升机在触发区开火 → 那块冰标成厚冰，待验证）；磁钩（已确认） |
| **怎么检验** | ①**平推**：沉车多，救出少。②**拆源**（轻兵打营地）：损失 ≥ 巧解 2 倍。③**巧解**：重车经厚冰到达营地的数量。④**消融**：直升机冻冰不改冰面 → 巧解 = 平推。⑤**失误**：保底援军 |
| **风险** | 入门关就要"诱敌 + 算时间"两步，太绕；依赖的两条全是待验证，灰盒前要先测；巧解要玩家想到"敌人的冷冻能帮我"，没有前置经验，容易变成猜 |

## 评委意见和推荐顺序

评委：独立的 Sonnet 子 Agent，只读 ADR 0010 和三份卡（2026-10-30）。

- **甲**（轻，已改成第二版）：转折有逻辑洞（磁钩是往自己这边拽，站在岸上拽不到薄冰上）；没限空军、悬浮、水陆单位；岸上的大团兵自动开火会误伤卡车，逼人微操，考的是手速。入门关单解法可以接受。
- **乙**（重）：车队受惊冲刺仍要经过贴岸段，磁钩沿岸摆好照样钩得到，退化成甲；规则"挨打就跑"和巧解"钩到视野外再打"自相矛盾；省力解是直接钩押人车，"先钩护卫"没必要；"钩不算挨打"是要玩家试探的隐藏规则。建议并入甲，"警戒"点子留给 S3。
- **丙**（重）：龟缩守岸边等冷冻部队上门是免费刷怪，没有钟；轻型车和空军能绕开光谱塔；任何单位都能当诱饵；"直升机在触发区开火才标厚冰"很脆。好的一点：60 秒变回薄冰、营地门口成唯一厚冰路是真变化。

**推荐顺序：甲 > 丙 > 乙。** 入门关要稳，甲规则只有一条（冰），强弱同源（冰挡你的坦克，也逼他用钩得动的轻车、吞他的守护者），第二版每批车队的护卫不同，每批重选先钩谁。丙的想法更好但依赖两条全靠脚本的机制，适合放到苏联线后面的"组合"关。
