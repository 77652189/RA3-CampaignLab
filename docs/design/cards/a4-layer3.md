# A4 第 3 层（摆放和实现）要什么

给关卡线。A4 甲的剧情和流程在 [flow/a4.md](../flow/a4.md)，地图内容在 [maps/a4.md](../maps/a4.md)，数字在提交 `e94bb0f` 的 `docs/design/cards/a4.md` 甲（`git show e94bb0f:docs/design/cards/a4.md | sed -n 14,46p`）。旧 A4 粗版里和新题冲突的要拆掉：二号广场"杀不完"的地道、修理厂奖励、拆光北营就不来的北坡口一路、海上的天狗。

## 一、地图要改（sapporo）

1. **会场三条街接大街的地方相距 ≥ 800**：后巷口（`lane foot`，x 1250）、一号广场、二号广场。现在一号广场（x 2150～2460）和二号广场（x 2680～2980）只隔约 500，要把一号广场往西挪到接点约 x 2050，或者另开一条街。街口一百二十宽，冰墙封得住（空地上冰墙挡不住步兵）。
2. **三条街之间有后街连着**：冻住一条街，那条街的兵走后街绕去开着的街。三条绕路长短差 ≥ 10 秒（灰盒按这个算的错开到达）。现成的后巷（北侧街区高一层）可以当后街用。
3. **最后一程三个口子后面各一块炮位**：炮打得到口子前和旁边空地上的冰墙（解法之一是拿一道墙在炮口前给鬼王当诱饵，它砸墙时站着不动）。
4. 要加的布景（地道口六个、雪祭舞台、节目单、金奖牌子、北营冰雕作坊）见 maps/a4.md 末尾"还缺的"；不挡试玩，可以先用替代品。

## 三、要先测或先算的

- **最后一程改了规则**（2026-10-31）：关卡线 `4f9fc05` 灰盒第三轮说大军堵三个口子很轻、鬼王只欺负车。用户定了不按玩家兵力分档派兵，每口一波按难度固定，一边倒等实机再说；"鬼王专扑车、换步兵围它"也去掉了（按敌人兵种换兵是用户的习惯打法，不用推理）。转折改成同一条规则换后果：会场冻住的兵绕路错开，最后一程冻住的兵在墙后攒着，鬼王先砸冰墙替帝国开闸。这版没重跑灰盒，攒兵会不会让"冻两个口子"明显吃亏、诱饵墙值不值一道墙，留给实机。
- 测试台上要查（`checks/` 里照 `icewall.py` 做最小检查）：
  1. 鬼王自己砸不砸冰墙；不砸的话，攻击令能不能对冰墙下（冰墙是技能造的临时物体）。
  2. 脚本能不能判断一个区域里有没有冰墙：会场"冻住的街改路"和最后一程"冻住的口子攒兵"都靠它。判不出来的退路：玩家对口子放冰墙时按技能目标点判（看脚本能不能读到技能用在哪），再不行就把攒兵改成"冻住的口子这波晚 30 秒出"。
  3. 脚本能不能找到"离鬼王最近的冰墙"并对它下令；找不到的退路是每个口子和每块炮位空地各一个区域，按区域里有没有冰墙挑最近的区域。
- 实机留给用户：间距 800 够不够、错开 10 秒会不会被拥堵抹平、补给怎么到。
