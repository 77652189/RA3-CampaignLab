# J7 发射窗口 · 候选题卡

帝国线第 7 关，高峰段，综合用前面给过的工具（纸鹤、式神、合体机甲）。用户对第一版的意见："J7以后期关卡的角度来看是不是流程太简单了"。模板和自查清单见 [question-handbook.md](../question-handbook.md)，课程位置见 [curriculum.md](../curriculum.md)。

三张卡共用的底子（来自 [flow/j7.md](../flow/j7.md)，已定的不再改）：
- 三段：百合子、纸鹤、式神三个人摸进山谷 → 打开一条谷口，主力和基地车开进来，建基地、拆三座给发射塔供电的供能塔 → 护盾一掉苏联提前发射、西边基地全线反扑，最后两分钟合体机甲砸塔；
- 三条谷里有苏联协调器干扰车：250 内所有单位（含苏联自己的）慢到四成（已确认）；一辆的光环整个穿过只多花 10～15 秒（模拟器，[graybox-cards.md](../../story/graybox-cards.md)），所以要连着摆才拖得住人；
- 发射塔护盾 = 无敌到条件（已确认）；倒计时显示已确认，倒计时提前待验证；
- 纸鹤驱雾 900（已确认）；式神打开护卫后 200 内的敌人改打它（已确认）；合体机甲合体已确认，拆建筑的本事待验证；
- 敌人：干扰车、动员兵、防空步兵、铁锤、磁暴线圈、天启、V4 火箭车。

后期关的分寸：普通档不动脑代价很大，困难档必须用巧解；至少两条不同的好路线（清单第 15 条）。

## 甲 · 留着干扰车（灰盒后第三版）

| 栏目 | 内容 |
|---|---|
| **课程位置** | J7，帝国第 7 关（高峰）。组合 K5 借力（双刃）+ K1 改道（你选苏联人走哪条谷）+ K9 引火（转折段）。难度 4.5 |
| **剧情一句话** | 苏联人在三条谷口停了干扰车防帝国的快攻；可干扰车分不清敌我，苏联自己的援军也得在光环里爬——拆它的人等于替苏联人修路 |
| **本关规则** | 干扰车光环里所有人都慢到四成。每条谷里**连着摆三辆**，间距 ≥ 500（光环不重叠），每辆让穿过的人多花约 15 秒，一整串约 45 秒。三条谷对苏联人的远近不同：近谷、中谷、远谷不带干扰时差 15 秒一档。苏联的援军从**地图西边界外**开进来（扩边界外的主力，拆不到），走"路程 + 剩下的干扰车"加起来最快的那条谷，打平时走近的。最后的反扑三路齐出，按"没有干扰时同时到塔下"出发，哪条谷剩几辆，那一路就晚到几个 15 秒。拔一辆，那条谷对双方都快约 15 秒 |
| **强和弱同一条规则** | 苏联人强，是因为干扰车：你的突击在谷口爬，进了线圈射程出不来。苏联人弱，也因为干扰车：它不认人，他们的援军也爬；而且他们总走最快的谷，你在哪条谷拔几辆，就是替他们选路 |
| **每轮的取舍** | 你的突击要走一条谷，拔得越干净越快；可中谷只要拔掉两辆、远谷拔光，它对苏联人就比近谷（三辆全在）还快（中谷拔一辆、远谷拔两辆是打平，苏联人仍走近谷，但已经没有余量），下一波援军就改走你的路。苏联人还会学：每一波援军过后，他们把别处的一辆干扰车挪到你上一波走的那条谷。所以每一轮都要重新算——拔掉新挪来的这辆（自己快了，可能把苏联人引过来），还是换一条谷走（绕远，但不改苏联人的路）。三条谷剩几辆、线圈在哪每轮都不同，最好的答案跟着变 |
| **卡点** | **平推**：大军顶着干扰硬推，在线圈射程里以四成速度走，损失大；在基地里攒兵等反扑，也只能挡住，挡不住他们拖住你砸塔的时间。**拆源**：苏联主力在边界外拆不到；谷里的干扰车拆得到，但每拔一辆，苏联援军走那条谷就快约 15 秒；九辆全拔，最后两分钟三路反扑同时冲到发射塔下（模拟器：同时到比错开到对守方差得多，见 A4 甲的 1.0 对 1.8），砸塔的合体机甲被围；留得多，反扑整体晚到、剩的辆数不同的几路还会错开到。**龟缩**：发射倒计时在走 |
| **巧解** | 只在远谷拔一辆（拔两辆就和近谷打平，没余量），给自己开一条慢一点但够用的路，其余的留着，苏联人照旧走近谷、还在光环里爬；每轮看他们挪哪辆、你的谷还剩几辆，算一下"再拔一辆会不会让它比近谷快"，再决定拔还是绕。到最后反扑时，近、中两路晚到 45 秒，远谷那路晚 30 秒：先到的一路先吃，另两路才一起到 |
| **转折** | 护盾一掉、提前发射：苏联人把剩下的干扰车开到发射塔下，光环罩住塔，合体机甲走进去就慢。干扰车从帮你变成卡你——这时才拔它：式神把护卫的火力引开，坦克杀手拆车 |
| **暗示（可推理）** | ①演示：开场纸鹤巡过谷口时，一队苏联援军在光环里爬得很慢，另一条没干扰车的谷里一队飞快（对照）。②小考：第一段只有百合子小队，面前一条谷、一辆干扰车，玩家自己感受进光环变慢、出光环变快。③可见：光环在地上有范围圈（特效，**待查**原版干扰类光环有没有地面圈，没有就用脚本放标记物）；苏联援军从边界外开进来时雷达提示方向（雷达提示，**待查**）；苏联人挪干扰车时小地图闪点。④千岁的延迟台词只说规则："那东西不认人。" |
| **难度** | 简单：倒计时长，全拔也来得及（笨办法能过）。普通：全拔，三路反扑在最后两分钟同时冲到塔下，砸塔大概率失败。困难：苏联每波挪两辆，反扑更大；三串里至少要留两串，转折段要先拔塔下那辆 |
| **漏洞表** | 全拔干扰车平推：允许（简单档），普通档代价是最后两分钟被三路包。大军提前驻在塔下等反扑：**待复算**——卡上还没给反扑的造价，要关卡线按"驻塔大军 vs 三路同时到"定反扑多大，普通档才吃不下。先拆西边的苏联前沿营地：允许，但主力在边界外，反扑照来。基地里攒兵挡反扑：允许，挡得住基地，挡不住塔下的围攻。空军（天狗）绕过干扰：**待验证**干扰对飞机有没有效；没效就把天狗当允许的路线，台上和谷口配防空步兵（P28），更亏。远程单位在光环外打干扰车：允许，等于拔车，后果同上。意外的好点子：故意拔一辆近的，把苏联援军全引进一条你布满防线的谷（主动改道当伏击，留着当第二条好路线） |
| **依赖的机制** | 干扰车减速所有人（已确认）；扩边界外的单位由脚本开进来（已确认）；苏联援军走最快的谷（AI 寻路，**留给实机**；退路是脚本按"路程秒数 + 15 × 剩下几辆"选最小的那条谷）；脚本挪动敌方干扰车（已确认能给敌方下令） |
| **灰盒（模拟器能答的，关卡线复算）** | ①按动员兵、铁锤、天启的速度算三条谷的路程秒数和每辆干扰车的拖延，列"拔几辆以后谁最快"的表，确认中谷拔两辆、远谷拔光就会抢走近谷，远谷拔一辆不会。③定反扑造价：驻在塔下的大军吃不下三路同时到、吃得下错开到。②最后反扑：三路同时到 vs 巧解后的到达时刻，合体机甲和守塔兵剩多少（同 A4 甲的纵队算法）。**留给实机**：AI 是不是真走最快的谷、九辆的光环在地上看不看得清 |
| **怎么检验** | ①**平推**（三条谷都硬推，全拔）vs ③**巧解**（只拔最远的一辆，每轮拆或绕）：最后两分钟塔下的苏联兵数，巧解 ≤ 平推一半；普通档平推砸塔失败率明显更高。②**拆源**（开局先拔光三辆、再拆西边营地）：同①。④**消融**：干扰车不影响苏联单位 → 巧解 = 平推。⑤**机制事件**：苏联援军在光环里停留的总秒数，巧解明显更长。⑥**最优解测试**：巧解脚本每轮"拆 / 绕"的选择不全相同。⑦**失误**：保底援军 |
| **风险** | 九辆干扰车摆满三条谷，每条谷要 ≥ 1500 长；"不拆"是反直觉的，正好打中用户的拆源习惯，但也可能玩家根本不往这想——靠演示里的对照撑；三条谷的远近和线圈布置要灰盒调，否则"每轮都一样"又会回来 |

**第一版评委挑出的漏洞**（已改）：没考虑拆西边苏联基地（用户正会这么干），现在主力在边界外拆不到；在基地攒兵能把爬行的援军逐路吃掉，现在压力落在塔下的砸塔窗口；空军受不受减速没写；台词和目标栏直接说出答案。

## 乙 · 看不见的炮

| 栏目 | 内容 |
|---|---|
| **课程位置** | J7。组合 K2 视野（J3 纸鹤教过）+ K9 引火（J5 式神教过）。难度 4.5 |
| **剧情一句话** | 苏联人把发射场修在高台上，V4 火箭车蹲在台边往谷里打——"谷底的人只看得见天上落下来的东西" |
| **本关规则** | 低处看不见高处。发射场的高台上有 V4 火箭车和磁暴线圈，从谷底打得到你、你打不到它；坡道是唯一的地面路，正对线圈；台上防空步兵多，天狗飞上去会被打下来 |
| **卡点** | **平推**：大军冲坡道，进线圈和天启的射界，一路挨火箭；在谷底攒兵，火箭一直打。**拆源**：V4 就是压力源，可看不见打不着——拆源要先解"怎么看见"，这本身就是题。**单兵种**：天狗空军上去被防空步兵打，地面冲坡被线圈打，要分开 |
| **巧解** | 纸鹤飞到台边给视野，谷底的坦克杀手直接打台上的火箭车，不走坡道；式神站在坡口吸住线圈的火 |
| **转折** | 护盾一掉、提前发射，西边苏联基地反扑：这次你在高台上，他们在低处看不见你，少数兵守住台沿就挡得住，主力腾出来砸塔。可苏联人带来了自己的"眼睛"（侦察单位），先打掉眼睛，台沿才守得住 |
| **暗示** | ①开场：百合子小队在谷底挨炮，看不见是谁打的；纸鹤飞过去，台上的 V4 现形（演示）。②被看不见的敌人打时，红圈标出炮弹来的方向。③千岁："纸鹤看得见的地方，我们的炮就够得着" |
| **难度** | 简单：坡道防守薄，硬冲也行。普通：坡道线圈 + 天启，硬冲损失大（≥ 巧解 2 倍）。困难：台上防空多，纸鹤要从死角进；冲坡道必败 |
| **依赖的机制** | 高地视野（用户确认；模拟器未对齐）；纸鹤视野给全队（推论，原版规则如此）；V4 开火暴露（待验证）；空军的处理（P28：台上配防空） |
| **怎么检验** | ①**平推**（冲坡道）vs ③**巧解**（纸鹤 + 谷底火力）：损失比 ≥ 2。②**拆源**（直接找 V4）：没有纸鹤时打不到，退化成冲坡。④**消融**：禁掉纸鹤 → 巧解 = 平推。⑤**机制事件**：台上单位被低处单位打死的数量。⑥**转折段**：守台沿的兵 ≤ 总数三分之一也守得住。⑦**失误**：保底援军 |
| **风险** | 高地题容易被空军和远程单位绕过（天狗、天启的射程）；"看不见打不着"如果引擎里有例外（比如被打时自动反击给视野），题就塌，灰盒先测 |

## 丙 · 一起倒

| 栏目 | 内容 |
|---|---|
| **课程位置** | J7。组合 K3 先后（这里是"同时"）+ K6 分兵（J4 合体机甲分合教过）+ K2 视野（纸鹤看塔的血量）。难度 4.5 |
| **剧情一句话** | 三座供能塔共用一份电：苏联工程师说"倒一座，电就挤到剩下两座上，护盾只会更厚"——他们没想过三座一起倒 |
| **本关规则** | 三座供能塔共用一份电。倒一座，剩下每座的护盾翻倍，发射倒计时也跳掉一截；三座都倒，发射塔的护盾才掉 |
| **卡点** | **平推**：一座一座拆，第二座两倍厚、第三座四倍厚，钟还跳了两截，拆到第三座时砸塔的时间所剩无几。**拆源**：供能塔就是压力源，拆得越快钟越快（结构"钟"），按距离一座座拆正好是最坏的顺序（结构"先后"）。**龟缩**：倒计时本来就在走 |
| **巧解** | 三座都先打到残血，再在同一刻推倒，护盾不加厚、钟只跳一次 |
| **转折** | 护盾掉的同一刻，西边苏联基地也停电 30 秒（它也吃这份电）：线圈、防空熄火。是趁停电反打西边、把反扑掐在家里，还是全压上去砸塔——共电的规则这次帮你，但只帮 30 秒 |
| **暗示** | ①开场纸鹤飞过，三座塔之间有看得见的电缆。②拆第一座时（简单档、普通档都会有人这么干），镜头切到另两座护盾变亮，倒计时跳一截，因果看得见；纸鹤看得见每座塔的血量。③千岁："一座一座拆，电只会越挤越多" |
| **难度** | 简单：护盾只加厚一半，一座座拆也来得及。普通：翻倍，一座座拆大概率砸不完塔。困难：翻倍且打残的塔会被苏联工程师修，残血留太久就白打；"同时"的窗口是 30 秒，不考手速 |
| **依赖的机制** | 无敌到条件（已确认）；护盾加厚（脚本改建筑血量或护甲，待查）；倒计时提前（待验证）；苏联基地停电（拆电厂让线圈断电是原版规则；脚本让整个基地停电，待验证） |
| **怎么检验** | ①**平推**（按距离逐座拆）vs ③**巧解**（打残后 30 秒内一起推倒）：拆三座的总用时比 ≥ 2，或平推普通档失败。②**拆源** = 平推（这关拆源就是平推的方式）。④**消融**：去掉"剩下的护盾加厚" → 巧解 ≈ 平推。⑤**机制事件**：三座塔倒下的最大间隔秒数，巧解 ≤ 30。⑥**另一条好路线**：先倒两座、用停电…（灰盒找）。⑦**失误**：保底援军 |
| **风险** | "同时推倒"要分三队，像在考操作；窗口 30 秒放宽到不考手速，但三队同时作战对大众玩家仍偏累；护盾翻倍是纯数值规则，玩家可能觉得是被设计者罚 |

## 评委意见和推荐顺序

评委：独立的 Sonnet 子 Agent，只读 ADR 0010 和三份卡（2026-10-30）。

- **甲**（重，已改成第二版）：没考虑拆西边苏联基地（用户正会这么干）；在基地攒兵能把爬行的援军逐路吃掉，"基地被拆"只是数值惩罚；寻路和空军减速没写。评委认为它"正好打中用户先拆源的习惯，三张里最有想法"。
- **乙**（重）：帝国有远程单位，加任何能给视野的单位（天狗、空中单位）都能打台上的 V4，"只有纸鹤"站不住；一旦看见就是普通战斗，题只有一层；V4 固定在台上，退到射程外龟缩就没压力。好的一点：转折（你在高台上，先打掉对方的眼睛）是真反转。修法：V4 打一下就换位，纸鹤视野有时限。
- **丙**（重）：用户习惯分队，同时打三座塔是他的默认动作，不需要洞察；护盾翻倍、钟跳一截是纯数值惩罚；"工程师修塔"用户先杀工程师就破；台词直给答案；没写第二条好路线。按新标准是"一把钥匙开一把锁"，也不过最优解测试。

**推荐顺序：甲 > 乙 > 丙。** 甲是强弱同源最干净的一张（干扰车不认人），第二版让苏联人每轮挪干扰车，每轮重新选"拆还是绕"。乙的"高地换手"转折可以留给 J9 或别的高地关。

### 灰盒后（2026-10-30，关卡线的模拟器结论见 [graybox-cards.md](../../story/graybox-cards.md)）

**推荐不变：甲（第三版）> 乙 > 丙。**

- **甲**：模拟器说一辆干扰车的光环（半径 250）整个穿过只多花 10～15 秒，第二版写的"快 2.5 倍"是错的，撑不起"拔哪辆就替苏联选路"。关卡线给了两条修法：把谷缩短到约 500，或让干扰车连着摆。选了**连着摆**（每谷三辆、九辆共一份账）：谷缩短只改变比例，拖住苏联人的绝对秒数不变，而最后两分钟砸塔看的是绝对秒数。第三版把"选路"写成一道算术题——近、中、远谷差 15 秒一档，每辆 15 秒，中谷拔两辆、远谷拔光就会抢走近谷——玩家每轮看剩几辆再决定拔还是绕。代价：地图要够长，九辆光环在地上要看得清。
- **乙**：模拟器说 V4 射程 500 压过帝国所有直射武器（最远 175），"纸鹤给视野、谷底坦克杀手打"只有台边紧贴谷底才成立；评委说的"随便加个视野单位就能打"在直射武器上反而不成立。题还在，但要地图把台边做到谷底 175 以内，高地视野规则本身模拟器没对齐，留给实机。
- **丙**：2.33 倍成立，但用户分队打三座本来就是默认动作，"一起拆" = 平推，不需要洞察（评委同）。
