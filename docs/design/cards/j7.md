# J7 发射窗口 · 候选题卡

帝国第 7 关，组合 K5 借力、K1 改道、K9 引火，难度 4.5（[curriculum.md](../curriculum.md)）。模板见 [question-handbook.md](../question-handbook.md) 第二节。带数字、复算的旧长版在提交 `e94bb0f`，灰盒时再取。

## 甲 · 给谁修路（推荐，第四版：旧甲"挑一条谷拆到底"就是自然打法，重出）

- **明示的规则**：三条谷里摆着苏联干扰车，光环里谁都慢到四成；苏联援军从地图边界外开来，拆不到，总挑当时最快的那条谷走；发射塔在倒计时。
- **衍生规则**：干扰车不认人，你拆通哪条谷就是给援军修哪条快路；反过来，拆一条你不走的谷能把援军引走；拆开的谷口是援军必经之路，可以先埋伏。
- **考什么**：拆路之前想清楚是给谁修的。
- **为什么不能无脑过**：挑一条谷拆通直冲是第一反应，这条谷成了援军的快路，正撞上你的队伍、断你后路；全拆，三条都快，援军四面来；龟缩攒兵，发射倒计时。
- **剧情**：苏联人在谷里停干扰车防帝国快攻，可干扰车分不清敌我——拆它的人等于替苏联人修路。

## 乙 · 看不见的炮（第二）

- **明示的规则**：低处看不见高处；发射场高台上的 V4 火箭车从谷底打得到你；坡道是唯一的地面路，正对磁暴线圈。
- **衍生规则**：看不见就打不了，先要解"怎么看见"；台上防空多，上去给视野的得是便宜、不怕丢的东西。
- **考什么**：先看见，再打到。
- **为什么不能无脑过**：冲坡道，正对线圈；天狗飞上去，被防空打下来；退出射程攒兵，倒计时。但答案"纸鹤开视野"对老玩家偏一把钥匙开一把锁。
- **剧情**：苏联人把发射场修在高台上——"谷底的人只看得见天上落下来的东西"。

## 丙 · 一起倒（不推荐）

- **明示的规则**：三座供能塔共用一份电；倒一座，剩下每座的护盾翻倍；三座都倒，发射塔的护盾才掉。
- **衍生规则**：一座座拆越拆越难，三座同一刻倒就不加厚。
- **考什么**：同时，而不是先后。
- **为什么不能无脑过**：过得去。分队同时打三座本来就是默认打法，第一反应就是巧解。
- **剧情**：苏联工程师说"倒一座，电就挤到剩下两座上"——他们没想过三座一起倒。
