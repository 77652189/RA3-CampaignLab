# A4 冰雕里的兵 · 候选题卡

[ADR 0010](../../adr/0010-question-first.md)：A4 先停在游戏实装之前，补写题卡；现有 A4 粗版当灰盒和检查器的校准样本（用户 2026-10-28："基本上可以平推"）。模板和自查清单见 [question-handbook.md](../question-handbook.md)，课程位置见 [curriculum.md](../curriculum.md)。

三张卡共用的底子（来自 [flow/a4.md](../flow/a4.md) 和 [a4-redesign.md](../a4-redesign.md)，已定的不再改）：
- 盟军护送队，车队归盟友第三方、按路线自己开，玩家选不中；
- 第 1 段没有基地，只有两个冰幕工兵和一小队护卫；第 2 段在北营交基地；第 3 段最后一程；
- 冰墙：300 内造一道，约 30 秒化，冷却 40 秒；挡得住车，窄门挡得住步兵，空地上挡不住步兵，桥面、坡道造不上（[flow/mechanics.md](../flow/mechanics.md)）；
- 2、3 号广场是帝国后补的加固冰雕，打不碎，兵从底下的地道里补；
- 港口桥头被北营的兵堵住；第一辆车到港，来接货的是未来科技的船。

## 甲 · 三条街，两个工兵（评委后第二版）

| 栏目 | 内容 |
|---|---|
| **课程位置** | A4，盟军第 4 关（上升段）。练 K1 改道（A3 用时停区教过"把敌人引到你要的地方"），教 K4 时机的前半（冰会化）。难度 3 |
| **剧情一句话** | 帝国要抢回被查封的克隆体，兵从雪祭冰雕底下的地道钻出来，只认车，不认人、不认路；盟军司令部只给了两个冰幕工兵——"一人一道门，够了"，可会场有三条街 |
| **本关规则** | 三条街分别在车队路线的**前、中、后三个不同的点**接上主路（不是汇到一个路口）。每次号角响，帝国兵从其中两条或三条街的地道口同时涌出，直扑离自己最近的车；地道口加固过、打不坏。冻住一条街，那条街的兵就绕去还开着的街，从那条街接主路的地方扑上来。两个工兵的冰墙一次最多封两条街，墙 30 秒化、冷却 40 秒 |
| **强和弱同一条规则** | 敌人强，是因为"只认车"：他们绕过你的护卫，护卫挡在哪都没用。敌人弱，也因为"只认车"：他们不躲冰墙、不挑路，冻住哪条街，他们就老老实实绕去哪条，落点可预测 |
| **每轮的取舍** | 每波号角，开哪几条街、每条街出什么兵（步兵街、坦克杀手街、海啸街轮换）都在变，车队又在往前走，三个接点离车的远近也在变。所以每轮都要重新选：留哪条街开着——留给护卫克得住的那种兵，还是留给离车最远、绕得最久的那条 |
| **卡点** | **平推**：第 1 段没有基地，护卫是固定的一小队；三个接点分在车队前后，贴着车走只顾得上一个点，另两个点的兵扑上来。**龟缩**：车队按时刻表开，不等你。**拆源**：地道口打不坏；车队**按时刻表**出发（不再挂在"拆指挥所"上），第 2 段先拆光北营也拆不掉会场的地道，最后一程照样三条街出兵。**单兵种**：每轮开着的街出的兵不同，护卫要跟着换位、换配兵 |
| **巧解** | 每波冻住两条街，把这一波并进护卫克得住、离车最远的那一条，护卫提前站到那条街接主路的点（解完的工具：冰墙不是挡人，是给敌人选路；A9 再用） |
| **转折** | 最后一程北营反扑带着能砸冰墙的重机甲：冰墙挡不住它了，但它停下砸墙的那几秒正好站在你的炮口下。冰墙从"挡路"变成"拖时间的诱饵"，要冻在炮口前，而不是冻在路口 |
| **暗示（可推理）** | ①演示：开场镜头里一个盟军工兵冻住一条街，那条街冒出的兵掉头去了另一条（友军示范一次）。②小考：第一波只开两条街、只出步兵，玩家单独练"冻一条、守一条"。③可见：号角响时小地图闪出这一波开的地道口（雷达提示，**待查**能不能按物体闪）；每条街口挂兵种图标（信息框，**待验证**）；冰墙化前开裂（特效，美术期）；车队路线和三个接点在开场揭图时画出来（揭图，已确认）。④延迟台词：车第一次挨打后，工兵说"他们只认车，不认路"——只说规则，不说解法 |
| **难度** | 简单：一波最多开两条街，车血厚，丢一辆不判负，贴车硬守也能赢（笨办法能过，只是更慢更亏）。普通：常有三条街同时开，不并路平均丢两辆（允许丢一辆）。困难：三条街同时开更频繁、兵种轮换更快，允许丢一辆；并错路（把坦克杀手放进只有步兵的护卫那条街）就会丢 |
| **漏洞表** | 贴车走的大团兵：允许，第 1 段没有大团兵，第 3 段有但三个接点分散，代价大。护卫蹲在一个接点：堵住，三个接点轮流开。空军：堵住，A4 禁造机场（P28，[test_plan_bans](../../../tests/test_plan_bans.py)）。远程炮守地道口：允许，地道口打不坏、兵出来就跑向车，炮只能追着打，更亏。冰墙封住所有地道口：堵住，一次只够封两条街。把兵引进空地上的冰墙：堵住，街口是宫墙夹出的窄口（**地图要求**：街口宽 ≤ 冰墙长 200，宫墙拦得住步兵）。意外的好点子：用冰墙让一波兵绕最远的路，拖到下一波号角前才到——两波撞在同一条街上，护卫一次吃两波（留着，当第二条好路线） |
| **依赖的机制** | 冰墙封门、逼改道（已确认）；冷却 40（a4-redesign 定的值）；敌兵只扑车（编译器的 `打: 猎杀`，游戏里能用，模拟器不认）；车队按时刻表出发（已有）；重机甲砸冰墙（待验证，退路是脚本令它攻击冰墙）；禁造机场（已确认） |
| **怎么检验** | 打法脚本（普通档，各跑多局）：①**平推**（护卫贴车走，不用冰墙；第 2 段造兵推平北营）：丢车 ≥ 2 或失败；简单档能赢。②**拆源**（第 2 段先拆光北营）：最后一程丢车数不低于巧解。③**巧解**（每波冻两条街，护卫守开着的那条的接点）：丢车 0～1，护卫损失 ≤ 平推的一半。④**消融**：禁掉冰墙 → 巧解退化到平推的水平。⑤**机制事件**：每波进入"开着的那条街"触发区的敌人占比，巧解 ≥ 70%，平推 ≈ 1/3～2/3。⑥**最优解测试**：记录巧解脚本每波选的"开着的街"，连续三波相同的比例要低（局面真在变）。⑦**失误**：护卫死光 → 保底援军出现一次 |
| **风险** | 三个接点、兵种轮换的数值要灰盒调：接点太近，一团兵又能全接住；"按时刻表出发"后北营那段的取舍（a4-redesign 第 2 个关键取舍）要重新想 |

**第一版评委挑出的漏洞**（已改）：三条街汇到一个路口，大军站在路口就是免费杀戮区；规则写"轮流"、难度写"同时"自相矛盾；"拆指挥所即出发"是玩家能提前布好的钟；台词和目标栏直接说出答案；没写街宽，空地上冰墙挡不住步兵。

## 乙 · 车到了再冻门

| 栏目 | 内容 |
|---|---|
| **课程位置** | A4。教 K4 时机（冰会化：早了白冻，晚了来不及），练 K1。难度 3 |
| **剧情一句话** | 雪祭评委给帝国后补的冰雕发了金奖，没人知道它们是地道口的门；门打不碎，但门是窄门，冰封得住 |
| **本关规则** | 每个广场都有打不碎的地道门，车队过广场时门里不断出兵；门出兵到打到车只要一两秒。冰墙封得住窄门，30 秒就化；车队过一个广场要约 40 秒，一堵墙盖不住全程 |
| **卡点** | **平推**：兵贴着车冒出来（结构"贴"），护卫再多也来不及在第一轮开火前打死，车队遇袭停在广场里挨打；在门口蹲守，出来的坦克杀手一出门就打你的车，守门的代价比护车还大。**拆源**：门打不碎，只能封。**龟缩**：车队按时刻表开。**冻得太早**：开局一口气冻满，车到时冰正好化，比不冻还糟（兵集中在门后一起出来） |
| **巧解** | 车头进广场前几秒冻第一堵，第一堵快化时另一个工兵接上第二堵，两个人接力盖住车过广场的 40 秒 |
| **转折** | 第 3 段北营反扑的兵也从地道追车：这次故意不封门，等第一批出门走进你的炮口，再冻门把后面的关在里面。冰墙从"不让出来"变成"把一波切成两半" |
| **暗示** | ①开场：演示冰雕当着镜头裂开出兵（已有）；1 号广场门口立着一堵快化的冰墙，玩家看着它化掉、门里涌出兵（教"化"的时长）。②冰墙化前开裂滴水；车队头上显示到下一个广场的秒数。③延迟提示：第一次冻早了，工兵说"车到了再冻，早了撑不住" |
| **难度** | 简单：车队过广场不停车（遇袭也不停），门出兵慢，一堵墙也够。普通：车遇袭停车，门出坦克杀手，一堵墙盖不住，要两人接力。困难：门出兵快，接力出一次空当就丢车；第 3 段反扑大，不切开打不过 |
| **依赖的机制** | 冰墙封窄门（已确认，A4 庭院门口挡得住坦克杀手）；车队遇袭停车（触发区 + 停车，编译器已有停车，遇袭判定待查）；倒计时显示（已确认） |
| **怎么检验** | ①**平推**（不冻门，护卫贴车或守门口）：普通档车队在广场里的停车总时长 ≥ 巧解的 3 倍，或丢车 ≥ 2；简单档能赢。②**拆源**：对门的伤害无效，脚本退化成平推，结论同①。③**巧解**（按车头位置接力冻门）：车在广场内时门被封住的时间占比 ≥ 80%，丢车 0～1。④**消融**：禁掉冰墙 → 巧解 = 平推。⑤**机制事件**：车在广场内时门里出来的兵数，巧解接近 0。⑥**冻早了**（开局冻满）：比不冻更糟或持平，证明"时机"真的是题。⑦**失误**：保底援军 |
| **风险** | 和现在的粗版最像（用户已经说过能平推）；车过广场的时间和冰的寿命要灰盒调准，差一点题就消失（一堵墙够用 = 没题） |

## 丙 · 冷链

| 栏目 | 内容 |
|---|---|
| **课程位置** | A4。教 K4 时机，配一个资源取舍（冰墙用来挡兵还是给车降温）。难度 3 |
| **剧情一句话** | 克隆体冻在冷藏车里运，盟军的冷藏机组是最低价中标的：车一停就扛不住，克隆体会醒——醒来认谁当主人，第一辆车到港时才知道（来接货的未来科技的船，A6、A7 的伏笔） |
| **本关规则** | 每辆车头上一根解冻条：车停着就涨，开着慢慢降；涨满了那辆车的克隆体破门而出，变成敌人。冰幕工兵贴着车造冰墙能给车降温（条往下掉），但冷却 40 秒，拿去降温就不能拿去封门 |
| **卡点** | **平推**：大军清路时车队遇敌要停，条在涨；清得越慢，克隆体就在你阵中醒来。**拆源**：第 2 段车停在港口桥头前等你打北营，条一直在涨——先拆光北营再拆指挥所，车停得更久，醒得更多（拆源让局面变坏）。**龟缩**：越等越涨（钟） |
| **巧解** | 冰墙不拿来挡兵，贴着冷藏车冻：给车降温，换来慢慢打北营的时间 |
| **转折** | 到了港口，船的吊机要车停满 60 秒才卸得完：这一次车必须停着，条一定涨。两个工兵全拿去降温，反扑正好这时到，只能靠兵守——前面省下的兵力就是这时候的本钱 |
| **暗示** | ①开场：一辆车抛锚，条涨满，克隆体当着镜头破门（演示后果）；工兵在另一辆车边冻了一堵，那辆车的条往下掉（演示解法）。②条挂在车头上，颜色随温度变。③延迟提示：条过半时工兵说"冻在车边能撑一会儿" |
| **难度** | 简单：条涨得慢，涨满的克隆体只是逃跑、不变敌人。普通：涨满变敌人，丢车。困难：遇袭停车更久、条涨得快，第 2 段不降温一定来不及 |
| **依赖的机制** | 解冻条（计数器 + 显示：倒计时显示已确认，挂在车头的条要用信息框，待验证）；车停判定（触发区，已有）；冰墙贴车降温（脚本查"冰墙出现在车旁触发区"，待验证）；克隆体变敌人（翻脸 / 克隆体换方，已确认） |
| **怎么检验** | ①**平推**（大军清路、慢慢推平北营）：普通档涨满 ≥ 2 辆。②**拆源**（第 2 段先拆光北营）：涨满数比平推更多。③**巧解**（工兵贴车降温，大军只拆指挥所）：涨满 0。④**消融**：冰墙不降温 → 巧解 = 平推。⑤**机制事件**：降温触发次数；第 2 段车停期间条的峰值。⑥**失误**：保底援军 |
| **风险** | "冰墙降温"是新加的规则，玩家没见过，得靠开场演示撑住（清单第 2 条）；三样机制叠在上升段第 3 关，可能过载；用途和冰墙"封门、改道"的本职有点远 |

## 评委意见和推荐顺序

评委：独立的 Sonnet 子 Agent，只读 ADR 0010 和三份卡（2026-10-30）。它像想偷懒的老玩家一样挑"平推、拆源能不能过"。

- **甲**（重，已改成第二版）：三条街汇到一个路口，大军站在路口就是免费杀戮区；"轮流"和"同时"自相矛盾；"拆指挥所即出发"是能提前布好的钟；暗示直给答案；没写街宽。
- **乙**（致命）：大军提前站在每个广场，单个兵一出门就被秒；两个工兵（墙 30 秒、冷却 40 秒）永远接得上，"接力"只是按节奏点按钮，没有稀缺也没有取舍；只有一种走法；和用户已判"能平推"的粗版最像。按新标准也不过"最优解测试"：每个广场的最优做法都一样。
- **丙**（重）：大军在车队前面开路、车不停条就不涨，只惩罚慢，而用户清得快；第 2 段没写车到桥头和拆完北营谁先；本卡没有需要冰墙去挡的东西，"挡兵还是降温"的取舍是空的；克隆体醒来只是多一个敌人。好的一点：港口必停 60 秒是真转折。

**推荐顺序：甲 > 丙 > 乙。** 甲的"只认车"同时是敌人的强和弱（强弱同源），每波开哪几条街、出什么兵都在变，每轮重选留哪条街（过最优解测试）。丙的"港口必停 60 秒"可以并进甲的最后一程当第二个转折；乙建议放弃。
