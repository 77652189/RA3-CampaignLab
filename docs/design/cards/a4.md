# A4 冰雕里的兵 · 候选题卡

[ADR 0010](../../adr/0010-question-first.md)：A4 先停在游戏实装之前，补写题卡；现有 A4 粗版当灰盒和检查器的校准样本（用户 2026-10-28："基本上可以平推"）。模板和自查清单见 [question-handbook.md](../question-handbook.md)，课程位置见 [curriculum.md](../curriculum.md)。

三张卡共用的底子（来自 [flow/a4.md](../flow/a4.md) 和 [a4-redesign.md](../a4-redesign.md)，已定的不再改）：
- 盟军护送队，车队归盟友第三方、按路线自己开，玩家选不中；
- 第 1 段没有基地，只有两个冰幕工兵和一小队护卫；第 2 段在北营交基地；第 3 段最后一程；
- 冰墙：300 内造一道，约 30 秒化，冷却 40 秒；挡得住车，窄门挡得住步兵，空地上挡不住步兵，桥面、坡道造不上（[flow/mechanics.md](../flow/mechanics.md)）；
- 2、3 号广场是帝国后补的加固冰雕，打不碎，兵从底下的地道里补；
- 港口桥头被北营的兵堵住；第一辆车到港，来接货的是未来科技的船。

## 甲 · 三条街，两个工兵（灰盒后第三版）

| 栏目 | 内容 |
|---|---|
| **课程位置** | A4，盟军第 4 关（上升段）。练 K1 改道（A3 用时停区教过"把敌人引到你要的地方"），教 K4 时机的前半（冰会化、工兵要冷却）。难度 3 |
| **剧情一句话** | 帝国要抢回被查封的克隆体，兵从雪祭冰雕底下的地道钻出来，只认车，不认人、不认路；盟军司令部只给了两个冰幕工兵——"一人一道门，够了"，可会场有三条街，号角也不等工兵冷却 |
| **本关规则** | 三条街分别在车队路线的**前、中、后三个点**接上主路，接点之间相距 ≥ 800（守护者走 10 秒，比一条街的兵打死一辆车的 4～8 秒长）。每次号角，三条街的地道口同时出兵，每条街一波约 1050（3 武士 + 2 坦克杀手），直扑离自己最近的车；地道口加固过、打不坏。冻住一条街，那条街的兵就绕去还开着的街，从那条街的接点扑上来；三条绕行路长短不同，绕过来的兵比那条街自己的兵**晚到 ≥ 10 秒**，两条绕行路之间也差 ≥ 10 秒。第 1 段号角约 5 次，护卫第 3 次号角后补一次（巧解自己也要掉兵：错开到时护卫顶每组约 1080，对 1050 余量只有几个百分点）。号角间隔不固定（30 到 50 秒），下一声的倒计时挂在屏幕上；两个工兵的冰墙各冷却 40 秒、墙 30 秒化 |
| **强和弱同一条规则** | 敌人强，是因为"只认车"：他们绕过你的护卫，护卫挡在哪都没用。敌人弱，也因为"只认车"：他们不躲冰墙、不挑路，冻住哪条街，他们就老老实实绕去哪条，落点和到达的先后都可预测 |
| **每轮的取舍** | 两件事每轮都在变。①**用几道墙**：号角间隔比冷却短的时候，这一波两道墙全用（三路并一路，稳），下一波就一道都没有（三路全开，必丢车）；只用一道（剩两路，护卫守近的那条、远的那条要靠车先跑出它的落点），下一波还有一道。看倒计时决定这一波"全并"还是"留一道"。②**冻哪条**：车队在往前开，三个接点离车头、车尾的远近一直在变；留着开的应该是接点离车最远、绕过来的兵最晚到的那条，这一条每波不同 |
| **卡点** | **平推**：第 1 段没有基地，护卫是固定的一小队（4250），不补充；三个接点相距 ≥ 800，贴着车走只顾得上一个点，另两条街的兵各打死一辆车只要 4～8 秒。**护卫分三份守三个点**：每份约 1400；模拟器说整队护卫单打一条街、剩一半的上限约 1860，按平方律三分之一的护卫只顶得住约 620，打 1050 剩不下多少，几波下来护卫磨光（待关卡线复算）。**龟缩**：车队按时刻表开，不等你。**拆源**：地道口打不坏；车队按时刻表出发，第 2 段先拆光北营也拆不掉会场的地道，最后一程照样三条街出兵。**单兵种**：不卡——模拟器说维和步兵一种就答得了三条街，这关不考换兵 |
| **巧解** | 看号角倒计时：间隔长就两道墙全用，把三路并进接点离车最远的那一条，护卫提前站在那个接点，兵错开 10 秒一组一组到，一组一组吃；间隔短就只冻一道，留一道给下一波（解完的工具：冰墙不是挡人，是给敌人选路、排队；A9 再用） |
| **转折** | 最后一程北营反扑带着能砸冰墙的重机甲：冰墙挡不住它了，但它停下砸墙的那几秒正好站在你的炮口下。冰墙从"挡路"变成"拖时间的诱饵"，要冻在炮口前，而不是冻在路口 |
| **暗示（可推理）** | ①演示：开场镜头里一个盟军工兵冻住一条街，那条街冒出的兵掉头去了另一条（友军示范一次）。②小考：第一波只开两条街，号角间隔长，玩家单独练"冻一条、守一条"。③可见：号角倒计时（倒计时显示，已确认）；号角响时小地图闪出三个地道口（雷达提示，**待查**能不能按物体闪）；冰墙化前开裂（特效，美术期）；工兵头上的冷却（原版技能冷却，已有）；车队路线和三个接点在开场揭图时画出来（揭图，已确认）。④延迟台词：车第一次挨打后，工兵说"他们只认车，不认路"；第一次三路全开时说"号角比我们的冰快"——只说规则，不说解法 |
| **难度** | 简单：号角间隔都 ≥ 45 秒（两道墙每波都有），车血厚，丢一辆不判负；贴车硬守也能赢，只是丢得多。普通：间隔 30、50 混着来，不看倒计时必有一波三路全开（允许丢一辆）。困难：短间隔更多、每条街一波更大，允许丢一辆；冻错了街（留开的接点离车太近）就会丢 |
| **漏洞表** | 贴车走的大团兵：允许，第 1 段没有大团兵，第 3 段有但三个接点相距 ≥ 800，代价大。护卫分三份：允许，打得过一两波，磨光后后面全丢。护卫蹲在一个接点：堵住，接点离车的远近在变，蹲住的那个常常不是该守的。空军：堵住，A4 禁造机场（P28，[test_plan_bans](../../../tests/test_plan_bans.py)）。远程炮守地道口：允许，地道口打不坏、兵出来就跑向车，炮只能追着打，更亏。冰墙封住所有地道口：堵住，一次只够封两条街。把兵引进空地上的冰墙：堵住，街口是宫墙夹出的窄口（**地图要求**：街口宽 ≤ 冰墙长 200，宫墙拦得住步兵）。**三路并一路但同时到**：堵住，三条绕行路长短差 ≥ 10 秒（**地图要求**）；模拟器说三组同时到护卫只顶得住每组 600，错开到能顶每组约 1080——所以"冻哪两条"本身就决定了它们错不错得开。意外的好点子：冻住一条、让它绕最远的路，拖到下一波号角后才到——要绕行路比号角间隔（30 秒起）还长，地图未必做得出，做不出就不留这条。**第 2、3 段有基地**：护卫能补，"分三份守三个点"不再磨光，三条街在这两段只是背景压力，题靠北营和转折（重机甲砸墙） |
| **依赖的机制** | 冰墙封门、逼改道（已确认）；冷却 40（a4-redesign 定的值）；敌兵只扑车（编译器的 `打: 猎杀`，游戏里能用，模拟器不认）；号角间隔不固定、倒计时显示（脚本计时 + 倒计时显示，已确认）；车队按时刻表出发（已有）；重机甲砸冰墙（待验证，退路是脚本令它攻击冰墙）；禁造机场（已确认） |
| **灰盒（模拟器能答的，关卡线复算）** | ①一条街 3 武士 + 2 坦克杀手（1050）打死一辆车要几秒（第二版的 2:1 一组 600 是 7.5 秒）。②护卫对三组 1050：同时到（应当输）、错开排队（应当剩一半上下）、分三份各打一组（应当磨光）。③第 1 段 5 次号角、第 3 次后补一次，三种打法护卫剩多少：贴车 / 分三份 / 巧解；巧解若也磨光，就把每街一波降到约 900（模拟器的纵队上限 1080 以内留余量），再看平推是否仍丢车。**留给实机**：接点间距 800 够不够让护卫来不及（走位）、绕行路差 10 秒在街里会不会被拥堵抹平、敌人是不是真扑最近的车 |
| **怎么检验**（实机，用户） | 普通档：不看倒计时、每波都两道墙全用，一定有一波三路全开；看着倒计时打，丢车 0～1。再玩一次：号角间隔和车队位置变了，冻的街和用几道墙跟着变 |
| **风险** | 加了"号角间隔"之后，每轮要想两件事（几道、哪条），对上升段第 3 关可能偏重——简单档间隔都长，只剩"冻哪条"一件事，用来兜底；三条绕行路的长短差、接点间距、每街一波的大小三个数要一起调，差一个就退回"一种兵站在一个点就够" |

**第一版评委挑出的漏洞**（已改）：三条街汇到一个路口，大军站在路口就是免费杀戮区；规则写"轮流"、难度写"同时"自相矛盾；"拆指挥所即出发"是玩家能提前布好的钟；台词和目标栏直接说出答案；没写街宽，空地上冰墙挡不住步兵。

**灰盒后改了什么**（第二版 → 第三版，依据 [graybox-cards.md](../../story/graybox-cards.md)）：
- 模拟器说护卫 3 秒清一条街（600）、一条街 7.5 秒才打死一辆车，一种维和步兵就答三条街：把每条街一波加到约 1050（关卡线建议 ≥ 1000），接点间距写成 ≥ 800，让"丢车"来自护卫赶不到，而不是打不过。
- "要换配兵"站不住：删掉兵种轮换这个取舍来源，"单兵种"一栏改成"不卡"。
- 每轮的取舍换成两件模拟器以外、玩家看得见的事：号角间隔和冷却对不对得上（用几道墙）、车走到哪了（冻哪条）。这借了乙卡里唯一被数字撑住的那组数（墙 30、冷却 40）。
- 模拟器说并成一团比排成纵队对护卫差 1.8 倍：加"三条绕行路长短差 ≥ 10 秒"，让被并过来的兵自然错开，不靠街道拥堵。

## 乙 · 车到了再冻门

| 栏目 | 内容 |
|---|---|
| **课程位置** | A4。教 K4 时机（冰会化：早了白冻，晚了来不及），练 K1。难度 3 |
| **剧情一句话** | 雪祭评委给帝国后补的冰雕发了金奖，没人知道它们是地道口的门；门打不碎，但门是窄门，冰封得住 |
| **本关规则** | 每个广场都有打不碎的地道门，车队过广场时门里不断出兵；门出兵到打到车只要一两秒。冰墙封得住窄门，30 秒就化；车队过一个广场要约 40 秒，一堵墙盖不住全程 |
| **卡点** | **平推**：兵贴着车冒出来（结构"贴"），护卫再多也来不及在第一轮开火前打死，车队遇袭停在广场里挨打；在门口蹲守，出来的坦克杀手一出门就打你的车，守门的代价比护车还大。**拆源**：门打不碎，只能封。**龟缩**：车队按时刻表开。**冻得太早**：开局一口气冻满，车到时冰正好化，比不冻还糟（兵集中在门后一起出来） |
| **巧解** | 车头进广场前几秒冻第一堵，第一堵快化时另一个工兵接上第二堵，两个人接力盖住车过广场的 40 秒 |
| **转折** | 第 3 段北营反扑的兵也从地道追车：这次故意不封门，等第一批出门走进你的炮口，再冻门把后面的关在里面。冰墙从"不让出来"变成"把一波切成两半" |
| **暗示** | ①开场：演示冰雕当着镜头裂开出兵（已有）；1 号广场门口立着一堵快化的冰墙，玩家看着它化掉、门里涌出兵（教"化"的时长）。②冰墙化前开裂滴水；车队头上显示到下一个广场的秒数。③延迟提示：第一次冻早了，工兵说"车到了再冻，早了撑不住" |
| **难度** | 简单：车队过广场不停车（遇袭也不停），门出兵慢，一堵墙也够。普通：车遇袭停车，门出坦克杀手，一堵墙盖不住，要两人接力。困难：门出兵快，接力出一次空当就丢车；第 3 段反扑大，不切开打不过 |
| **依赖的机制** | 冰墙封窄门（已确认，A4 庭院门口挡得住坦克杀手）；车队遇袭停车（触发区 + 停车，编译器已有停车，遇袭判定待查）；倒计时显示（已确认） |
| **怎么检验** | ①**平推**（不冻门，护卫贴车或守门口）：普通档车队在广场里的停车总时长 ≥ 巧解的 3 倍，或丢车 ≥ 2；简单档能赢。②**拆源**：对门的伤害无效，脚本退化成平推，结论同①。③**巧解**（按车头位置接力冻门）：车在广场内时门被封住的时间占比 ≥ 80%，丢车 0～1。④**消融**：禁掉冰墙 → 巧解 = 平推。⑤**机制事件**：车在广场内时门里出来的兵数，巧解接近 0。⑥**冻早了**（开局冻满）：比不冻更糟或持平，证明"时机"真的是题。⑦**失误**：保底援军 |
| **风险** | 和现在的粗版最像（用户已经说过能平推）；车过广场的时间和冰的寿命要灰盒调准，差一点题就消失（一堵墙够用 = 没题） |

## 丙 · 冷链

| 栏目 | 内容 |
|---|---|
| **课程位置** | A4。教 K4 时机，配一个资源取舍（冰墙用来挡兵还是给车降温）。难度 3 |
| **剧情一句话** | 克隆体冻在冷藏车里运，盟军的冷藏机组是最低价中标的：车一停就扛不住，克隆体会醒——醒来认谁当主人，第一辆车到港时才知道（来接货的未来科技的船，A6、A7 的伏笔） |
| **本关规则** | 每辆车头上一根解冻条：车停着就涨，开着慢慢降；涨满了那辆车的克隆体破门而出，变成敌人。冰幕工兵贴着车造冰墙能给车降温（条往下掉），但冷却 40 秒，拿去降温就不能拿去封门 |
| **卡点** | **平推**：大军清路时车队遇敌要停，条在涨；清得越慢，克隆体就在你阵中醒来。**拆源**：第 2 段车停在港口桥头前等你打北营，条一直在涨——先拆光北营再拆指挥所，车停得更久，醒得更多（拆源让局面变坏）。**龟缩**：越等越涨（钟） |
| **巧解** | 冰墙不拿来挡兵，贴着冷藏车冻：给车降温，换来慢慢打北营的时间 |
| **转折** | 到了港口，船的吊机要车停满 60 秒才卸得完：这一次车必须停着，条一定涨。两个工兵全拿去降温，反扑正好这时到，只能靠兵守——前面省下的兵力就是这时候的本钱 |
| **暗示** | ①开场：一辆车抛锚，条涨满，克隆体当着镜头破门（演示后果）；工兵在另一辆车边冻了一堵，那辆车的条往下掉（演示解法）。②条挂在车头上，颜色随温度变。③延迟提示：条过半时工兵说"冻在车边能撑一会儿" |
| **难度** | 简单：条涨得慢，涨满的克隆体只是逃跑、不变敌人。普通：涨满变敌人，丢车。困难：遇袭停车更久、条涨得快，第 2 段不降温一定来不及 |
| **依赖的机制** | 解冻条（计数器 + 显示：倒计时显示已确认，挂在车头的条要用信息框，待验证）；车停判定（触发区，已有）；冰墙贴车降温（脚本查"冰墙出现在车旁触发区"，待验证）；克隆体变敌人（翻脸 / 克隆体换方，已确认） |
| **怎么检验** | ①**平推**（大军清路、慢慢推平北营）：普通档涨满 ≥ 2 辆。②**拆源**（第 2 段先拆光北营）：涨满数比平推更多。③**巧解**（工兵贴车降温，大军只拆指挥所）：涨满 0。④**消融**：冰墙不降温 → 巧解 = 平推。⑤**机制事件**：降温触发次数；第 2 段车停期间条的峰值。⑥**失误**：保底援军 |
| **风险** | "冰墙降温"是新加的规则，玩家没见过，得靠开场演示撑住（清单第 2 条）；三样机制叠在上升段第 3 关，可能过载；用途和冰墙"封门、改道"的本职有点远 |

## 评委意见和推荐顺序

评委：独立的 Sonnet 子 Agent，只读 ADR 0010 和三份卡（2026-10-30）。它像想偷懒的老玩家一样挑"平推、拆源能不能过"。

- **甲**（重，已改成第二版）：三条街汇到一个路口，大军站在路口就是免费杀戮区；"轮流"和"同时"自相矛盾；"拆指挥所即出发"是能提前布好的钟；暗示直给答案；没写街宽。
- **乙**（致命）：大军提前站在每个广场，单个兵一出门就被秒；两个工兵（墙 30 秒、冷却 40 秒）永远接得上，"接力"只是按节奏点按钮，没有稀缺也没有取舍；只有一种走法；和用户已判"能平推"的粗版最像。按新标准也不过"最优解测试"：每个广场的最优做法都一样。
- **丙**（重）：大军在车队前面开路、车不停条就不涨，只惩罚慢，而用户清得快；第 2 段没写车到桥头和拆完北营谁先；本卡没有需要冰墙去挡的东西，"挡兵还是降温"的取舍是空的；克隆体醒来只是多一个敌人。好的一点：港口必停 60 秒是真转折。

**推荐顺序：甲 > 丙 > 乙。** 甲的"只认车"同时是敌人的强和弱（强弱同源），每波开哪几条街、出什么兵都在变，每轮重选留哪条街（过最优解测试）。丙的"港口必停 60 秒"可以并进甲的最后一程当第二个转折；乙建议放弃。

### 灰盒后（2026-10-30，关卡线的模拟器结论见 [graybox-cards.md](../../story/graybox-cards.md)）

**推荐不变：甲（第三版）> 丙 > 乙**，但理由换了，两边的说法都回应如下。

- **关卡线说乙"数字最撑得住"**：对，撑住的是机制——一道墙只盖 75%、两道接力 100%、缺口 10 秒够丢车，这组数是真的。但撑不住的是"题"：关卡线自己也判了"每个广场最优做法一样，数字上不变"，过不了清单第 17 条；而且 30、40、40 三个数差一点（冷却 ≤ 30 或窗口 ≤ 30）题就消失，太脆。平推那一面（护卫守门口）战斗数字同甲，护卫不吃亏，"兵贴车出来来不及开火"要实机才知道。
- **评委说乙"致命"**：大军站门口秒、接力只是按节奏点按钮——模拟器没有反驳前一条（护卫守门不吃亏），后一条和关卡线的"每轮不变"是同一件事。所以评委的判断成立。
- **乙里唯一好用的东西已经搬进甲**：墙 30、冷却 40 这组数在第三版里不再是"每个广场一样的节奏"，而是和**不固定的号角间隔**撞在一起，变成每轮"全用还是留一道"的取舍。
- **甲为什么还在乙前面**：第二版的两个支点（"要换配兵"、"并路就赢"）都被模拟器否了，第三版换成了"接点远到护卫赶不及"和"绕行路长短差让兵错开到"。这两条都是地图能量出来的要求，不是数值惩罚；代价是比乙多了两条要实机确认的东西（间距 800 够不够、错开 10 秒会不会被拥堵抹平），已写进卡的"灰盒"一栏。
- **丙**：模拟器说北营几十秒就清完，平推不吃亏，除非解冻条涨得很快；条的速度没定。仍排第二，"港口必停 60 秒"仍建议并进甲的最后一程。
