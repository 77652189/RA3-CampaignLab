# 底线规则：只拦"一定不好玩"

用户 2026-11-04 和总控定的分工（[plan.md](../plan.md)"先把 27 关做成草稿"那一行）：

- 题卡的**好玩假设**是唯一说明"这关为什么好玩"的地方（写法见 [question-handbook.md](question-handbook.md) 第二节，样子见 [cards/a4.md](cards/a4.md) 甲）；
- 要素和**压力曲线**是实现假设的手段，也当诊断仪表，不设达标线（原版的量法和读数在 [pressure-curves.md](pressure-curves.md)）；
- **底线规则**就是这一页：只拦一定不好玩的情况，过了不说明好玩；
- 好不好玩，只看试玩时假设成立了没有。

所以这里每一条都要满足两点：违反了，不管题出得多好都不好玩；能写成机器检查，不靠人读稿判断。拿不准算不算"一定不好玩"的，不进这一页，放到压力曲线里当读数。

## 规则

每条写：什么情况、为什么一定不好玩、怎么查（数据从哪来、判法）。"攻略页"指 `work/walkthrough/<关>.json`（现在只有 A4，形状照 `a4.json`）。前五条由 [floorcheck.py](floorcheck.py) 在攻略页上查，后两条要上测试台。

### F1 有一波敌人，玩家没有任何手段克制

- **情况**：某一波里有一种兵（按步、车、空、船分），玩家那时手里没有一种兵、技能、机关或友军能打它。
- **为什么一定不好玩**：玩家只能看着它把目标打掉，输了也不知道该怎么做才对；题的决策根本轮不到。
- **怎么查**：每一波的每个兵种的身体类型（步车空船），对那一段玩家能用的兵种的"专打"类型（`units_measure.py` 的 `ROLES` 表，原版和我们量敌我克制用的同一张）。机关能挡的写在 `devices[].answers`，也算答案。不该打的布景波写 `set_piece: true` 跳过。
- **玩家名单**：攻略页写了 `phases[].roster` 就用它；没写就按开局的兵、援军里点名的兵，加上能造兵以后本阵营的标准兵种减去 `cannot_build`，结果会标"推断"。
- **原版对照**：[units.md](teardowns/data/units.md) 的"有没有缺答案"一栏，原版 40 关有 17 关某一段有缺答案的身体类型。那一栏把所有敌人都算上了，包括友军舰队、超武或者剧情负责处理的布景（布莱顿海滩的基洛夫、无畏舰）。F1 只算朝玩家或失败条件来的波，所以布景要标 `set_piece`；标了布景的波，压力曲线里要写清玩家靠什么躲开它。

### F2 有一条路从头到尾用不上

- **情况**：地图上做出来的一条路线（坡、桥、街口、后巷），没有哪一段的敌人走它，玩家也没有理由走它。
- **为什么一定不好玩**：玩家看见一条路会去试，试完发现什么都没有，是白跑；地图也因此看不懂（ADR 0015 的"看得懂"层）。
- **怎么查**：攻略页 `map.sites` 里 `kind` 为"路线"的点，要么写了 `used_by`（谁、哪一段走它），要么页面别处（波、目标、机关、段落）提到它的编号或名字。`used_by` 写成空列表就是明说没人用，判 FAIL；两样都没有判"缺数据"，要补 `used_by` 或者把路删掉。
- **A4 现状**：后巷西口、后巷下坡口、南高原坡脚、西岭坡脚、运河南北两座桥，攻略页都没提到。前两个是会场"冻住的街改走后街"的路，南高原坡脚是玩家基地下坡的路，应该补 `used_by`；西岭坡脚的说明还写着电视塔（11-03 已换成油井），攻略页这一块是旧的；运河两座桥要关卡线答一句谁走。

### F3 守或护送的段落里，很长一段时间完全没有压力

- **情况**：玩家在守、在护送，这一段里既没有敌人来，也没有倒计时挂着，超过 180 秒。
- **为什么一定不好玩**：守和护送的段落里，主动权在敌人手上，敌人不来玩家就只能干等。进攻段不算：压力由玩家自己推进来定。喘息段也不算，但要有看得见的长度（倒计时），A4 的布防就是这样。
- **怎么查**：攻略页的段落按类型（`phases[].kind`，没写就读名字括号里的第一个词：会场（护送，拮据））挑出"守"和"护送"；这一段有倒计时类的压力就过；没有的话，用段落起止和这一段每一波的出兵时刻算最长的空档，超过 `QUIET_S` 判 FAIL。缺时刻判"缺数据"。
- **180 秒怎么来的**：见 [pressure-curves.md](pressure-curves.md) 第三节的原版空档读数。这条只拦干等，所以取得宽，不拿原版的平均当标准。

### F4 玩家什么都不做也能赢

- **情况**：玩家挂机，任务自己赢了。
- **为什么一定不好玩**：没有一个决策是必要的。
- **怎么查**：攻略页的 `sim_result`（玩家挂机跑一遍的结果，`player` 写明挂机），结果是"赢"判 FAIL。A4 现在挂机 2:24 输。以后挂机结果要来自测试台（`cnv_check`）而不是模拟器时，字段照用。

### F5 题的核心机关删掉了也一样

- **情况**：题卡明示规则里的那个机关（A4 的冰墙、J7 的干扰车），在它负责的段落里不影响结果。
- **为什么一定不好玩**：玩家学会的那条规则用不上，题就不存在了（ADR 0010 第 3 条的"消融"）。
- **怎么查（测试台）**：同一套"最自然的打法"脚本跑两遍，一遍正常，一遍禁掉这个机关（不给技能或不放机关）；两遍的胜负和关键计数（丢车数、存活时间）都一样，判 FAIL。只比大的差距。攻略页上能先查的一半：每个有 `decision` 的段落，至少一波的出兵点在某个机关的作用点上；这一半等攻略页的机关写成站点编号再加进 floorcheck。

### F6 能让玩家输的一波，没有任何预警

- **情况**：一波朝失败条件来的敌人，从玩家能看到第一个征兆（倒计时、红烟、小地图闪点、敌人在视野里出现）到它出生不到 5 秒。
- **为什么一定不好玩**：玩家没有机会做决策就丢了东西，只会觉得被坑。
- **怎么查**：每一波的 `warn_s`；没写就用攻略页上通用的"出兵预警"压力里写的秒数；都没有判"缺数据"。小于 `WARN_S`（5 秒）判 FAIL。出生到接触的路程时间也算预警的一部分，现在只查出生前的预警，偏严。

### F7 输定了却不结束

- **情况**：玩家丢了完成任务必需的东西（唯一的工程师、全部冰幕工兵、自由号以外的唯一运输手段），任务没法赢了，也不判负。
- **为什么一定不好玩**：玩家要么白玩到放弃，要么找不到原因。
- **怎么查（测试台）**：对每个"必需的单位"（题卡解法要用的、只给了有限个的单位），用测试台把它们全部杀掉，再等 60 秒：要么判负，要么补派（A4 的冰幕工兵少于 2 个就补），要么还有别的路能赢。三样都没有判 FAIL。攻略页里先列出必需单位和它们的补派规则（`start.units[].note`），关卡线照着写机关单测。

## 不进底线的（只当读数）

这些看着像毛病，但原版里常见，不一定不好玩，放进压力曲线当诊断读数：

- 一招鲜：一个兵种对付一段里大部分敌人（原版常见，[units.md](teardowns/data/units.md)）；
- 敌人只有一种身体类型；
- 某一段很简单或很难：难度按 ADR 0010 的"不动脑的代价"，试玩时调；
- 进攻段长时间没有敌人主动来：压力由玩家推进决定；
- 最后一段比前面松：节奏问题，看试玩。

## 怎么跑

```
python -X utf8 docs/design/floorcheck.py a4
python -X utf8 docs/design/floorcheck.py a4 --verbose
```

每条一行：PASS、FAIL（什么、在哪）或"缺数据"（攻略页还要补哪个字段）；最后一行是合计。有 FAIL 时退出码是 1。规则是不是真能拦住问题，用变异自测检查过：给 A4 的攻略页各造一个坏例子（会场一波加潜艇、一座桥写明没人用、最后一程拉出 380 秒空档、挂机改成赢、一波预警改成 0 秒），五条都报 FAIL。

**攻略页要补的字段**（给生成攻略页的人；都是可选的，写了就比推断准）：`phases[].kind`、`phases[].roster`、`waves[].warn_s`、`waves[].set_piece`、`devices[].answers`、`map.sites[].used_by`。
