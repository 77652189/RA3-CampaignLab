# A4 冰雕里的兵 · 按准则重新设计（样板）

这份文件是**策划线的样板**：演示怎么用 [principles.md](principles.md) 从上往下设计一关，顺序是体验目标 → 决策 → 张力曲线 → 机制 → 地图。它不是策划案：
- 不改 [plans/a4.md](../story/plans/a4.md)，那是关卡线的文件，返工由关卡线按这里的设计来做；
- 数字（时间、兵力、血量）是起点，等用户试玩再调（用户 2026-10-27："难度最后调"）；
- 结构和用户 2026-10-27 定的方向一致（a4.md"待办"：先护送 → 拆北营 → 守住车队挡反扑），这里补的是"为什么这样排、每段让玩家想什么"。

## 一、体验目标

> **冰是借来的时间：冻早了会化，冻晚了来不及；冻对了，车队一路不停，敌人撞在冰上。**

情绪的弧线（三段各管一截）：

| 段 | 玩家的感受 | 对应的原版 |
|---|---|---|
| 1 会场 | **拮据**：兵少、没基地、看不远；每个广场都要算"现在冻还是等一等" | 敖德萨的护航（[odessa.md](teardowns/odessa.md)）、伊贺的"车停在火力下等你"（[iga.md](teardowns/iga.md)） |
| 2 北营 | **掌控**：拿到基地，自己决定什么时候开战 | 斯大林格勒拆母亲像（[stalingrad.md](teardowns/stalingrad.md)） |
| 3 最后一程 | **高潮**：在自家门口用冰给车队开路、把反扑挡在冰外 | 斯大林格勒守河道；零点的"最后几分钟最猛"（[zero-hour.md](teardowns/zero-hour.md)） |

剧情一句话（服务玩法，带黑色幽默）：帝国残部把兵藏进雪祭冰雕；车队躲进清空的 2 号广场时，帝国趁机在 3 号广场连夜"补展"了一批新冰雕——**雪祭评委还给它们发了奖**。

## 二、关键决策（每段玩家在什么之间取舍）

| 段 | 取舍 | 每个选项的代价（必须看得见） |
|---|---|---|
| 1 会场 | 每个广场：**先冻** / **先打碎清兵** / **硬扛** | 先冻：要工兵活着走到门口，而且冰 30 秒就化，早了白冻；先打碎：要兵、要时间，车队在后面等；硬扛：车队停在火力下挨打，丢车 |
| 1 会场 | 两个工兵**一人一门**，还是**两人轮班守死 2 号门** | 冷却改到比冰的寿命长以后（见"机制"），一个工兵封不死一道门：守死 2 号就顾不上 1 号 |
| 2 北营 | **现在就拆指挥所**，还是**先把第 3 段的防线摆好** | 拆掉的那一刻开始第 3 段，布防只有 90/60/30 秒（玩家决定节奏，P8） |
| 2 北营 | 走**正坡**还是**后坡**上北高原 | 正坡宽、有炮塔；后坡窄、远，但能先拆电厂让炮塔断电 |
| 2 北营 | 去不去**西北角占电视塔**（奖励） | 远、有守军；回报是第 3 段开局就看得见三路反扑从哪来（P5、P10、P16） |
| 3 最后一程 | **冻哪条路**：把反扑**关在外面**，还是**逼进你的炮口** | 三路汇到车队路线上；冻住一路，敌人改走另一路（冰从"封口"变成"改道"，这是"变"） |
| 3 最后一程 | 工兵**守 3 号广场门**还是**守路口** | 3 号广场的新冰雕在车到时裂开；路口来的是重兵。工兵只有两三个 |

**不算决策的**（删掉或降级）：现在的"冻住三个广场的出口"奖励目标——顺路就拿，不是取舍。

3:20    2 北营       █       交基地；北营 AI 2:00/1:30/1:00 后醒（喘息 = 难度旋钮）
~5:30                ██▲     AI 醒来，分档放开：先步兵，再战车

~11:00  3 最后一程   ████    第 1 辆车出发 + 北坡重坦
~11:50               ████▌   第 2 辆车 + 3 号广场新冰雕裂开

对照准则：高峰分别落在"第一次自己冻""只能冻""最后一程"（P7）；两次大喘息都在段切换后，且长度随难度变短（P7）；结尾最高（P1、P7）；第 2 段中间的升级由玩家推进驱动（P8）。

## 四、机制（从体验倒推需要什么）

| 要的体验 | 机制 | 现在有没有 |
|---|---|---|
| 车队依赖玩家（P9） | 车队归**和玩家结盟的第三方**，玩家点不了；遇伏、出口没封就**停在原地挨打**，伏兵清光才走 | 停车已有（`遇伏: 停下`）；"盟友第三方"缺（a4.md 待办已列） |
| 车队不等人太久 | 起步：玩家走出起步区或 0:20；停车点之外不设超时，但每个"走"条件都有一条提示（伊贺） | 有：`进入` 条件和规则；"走出某区域"缺，用 `开局 + 0:20` 兜底 |
| 冻早了会化（P4"考"） | **工兵冷却 > 冰的寿命**：建议冷却 40 秒、冰 30 秒。一个工兵封不死一道门，两个轮班才行 → 第 1 段的分工决策 | 参数归单位线（`CNV_IceEngineer.reload`，现在 20 秒） |
| 新单位是钥匙（P3） | 2 号广场：冰雕打不碎、兵会补，只能冻（保留）；第 3 段：3 号广场的新冰雕同样只能冻 | 2 号已有；3 号照 2 号写 |
| 冰的"变"（P4） | 第 3 段三路反扑都要经过 120 宽的口子（北坡、东街、3 号广场门），冻住一路，进攻改走下一路 | 冰墙挡路已有；"被挡就改道"靠遭遇战 AI 自己寻路，需要测试台确认 |
| 玩家决定节奏（P8） | 拆掉北营指挥所 = 第 3 段开始；北营 AI 先动手就提前醒 | 有（`摧毁`、`敌方AI 唤醒 任一`） |
| 第 2 段 AI 分档（P7） | 醒来先只造步兵，2 分钟后放开战车（斯大林格勒） | 缺："按时间改 `上限`"的词（stalingrad 卡 / 原版第 12.5 条已提） |
| 第 3 段分档反扑（P6、P10） | 三档：0 秒重坦（北坡）、50～60 秒 3 号广场冰雕兵、120～140 秒天狗（海上）；路数按难度 2/3/4；每档出发有预警 | 能写（`进攻` + 随机区间 + 数量 `0/0/2`） |
| 车队分批（P7 结尾最高） | 三辆车在 2 号广场里，第 3 段按 0 / 50 / 110 秒一辆一辆出发 | 缺：车队机关"分批出发"（retail README 第 4 条已列） |
| 送够就赢（P11） | 要送到 2/2/3 辆，困难零容忍；送够就赢 | 能写（a4.md 待办已列） |
| 奖励给信息（P5、P10） | 占西北电视塔（观察站）：第 3 段三路的出发点在小地图上亮出来 | 占领能写；"揭开某块迷雾"的动作缺，可先用 `通报` + 标记代替 |
| 失败说清楚（P11） | 第 1 段丢车："X 号广场的伏兵劫走了车"；第 3 段丢车：按哪一路打掉的报原因 | 部分能写：失败按段写不同的 `原因` |

压力开关的形式（P6，避免又是"拆兵营战车工厂就停"）：第 1 段的压力**可封不可拆**（冰）；第 2 段的压力**可拆**（北营 AI，拆指挥所就停）；第 3 段的压力**只能扛**（三档一次性反扑，没有来源），工具是冰和防线。

## 六、布局：要改，怎么改（P17～P20）

依据：[teardowns/layout.md](teardowns/layout.md) 和总表 [data/layout.md](teardowns/data/layout.md)。现在的数字量自最新的完整构建 `CampA4Idle`。

**要改。** 现在 A4 的布局和原版护送关正好相反：

| | 现在的 A4 | 原版护送 5 关（伊贺、斯大林格勒、敖德萨、海德堡、北海） | 样板的目标 |
|---|---|---|---|
| 出生点（第一块可玩区） | **中间** (0.40, 0.49) | 全部在角落、边上或从图外开进 | 边上：第一块的西边、路的西头 |
| 出生点背后 | 西、南、北三块台地都空着 | 地图边、海 | 地图边：车队和护卫从图外开进来（像海德堡的基地车） |
| 第一块占全图 | 0.73（运河以西整片） | 0.1～1.0，伊贺 0.30、敖德萨 0.39 | 约 0.2：只开 1、2 号广场这一段街和两侧 |
| 推进纵深 | 0.38 | 伊贺 0.59、斯大林格勒 0.61 | 约 0.7：从路的西头到 2 号广场的停车点 |
| 去主目标的陆路 | 2 | 伊贺 2（南桥、西桥） | 2：大街 + 1 号广场后巷 |
| 第一块里的奖励 | 1 个（冻出口，顺路、不贴敌） | 伊贺的道场之一在敌人基地里 | 1 个：后巷里的修理厂，绕路、有守军 |

**怎么改**（改地图归地图线 / 关卡线，这里只写设计；地点只能新增，要挪地点先告诉关卡线和总控，见 [map-language.md](../story/map-language.md) 4.1 节第 5 条）：

1. **第 1 段的窗口**：约 x 300～3200、y 1700～3300 的一条走廊，只含大街、1 号和 2 号广场、后巷。出生点在走廊西头，紧贴地图边；车队和护卫从图外开进来。背后是地图边，不再有空台地。敌人只从前方来：东边的街、北边 1 号广场的门、南边 2 号广场的门（P17、P18）。
2. **后巷是备选路，要付代价才打开**：1 号广场北侧一条窄巷直通 2 号广场的门，巷口被一排冰雕堵着。打碎它就能抄近路让工兵先到 2 号门，但冰雕里也有兵（P19）。巷子中段是**修理厂**（原版的科技建筑），占下来，第 3 段车队可以回来修车（P16、P20）。
3. **第 2 段的窗口**：向北、向南各长一块。北面是北营和西北角的电视塔（奖励），南面是南高原的基地位。基地背靠南边的地图边，前面就是第 3 段车队要走的路，离路约 600（斯大林格勒的基地位 a 离航线 640）。
4. **第 3 段的窗口**：向东长到全图，包括 3 号广场、运河桥和港口。出生点那一头已经在身后很远。三路反扑经北坡口、东街口和 3 号广场门进来，都是 120 宽的口子（P19：路线收紧，冰墙正好封得住）。
5. **方向先不转**：原版 78% 往北推，推断和默认镜头朝北有关。festival 是往东推的，转图工作量大，先按 [playtest.md](playtest.md) 进游戏看一次往东推的观感再定。

量化验收：改完用 `layout_measure.py` 量一遍，第一块出生点应为"边上"，第一块占全图在 0.15～0.45，推进纵深 ≥ 0.5，去 2 号广场的陆路 2 条，第一块里有 1 个奖励且绕路 > 500。

## 七、怎么验证（试玩对照体验目标）

测试台只能证明"机制按脚本发生"；体验要人来玩。试玩时问的问题见 [playtest.md](playtest.md) 的 A4 部分，每个问题对着上面"关键决策"表的一行。返工后如果玩家说"第 1 段我没犹豫过冻不冻"，说明冷却和寿命的数字还没调对，而不是结构错了。
